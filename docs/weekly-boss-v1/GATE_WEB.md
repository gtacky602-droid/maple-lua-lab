# 扉に通ずる対局・再現盤

モンド・城門広場のx442から、Lv112の「扉の対局・再現盤」に入る。アルベドの依頼「扉の対局・駒を誘う」から接続する。Lvと報酬はWeb版の調整用仮値。 [個別設計](GAME_BEFORE_THE_GATE.md)・[修正版の誘導](CORRECTIONS_V02.md)・[出典](https://wiki.hoyolab.com/pc/genshin/entry/7672?lang=ja-jp)

- 前半は、ポーンの向こう側に立ち、駒王の突進を3体へ順に当てる。1回の突進で最初に接触した1体だけが消える。駒王を25%まで削った後は、女王駒、残りの駒王、王族二体の順に移る。
- 後半はキングとクイーンが別々のHPを持つ。クイーンの試練では両端の霜印をGか画面のボタンで90ティック保持する。1回で凍結値50。入力をいったん離し、120ティック後にもう一度保持する。凍結後はクイーンの向こう側へ移動する。3.5秒後に走路が固定され、キングが実際にクイーンに当たると津波が止まり、6秒間反撃できる。
- 片方が倒れたら、生存側が3秒かけてHPを譲る。成功は1戦2回まで。整数HPのため端数は切り捨て、譲渡前後の合計HPが一致する。二体が同じ攻撃で倒れた場合は討伐を一度だけ記録する。
- 霜印は試練専用の操作。通常戦の元素凍結との連携は未接続。装備ごとの難度、同行の回避、連続ドット作画と効果音は制作を続ける。

共闘では各駒のHPと凍結値を共有する。霜印は一人ずつ使い、誘導役の番号と固定された走路は全員の画面に出る。全員が退避した間は戦闘が止まり、全滅した場合は初期状態から再戦になる。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#扉に通ずる対局の週ボス戦)

## ドット絵と描画比較

王冠を除いた兜から靴底まで、キングは約2.92頭身、クイーンは約3.19頭身。先行ラボ素材、先行素材に用いた3Dの静止画像、装飾と武器が見える作品画像を照合し、形を簡略化した。前半の小駒は独立したLua描画。背景はホストに扉の間の仮画像を表示する。本番背景は3Dで用意する方針。 [素材と圧縮の記録](../../assets/gate-weekly-generation-v1.json)

Pで一時停止し、画像・標準矩形・軽量を切り替える。二体戦の同じ場面で、標準19,175件から軽量5,258件へ描画コマンドが72.6%減った。軽量でも王冠と剣、青い杖の区別がつき、金属の細い縁と陰影が簡略化される。 [画像](../../evidence/gate-weekly-png.png)・[標準](../../evidence/gate-weekly-standard.png)・[軽量](../../evidence/gate-weekly-light.png)

Luaで、凍結600ティック目の成立、HP譲渡前後の合計、二体を同時に倒したときの報酬を検証した。Chromeでは受注から三体のポーン、キーボードとマウスでの霜印、クイーンへの誘導、HP譲渡、討伐、報告、保存再開まで確認した。 [Luaの検証](../../evidence/gate-weekly-lua.json)・[Chromeの記録](../../evidence/gate-weekly-browser.json)
