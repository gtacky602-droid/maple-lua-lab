# 北風の王狼 Web/Lua試作

2026-11-18。設計ID `boss-29020101`、実行ノード `andrius-wolf-ring`。[ANDRIUS.md](ANDRIUS.md) のWA01〜11と、[QAの風刃追補](QA.md) をWebへ接続した途中段階。

モンド城門広場で「王狼の再現戦・氷と北風」を受注する。広場x1380→南の街道x940の門から狼の領へ入る。討伐後は試練場x35→街道x60→広場へ戻って報告する。

## 戦闘

- 前半は肩、腰、後脚の姿勢から、前脚・尾・跳躍・突進・回転を読む。尾の向きは技の途中で追い直さず、遠距離variantは開始時に選び氷片3本を追加する。同一castは最大2hit。
- HP半分以下では現在の技を終えてから疾走試練へ一度だけ移る。左/右の走り込みと最後の中央着地だけに判定があり、奥を走る狼は装飾。通常ジャンプで届く左右の上段に退避できる。移行のt504〜624は本体への反撃時間。
- 後半は白い鬣になり、氷波・風刃・氷雨・咆哮・幻影狼を追加。前半の前脚と尾の技にも白い鬣の専用絵を使う。HP0なら段階演出を優先して生き残らせず、試練終了へ進む。
- 風刃は追補に従い全408tick、spawn96/186/276、低/高/低、消失上限342。実際にジャンプして着地し、高い刃をやり過ごせることを検査した。初版の12tick差は使わない。
- 氷波は床に沿う低い判定。氷雨の3地点はロック後に追尾せず、外縁の冷気床は各52.8px、最大360tick、地上だけ毎秒1回。中央の安全経路を残し、冷気が消えるまで外周退避だけの突進/回転を始めない。
- 咆哮の3pulseも通常の被弾無敵を守る。上段へ無警告に貫通しない。幻影は同時1体の短命な攻撃で、雑魚HPや撃破報酬を持たない。
- 咆哮は予兆から危険域を枠で示し、判定が出る波に合わせて色と番号を変える。残影は半透明の走る姿と足元の印で区別する。氷雨は外縁の冷気床の予兆と発生後の表示を切り替える。

原作コミュニティの[実戦資料](https://library.keqingmains.com/enemy-data/bosses/weekly-bosses/andrius-boreas)で二形態と移行、近遠の尾、氷/風の攻撃を照合した。原作の全フレーム、回避不能攻撃、時間経過による幻影の無限強化は再現していない。

## 仮値・保存・舞台

[weekly-boss-spawns.json](../../content/weekly-boss-spawns.json) にLv24、HP900、風/氷無効、その他10%耐性、被ダメージ、討伐330モラを比較用に分離。風/氷無効は原作再現案からの今回の試作採用で、本人の確定した新ルールとは記録しない。UIで属性を示し、実際に「無効」を表示する。物理通常と他元素は有効で、混合技は各成分の抵抗を平均する既存計算を使う。好きな同行者を禁止しない。

試作依頼は1600EXP/390モラ。難度別・個人別の本番報酬は未完成。未完挑戦は退出・全滅・保存読込で初期化し、撃破済みは60秒の再出現待ちを保存。週制限・樹脂・他人蘇生・人数によるHP加算は追加していない。

床は960pxの表示幅の中に880pxの主戦場と出入口用の余白を確保する。左右の上段は幅176px、高さ123.2px。見かけの鼻・鬣・尾全体へ接触ダメージを足さず、突進の移動capsuleと表示位置を共通にする。支持脚と脚の間の安全性は姿勢から推測しない。

## ローカル共闘

同じ部屋で同じ難度を選ぶと、HP・疾走と着地・形態・風刃の軌道・冷気床を共有する。風刃の命中上限と冷気床の被弾間隔は参加者のキャラクターごとに進む。討伐と難度別の初回報酬は個人の記録に残る。 [会場・戦闘画面・検証](../COOP_WEB_PREVIEW.md#北風の王狼の週ボス戦)

## 美術

通常形態6姿勢、後半8姿勢の計14キー姿勢。参照を添付した内蔵image_genで生成し、四足、青/白の鬣、細い巻き尾、後脚の結晶、胴の模様を保った。旧待機原画を保持し、支持足の下端と胴の基準点を揃えてPNG/矩形へ接続。背景は独立した月夜の狼の領の仮画像で、本番の3D背景とは別。

[美術監査](../../evidence/andrius-weekly-art-audit.json) に参照URL/ハッシュ、プロンプト、正規化、描画設定を保存。公開3Dモデルの頭・側面・斜めのプレビューも実見したが100×75pxで、モデル本体は購入・取得していない。背面・腹面や関節の詳細は未確認。連続歩行、中割り、左右別の忠実性、被弾/試練終了、音は今後の制作項目。
