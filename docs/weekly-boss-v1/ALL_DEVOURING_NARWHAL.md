## 2. 舞台・原点・攻撃先

60tick/秒、区間[start,end)、U=旅人88px、比較画面960×540。背景は本番3D、ここは2D敵/演出の設計。基本床x=[0,10]U、左右に幅2U・z=1.4Uの補助足場。外海と腹中で同じ移動性能を使う。人体約3頭身を鯨へ適用しない。

鯨の見かけ全長7Uを比較値とし、頭・胴・胸鰭・尾・背の発光・境界の渦を別レイヤーにする。骨格の波は頭→胴→尾へ遅れる。全身の絵を一枚のまま上下させない。水面と星空は装飾で、泳ぎ操作や溺死を追加しない。

外海で攻撃可能な頭/側腹/尾は同じHPの一体。AoEが複数部位に当たっても `castId + hitEventId + bossId` で一回。巨体の全輪郭に接触ダメージを付けない。ACTIVEに定義した衝撃と噴出だけが危険。近接で殴れる露出部の下端はz≤0.6U。飛行技が2つ続いたらWV01/02/03の近接露出を優先し、長い待ち時間を防ぐ。

腹中の幻影は見かけ高140pxを開始値にし、巨剣・片腕の防具・背後の核を分離。幻影HPをS=100%の耐久バーで表示するが、元素盾の単位と混同しない。通常の物理・元素攻撃で削れる。背後の大きな球は舞台装飾で、無告知の接触や吸引なし。

## 3. HP・敵意H・幻影Sと状態遷移

`OUTER → WV07 → INNER → WV14 → WV15 → OUTER/OUTER_FINAL → CLEAR`。主HPは鯨の一本。内部では鯨HPは通常攻撃対象でなく、Sを削る。実プレイヤー数によるHP倍率は付けない。

Hはパーティー共有0〜100。外海で60tickごと+1、有効な鯨への攻撃castにつき+5（全体で24tickの加算間隔）、渦の眼の破壊で+25。光界・キャラのエネルギーではない。H100到達は現在技の終了後に一度だけ捕食予約。鯨HP≤20%またはHP0なら予約を取消す。Hが満たされた瞬間に操作を切断しない。

Sは実HPから正規化する表示。幻形の核の中断成功でSを25ポイント削る開始案だが、これは通常ダメージ数字を出す追加ヒットではなく専用の耐久減少。S0は一度だけ内部勝利。二回目以降の内部HPは初回の50%を比較値にし、同じ長い試練を何度も要求しない。

内部勝利後は鯨最大HPの20%相当を一度だけ減算する本作値。通常攻撃と重複加算せず、鯨HP0なら脱出後に勝利へ。キャラHP・CT・光界を無料回復しない。生存者を同時に移し、観戦者を蘇生しない。原作のエネルギー補充は導入しない。

アルケーは既存実装で明示タグが存在する場合だけ利用可。渦の眼はアルケー1回または通常/元素の有効hitEvent8回で破壊。核はアルケー1回、または後述の本作代替4回。エフェクトの色だけでアルケーと判定せず、特定同行・弓を必須にしない。

## 5. 個別モーション・予兆・危険範囲

共通WARN/音/命中火花は[幽境COMMON](../stygian-motion-v1/COMMON.md)を継承。属性は外海Hydro、幻影の剣/雷Electro、幻形は分岐別に指定。見た目が宇宙色でも新元素なし。通常shake0、大着水だけ2px/10tick上限。reduced_motionは0。

### WV01 星海の飛び出し：360tick

t0–54床に裂け目、t54位置LOCK。頭を先に上へ出し、胸鰭を開き、胴と尾が遅れて続く。ACTIVE[108,120)幅2U/高さ1.2Uの主衝撃、t126に周辺水紋を再予告、[174,186)に左右0.7U幅の噴出。主衝撃と噴出の各group1hit、cast最大2。主範囲の外側に1.2U以上の安全床を残す。頭の突端・空中の尾は非攻撃。

t186–276は腹側が低く見え、近接HPターゲットを維持。RECOVERY[276,360)も同じ位置へ攻撃可。核心は裂け目の線→頭の上向き→胸鰭の開き→浮いた胴→尾の抜け。着地でなく出現のBURST、水滴は最大6個/18tick。飛沫で自機を隠す部分は透明度を下げる。

### WV02 巨鯨の飛び込み：420tick

t0–72奥で頭を下げ、尾を高く反らし、着水域を先に表示。t72LOCK、t96–156に弧を描いて下る。ACTIVE[156,168)幅2.5U、別水紋をt180に表示し[228,240)で二次噴出。各group1、cast2上限。飛行中の全長には判定なし。

頭→腹→尾の順に水面へ触れるが、装飾接地回数をヒット数にしない。t240–300は側腹が見え、RECOVERY[300,420)で近接可。白い圧縮輪→青い厚い弧→小滴の順で消え、尾の最後の一振りに追加ダメージなし。

### WV03 境界の遊泳：480tick

t0–60進路と終点を表示、t60LOCK。t96–126に腹が触れる衝撃帯（幅2U）、t126–276は最大3U横移動する姿勢を見せる。全身接触なし、腹下の縁に沿って殴れる低いHP領域を維持。t240に沈む点を別予告し、[300,312)で最後の噴出。cast最大2。

頭と胴の波に尾を12tick遅らせ、胸鰭は床を擦らない。RECOVERY[336,480)は胴が側面を向け低空で止まり攻撃可。安全策は走路外の床で、巨大な胴体を跳び越えることを要求しない。

### WV04 潮吹きと星座の雨：420tick／星座variant 480tick

潮吹きはt0–48に背の発光を集め、着地点3個をt48でLOCK。[108,114)、[180,186)、[252,258)の落下3回、幅0.9U、各group1。RECOVERY[300,420)。背の孔から上へ1本の光、床の小輪、落下の細い柱の順。高空は装飾、落下点を発射後に追い直さない。

星座variantはt0–60に星点をつなぐ。t60LOCK、[120,126)、[210,216)、[300,306)の3点落下、幅1.3U。RECOVERY[360,480)。星座は奥に薄く、前景は危険輪だけ。原作の多数のランダム落下を3点の明示パターンへ整理した翻案。どちらも身体が低く留まる区間は殴れるが、RECOVERYの初めには近接領域を安定させる。安全床と装置位置を全て同時に封鎖しない。

### WV05 渦の眼：720tick（未破壊ルート）

t0–60鯨が奥へ退き、x=5U/z=0.8Uに半径0.38Uの眼を生成。受付[60,480)。通常の実hitEvent8回、同cast/event重複なし、または対応アルケー1回で破壊。物理の多段も実イベントなら数える。幻形核の4回とは別。周囲の回転線は吸引の印象だけにし、初版では実強制移動を加えない。

成功sで眼を消し、H+25を一度加算。s+36まで非攻撃の収束、以後外海の次技へ。未破壊時t480から爆発予告、ACTIVE[510,522)は眼中心半径1.6U、cast1hit。眼はt522に消滅、RECOVERY[540,720)は鯨が低く戻り攻撃可。未破壊でもHの時間増加を維持し進行不能にしない。眼中は他の大攻撃なし。影/粒子を殴ってカウントを稼がない。

### WV06 敵意と捕食予約：イベント状態

Hのルールは節3。表示は主HP下の細い渦付きバー。満タンは口の形のアイコン、捕食予約中も現在技を安全に終える。HP20%以下になることをHより優先し、予約取消を表示。初版では各技終端に必ず低い身体への攻撃機会を置き、時間だけのH蓄積を唯一の進行にしない。取得/破壊/攻撃の加算にイベントIDを付け、人数倍の自動加算をしない。

### WV07 呑噬・腹中への移行：180tick

t0で旧弾/眼/危険床を解除してシーンepochを進める。t0–48口の奥に黒紫の渦、t48–96画面奥だけが歪む。t96で同じ床座標へ腹中の背景/幻影を切替。t96–144位置を安全床へ確認、RECOVERY[144,180)は構え直しでHP攻撃不可。全区間非攻撃、HP/CT/状態を巻き戻さず、演出による強制死亡なし。生存AIも同時移行、観戦者を復活させない。移行保護中は攻撃入力を蓄積して無限連打しない。

### WV08 幻影の三斬・遅裂：300tick

t0–42に剣を斜め下へ、t42方向LOCK。斬撃[84,90)、[132,138)、[180,186)、対応する遅い裂け目[108,114)、[156,162)、[204,210)。斬りと対応遅裂は同group最大1hit、全cast3。剣先が縦→横→回転へ移り、腰のひねりと肩が戻るまで次の打撃を予測できる。

前方rect[0.2,1.8,0.2,1.5]Uを基準、最終回転は半径1.35U。すべて同じ広域判定にしない。遅裂は最初から二重線で示し、斬りの光が消えた瞬間を安全と誤認させない。RECOVERY[228,300)。雷芯2tick→暗紫の裂け目24tick、残る装飾を次hitにしない。

### WV09 巨剣の往還：360tick

t0–54剣を後ろへ、t54往復の線LOCK。t90に水平高さ0.9Uの回転剣を投擲、最大寿命180tick、t270までに消える。往路/復路それぞれ同対象1hit、全cast2。往復転向点と復路の開始を別の矢印で表示。本人の周囲にも常に全周判定を置かない。

投擲手→手の空いた構え→剣を受ける→下げる4姿勢を基準。RECOVERY[288,360)。戻る時だけ追尾速度を上げて避け不能にしない。場外失効なら手に非攻撃で再形成し、遠方から復帰弾を再発射しない。

### WV10 雷裂の三柱：336tick

t0手を上げ、床の三位置を順に提示。LOCK48/108/168、ACTIVE[108,114)、[168,174)、[228,234)。各点幅0.8U、各1hit、全3。少なくとも60tickの個別予告を維持、柱が上段まで届くならその高さもWARNに含む。RECOVERY[252,336)。床亀裂→白紫柱→角片の順。自機の真下を直前で追い直さない。

### WV11 幻形の核：条件分岐、標準期限300tick

t0–60幻影が胸前へ光を集め、核を地上近接が届くz=0.9Uへ開く。中断受付[60,240)。対応アルケー1回、または本作代替の操作キャラによる新規攻撃cast4回で中断（同castの多段は一回、同actor最小12tick間隔）。通常攻撃での中断は原作そのままではない。本人へのHP攻撃と核のcountを同時に二重処理しない。

成功sで核と予約を取消し、S-25を一度適用。S0ならWV14、残ればsから96tickの中断姿勢の後に近接戦へ。中断中はSへ攻撃可。失敗時t240に核の色と獣/竜/クラゲの形を表示、t300にWV12の選択済み分岐へ。失敗ルート後半は反撃窓ではない。初回は単独で提示、核を画面外へ置かない。

### WV12 幻形の襲来：獣456tick／竜432tick／クラゲ480tick

原作の三種の幻形を、同時の召喚敵ではなく短い攻撃実体として扱う。倒した時の経験値や撃破報酬なし。各分岐後に本人の一閃が来ることを、核上の小さい剣印で先に知らせる。

獣：t0–48四つの入口をLOCK、t84/144/204/264に各1体出現、速度5U/秒・寿命60tick。雷の転がる輪郭、各1hit。最後t324失効。本人はt312に一閃を再予告、[348,354)に短斬、RECOVERY[384,456)。最大5hit要求。入口は左右から交互、全地上を同時に塞がない。

竜：t48着地二点LOCK、炎の竜影が跳び、ACTIVE[108,120)、[228,240)。本体再接近をt252予告し[300,306)一閃。RECOVERY[336,432)。最大3。影と実落下地点を一致させ、竜の全身が触れただけでhitにしない。

クラゲ：t60に四射線LOCK。t90/150/210/270に水弾各1、速さ4U/秒・寿命90tick、最大4hit。最終t360失効、本人の一閃[384,390)、RECOVERY[408,480)。最大5。水弾の丸い縁と雷の本人を区別、剣の再予告はt330から保持。幻形中断なら未生成分も取消す。

### WV13 幻影耐久と中断：イベント状態

Sの実体は独立した幻影HP、表示だけ盾風バー。通常防御・無敵は既存処理を通す。核成功の25ポイント減少はshadowMaxHPの25%相当を専用作用として一度だけ適用、通常のヒットと重複しない。S0後は攻撃/予約/幻形実体を即消去。二体以上に分かれた見た目でもHPは一つ。内部で鯨本体へ攻撃が漏れない。マルチの同時核破壊は一度だけ。二回目以降のHP半減は入場回数から設定し、毎回のダメージで再計算しない。

### WV14 内部崩落・帰還：180tick

S0をt0に確定。剣→腕→胸の順に幻影が輪郭の欠片になり、t48–96で奥の球に亀裂。t96で外海の安全床へ全生存者を戻す。t120に鯨最大HP20%の損傷を一度だけ確定。RECOVERY[144,180)は移行でHP攻撃不可。HP0なら勝利へ、残ればWV15。原作の大きな損傷の量を本作用20%へ固定した翻案。全体白フラッシュ、強制蘇生、CT回復、追加の被ダメなし。

### WV15 巨鯨の衰弱：720tick

t0–60胸鰭が下がり胴が水平に倒れる。EXPOSURE[60,660)＝600tick/10秒、側腹を近接で殴れる。尾までAoEが届いても同じHP一回化。t660–720は起き直しで攻撃不可、移動準備。HP0ならその場で勝利を優先し起立しない。H0へ戻すのはこのcycle終了時一度。HP20%以下なら再捕食を停止して外海の低い攻撃機会を繰り返す。背景星の明滅ではなく、横たわる身体そのものをチャンスの表示にする。

### WV16 戦場・再捕食・終了管理：イベント状態

シーン切替ごとepochを更新し、旧弾・核・眼・遅裂・入力予約を失効させる。外海/腹中は同時にダメージを出さない。H/S/UI/主HPのownerを分離。鯨HP0を捕食予約より優先する。内部勝利ボーナスはcycleIdで一回、全滅して新試行ならHP/H/Sと移動回数を初期化。再接続だけで再試行にしない。

HP20%以下で内部へ入らない設定は本作値。内部を必ず一回見せるための無敵ストッパーは付けず、高火力で外海のみ討伐可能。多人数でも攻撃数やHPを人数倍にしない。観戦者を帰還時に蘇生しない。必要な操作は通常移動・ジャンプ・攻撃、低い核、明示したアルケー代替で完結する。

## 6. 作画・音・受入条件

色は鯨の白青#D9F5FF、胴の群青#355B91、星紫#7E68BA、外海の攻撃芯#ECFAFF。幻影は黒紺#1C2035と雷紫#B695F0。鯨の尾は大きい曲線、幻影の裂け目は短い直線。本人、HPターゲット、危険な噴出、装飾の水面を分ける。
