# 正機の神の週ボス試作

Lv64でスメール・樹陰の広場の依頼「工房の再現戦・端末と胸部」を受け、広場のx950から入る。ボスのHPは上半身590、全身1,040。共有充填100と後半の装甲100は別々に表示する。HP、装置効果、攻撃、報酬の具体値はラボの試作値。

## 戦い方

- 前半は胸と両腕を攻撃できる。範囲攻撃が複数部位をとらえてもHPへの加算は1回。緑の充填ブロックを歩いて拾い、装置の近くでボタンを押す。炎は氷床、氷は炎床を解除し、風はジャンプを補助し、水は回復場を作る。雷Aと雷Bが同時に効くと、6秒の攻撃機会が生まれる。
- 後半は通常攻撃と端末射撃で装甲を削る。充填100で **H** を押すと端末を構え、もう一度 **H** を押すと射撃を確定する。発射までは **Esc** で中止できる。胸部に弾が届くと装甲を25削る。前半は使用可能な元素装置の近くで **H** を押して起動する。
- 装甲が消えたら滅度機4基を通常攻撃で破壊し、端末で胸部を撃つ。支援先を指定すると、同行者も指定した1基を攻撃できる。弾が届くと10秒間ボスを攻撃できる。時間切れの場合は通常計算の大ダメージが発生し、装甲0のまま戦闘に戻る。

## 素材

既存の全身ドット絵と、同じ原画から作った上半身の描画データを使う。原画には3Dモデルの正面・側面・背面と顔の参照記録がある。装置、滅度機、端末と攻撃の予兆は仮描画。会場には造神工房の仮背景を使う。本番は3D配置を想定している。M地図の背景比較で、開戦時と同じ位置・大きさの元PNGと軽量版を並べられる。[原画の参照記録](../../evidence/shouki-reference-audit.json)

画面外の矩形を除くと、開戦時の機体の描画数は標準6,224→3,061、中間3,741→1,851、16色版2,125→1,392になる。16色版は仮面を縦横2倍、胸の雷紋の中心を縦横3倍の細かさで原画から採った。機体全体を一様に縮めた旧16色版は861個で描けたが、胸の紋様に紫の濃淡がほとんど残らなかった。胸の領域で、元PNGに対するRGB平均絶対誤差は55.23から31.98に下がった（0～255、アルファ240以上の画素）。[新旧16色版の拡大比較](../../evidence/shouki-focus-comparison.png) · [ゲームと比較画面の照合](../../evidence/weekly-opening-poses-browser.json) · [造神工房の全景](../../evidence/weekly-opening-shouki-light.png)


960×540の戦闘画面で、胴の細いくびれから上だけを表示する。くびれを旅人と同じ床面に合わせ、高さ1,160px、幅約1,393pxで描画する。頭飾りと両腕が画面の上と左右にはみ出し、手前に旅人と6つの装置、攻撃予告が見える。装甲起動後、滅度機の試練、胸部命中後も同じ高さと接地位置で描画する。 [調整前](../../evidence/shouki-weekly-waist-rise-upper-png.png) · [現行の上半身](../../evidence/shouki-weekly-floor-contact-upper-png.png)

端末弾は画面に見える胸の宝玉を狙う。滅度機が残っている間は胸の印が紫で、4基が消えると緑になる。通常攻撃が届く部位は前半が両腕と中央、後半が足元。 [ラボを開く](http://127.0.0.1:9051/)

樹陰の広場で共闘部屋を作ると、充填や装甲、滅度機を共有して戦える。端末の予約者だけが照準を操作し、各組は自分の同行者に支援先を指定できる。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#正機の神の週ボス戦)

## 検証

- `test_shouki_weekly.py` は全描画設定でくびれが床面にそろうことを検査する。胸部照準、通常攻撃が届く高さ、装置、予約と発射、期限切れと600tickの露出、保存復元も確認する。 [正機の神の設計](SHOUKI_NO_KAMI.md) · [スメールの検証仕様](QA_SUMERU.md) · [Luaの結果](../../evidence/shouki-weekly-floor-contact-lua.json)
- `test_shouki_weekly.mjs` は装備付きLv64の試験データで、Chromeから受注、Hで元素装置の起動、Hで照準を構える操作、Escで中止、Hで射撃を確定する操作を確認する。装甲と胸部への射撃、滅度機4基の破壊、討伐、報告、保存復元まで進め、390px幅での操作欄も検査する。 [Chromeの結果](../../evidence/shouki-weekly-floor-contact-browser.json)
- 獲得済みのLv160・180・200セーブを使ったLua試走では、胸部への射撃2回で装甲を削り、滅度機4基を通常攻撃で破壊した。端末で胸部を撃ったあと10秒の攻撃時間に入り、37.0〜37.8秒でクリアできた。上級・最上級のEXP、モラ、勝利記録も照合した。 [試練成功のLuaログ](../../evidence/earned-shouki-trial.json)
- 上半身戦の同じフレームで描画方式を比較できる。画面全体の描画指示はPNGで39件、標準矩形で10,483件、軽量16色で2,750件。軽量16色は標準矩形より約74%少なく、顔や胸の細部は粗く見える。 [PNG](../../evidence/shouki-weekly-floor-contact-upper-png.png) · [標準矩形](../../evidence/shouki-weekly-floor-contact-upper-standard.png) · [軽量16色](../../evidence/shouki-weekly-floor-contact-upper-light.png)

## 最上級で胸部命中と時間切れを比較

同じ獲得済みLv200セーブの2コピーで再戦した。最初の試練で滅度機4基を壊して胸部に命中させた経路では、600tick（10秒）の攻撃機会に512ダメージを与えた。2基残して時間切れになった経路では、刹那生滅で72ダメージを受け、装甲0で戦闘に復帰した。再試練までに本体へ808ダメージを与え、再試練で胸部に命中させて討伐した。両戦とも周回報酬と最上級の勝数を再読込した。 [最上級の試走](../../evidence/shouki-trial-outcomes-20261128.json)

HUDには胸部への命中、攻撃機会の残り時間、刹那生滅による操作キャラの被ダメージ、装甲0での戦闘再開を表示する。Chromeの通常戦ではLv64の試験データで両経路を討伐・依頼報告・再読込まで確認した。Luaの4人共闘では同じ刹那生滅で72ダメージを受けた組と無傷の組の表示を、ローカルHTTPの2人共闘では胸部命中の共有を確認した。

画面に見える上半身の矩形の色を番号に置き換え、1つのパレットを送る。矩形の形・位置・描画順と色は従来と同じ。32場面で既存の矩形圧縮と比べ、描画JSONは中間14.90%、軽量16色19.89%減った。2画質の計64組で展開した描画命令とChromeの画素が一致した。開戦画面の軽量16色では、従来の矩形圧縮のgzipデータが18,888 B、新しい方式が17,954 Bだった。Chromeで同じフレームの圧縮をオン・オフしても画素は一致した。 [描画と共闘の測定値](../../evidence/shouki-trial-outcomes-20261128.json)
