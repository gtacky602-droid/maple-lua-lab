# 蝕まれし源焔の主・源焔の再現戦

ナタ・谷の集落で、Lv104の依頼「源焔の再現戦・虚界の障壁」をマーヴィカから受注する。入口は広場のx351。ラボには溶岩棚の画像を仮置きした。本番の背景は3Dで用意する方針。 [個別設計](LORD_OF_ERODED_PRIMAL_FIRE.md)・[修正版の障壁](CORRECTIONS_V02.md)

- 炎剣から双剣に移って最初の床切断を行う。初期幅880pxから、左端を88pxずつ最大3回切り落とす。二回目以降は通常技を二つ終え、前回切断から10秒経過してから行う。崩落する帯と次の足場が先に見え、床判定と表示は同時に変わる。落下後は最大HPの25%を通常ダメージとして要求し、安全な床へ戻す。
- 指定された被弾で蝕破を予約する。各キャラ4つまでで、予約120ティック後にそれぞれのキャラへ通常ダメージを要求する。付与間隔は30ティック以上。交代後も対象は変わらず、HP回復は蝕破の予約を解除しない。
- 刺剣と終焔の障壁は各12。受付は開始1秒後から12秒間。通常攻撃は1、元素攻撃は2、同じ攻撃の多段は対象ごとに一度。同じキャラが同じ対象を削る間隔は24ティック以上。擬態芽は各4、柱は各6。成功時は試練の波や弾を消し、崩れる動きのあと8秒間ボスHPへ攻撃できる。期限切れには固有の予兆と失敗技がある。
- 竜体の待機ドット絵を再利用し、炎剣・紫剣、障壁、芽、柱、床をLuaの別描画にした。下腹と手は一つのHPを共有する。HP、落下量、攻撃威力、依頼報酬はラボ調整用。連続作画と効果音は今後の制作範囲。 [既存素材の参照と圧縮記録](../../evidence/gosoythoth-reference-audit.json)

谷の集落からの共闘では床と障壁を共有し、落下と蝕破をキャラごとに判定する。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#蝕まれし源焔の主の週ボス戦) · [ローカルラボ](http://127.0.0.1:9055/)
