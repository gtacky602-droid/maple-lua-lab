# ドットーレ・左道の真諦者のローカル試作

スメール・樹陰の広場の入口（x222）からLv144「左道の再現戦・結合格子」へ入る。ナヒーダの依頼「左道の再現戦・結合点」を受注すると、討伐後に広場で報告できる。入場はF、移動はA・D、通常攻撃はJ、ジャンプはSpace。偽月の異端者はナド・クライの別の再現戦から挑戦する。

## 戦闘

- 第一形態はHP1,650、第二形態はHP2,250。第一形態を倒すと4秒かけて光背を組み立てる。移行中はボスの攻撃を取り消し、旅人と同行者のHP・クールダウン・光界を引き継ぐ。
- 第二形態の最初の三重波は、ジャンプと上段で避けられる。波の後に30秒の詠唱が始まる。左右の結合点はいずれも3回の命中で壊れる。片方が壊れた時点で両方と押し壁を片付け、本体が詠唱への命中を受け付ける。残り時間は引き継ぐ。
- 押し壁の緑枠は床側と上段で交互に切り替わる。穴の外で壁に触れると最大約31px押し戻される。壁はHPダメージを与えず、一枚につき各キャラクターを一度まで押す。
- 詠唱に24回命中すると、1秒後から12秒間本体へ反撃できる。物理・元素ともに有効で、同じ攻撃イベントは一度だけ数える。同じキャラクターから同じ対象への受付は12ティック間隔。残り0秒になるティックの有効な命中も受け付ける。
- 詠唱が間に合わなかった場合は通常の大ダメージを受ける。生き残れば本体のHPへ攻撃を続けられる。試練の再発動には15秒以上の経過と通常技二回が必要。
- 模倣の王・后はそれぞれ走路を進む攻撃。双剣と巨大刀にも専用の予告と当たり判定がある。戦闘データのHP、ダメージ、報酬はラボの暫定値。設計カードWH01〜WH20を状態・攻撃・終了処理に参照した。 [設計書](DOTTORE_HERETIC.md)

## ドット絵と仮背景

従来の立ち絵と偽月版の等身を参照して、約2.93頭身の専用ボス絵を生成した。水色の髪、赤い単眼、広い肩、短い脚と大きめの手足を採用。第二形態では同じ本体にLuaの光背を重ねる。遺構の画像はブラウザー側で読み込み、Luaは足場の当たり判定とキャラクター、戦闘を処理する。本番は3D配置を使う方針。 [生成記録](../../assets/heretic-weekly-generation-v1.json)

描画方式は「PNG見本」「矩形変換・標準」「矩形変換・軽量 16色」で切り替えられる。ボス単体の矩形は標準4,838件、中間3,084件、軽量1,422件。一時停止した同じ戦闘フレームで切り替えれば、輪郭や色の変化を見比べられる。 [PNG](../../evidence/heretic-weekly-png.png) [標準](../../evidence/heretic-weekly-standard.png) [軽量](../../evidence/heretic-weekly-light.png) [計測](../../evidence/heretic-weekly-browser.json)

## 検証と残作業

Luaで押し壁の通路、当たり判定、二重加算、核破壊後の片付け、期限ちょうどの最終命中、12秒の反撃窓、失敗からの復帰、報告後のセーブ再開を確認。Chromeでは広場から入場し、通常攻撃で結合点と詠唱を突破して討伐・報告まで確認した。 [Lua検証](../../evidence/heretic-weekly-lua.json) [Chrome検証](../../evidence/heretic-weekly-browser.json)

技ごとの連続作画、効果音、参照モデルの背面、全編成での難度、戦闘途中の保存と再開、実マルチ、本番3D配置と幻境実機検証が残る。現行ラボは町から再開し、記録するのは討伐済みの状態と依頼の進行。
