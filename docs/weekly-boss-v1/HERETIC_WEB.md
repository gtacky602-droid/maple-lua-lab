# ドットーレ・左道の真諦者のローカル試作

スメール・樹陰の広場の入口（x222）からLv144「左道の再現戦・結合格子」へ入る。ナヒーダの依頼「左道の再現戦・結合点」を受注すると、討伐後に広場で報告できる。入場はF、移動はA・D、通常攻撃はJ、ジャンプはSpace。偽月の異端者はナド・クライの別の再現戦から挑戦する。

## 戦闘

- 第一形態はHP1,650、第二形態はHP2,250。第一形態を倒すと4秒かけて光背を組み立てる。移行中はボスの攻撃を取り消し、旅人と同行者のHP・クールダウン・光界を引き継ぐ。
- 第二形態の最初の三重波は、ジャンプと上段で避けられる。波の後に30秒の詠唱が始まる。左右の結合点はいずれも3回の命中で壊れる。片方が壊れた時点で両方と押し壁を片付け、本体が詠唱への命中を受け付ける。残り時間は引き継ぐ。
- 押し壁の緑枠は床側と上段で交互に切り替わる。穴の外で壁に触れると最大約31px押し戻される。壁はHPダメージを与えず、一枚につき各キャラクターを一度まで押す。
- 詠唱に24回命中すると、1秒後から12秒間本体へ反撃できる。物理・元素ともに有効で、同じ攻撃イベントは一度だけ数える。同じキャラクターから同じ対象への受付は12ティック間隔。残り0秒になるティックの有効な命中も受け付ける。
- 詠唱が間に合わなかった場合は通常の大ダメージを受ける。生き残れば本体のHPへ攻撃を続けられる。試練の再発動には15秒以上の経過と通常技二回が必要。
- 模倣の王・后はそれぞれ走路を進む攻撃。双剣と巨大刀にも専用の予告と当たり判定がある。戦闘データのHP、ダメージ、報酬はラボの暫定値。設計カードWH01〜WH20を状態・攻撃・終了処理に参照した。 [設計書](DOTTORE_HERETIC.md)

共闘では結合点と詠唱の残りを全員で削る。押し壁と模倣技は各キャラの位置に応じて処理し、詠唱が途切れた後の12秒は全員が反撃できる。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#ドットーレ左道の真諦者の週ボス戦)

## ドット絵と仮背景

従来の立ち絵と偽月版の等身を参照して、約2.93頭身の専用ボス絵を生成した。水色の髪、赤い単眼、広い肩、短い脚と大きめの手足を採用。第二形態では同じ本体にLuaの光背を重ねる。遺構の画像はブラウザー側で読み込み、Luaは足場の当たり判定とキャラクター、戦闘を処理する。本番は3D配置を使う方針。 [生成記録](../../assets/heretic-weekly-generation-v1.json)

描画方式は「PNG見本」「矩形変換・標準」「矩形変換・軽量 16色」で切り替えられる。ボス単体の矩形は標準4,838件、中間3,084件、軽量1,422件。一時停止した同じ戦闘フレームで切り替えれば、輪郭や色の変化を見比べられる。 [PNG](../../evidence/heretic-weekly-png.png) [標準](../../evidence/heretic-weekly-standard.png) [軽量](../../evidence/heretic-weekly-light.png) [計測](../../evidence/heretic-weekly-browser.json)

## 検証と残作業

獲得済みLv200の同じセーブから最上級を3通りで再戦した。片方の結合点を壊すと両方と押し壁が消え、詠唱の期限は最初の30秒のまま。結合点を残した経路では、床に留まった旅人が押し壁で2回、各30.8px後退した。接触時のHP減少は0だった。

| 最初の詠唱での行動 | 旅人への腐敗の衝撃 | 中断後の反撃時間 |
| --- | ---: | ---: |
| 片方の結合点を壊し、本体に24回命中させる | 0 | 12秒 |
| 片方の結合点を壊し、時間切れまで待つ | 125 | なし |
| 両方の結合点を残して時間切れまで待つ | 125 | なし |

3戦とも討伐し、報酬と再読込後の最上級勝数を確認した。再現には同戦勝利済みのLv200セーブで `test_earned_heretic_chant.py --from-save SAVE.json --output-dir work/heretic-replay` を実行する。ラボを起動し、`node test_earned_weekly_frames.mjs work/heretic-replay work/heretic-comparison` で3画質を並べられる。中間画質で矩形の圧縮を切り替えたChromeの停止フレームでは、Canvasの全画素が一致した。 [再戦と描画の計測](../../evidence/heretic-chant-branches-20261128.json)

Luaで押し壁の通路、当たり判定、二重加算、核破壊後の片付け、期限ちょうどの最終命中、12秒の反撃窓、失敗からの復帰、報告後のセーブ再開を確認。Chromeでは広場から入場し、通常攻撃で結合点と詠唱を突破して討伐・報告まで確認した。 [Lua検証](../../evidence/heretic-weekly-lua.json) [Chrome検証](../../evidence/heretic-weekly-browser.json)

技ごとの連続作画、効果音、参照モデルの背面、全編成での難度、戦闘途中の保存と再開、別端末間の通信、本番3D配置と幻境実機検証が残る。現行ラボは町から再開し、記録するのは討伐済みの状態と依頼の進行。

## Lv200セーブでの最上級4勝

偽月の異端者の最上級4勝と依頼報告119件を記録したセーブで、スメールの樹陰の広場から最上級へ入った。押し壁の案内は、現在の高さで穴を通過できるかを実際の衝突判定と同じ条件で表示する。結合点と本体の必要命中回数、残り時間、反撃が始まるまでの時間も表示する。

- Chromeの初回は床側の穴を通過し、旅人の位置とHPが変わらないことを確認した。右の結合点に3回、本体の詠唱に24回当てて中断した。討伐で32,560,274 EXPと3,590,160モラ、ナヒーダへの報告で1,230,000 EXPと26,500モラを獲得した。 [最上級初回と報告](../../evidence/earned-heretic-first-expert-browser.json)
- Luaの3連戦は詠唱の中断、結合点を壊してからの時間切れ、両方を残しての時間切れを比較した。中断後の12秒で336ダメージを与え、時間切れの2戦では各125ダメージを受けた。壁の穴から外れたときは30.8px押し戻されたが、接触によるHP減少はなかった。周回報酬は各18,999,684 EXPと1,538,640モラ。検証中は旅人の聖遺物を一時変更し、同行者の攻撃を止めた。同行者は再戦3回とも戦闘不能になった。 [3連戦の記録](../../evidence/earned-heretic-rematch-lua.json)
- 元の装備と未回収聖遺物を保持した。Chromeで左道の真諦者と偽月の異端者の最上級各4勝、報告120件を復元した。 [再読込の記録](../../evidence/earned-heretic-rematch-browser.json)
- 3戦の17場面を元絵・中間・軽量で比較した。結合点が出ている同じフレームで、標準の描画命令7,085件に対して軽量16色は2,097件だった。軽量版はパック前後でCanvasの画素が一致し、gzip転送量は44,862 Bから36,907 Bになった。 [比較の記録](../../evidence/earned-heretic-rematch-frames-browser.json)

最上級初回後のセーブから、`python -X utf8 test_earned_heretic_chant.py --from-save work/earned-heretic/first/heretic-complete.json --output-dir work/earned-heretic/replays --chain --weapon SW07` で3戦を再現できる。ラボを起動して `node test_earned_weekly_frames.mjs work/earned-heretic/replays work/earned-heretic/comparison` を実行すると3画質を比較できる。
