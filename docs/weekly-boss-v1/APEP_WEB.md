# アペプのオアシス守護者の週ボス試作

Lv68でスメール・樹陰の広場の依頼「オアシスの再現戦・心の防衛」を受け、広場のx780から入る。HP560の暗色の守護者と、HP1,020の緑の守護者の間に「オアシスの心」の防衛がある。HP、攻撃、防衛、報酬の数値はラボの試作値。 [設計](APEP_GUARDIAN.md)

## 防衛場面の比較

M地図の会場比較から「オアシスの心の防衛場面を見比べる」を開く。左右には同じLuaの戦闘時刻を使い、元PNGと16色版で、心の左右から近づく第一波4体を表示する。中央の淡黄色の芽が守る対象で、直上の短い金色のゲージは回復進行度を表す。「動かして比較」で再生し、「この場面で止める」で止められる。「オアシスの心の防衛で比較」で第一波に戻る。通常の冒険は別セッションで進む。[防衛を開く](http://127.0.0.1:9117/compare.html?scene=apep-defense) · [同じフレームでの比較](../../evidence/apep-heart-defense-comparison.png)

## 三段階の操作

- 初戦で薙ぎ、前肢の連撃、潜行からの再出現、地中の四肢をかわす。複数の部位を巻き込んだ攻撃は共通HPへ一度入る。
- 防衛では心を打たれると進行が下がる。基本の取り巻きは近接と小弾の2型。護衛は基本体を守り、飼育はリンクした基本体を強める。捕食は基本体を取り込み、障壁は短時間通路を狭め、自爆は心の近くで大きく進行を下げる。壁はジャンプで越えるか新規攻撃2回で破壊できる。支援先を指定すると同行者も指定した壁を攻撃する。
- 防衛は25から始まり、取り巻きを倒すか心を守り続けて100を目指す。捕食や自爆で敵が消えても自分の撃破点は増えない。進行が0になった場合は「防衛をやり直す」で25から再開できる。
- 後半でドームが三つ開いたら、色の付いた内側に入る。三回の波と最後の一撃をしのぐと、8秒間の安定した攻撃機会がある。ドームは横と高さの両方で判定し、上段にいる同行者は地面のドームを目指す。

樹陰の広場から共闘で入ると、心の進行度と取り巻きを共有する。味方が心への小弾を受け止められ、ドームで防げるかは各キャラの位置で決まる。 [共闘の入口・操作・検証](../COOP_WEB_PREVIEW.md#アペプのオアシス守護者の週ボス戦) · [ラボを開く](http://127.0.0.1:9052/)

## 素材と検証

既存の暗色・緑の守護者のドット絵と、基本増殖体に既存のキノコン候補を使用。特殊役、心、障壁、ドームは仮描画。ラボでは「オアシスの心」の仮背景画像を使い、本番は3D配置の方針。連続作画、音、報酬と難度の調整、遠隔接続と幻境実機は後続。 [暗色の参照記録](../../evidence/apep-dark-reference-audit.json) ／ [緑の参照記録](../../evidence/apep-prime-reference-audit.json)

`test_apep_weekly.py` は、攻撃の時刻とHP、同時刻の防衛点、8体上限、捕食と自爆、盾とリンク、壁を歩いて阻まれることとジャンプで越えられること、ドームの寿命、8秒の攻撃機会、保存復元を検査する。 [Luaの結果](../../evidence/apep-weekly-lua.json)

- `test_apep_weekly.mjs` は装備付きLv68から受注し、操作で防衛を一度で通過。最後の余波をドーム内でしのぎ、反撃時間、討伐、報告、セーブ再開を確認した。 [Chromeの結果](../../evidence/apep-weekly-browser.json) ／ [心の防衛](../../evidence/apep-weekly-defense.png) ／ [最後の余波](../../evidence/apep-weekly-dome.png)

## 最後の余波の内外を比べる

同じ獲得済みLv200セーブを使い、最上級の暗色の守護者と心の防衛から2戦を完走した。通常攻撃と移動で増殖体を13体倒し、両戦とも最初の余波3回を中央ドームで防いだ。ドーム開始から540tickの最後の余波では、中央に残ると被ダメージ0、地上でドーム外に出ると54だった。どちらも480tick（8秒）の攻撃機会があり、最初の攻撃機会で本体に攻撃を当てた。討伐後は周回報酬を受け取り、再読込で最上級の勝数が2から3に増えた。 [最上級の試走](../../evidence/apep-dome-results-20261128.json)

HUDに最後の余波をドームで防いだか、受けたダメージはいくつかを表示し、続けて反撃時間を知らせる。Chrome通常戦でもドーム内外の両方で、防衛のやり直しなしに討伐・依頼報告・再読込まで確認した。Luaの4人共闘とローカルHTTPの2人共闘では、同じ余波に対して各プレイヤーに個別の結果が届いた。

暗色・緑の守護者の本体も既存の矩形圧縮に通し、前景と本体の重なり順を保った。22場面の中間・軽量の計44組で、展開後の描画命令とChromeの画素が一致した。変更前の描画JSONと比べて中間画質で76.80％、軽量16色で76.15％減った。通常戦で最後の余波を止めた同一画面でも、軽量16色の圧縮を切り替えて画素が一致し、ドーム内側のgzip応答は70,204 Bから50,040 Bに減った。 [描画と共闘の測定値](../../evidence/apep-dome-results-20261128.json)

## オアシスの心の防衛と最上級3勝

ドームが開くと、操作キャラに近い左・中央・右の入口を案内する。ドームの真上でも保護されない高さでは床へ降りるよう表示する。残り時間は次の余波か最後の余波かを区別し、0.1秒刻みで表示する。

正機の神の最上級3勝を記録したLv200セーブからM地図でオアシスの再現戦に入り、Chromeで心の防衛を一度で通過した。左のドームで最後の余波を防いで最上級初回を討伐し、32,560,274 EXPと3,590,160モラを受け取った。ナヒーダへの依頼報告は90,000 EXPと5,600モラだった。 [Chromeの初回、幅390pxの案内、報告](../../evidence/earned-apep-first-expert-browser.json)

同じセーブでLuaの再戦を2回続け、両戦で増殖体13体を倒して防衛を通過した。最初の3波を中央ドームで防ぎ、最後の余波は内側で0ダメージ、外側で54ダメージだった。両戦とも8秒の攻撃機会で本体に一撃を当て、各18,999,684 EXPと1,538,640モラを得た。試走では獲得済みの花を一時装備して羽を外した。装備を戻したセーブで最上級3勝、再出現待ち、依頼報告116件をChromeで読み戻した。 [連続再戦](../../evidence/earned-apep-rematch-lua.json)・[Chromeで再開](../../evidence/earned-apep-rematch-browser.json)

初回討伐と依頼報告を終えたセーブを `test_earned_apep_domes.py --from-save SAVE --output-dir OUTPUT --weapon SW07 --chain` に渡すと2条件を続けて試せる。ラボ配信中に `node test_earned_weekly_frames.mjs OUTPUT OUTPUT/comparison` を実行すると最後の余波の直前を含む24場面を3画質で比較できる。 [描画比較の記録](../../evidence/earned-apep-rematch-frames-browser.json)
