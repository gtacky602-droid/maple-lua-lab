# アペプのオアシス守護者の週ボス試作

Lv68でスメール・樹陰の広場の依頼「オアシスの再現戦・心の防衛」を受け、広場のx780から入る。HP560の暗色の守護者と、HP1,020の緑の守護者の間に「オアシスの心」の防衛がある。HP、攻撃、防衛、報酬の数値はラボの試作値。 [設計](APEP_GUARDIAN.md)

## 三段階の操作

- 初戦で薙ぎ、前肢の連撃、潜行からの再出現、地中の四肢をかわす。複数の部位を巻き込んだ攻撃は共通HPへ一度入る。
- 防衛では心を打たれると進行が下がる。基本の取り巻きは近接と小弾の2型。護衛は基本体を守り、飼育はリンクした基本体を強める。捕食は基本体を取り込み、障壁は短時間通路を狭め、自爆は心の近くで大きく進行を下げる。壁はジャンプで越えるか新規攻撃2回で破壊できる。支援先を指定すると同行者も指定した壁を攻撃する。
- 防衛は25から始まり、取り巻きを倒すか心を守り続けて100を目指す。捕食や自爆で敵が消えても自分の撃破点は増えない。進行が0になった場合は「防衛をやり直す」で25から再開できる。
- 後半でドームが三つ開いたら、色の付いた内側に入る。三回の波と最後の一撃をしのぐと、8秒間の安定した攻撃機会がある。ドームは横と高さの両方で判定し、上段にいる同行者は地面のドームを目指す。

## 素材と検証

既存の暗色・緑の守護者のドット絵と、基本増殖体に既存のキノコン候補を使用。特殊役、心、障壁、ドームは仮描画。背景はトゥニギの掘削場の仮画像を流用し、本番は3D配置の方針。連続作画、音、報酬と難度の調整、多人数や幻境実機は後続。 [暗色の参照記録](../../evidence/apep-dark-reference-audit.json) ／ [緑の参照記録](../../evidence/apep-prime-reference-audit.json)

`test_apep_weekly.py` は、攻撃の時刻とHP、同時刻の防衛点、8体上限、捕食と自爆、盾とリンク、壁を歩いて阻まれることとジャンプで越えられること、ドームの寿命、8秒の攻撃機会、保存復元を検査する。 [Luaの結果](../../evidence/apep-weekly-lua.json)

- `test_apep_weekly.mjs` は装備付きLv68から受注し、操作で防衛を一度で通過。最後の余波をドーム内でしのぎ、反撃時間、討伐、報告、セーブ再開を確認した。 [Chromeの結果](../../evidence/apep-weekly-browser.json) ／ [心の防衛](../../evidence/apep-weekly-defense.png) ／ [最後の余波](../../evidence/apep-weekly-dome.png)
