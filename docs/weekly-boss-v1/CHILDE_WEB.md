# 公子の週ボス Web試作

璃月・港の広場で「黄金屋の再現戦・水と雷」を受注し、広場のx1040の門から再現戦へ入る。Lv28、三形態のHPは240、300、420。HP、威力、初回報告と周回報酬は比較用の仮値。[個別設計](CHILDE.md)のWC01〜14をローカルLuaの週ボス基盤につないだ。

- 水弓、邪眼、魔王武装のHPを3本で表示する。第1・第2形態の最後の一撃は次のHP区間へ持ち越さない。変身中は旧弾・断流・反撃予約が消え、次の形態が表示されても演出完了まで本体にダメージが通らない。勝利・報酬・自己記録は魔王武装の討伐時に一度だけ保存する。
- 水・雷の断流印は現在の操作キャラに表示し、操作交代で引き継ぐ。両端の金灯で解除する。追雷の地点固定前に解除すると落撃を中止し、固定後は予告済みの地点に落ちる。
- 水鯨は出現と着水の2領域で判定する。障壁の反撃は、障壁前方に届いた新規の手動攻撃だけが予約する。追雨は固定した段の床に落ち、雷走は前の終点から再開する。
- 帰還や未完のセーブからの再開では一戦をやり直せる。討伐後は再出現待ち、報告、個人の最速記録を既存のラボの保存へ引き継ぐ。

描画には既存の[第一形態](../../evidence/childe-reference-audit.json)と[魔王武装](../../evidence/childe-foul-reference-audit.json)の待機絵を使った。邪眼の本体は第一形態と共用し、雷の双刃と合図で区別する。弓、長柄、鯨、雷などは試作描画。ラボでは黄金屋の仮背景画像を使い、本番は3D配置を想定する。三形態別の低頭身ポーズ・連続アニメーション・音、装備別の戦闘検証は後続。

共闘では三形態のHP・技・変身を共有する。断流と解除はプレイヤーごとに持ち、追撃の対象に選ばれた組は操作交代後も追撃を受ける。 [入場ルートと共闘の検証](../COOP_WEB_PREVIEW.md#公子の週ボス戦)

[Luaの検証](../../evidence/childe-weekly-lua.json)は全12攻撃の時間割、断流、追雷・鯨・反撃の判定、二度の変身と一度の討伐を対象にした。Lv28、★3の羽を装備した旅人の通常攻撃のみで13.88秒、残HP94、回復・同行攻撃・戦闘不能帰還なしで突破した。

[Chromeの検証](../../evidence/childe-weekly-browser.json)では受注、門から入場、水断流を受けて交代・解除、三形態の討伐、報告とセーブ再開を確認した。同じ時点の魔王武装で[PNG](../../evidence/childe-weekly-png.png)と[軽量矩形](../../evidence/childe-weekly-light.png)を比較した。描画命令数はブラウザに渡す命令の集計で、幻境実機の計測は別工程。

## 追雷の追尾と固定

邪眼の追雷（WC10）は、追尾中に予告線が対象の移動を追う。技開始84tickで位置を固定し、解除が間に合わなければ144tickでその地点に落ちる。HUDには追尾中の金灯案内、固定後の回避案内、落撃の結果と残りの反撃時間が出る。共闘では追雷の対象と操作中のキャラへの被ダメージを組ごとに表示する。

獲得済みLv200セーブのコピーで、最上級の三形態を3回再戦した。同行者の攻撃を一時停止し、旅人が邪眼の攻撃から雷断流を受けて金灯で解除した。

| 金灯と回避 | 追雷の結果 | 反撃時間 |
| --- | --- | --- |
| 固定前に金灯へ（27tick） | 落撃中止 | 60tick（1秒） |
| 固定後に金灯へ（111tick）、予告線の外へ | 固定点に落撃、被ダメージ0 | 120tick（2秒） |
| 固定後に金灯へ（111tick）、予告線の内側へ戻る | 26ダメージ、雷断流を再付与 | 120tick（2秒） |

3戦とも反撃中の通常攻撃が32ダメージを与えた。討伐後に周回報酬を受け取り、再読込した最上級の勝数は各コピーで2から3になった。 [試走と描画の記録](../../evidence/childe-riptide-lock-20261128.json)

22場面の既存の矩形圧縮を測定した。中間画質の描画JSONは8,130,783 Bから1,507,675 B、軽量版は2,857,695 Bから672,846 B。各画質で展開した描画命令は圧縮前と一致した。追尾予告を出した時点など、同じ22場面のChromeの画素は今回の変更前後でも一致した。

ローカルChromeの通常戦では、検証用の花を装備して固定前の解除と固定後の回避を試した。HUDの「追雷中止」「落撃の被ダメージなし」をそれぞれ表示した後、第三形態を討伐し、依頼を報告して再読込した。停止した第三形態の軽量描画は、矩形のまとめ送りを切り替えても画素が一致した。gzip応答は固定前の試走で39,016 Bから29,819 B、固定後の試走で39,177 Bから29,963 Bに減った。Luaの4人共闘では対象と被弾者の表示を、ローカルHTTPの2人共闘では共有変身と個別報酬を確認した。

## 黄金屋から最上級4勝まで

断流が付いたときは戦場で近い方の金灯を明るくし、操作キャラの位置に応じて左か右を案内する。追雷の対象になったプレイヤーには、地点固定までの残り時間も表示する。共闘では他のプレイヤーが追尾されている間、落撃の予告から離れる案内を表示する。

若陀龍王の最上級5勝を記録したLv200セーブから、M地図で黄金屋へ進んだ。Chromeでは左の金灯で固定前に断流を解除し、水弓・邪眼・魔王武装を撃破。最上級初回の32,560,274 EXPと3,590,160モラを受け取り、北斗に依頼を報告した。 [初回と幅390pxの操作確認](../../evidence/earned-childe-first-expert-browser.json)

同じセーブからLuaで3回続けて再戦した。固定前の解除で落撃中止、固定後の解除と退避で0ダメージ、固定後の解除と予告地点への再進入で26ダメージと雷断流の再付与を確認した。撃破報酬は各18,999,684 EXPと1,538,640モラ。試走用には獲得済みの花へ付け替えて羽を外し、Luaでは水路の配達剣を使って反撃時間を確かめた。元の装備へ戻すと、Chromeで最上級4勝、再出現待ち、報告112件を読み戻せる。 [3回の連続試走](../../evidence/earned-childe-rematch-lua.json)・[Chromeで再開](../../evidence/earned-childe-rematch-browser.json)

再戦は `test_earned_childe_riptide.py --from-save SAVE --output-dir OUTPUT --weapon SW05 --chain` で再現できる。最上級初回と依頼を終えた上記のセーブを使う。ラボの配信中に `node test_earned_weekly_frames.mjs OUTPUT OUTPUT/comparison` を実行すると22場面を3画質で比較できる。 [描画比較の記録](../../evidence/earned-childe-rematch-frames-browser.json)
