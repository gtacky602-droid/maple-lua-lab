# 双杼織機

港の広場で「夜明けまでに織機を止める」を受注する。右手に並ぶ門のうち「埋もれた織房」へ向かう門から挑戦できる。

杼（ひ）は糸を送る左右の部品。片方を破壊すると、その部品の糸だけが止まる。両方を壊した直後に中央の扉が開き、13秒のあいだ芯を攻撃できる。時間が来ると左右の杼が再生する。本体の残HPは次の露出へ持ち越す。

| 行動 | 画面の予告と回避 |
| --- | --- |
| 左右の送り糸 | 左右の地上に順に帯が出る。片側の杼を壊すとその帯が消える。 |
| かがり糸の柱 | 行動開始時に位置が決まる。縦に長い予告の外へ横移動する。 |
| 床を走る横糸 | 低い帯が床を覆う。通常ジャンプか上段で避ける。 |
| 上糸・中央の返し縫い | 杼が再生した後に追加。左右上段の帯が消えた後、中央の低い帯が発動する。 |

Lv34、本体HP250、杼HP24ずつ。数値と報酬はラボの仮設定。芯を倒すと討伐記録が一度進み、360モラを得る。帰還報告は2100EXPと450モラ。ソロでは退出や保存再開で未完の戦闘が初期化される。討伐後は再出現待ちを保持する。週ボス台帳に独自枠として登録している。

共闘では、左右の杼と芯のHP、13秒の露出を共有する。全員で退避すると、壊した杼や芯の残HPを保持したまま進行が止まる。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#測潮機関士と双杼織機の週ボス戦)

本体の開閉と杼の破壊前後の4点を、PNGと同じ素材から作る3通りの矩形描画へ接続した。織房の仮背景と戦闘の足場は個別に描画する。連続アニメーション、難度別報酬、別端末間の通信、本番の3D背景は今後の作業。
