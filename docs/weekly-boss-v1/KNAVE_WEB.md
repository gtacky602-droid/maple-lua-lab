# 召使・凶月の再現戦

フォンテーヌ・水辺の広場で、Lv88の依頼「凶月の再現戦・命の契約」をリネから受注する。広場のx186にある門から入る。背景にはフォンテーヌの舞台裏の画像を仮置きした。本番の背景は3Dで用意する方針。

- HPは片鎌1080、凶月・双鎌1320の二段。最初のHPを削りきると240ティックで変身する。命の契約と羽印をキャラごとに引き継ぎ、変身中は侵食の時計を止める。
- 命の契約は対象の最大HPの25%を付与し、50%が上限。回復量は先に契約へ充て、余った分でHPを回復する。両端の返済灯はGか画面のボタンを長押しし、45ティック後の初回以降は30ティックごとに最大HPの5%を返す。途中で離しても返済分は残る。
- 契約を完済したキャラに羽印がつく。赤宴の受付表示を確認し、Hか画面の「償還の一撃」で通常攻撃を当てる。成功すると羽印を使い、その赤宴の後続判定が消える。ひざをついた後の反撃時間は3.6秒。赤月降臨は着地点と周囲の予告から離れてかわす。
- 各カードの開始・受付・攻撃・後隙はフォンテーヌ設計表に沿う。HP、攻撃の威力、依頼報酬、装備差、回避ルートは調整用の試作。帯や走路で当たり判定を示す。連続した斬り・変身のドット絵は制作中。

共闘では、同じ返済灯で別々に契約を返せる。赤宴を最初に中断したキャラの羽印だけを使い、反撃時間は全員で共有する。 [共闘の入口・操作・検証](../COOP_WEB_PREVIEW.md#召使の週ボス戦) · [ラボを開く](http://127.0.0.1:9054/)
