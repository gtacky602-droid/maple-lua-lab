# アペプのオアシス守護者：戦闘・心の防衛・蘇生の盾 v0.1

2026-11-17 JST。入口：[週ボスMASTER](../../DESIGN_WEEKLY_BOSS_MASTER_V01.md)。既存ID `boss-29080101`。18項目には守護者の攻撃、6種の増殖生命体、移行・防衛・保護状態を含む。アペプ本体の巨竜をそのまま倒すボスとは区別し、作品内表示は「アペプのオアシス守護者」。コード・画像・音・カタログ・HP倍率・報酬は今回変更しない。

## 1. 原作で残す攻略・参照の限界

一次の基準は[原神公式ボス紹介](https://www.hoyolab.com/article/17634171)と[公式サイト版](https://genshin.hoyoverse.com/en/news/detail/111055)。初戦→オアシスの心を守る蘇生→後半の守護者と広域攻撃・蘇生の盾、という攻略を残す。公式記事は画像主体で本文を取得できない箇所がある。[プレイヤーの実戦攻略](https://www.hoyolab.com/article/29620753)も参照する。細分化した行動は[コミュニティの実戦記録](https://genshin-impact.fandom.com/wiki/Guardian_of_Apep%27s_Oasis)を二次照合に使い、公式の技名・倍率と混同しない。

原作の防衛では心が攻撃されると進行が後退する。援護する生命体を見分けることが重要。後半の大技は保護の内側へ入って防ぐ。本書では各生命体の役割を横スクロールへ整理し、攻撃数・期限・進行値・出現順・物理による障壁破壊を独自に選定する。原作全行動のフレーム一致ではなく、モーション制作の開始値。

既存台帳は `apep-dark` が暗色の這う待機候補、`apep-prime` が緑の待機候補。増殖生命体、心、盾、変化アニメ、戦闘は完成素材ではない。既存の二つの原画を残して、胴・頭・前肢・尾・葉冠・発光紋を別部品へする。巨体へ人型3頭身規則を適用しない。

## 2. 三段階・舞台・勝敗

`DARK_COMBAT → WP05 → WP06(DEFENSE) → WP13 → PRIME_COMBAT → CLEAR`。初戦と最終戦は別HP区間、防衛中はHPバーの代わりに「オアシスの蘇生」を表示。心を敵弱点にして殴らせない。初戦HP0は移行、最終HP0は勝利で、残留攻撃より先に確定する。原作のHP倍率・草耐性・報酬曜日はここで設定しない。

U=旅人88px、60tick/秒、半開区間。比較床幅10U、心の中心x=5U・z=0、左右に幅2U・高さ1.4Uの補助足場。心は味方対象かつプレイヤーの通行を妨げない。増殖生命体は左右の入口から来るが、心から3.5U以上離れた位置へ予告付きで出す。背景は本番3D、PCラボは仮表示。

守護者は頭〜尾を5U程度、攻撃時の主形が高さ2.6U程度を比較開始値にする。長い体の節をすべて別HPにせず、ボスID共有で同一cast/eventは一回だけ減算。胴・尾の単なる接触ダメージは新設しない。最終戦の緑の姿でも、顔・前肢・尾の向きが前半とつながるように描く。

## 3. 防衛の進行P・出現制御

本作用のPは0〜100、初期25。毎60tickに+1、基本生命体をプレイヤー側が倒すと+3、特殊役は+8。心への確定した通常攻撃は-4、自爆の到達爆発は-18。原作の正確な進行割合ではなく調整開始値。心に別HPを追加せず、既存HP回復・盾でPが回復する仕様にもせず、HUDと同じ値だけを持つ。

同tickの有効な加減算を集約してからclampし、P>=100なら成功、P<=0なら試行失敗。破棄・消費・幕間cleanupの死亡に撃破加算を付けない。多人数でもP・出現数・敵HPは共有で人数倍率なし。各撃破IDは一度だけ。プレイヤー全員が戦闘不能なら既存の敗北ルールを優先、ロノヴァの残機は付けない。

初期波はt60に基本4体。P40で護衛役＋基本3、P60で飼育役＋基本3、P80で捕食役＋障壁役を一度ずつ予約する。閾値が後退して再上昇しても同波を二度予約しない。波間は最低300tick、生存上限8体。上限に達した予約は次の空きを待つ。特殊が残り続けても、必要な基本個体の枠を予約して支援リンク先の欠落で進行不能にしない。

生存が2体以下で480tick補充されなければ基本3体を補給。開始3600tick以降は自爆役を最大1体だけ追加、次は600tick以上間隔。これは本作用の長期化抑制で、突然の制限時間敗北や無限の敵強化ではない。P成功時に残敵・障壁・リンク・飛翔体を消し、掃除による追加報酬を出さずWP13へ。

既存の「普通モブは基本モーション一つ程度」を守り、6役は一つの主動作と待機・移動・消滅を基礎に作る。攻撃火花を増やすより、支援元と対象を結ぶ線、膨らむ自爆体、接近の影を優先する。

## 5. 技ごとの時間・キー姿勢・安全情報

### WP01 長躯の薙ぎ：210tick、prime差分264tick

通常t0–36に頭が横へ引かれ、前肢を支点に胴と尾を反対側へ溜める。t36方向LOCK、ACTIVE[84,96)に前方2.4U・高さ1.1Uを払う。RECOVERY[132,210)。頭→胴節→尾の順に曲がり、尾は12tick遅れて戻る。体の全画素を当たり判定にせず、警告した弧の1hitだけ。原作の広い回転を横の払いへ翻案。

prime差分は二払い、ACTIVE[84,96)と[144,156)、t108に第二弧を明示、RECOVERY[180,264)。各1hit。暗色の土埃から緑金の短い光へ替え、長い煙を残さない。近接でも間合い外へ逃げられる道を確保し、巨大な胴を飛び越えることを唯一の対処にしない。

### WP02 前肢の四連：336tick、短縮216tick

t0–36に前肢を高く折り、次の床4位置を薄く表示。LOCK36。ACTIVE[72,78)、[108,114)、[162,168)、[222,234)、RECOVERY[252,336)。順は前方の薙ぎ、地面叩き、低い払い、重い終撃。手前奥の前肢で力を掛ける位置をずらし、最後は頭が下がって反撃の合図。各1hit、最大4。全て同じ地点へ無制限に追跡しない。

短縮版は最初から光点2つ、二撃で腕をほどく。ACTIVEは前二つのみ、RECOVERY[132,216)。四連版を二連終了に見せて隠し追撃しない。元の一つの姿勢群を前半だけ使い、素材数を抑える。

### WP03 潜行・再臨：330tick

t0–48頭を沈め、身体が地面へ畳まれる。t48–150は本体HPターゲットを退場。t72で出現位置LOCK、明るい輪を地表へ残す。ACTIVE[180,192)に局所浮上、[216,222)に前方横払い、RECOVERY[246,330)。潜っている胴を別対象として殴らせず、地面を追う土の盛り上がりに追加接触判定なし。後半は同じ時間で緑の軌跡へ置換。首を伸ばす→前肢接地→胴が続く、の順で再出現し、別の位置へ一瞬で絵を飛ばさない。

### WP04 地中の四肢：420tick

t0–60：四つの細い肢を床へ差し、4つの着地点をロック。ACTIVE[120,126)、[180,186)、[240,246)、[300,306)、RECOVERY[336,420)。場所を一つずつ光らせ、長い肢が地表へ現れて叩く。各1hit、判定幅0.9U。四本全てを画面いっぱいに描かず、遠景の根元と前景の先端を分離。4地点の和が全床を塞がない。地面に埋まった見えない肢にもHPを持たせない。

### WP05 心の露出：180tick

初戦HP0で一度だけ。全攻撃を止め、暗い体が縮んで舞台奥へ沈む。t48に心の輪郭、t96に中心の白金の種、t144に左右入口の薄い表示。RECOVERY[144,180)は非攻撃の場面移行で、ボスへの反撃ではない。t180にP25を設定してWP06開始。BGM変化は独自素材、HPゲージを蘇生進行へ切り替える。原作の長い物語カットを毎回挿入しない。

### WP06 オアシス防衛：イベント状態

3節の進行と出現を管理。心は友好target、プレイヤー攻撃は通り抜け、敵の心対象eventだけPを減らす。残る総数・特殊役のアイコン・進行を一行にまとめ、ダメージ数字列とは分離。敵が心へ到達しただけで即減算せず、各モーションの攻撃成立時だけ減らす。近接敵が1秒に何度も心へ当たらないよう、同一個体の攻撃間隔は180tick以上。

HP回復や味方シールドが心へ自動転用されない。通常敵を攻撃してもPに直接ダメージを与えない。HPの敵選択とPの増減を別ログにする。誰かの範囲攻撃でまとめて倒した場合は各個体の一度の撃破を加算するが、フェーズ掃除には加算しない。

### WP07 基本増殖体：近接150tick／小弾210tick

近接：t0–24に丸い身体を縮め、対象を固定。ACTIVE[60,66)に一回の突き/叩き、RECOVERY[90,150)。攻撃対象が心ならP-4、人なら既存通常ダメージを一回。見た目の接触だけでは発動しない。

小弾：t0–30に先端を持ち上げLOCK、t72に一発、速度3U/秒・寿命72tick、最終t144失効、RECOVERY[150,210)。一弾の衝突で心または人のどちらか一対象だけに作用。近接と弾は同一個体に同時に持たせず、出現時に役割を固定。単純な1動作・小さい被弾点滅・短い消滅で十分。派手な火花は主人公の攻撃側に任せる。

### WP08 護衛増殖体：イベント支援

主動作は頭部を開いて薄い緑の膜を送る一回の展開。半径2U内の基本体を最大3体守り、元を示す線を描く。対象は基本体だけ、護衛同士・他支援役を守らない。護衛本体には盾なし。プレイヤーは源を倒すと対象の無敵を即時解除、膜は12tickだけ解ける装飾。物理で源を倒せるため特定元素不要。リンク中の対象に命中した場合は『保護』を小表示し、実HP減算を装飾数字で偽装しない。

### WP09 捕食増殖体：300tick

近くの未保護・未飼育の基本体一体を選び、t0–42に口/腕を開く予告。t60でそのIDを消費し強化表示。消費はプレイヤー撃破でなくPを増やさない。該当個体が死んだら空振りの捕食へ切替、存在しないHPを盗まない。攻撃はACTIVE[90,96)、[126,132)、[162,168)、[198,204)、RECOVERY[228,300)。一度距離を詰めて4回噛む、再照準は最初の接近まで。対象はプレイヤー、心へ4連打しない。

基礎噛みの一動作を4回使い、強化後は腹の紋だけ太くする。原作の長い連打を本作では四打へ短縮。倍率は別調整で、今ここに未検証の数値を足さない。消費候補がない場合でも戦闘が停止しない。

### WP10 飼育増殖体：イベント支援

主動作は花状の頭を上下させ、基本3体へ金緑の線をつなぐ。自身は3枚の外殻を表示し、リンク相手がプレイヤーに倒されるごとに一枚を失い、3枚全て消えると無防備になる。元の超高耐性をそのまま数値移植せず、敵を選ぶ仕組みとして明示。外殻中にも通常攻撃でゆっくり削れる調整余地を残し、倍率は別承認。

必要な基本体はWP06が予約。リンク候補不足なら不足枚数は付けない。対象は護衛を受けていない基本体だけとし、護衛＋飼育で無敵の輪を作らない。対象のフェーズ掃除/消費でPを増やさず、リンクは必ず解除。強化対象は腕の線を太くし攻撃テンポは変えない。原作の支援関係を横画面で読みやすくした独自の殻3枚ルール。

### WP11 障壁増殖体：300tick

t0–48に身体を縦へ伸ばし、置く壁の位置を固定。t90に最大2枚の薄い有機板、寿命180tickでt270消失。RECOVERY[276,300)。攻撃ダメージなし。心への一本道を閉じず、通路幅1.2Uか通常ジャンプで越える経路を常に残す。操作キャラが新規に当てた攻撃group2回で壁を壊せる本作代替。味方AIも明示した壁を攻撃可。

壁は灰緑の実線輪郭で実衝突と一致、粒子は少なくする。移動/同期が検証できない初版では『壊せる実障害』を有効化せず、見た目だけの壁を完成ギミック扱いしない。敵死/防衛終了で直ちに判定解除。壁に囲まれた正解のない閉路を生成しない。

### WP12 自爆増殖体：接近後240tick

心に近づく経路の入口を60tick前に知らせ、転がって接近。心から1.5U内でこのカード開始。t0–36に膨らみ、位置を固定。t48–126に心の前まで短く転がり、t126–150は明白な点灯カウント。ACTIVE[150,162)に一回破裂、RECOVERY[180,240)は消滅。心P-18、近傍プレイヤーには既存ダメージ一回。爆発前撃破なら爆発は取消し、特殊撃破P+8だけ、原作の元素エネルギー回復を光界へ転用しない。

死亡と爆発が同tickなら先に受理した撃破を優先して爆発を止める。残った粒子を次の爆発として当てない。常時大点滅させず、膨らむ輪郭と短い三つの点でカウントを示す。

### WP13 原初の蘇生：210tick

P100を確定後、残敵・壁・支援・未着弾弾・予約を取消す。t0–60に心の光が幹のように伸び、t60–120に緑の守護者が姿を形成、t120–180に葉冠が開き前肢が接地。RECOVERY[180,210)は非攻撃の移行。t210で最終HP区間を有効化。心は背景へ退き防衛の攻撃対象から外す。暗色の単純色替えではなく、姿勢・葉の開き・光の流れを変える。

### WP14 螺旋の光雨：330tick

t0–42に胸と葉冠が開き、3本の射線をLOCK。t90/126/162に3発ずつ、速度4U/秒・寿命90tick、最終消失252。RECOVERY[270,330)。各三発を一つのattackGroup最大1hit、cast最大3。二重螺旋の2本の線は一本の弾で二重ダメージにしない。原作の多数弾を9発へ整理し、固定した隙間を残す。顔や自機が緑の粒子で埋まる場合は弾の尾を先に削る。

### WP15 三度の天撃：360tick

t0–48に頭を高く、床3位置と順番を表示してLOCK。ACTIVE[108,114)、[180,186)、[252,258)、RECOVERY[288,360)。各円幅1.4U、同時に一つ、上段に落とす場合は足場IDを明示。地面の緑の細い外縁→縦に落ちる光→4片の葉脈破片18tick。前半の物理の肢とは違い、身体が直接来ない遠隔攻撃として見せる。cast最大3hit。

### WP16 蘇生の保護：120tick

WP17と一つの親シーケンス。t0に現在の通常攻撃と弾を解除、中央へ非攻撃の再配置。t30に三つの芽、t60にx=1.5/5/8.5Uへドーム完成、各寿命660tick（親時刻t720まで）。t120からWP17を開始。単に味方が持つ盾ではなく、指定の余波だけを防ぐ舞台領域。枠と内側の安全矩形を同時に示し、見た目の丸い縁ぎりぎりを安全と誤認させない。

安全矩形は幅1.4U・高さ1.5U、外殻は幅1.8U・高さ1.8U。各actorの足元基準点とhurtboxが内側へ収まったことを判定し、体格差が不利なら内側幅を調整する。ドームに人数制限なし、3つのうちどこでもよい。普通の敵弾を全て消す万能盾は付けない。

### WP17 終末の余波：600tick

WP16のt120を子のt0とする。t0–120に守護者が身体を上下へ縮め、周囲の地面に緑金の筋を増やす。通常波ACTIVE[120,126)、[210,216)、[300,306)、最後の大衝撃[420,432)。RECOVERY[480,600)は余光の収束。原作の連続床ダメージを、初版では予告した3脈動＋一終撃へ明示的に簡略化。各波group一回、cast最大4要求、通常HPダメージで確定死なし。威力は別調整。

各ACTIVEの時点で内側安全領域にいるactorはこのgroupを受けない。シールドの物理破壊HPや消費回数を設けず最後まで保つ。親時刻の終撃[540,552)と全体終了t720を、ドーム寿命[60,720)が覆う。守護者の跳ねる絵そのものには別接触ダメージなし。画面を緑に塗るのではなく床の筋・奥の波・白金の短い外輪で表現する。

同時にWP14/15を重ねてドームへ行く道を消さない。AIはドームへの退避を最高優先にし、未実装ならAI同行で成立と宣言しない。未到達のプレイヤーを自動移動させず、位置と残時間を示す。大技中HP0を達成可能な実装なら勝利が先、死んだボスの余波を継続しない。

### WP18 余波後の脱力：600tick
