## 2. 身体・戦場・状態の所有

U=旅人表示高88px。60tick/秒、半開区間[start,end)。世界x右、z上。幅10U、床z0、常設上段x[1,3]/[7,9]U・z1.6Uを比較する。移動性能・足場は実測後に調整し、現行マップをこの文書だけで変更しない。

本体は約3頭身・144pxを比較値、足元Rと浮遊描画offsetを分離。白青の髪、白黒の衣服、金青の輪、長い布端を識別記号にする。月輪・三つの月具・射線・柱・擬影は別素材。指先→月具の回転→攻撃の順で、本人が静かでも開始を読めること。既存待機候補を全姿勢完成と扱わない。

状態は `OUTER → RIFT_VOTE → ENTER → INNER → RETURN → OUTER → CLEAR`。禁令・柱大技はOUTER専用。HP0を優先し、未実施のギミックを見せるためにHPを1へ固定しない。手前の本体の足元を攻撃可能にし、浮遊の見た目で剣が届かなくならないようにする。

HP、禁令owner、違反フラグ、裂け目cycle、擬影HP、損傷付与予算、回帰予算を別管理。マルチ人数によるHP/弾数増加なし。他人の復活なし。画面の中核はHPと、現在必要な禁令または残数一行だけ。

## 3. 禁令は入力・同行AI・連撃と矛盾させない

WM09/10はt0で大きな記号と短文を表示、t120まで準備、判定は[120,420)、t420に各人の結果を確定。ボスは動かず、他の危険・強制移動・裂け目移動を重ねない。開始前に全生存操作キャラが着地していること、残行動ロックが準備時間内に終わることを確認。不成立なら通常の安全な待機へ延期し、プレイヤーの技を無料キャンセルしない。

「停止」は、新しい能動移動・回避・ジャンプ、または新規発動したroot移動付き攻撃が判定期間に成立したときだけ違反。準備前からのモーション残移動、ノックバック、同期補正、AI歩行、既設の持続攻撃、描画上の呼吸は数えない。保持Jによって判定開始後に新しい移動技が発動するなら違反候補なので、準備中に『移動する連撃を止める』合図を出す。入力や移動の出所が区別できない場合は推測判定を実装せず、その条件を未対応として報告する。

「直視しない」はカメラでなく操作キャラの論理facing。ロックしたボス位置へ向くと違反。自動照準だけによる向き補正は判定から除外する本作案。プレイヤーが新しく向き付き攻撃を要求した場合は、その実行方向を判定する。ボスと同じx付近では開始前にボスを非攻撃再配置し、左右どちらへ向くべきか曖昧にしない。

1人につき1禁令1違反まで。交換しても違反は同じrealPlayerIdに残るが、交代入力自体は違反にしない。AIは明示した『禁令待機』姿勢、既設効果は継続してよい。AIが違反判定を受けたり人間の罰を増やしたりしない。成功の報酬は反撃機会で、エネルギーの増減なし。

罰はt420からWM12を違反者ごとに開始。位置を予告した一発のみ、拘束なし。t600までに全員分を解決して次へ進む。成功者にも罰の図形を表示するが、その攻撃はowner本人にだけ有効。同人数でHPを変えず、他人の失敗を無警告で伝播させない。

方位反転は別扱い。WM11の初版は入力を反転しない安定入力版。月輪と進路矢印が反転する非攻撃状態として攻撃機会を残す。実移動軸を反転する原作寄りの版は採否待ち・実装対象外。見た目だけで実反転を実装したと報告しない。

## 5. 時間・ポーズ・判定

### WM01 月輪の転位：150tick

t0–36、片手を開き到着候補を白い輪で表示。t42位置LOCK、t72に本体を移動、布端は旧位置で12tickだけ溶ける。RECOVERY[96,150)はHP攻撃可。出現前後の接触ダメージなし。到着点は床上・隣接キャラから1.2U以上、不可なら元位置で構え直す。無予告背後攻撃へ連結しない。

### WM02 三条の水光：300tick

t0–42に背面の三月具が扇形に開きLOCK。ACTIVE[96,108)、[156,168)、各窓3本を同group最大1hit、cast2。RECOVERY[216,300)。三つの細いcapsuleは正面1〜4Uの低/中/高へ、最低1.2Uの間合い外か常設上段を安全にする。水は滑らかな白青の帯、雷の折れ線と区別。第二射で位置を追い直さない。

### WM03 雷線と追雷：360tick

t48に地上列と二つの落雷点LOCK。地上ACTIVE[108,120)、高さ0.5U、続く落雷[204,210)、[264,270)は幅0.7Uの別地点。後発地点はt144から再強調。RECOVERY[300,360)、最大3hit。雷線は折れた短い節、空の月具から床の印へ線をつなぎ、上段を警告なく貫かない。

### WM04 三月の近接連奏：480tick

t0–48に片腕を引き、手首の槍先と正面をLOCK。ACTIVE[96,102)前方突き1.8U、[168,174)三雷線、[252,258)氷の横弧2U、[336,348)水の水平帯3U。各1、cast4。RECOVERY[396,480)。槍先→三点→氷の刃→水管という形で残る手数を読む。すべて背後へ追尾せず最初の方向を保つ。既存通常の連撃へ無料中断を追加しない。

### WM05 古月の落柱：420tick

t42に5地点を固定。ACTIVE[108,114)、[150,156)、[192,198)、[234,240)、[276,282)、各幅0.65U・高さは対象足場から2U。RECOVERY[324,420)。金属的な欠片が先に集まり、柱の先端→全体→床破片の順。落下後に実障害物や保護を残さない。WM08の保護柱と区別するアイコンを使用。

### WM06 雨の逆行：540tick

t42、3つの落下点LOCK。雨ACTIVE[96,102)、[156,162)、[216,222)。t300–360に雨粒だけ空中で停止して逆へ流れ、周囲半径2Uの予告を別に表示。破裂ACTIVE[396,408)、RECOVERY[444,540)。cast4。止まるのは専用FXのみで、ゲーム時計・プレイヤー・CTは逆行しない。キャラへ通った過去の損傷を巻き戻さない。半径外の床まで実際に移動できるか要試験。

### WM07 月影の跳刃：432tick

t48に3つの入口、t276に締めの3影の走路をLOCK。ACTIVE[90,96)、[162,168)、[234,240)、[330,342)。最初の三打は一体ずつ、最後の三影は同group最大1、cast4。RECOVERY[360,432)。薄い人影→刃先の点灯→跳ぶ→消える。外界の影は攻撃実体で、HP/経験値なし。WM15の倒す影とは輪郭の実線/破線を変える。

### WM08 偽月の衝撃と遺骸：480tick

参加者のロードと着地を確認してから開始。t60にx1.8/5/8.2Uの三柱と安全側の空洞矩形を予告。落柱ACTIVE[120,126)、三柱合計group1。t150に各柱の背面に保護領域、寿命[150,420)。中央の月具は上昇、t300に巨球の縁が収束、衝撃ACTIVE[360,372)、group1。RECOVERY[420,480)はHP攻撃可。全cast最大2要求。

柱の保護は指定衝撃だけを無効にする舞台条件で、一般の岩生成物や盾へ転用しない。安全内側幅1.4U、高さ1.5U、判定はhurtbox全体の包含を基準とする。柱そのものは移動を封鎖しない。危険落下位置と、その後の安全位置は別表示。原作の割合多段・貫通・エネルギー補充ではなく、通常一発の大ダメージへ翻案。保護の外にいても確定死フラグは使わない。全体白フラッシュをせず、背景の球と前景の細い衝撃輪で見せる。

### WM09 禁令・停止／WM10 禁令・直視：各600tick

両カードともt0月具が一つ前へ出る。WM09は閉じた足跡、WM10は背中を向ける人影。t0–120準備、[120,420)だけ判定、t420結果を確定。違反があればWM12をt420から子として実行。親のRECOVERY[516,600)はHP攻撃可、成功者も他人の罰に遮られない距離から攻撃できる。全員成功ならt420から攻められるが、索引の共通後隙は516以降とする。

5秒の判定中に未通知の追加禁止を出さず、停止と直視を同時に要求しない。各人の判定結果はアイコンで表示。準備が来た瞬間にスキル入力を無効化せず、行動ロックが準備内に終わることを開始条件とする。長い技を発動している間は開始延期。最大待機が必要なら通常技選択へ戻し、永久に禁令待ちにならないようにする。

### WM11 方位の錯乱・安定入力版：420tick

t0–90、月輪の矢印が左右を交換。t90–330は逆向きの背景格子のみ、本人は静止しHP攻撃可能。RECOVERY[330,420)。実入力・移動速度・攻撃方向は通常のまま。この初版を操作反転の再現済みとはしない。実際の反転状態を追加する版はアクセシビリティ・連撃・AI・同期の検証と別承認が必要。

### WM12 禁令の罰：180tick（禁令の子）

t0で対象者の足元へ円、t36位置LOCK、ACTIVE[60,66)に氷の小柱一回、RECOVERY[96,180)。拘束/CT没収なし。半径0.55U、owner本人だけ通常ダメージ。移動で避けられる別予兆を残す。判定が始まるのは禁令終了後なので、避けた移動を再違反にしない。生存側へ交代していてもrealPlayerIdの現在操作キャラをt0で選び、既にペア全滅した人には発生しない。

### WM13 蝕月領域と入口：イベント状態

外界に一組だけ。床のx2/5/8Uに半径0.55Uの淡赤領域、最大900tick。中の小氷波は出現180tick後から180tickごと、一actorにつき同周期最大1。各波は36tick前に表示。初版は行動速度低下・攻撃硬直延長なし。元の危険の表現を保ち、ルートの狭さで位置を意識させる。幅1.2U以上の接続経路を残す。入口はt120に中央の安全側へ開く。

共同場面切替は生存している実プレイヤー全員の文脈確認を受付し、全員同意後90tickの予告でWM14へ。拒否/期限/死亡があれば再集計し、強制的に別マップへ連れ去らない。ソロは一回確認。未参加者を外界に残して二画面同時戦闘にしない初期案。入らず通常HPを削っても勝利可能。期限切れは領域を消去、再設置まで600tick以上。WM09/10/08中は設置と移行を開始しない。

### WM14 裂け目への移行：180tick

t0に外界の攻撃と禁令予約を取消し、t90でINNERへsceneEpochを一度更新。本人の輪が奥へ縮み、入口が画面奥の舞台へ広がる。RECOVERY[144,180)は非攻撃の移行。HP/CT/光界/死亡者を回復しない。全生存actorを同じ安全床へ配置し、入力受付が戻るまで敵の攻撃なし。

### WM15 異界の三擬影：イベント状態

x2/5/8Uの地上に三体の独立HPの影。最大1800tick、再挑戦の各個体最大HPは別バランス値。主動作は剣先を床へ向ける一姿勢、各影が180tickごとに低い氷の波を一回、発生72tick前に予告。位相0/60/120tickでずらし、全地上を同時に塞がない。通常攻撃と全元素で処理可能、引寄せ必須なし。

実際に倒したIDを記録し、WM16帰還時に一体につきボスMaxHP4%相当を別作用で一回だけ付与する初期案。全戦で固定損傷合計24%MaxHPを上限、予算0でも影を倒せば領域解除と露出は得る。原作の損傷割合やCTリセットを再現する値ではない。cleanup・退出・タイムアウト消去で撃破数を増やさない。

全三体撃破または全生存者の出口確認、期限でWM16。途中退出なら既撃破IDと未払分を同cycleへ保持し、同じ影を復活させて固定損傷を稼げないようにする。外界側の攻撃はこの間更新せず、罰や弾が別空間を追尾しない。

### WM16 異界崩落・帰還：540tick

t0に全影の攻撃を消し、t90で外界の安全床へ戻る。t96に未払い撃破分を上限内で一度精算。HP0なら勝利、それ以外はEXPOSURE[120,480)の6秒。月具が傾き、本体は近接が届く低位置で静止。RECOVERY[480,540)は再浮上でHP攻撃不可。全戦の損傷予算・各cycleの支払済みIDをsceneEpochと別に保持。死亡者は蘇生しない。

### WM17 偽月の回帰：360tick

受理済みの単一HP損失がMaxHP25%以上、本人が生存、回帰未使用のとき一戦一度だけ予約する初期案。HP0が先なら発動しない。t0–72、本体は後ろへ傾き、布と月輪だけが逆再生。t120の回復は `min(その損失*0.5, MaxHP*0.10, MaxHP-currentHP)`。回復予算10%MaxHPを超えず、映像の巻戻しで入力や全戦闘を巻き戻さない。RECOVERY[180,360)はHP攻撃可。

連打/多段を一つの架空単発へ合算して発動させない。回復条件が資料と一致するとは主張せず、強い一撃が無限に帳消しになるのを防ぐ本作値。ボスが120までに死亡したら回復予約も取消す。旧HPへの丸ごと復元は禁止。

### WM18 禁令・場面・終了管理：イベント状態

HP0勝利→有効な破壊/帰還精算→禁止判定終了→期限の順で同tick競合を処理。禁令罰はruleId/realPlayerIdで一回。弾はcastId/eventId/victimId、場面作用はsceneEpochで区別。再接続だけで回帰使用済み/損傷予算を戻さない。退出・新試行は全て初期化。禁止判定未対応、共同移動未対応を見た目だけで完成と呼ばない。

## 6. 作画・音・実機へ渡す条件

本体の低い待機、指差し、開掌、胸前の槍、浮上、後傾、帰還後の低下を共通姿勢として作る。月具3種は形を分け、白青の水、折れた紫雷、角張る氷を混同しない。禁止アイコンは危険予兆より常時大きくせず、判定期間だけ上中央に一行。数字が多い場合は装飾と数字を先に減らす。

音は月具の起動、LOCKの一音、禁令の開始/終了、違反一回、裂け目の共鳴を分離。音なしでも同じ情報が分かる。通常shake0、大衝撃のみ最大2px/10tick、reduced_motionは0。白フラッシュ・画面反転・公式ボイス抽出なし。

必須QA：禁令開始待ち、旧cast/新castの区別、facingと自動照準、AI除外、交代とrealPlayerId、罰の親子終端、保護の寿命、共同移動の拒否/死亡/再接続、影の一度だけ精算、回帰回復の上限、HP0優先。実プレイ・経路・入力・同期・FPS・原作全フレームは未検証。技ロジック実装の保留は解除しない。
