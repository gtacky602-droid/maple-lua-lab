# 淑女の週ボス試作

稲妻・城下の広場でLv44の依頼「天守の再現戦・氷と焔」を受注し、広場のx995にある入口から入る。マップの左右に温度装置がある。そばに立つと蓄積が下がり、Gを長押しすると蓄積を0にして周囲の床を消す。画面の「装置を放出」ボタンでも長押しできる。

氷形態のHPを削り切ると氷の繭ができる。繭が開いたら紅蓮蛾を拾い、次の手動攻撃を繭に当てる。紅蓮蛾がなくても通常で1、炎で5削れる。紅蓮蛾を使った一撃は25削る。繭が割れると変身を挟んで炎形態へ移る。討伐後は拠点で報告できる。

## 試作値と制作範囲

- Lv44、氷480・炎800、繭の強度100、装置の入力30tick。HP、被ダメージ、床の幅、移動距離と報酬はラボでの暫定値。
- 『淑女』のカード WS01〜WS16 をもとに、通常行動と繭・変身・床・温度装置を実装した。行動ごとの検証対象は [稲妻の検証仕様](QA_INAZUMA.md) と [マニフェスト](MANIFEST_INAZUMA.json) に記録している。
- 氷・炎の本体は既存のラボ用ドット絵を使用する。床、紅蓮蛾、装置や竜巻は形と当たり判定を確認するための仮描画。ラボでは天守の仮背景画像を使い、本番は3D配置の方針。連続アニメーション、難度・報酬の調整、幻境実機での検証は次の制作範囲。

## ローカル共闘

二形態のHP・氷の繭・蛾の出現位置・温度装置を全員で共有する。蛾と温度の蓄積はプレイヤーの組ごとに持つ。装置の放出が温度を下げる範囲は周囲の組に限られる。 [入場ルート・共闘の検証](../COOP_WEB_PREVIEW.md#淑女の週ボス戦)

## 紅蓮蛾と霜眼を使う最上級再戦

獲得済みの同じLv200セーブで、氷480・炎800の最上級を2戦した。紅蓮蛾を拾って手動攻撃を4回当てると、繭の強度は100から75、50、25、0に下がった。変身中も最後の一撃の結果が短時間表示され、繭を割ったことが分かる。

炎形態では同じ位置に焼尽の雨を誘導し、発生した火床2か所から左の霜眼へ移動した。Gの30tick長押しで霜眼を放出すると、灼熱はその場で0%になり、近い火床1か所が消えた。同じ技の295tick時点では、放出経路の灼熱は約0.4%で火床1か所、近くに立って冷却した経路は8%で火床2か所だった。両戦とも最初の灰燼の竜巻を越え、2秒の反撃中に通常攻撃で64ダメージを与えた。討伐後に周回報酬を受け取り、再読込で最上級の勝数が2から3へ増えた。 [再戦記録](../../evidence/signora-moth-release-20261128.json)

Chromeの通常戦でも検証用の花を装備し、両経路で繭を割り、火床の差を見た後に討伐・依頼報告・再読込まで確認した。Lua4人・ローカルHTTP2人の共闘では、繭への一撃の結果は当てた組に、放出結果は装置の近くで冷却された組に表示された。

25場面で既存の矩形圧縮を比較し、中間画質の描画JSONは81.28%、軽量16色は77.74%減った。各画質で圧縮を展開した描画命令は圧縮前と一致し、HUD変更前後のChromeの画素も全50組で一致した。Chrome通常戦の炎形態を止めて軽量16色で切り替えた場合も、画素が一致し、放出経路のgzip応答は34,760 Bから28,250 Bに減った。 [描画と共闘の測定値](../../evidence/signora-moth-release-20261128.json)

## 天守の装置案内と最上級3勝

操作キャラから近い使用可能な装置を案内する。段差の上にいて装置に届かないときは、装置のそばの床へ降りるよう表示する。装置の範囲に入ると放出ボタンが使えるようになる。Gキーやボタンの長押し中は、放出までの進み具合を装置の上にも表示する。

黄金屋の最上級4勝を記録したLv200セーブを使い、M地図で天守へ進んだ。Chromeの最上級初回で紅蓮蛾4回を使って繭を破り、左の霜眼を放出して火床を1か所消した。32,560,274 EXPと3,590,160モラを受け取り、綾華へ報告して36,000 EXPと3,000モラを受け取った。 [Chromeの初回記録](../../evidence/earned-signora-first-expert-browser.json)

同じセーブで続けてLuaの再戦を2回行った。左の霜眼を放出した戦闘ではその場で灼熱が0%になり、焼尽の雨の295tick時点で約0.4%・火床1か所だった。霜眼のそばに立って冷却した戦闘は同じ時点で8%・火床2か所。両方で灰燼の竜巻の後の反撃と周回報酬を確認した。試走では獲得済みの花を一時装備し、Lua再戦には水路の配達剣を使った。元の装備へ戻したセーブで、最上級3勝、再出現待ち、依頼報告113件をChromeで読み戻した。 [連続再戦](../../evidence/earned-signora-rematch-lua.json)・[Chromeで再開](../../evidence/earned-signora-rematch-browser.json)

初回の討伐と依頼報告を終えたセーブを `test_earned_signora_release.py --from-save SAVE --output-dir OUTPUT --weapon SW05 --chain` に渡すと、放出して冷却する戦闘と霜眼のそばで冷却する戦闘を続けて試せる。ラボの配信中に `node test_earned_weekly_frames.mjs OUTPUT OUTPUT/comparison` を実行すると、長押し50%の場面を含む26場面を3画質で比較できる。 [描画比較の記録](../../evidence/earned-signora-rematch-frames-browser.json)
