# 測潮機関士

ラボ独自の週ボス試作。港の広場で「夜間の潮位点検」を受け、広場右寄りの門から潮位較正室へ入る。測距・振り子・排水制御の三段階を攻略し、同じ門から港へ戻って報告する。

| 段階 | 行動と回避 |
| --- | --- |
| 測距 | 測距パルス、反響パルス、床下の圧力波。予告位置を見て横へ移動し、低い波は跳ぶ。 |
| 振り子 | 振り子払い、二連振り子、左右の検査光、反響パルス。前方の払いを避け、二連目は足元の予告を読む。 |
| 排水制御 | 排水弁の三連波、水門整流、両側排水と中央噴流、反響パルス。高さの違う波と、順に入れ替わる安全地帯を使う。 |

測距パルスで実際にHPを失うと、そのキャラに22秒の測距印が付く。緑の接地板に立つか、時間経過で解除できる。印のあるキャラが反響パルスでHPを失うと追加ダメージが発生し、印も消える。上段を経由して板の真上にいる間は印が残る。

段階切り替えは残HP70%と34%を目安に、現在の行動の後に起きる。HPは三段階で共有し、機構を交換している間も攻撃が通る。Lv30、HP650、討伐340モラ、依頼報告1800EXP／420モラは試作用。途中退出・全滅・保存再開では未完の戦闘が初期化され、討伐済みなら再出現待ちを保存する。

ドット絵は真鍮の計器頭、紫の作業外套、測距器、振り子、三脚機構を描いた6姿勢。各姿勢の足元と胴の基準位置をそろえた。背景は潮位計と排水設備を描いたラボ用の仮画像。本番背景は3D配置を想定する。

素材の生成条件と切り出しは [美術記録](../../evidence/tide-surveyor-art.json)。残る制作項目は連続アニメーション、難度別報酬、マルチと実機検証。
