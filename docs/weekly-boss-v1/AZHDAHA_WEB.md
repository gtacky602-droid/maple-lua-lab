# 若陀龍王の週ボス Web試作

璃月・港の広場で「伏龍の再現戦・二つの地脈」を受注する。港の受付で元素の組み合わせを選び、x635の門から伏龍の再現戦へ入る。Lv32、HP1,500と報酬は比較用の試作値。戦闘は[個別設計](AZHDAHA.md)と[璃月の時間割](MANIFEST_LIYUE.json)を基にしている。

- 炎／水のいずれかと雷／氷のいずれかを選べる。初期選択は炎＋氷。HPが2/3と1/3に達すると、発生中の危険が終わってから吸収へ進む。吸収がt396に達すると本体を再び攻撃できる。大ダメージで討伐に達した場合も、追加の吸収やとどめは要求しない。
- WZ01〜14を実装。炎の咆哮は残留する床、水の咆哮は動く球、雷と氷の結晶は固定した射線や落下位置を使う。雷の尾戦は安全帯を左・中・右の順に移し、氷の尾戦は各局面で一回まで当たる。
- 「潜地・落岩」中は本体が攻撃対象から外れる。「樹尾の戦場」中は同じHPを共有する唯一の対象が露出尾に移る。尾で倒しても残留攻撃と刻印を消し、週ボス報酬と個人記録は一度だけ付与する。
- 刻印は被弾した旅人・仲間ごとに保持する。シールドがあった攻撃では、攻撃でシールドを失っても新しい刻印を付けない。シールドを得ると解除。未解除の場合は8秒で消え、最大7回の周期ダメージを受ける。

既存の[若陀龍王の待機候補](../../evidence/azhdaha-reference-audit.json)を本体に用い、元素の結晶、予告、露出尾は試作描画で表現した。背景は璃月の仮画像。本番では3D配置を想定する。四足の動きと尾の専用作画、装飾音、装備別・マルチ・実機での検査は後続。

[Luaの検証](../../evidence/azhdaha-weekly-lua.json)で四組の選択、二度の吸収、全カードの時間割、三つの安全帯の移動、刻印、尾での討伐、報告と保存を確認した。[Chromeの検証](../../evidence/azhdaha-weekly-browser.json)は水＋雷で入場し、二度の吸収・尾への進行、討伐、報告とセーブ再開までを対象とした。[吸収のPNG版](../../evidence/azhdaha-weekly-png.png)と[軽量矩形版](../../evidence/azhdaha-weekly-light.png)は同じ戦闘時点の比較。 [尾戦の画面](../../evidence/azhdaha-weekly-tail.png)
