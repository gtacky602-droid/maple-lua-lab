## 再現方法

リポジトリのルートから標準Pythonで実行する。追加ライブラリ・ネット接続不要。

```sh
python docs/weekly-boss-v1/simulation-v2/verify.py --out /tmp/weekly-boss-v2-results
cd docs/weekly-boss-v1/simulation-v2
python -m unittest -v test_verify
cd ../simulation-v1
python -m unittest -v test_simulate
```

ローカル結果のsummary.jsonとCSVは再生成物。実行ログやユーザーのセーブをGitへ登録しない。タイミングモデルは旧caseを診断用に締切後まで進め、完了時刻が受付終端より小さい場合だけ成功とする。敵の全攻撃形状、被弾、DPS、通信遅延を含めていない。
