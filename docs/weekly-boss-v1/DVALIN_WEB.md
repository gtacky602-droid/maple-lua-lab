## 戦闘と保存

- 前脚左右と噛みつき後の頭は体勢だけを減らす。同じ攻撃イベントが複数部位に重なっても共有ゲージへの適用は1回。本来の後続多段イベントは別に受け付ける。
- 結晶のHP受付はWD08の `[42,462)` tick。首の踏み場へ通常ジャンプで上がり、画面の結晶そのものを狙う。地上から届く透明な代理判定は置かない。
- 踏み場は全員共用。起き上がりの72tickで床へ下げ、乗っているキャラを一緒に運ぶ。AIは跳び始めた区画移動を着地まで継続し、追従距離に入っても隙間の上で停止しない。
- 最初はWD01〜04、初回ダウン終了後にWD05〜07を加える。飛行2行動の後には接近行動を置く。早期撃破を防ぐHPロックはない。
- 危険床は同時1区画、600 active tick。地上だけ最大毎秒1回、ダウン中は停止、再開前に60tick予告。床を全て汚染する時間切れは追加しない。
- 退出・全滅・保存読込で未完の挑戦はHP/体勢を初期化。撃破済みは60秒の再出現待ちを保存する。既存v1セーブで週ボス項目がなくても読める。週制限や樹脂消費は追加していない。

比較用仮値は [weekly-boss-spawns.json](../../content/weekly-boss-spawns.json) に分離。Lv20、HP600、体勢24、討伐300モラ。試作依頼は1400EXP/360モラ。実プレイヤー人数によるHP加算はない。これは難度別・個人別の本番報酬実装を意味しない。

## 美術と描画

参照を添付して生成済みの6体勢と前脚・頭・結晶・風球を使用。接近中は胴/翼/尾の切り出しに前景の頭を一つだけ重ねる。ダウン時の首の基準点に結晶を重ねる。旧浄化後のギャラリー原画は保持する。非人型の6翼を人間の頭身へ変換しない。

生成記録、参照ハッシュ、切り出し座標、各軽量設定は [美術監査](../../evidence/dvalin-weekly-art-audit.json)。3Dモデルの取得はHTTP403で、背面と腹面のモデル照合は未確認。背景は独立した仮の空域画像で、本番の3D背景制作とは別。

保持した正規化アトラスからの再生成は `python tools/build_dvalin_weekly_art.py`。PNGを上書きせず、監査のハッシュを確認して12部位/体勢の3描画設定をコンパイルする。中割り・部位の継ぎ目・左右別の忠実性は今後の作画項目。
