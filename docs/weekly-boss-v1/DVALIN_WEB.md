# トワリン Web/Lua試作

2026-11-18。設計ID `boss-29010101`、実行ノード `dvalin-sky-arena`。原設計 [DVALIN.md](DVALIN.md) のWD01〜08を接続した途中段階。ローカルラボで難度別の討伐報酬を受け取れる。連続アニメーション、装備別バランス、幻境での実機動作は今後の検証に残る。

モンド城門広場で「風龍の再現戦・首の結晶」を受注し、城門の門x1380から南の街道へ。街道x1280の門から風龍の空域へ入る。最上級は同じ場所の週ボス受付で選ぶ。戦闘後は空域x35→街道x60→広場へ戻り報告する。足場の隙間は通常ジャンプで渡る。

## 戦闘と保存

- 前脚左右と噛みつき後の頭は体勢だけを減らす。同じ攻撃イベントが複数部位に重なっても共有ゲージへの適用は1回。本来の後続多段イベントは別に受け付ける。
- 結晶のHP受付はWD08の `[42,462)` tick。首の踏み場へ通常ジャンプで上がり、画面の結晶そのものを狙う。画面は結晶の真下への移動、踏み場へ上るジャンプ、着地後の通常攻撃を現在地に応じて案内する。結晶が開くまでと閉じるまでの時間は0.1秒刻みで表示する。地上から届く透明な代理判定は置かない。
- 踏み場は全員共用。起き上がりの72tickで床へ下げ、乗っているキャラを一緒に運ぶ。AIは跳び始めた区画移動を着地まで継続し、追従距離に入っても隙間の上で停止しない。
- 最初はWD01〜04、初回ダウン終了後にWD05〜07を加える。飛行2行動の後には接近行動を置く。早期撃破を防ぐHPロックはない。
- 危険床は同時1区画、600 active tick。地上だけ最大毎秒1回、ダウン中は停止、再開前に60tick予告。床を全て汚染する時間切れは追加しない。
- 退出・全滅・保存読込で未完の挑戦はHP/体勢を初期化。撃破済みは60秒の再出現待ちを保存する。既存v1セーブで週ボス項目がなくても読める。週制限や樹脂消費は追加していない。

比較用仮値は [weekly-boss-spawns.json](../../content/weekly-boss-spawns.json) に分離。Lv20、HP600、体勢24、討伐300モラ。試作依頼は1400EXP/360モラ。実プレイヤー人数によるHP加算はない。これは難度別・個人別の本番報酬実装を意味しない。

## 最上級で首の結晶を比較

同じLv200の冒険セーブから、通常入力で2戦した。どちらも最初の踏み場にジャンプで着地し、結晶の露出開始から7秒間に攻撃できることを確認した。

| 最初の露出 | 最初の結晶ダメージ | 体勢を崩した回数 |
| --- | ---: | ---: |
| 踏み場から通常攻撃 | 384 | 2回で討伐 |
| 踏み場で攻撃せず待つ | 0 | 3回で討伐 |

両方で周回報酬の経験値18,999,684とモラ1,538,640を受け取り、再読込で勝数の加算を確認した。戦闘画面は結晶の残り時間を表示し、閉じた時点で今回の結晶ダメージを知らせる。ダメージがなければ次の体勢崩しを案内する。共闘では結晶ダメージと時間を全員で共有する。 [最上級の試走と描画比較の記録](../../evidence/dvalin-crystal-windows-20261128.json)

## ローカル共闘

風龍の空域では、体勢・本体HP・風弾の軌道・危険な床・結晶への踏み場を部屋で共有する。体勢を削る攻撃も討伐参加に数える。被弾・落下と再出現待ちの保存は各参加者の冒険に記録する。 [共闘での入場・報酬・検証](../COOP_WEB_PREVIEW.md#トワリンの週ボス戦)

## 美術と描画

参照を添付して生成済みの6体勢と前脚・頭・結晶・風球を使用。接近中は胴/翼/尾の切り出しに前景の頭を一つだけ重ねる。ダウン時の首の基準点に結晶を重ねる。旧浄化後のギャラリー原画は保持する。非人型の6翼を人間の頭身へ変換しない。

生成記録、参照ハッシュ、切り出し座標、各軽量設定は [美術監査](../../evidence/dvalin-weekly-art-audit.json)。3Dモデルの取得はHTTP403で、背面と腹面のモデル照合は未確認。背景は独立した仮の空域画像で、本番の3D背景制作とは別。

保持した正規化アトラスからの再生成は `python tools/build_dvalin_weekly_art.py`。PNGを上書きせず、監査のハッシュを確認して12部位/体勢の3描画設定をコンパイルする。中割り・部位の継ぎ目・左右別の忠実性は今後の作画項目。

## Lv200セーブでの最上級3勝と週ボス14戦

左道の真諦者の最上級4勝と報告120件を記録したセーブから、モンド・南の街道の受付でトワリンの最上級へ入った。

- Chromeの初回は結晶に手動で600ダメージを与えて討伐した。初回の露出で98ダメージ、合計7回の体勢崩し、落下と帰還は0回。踏み場の着地と降下、危険床からの移動を確認した。初回報酬は32,560,274 EXPと3,590,160モラ、依頼報告は1,400 EXPと360モラだった。 [最上級初回と報告](../../evidence/earned-dvalin-first-expert-browser.json)
- Luaの2連戦では、最初の露出で攻撃すると結晶に96ダメージ入り、体勢崩し7回で討伐した。見送った場合は最初のダメージが0で、8回で討伐した。両方で最初の踏み場への着地と落下0を確認し、周回報酬は各18,999,684 EXPと1,538,640モラだった。検証では入手済みの森の観測剣と試走用の聖遺物を装備し、同行者の攻撃を止めた。Luaの再戦では同行者は両方とも戦闘不能になった。 [2連戦の記録](../../evidence/earned-dvalin-rematch-lua.json)
- 元の装備に戻し、未回収聖遺物を残してセーブした。Chromeでトワリンの最上級3勝と依頼報告121件を復元し、同じセーブで現行ラボに登録されている原神題材の週ボス14戦すべてに最上級の勝利記録があることを照合した。 [再読込と14戦の照合](../../evidence/earned-dvalin-rematch-browser.json)
- 2戦の38場面を元絵・中間・軽量で比較した。結晶が露出している同じフレームで、標準の描画命令14,075件に対して軽量16色は3,822件だった。軽量版はパック前後でCanvasの画素が一致し、gzip転送量は72,449 Bから51,445 Bになった。 [比較の記録](../../evidence/earned-dvalin-rematch-frames-browser.json)
