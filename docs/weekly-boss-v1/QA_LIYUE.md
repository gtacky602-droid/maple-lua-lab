## 2. 索引の解釈と優先事項

正本はボス別カード。MANIFESTは実行用ゲームデータではない。variantは親の差分を無条件に足し算するのではなく、指定された時間割を置き換える。水球と隕石の両方を同時に起動しない。

- `damage` は通常ダメージの判定要求期間。被弾無敵・盾・耐性を無視して全段確実に当てる指示ではない。
- `spawn` は弾の生成。実命中は衝突時で、同じ弾を毎tick命中させない。
- `hazard_contact_group` は接触群。同じ群の球が3個あっても3回の保証命中ではない。
- `projectiles[].secondary_max_lifetime` は最後の衝突後に残り得る二次効果の寿命上限。WZ14のdamageは衝突+36tickに別途判定し、場外失効時には発生しない。
- `event_state` のWC13/WZ13は独立した攻撃アニメではない。付与・解除・期間終了に同期する。
- WC14とその魔王武装variantの`recovery`だけは、変身の最後に構えを整える区間を表す。**変身の全区間は新規攻撃なし・本体へのダメージ無効**で、通常技の『攻撃可能な後隙』と混同しない。新HP区間の表示切替が被ダメ可能時刻を自動決定するわけではない。WC14終了後から通常の予兆と攻撃機会へ戻る。
- WZ09は`attack_transition`。t396まで移行中の防御状態、[396,540)は攻撃可能なRECOVERY。WC14の例外をこちらへ流用しない。

## 3. 公子の優先検証

1. **3形態のIDとHP**：P1/P2のHP0は一度の変身、P3のHP0は一度の討伐。既存の同一encounter内で扱い、報酬を三回出さない。旧弾・印・予約反撃は新phaseへ残さない。
2. **印の境界**：付与→任意交代で維持→外周接触で解除。旧印消去と新被弾の同tick順序をログで確認。AI被弾の簡略化と人間プレイヤーの所有IDを混同しない。
3. **巨鯨**：出現と着水の二つの危険形状がWARNと一致。空中の尾には判定なし。A/Bの和の外側に実際に逃げられる安全域がある。画面外へ避けることを唯一解にしない。
4. **追雷**：LOCK前解除で落下中止、LOCK後解除は固定地点への落下が残る。途中交代・死亡・再接続で新標的へ突然落ちない。
5. **障壁**：新規攻撃だけに反撃予約、発動済み継続技やAIだけで無告知に連鎖しない。区別できないエンジンなら予告付き固定反撃へ置換し差分記録。
6. **連撃**：WC08の4段目だけ長い突き、WC09は三回とも終点固定、WC11は往路と復路、WC12は水終了後に雷。すべて通常移動・ジャンプで逃げる道があるか入力再現で測る。
7. **制作開始値の検証**：WC03の90tick間隔、WC05後の180tick、WC12後の120tickは既存のジャンプ・通常技・組込技の硬直に合うか。必要なら原作再現の名目で固守せず試験根拠付きで修正。

## 4. 若陀龍王の優先検証

1. **四元素組合せ**：4組すべてでP1→P2→P3へ到達し、色・damage tag・技variant・挑戦前の表示が一致する。選んだ2元素以外を勝手に混ぜない。
2. **四足の接地**：WZ02は一回の接地と三波、WZ03は横打ち側、WZ04/05は尾の後方、WZ06は頭の走路。巨大な画像BBoxをそのまま判定へ使わない。
3. **移行**：閾値を跨いでも旧危険とWZ09を無告知で同時発生させない。HP0が先に確定したら勝利し、HP1ロックや追加一撃を要求しない。
4. **尻尾**：WZ12中は露出尾の1ターゲットだけ。範囲技が地中の本体も拾って倍ダメージにならない。HP0で残留を取消し、復帰演出は非攻撃。
5. **刻印と盾**：盾を壊す一撃では新刻印なし、次の無防護命中で付く。盾取得で解除、HP回復だけでは消えない。持続7回・480tick終了、新印置換、交代・AIの表示を確認。周期ダメージから印を再付与しない。
6. **水/炎**：動く水球は固定道と寿命、炎床は同時最大2。攻撃間で残留が全床を埋めない。WZ09/12前に安全な終了を保証。
7. **雷/氷**：安全帯の移動経路、氷の局面group上限、鱗弾の着弾後予告と二次衝撃を確認。『9窓=9回命中』へ変換しない。
8. **盾なし編成**：基礎移動とジャンプで回避でき、有限時間の刻印をHP維持でも扱えるか。威力未設定なので成立を断言しない。特定仲間の加入を入場条件にしない。

## 5. 制作順と成果の区分

最初は参照画像と動画で原作の構えを確認し、衣装・武器・尾・元素差分の台帳を作る。次に公子の水弓/WC05鯨/WC14変身、若陀のWZ02前脚/WZ09吸収/WZ12尾だけの姿をキー絵で比較。全技を一度に完成扱いせず、姿勢・予兆・実判定・音を順に合わせる。

実装許可後は、無装備相当の移動、回避CT中、同行AIあり/なし、左右反転、画面端、上段足場、4人、途中死亡、HP0相討ちを検査。描画30fps/60fpsでもロジック時刻と命中数が変わらないこと。PNG/矩形/最低画質で安全域・自機・印が読めること。
