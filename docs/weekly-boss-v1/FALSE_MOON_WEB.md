# 「博士」・偽月の異端者の再現戦

ナド・クライ・町の広場のx210からLv132の「偽月の再現戦・外界」へ入る。ラウマの依頼「偽月の再現戦・裂け目の向こう」から接続する。Lv、HP、攻撃威力と依頼報酬は調整用の仮値。 [戦闘設計](DOCTOR_FALSE_MOON.md)・[入力の扱い](ENCOUNTER_INTERACTION_V01.md)

- 禁令には2秒の準備と5秒の判定がある。停止は新しく受理した移動、ジャンプ、回避、移動を伴う技を数える。開始前のダッシュや押し出し、同行AI、既設の攻撃効果で違反は増えない。直視は操作キャラが入力で決めた向きを見る。違反すると判定の後に足元へ予告が出て、罰はその操作側だけに当たる。
- 脅威の落柱と保護枠は別の表示。衝撃時にキャラの当たり範囲全体が柱の青い枠に入っていれば防げる。他の攻撃は通常の判定を使う。
- 外界中央の裂け目でHか画面ボタンを押し、1.5秒の確認後に異界へ進む。確認中は取り消しできる。異界で三体の擬影を倒すか、右端の出口でHを押すと帰還する。倒した擬影のみ、一体につきボス最大HPの4%、全戦24%まで、一度だけ精算する。その後6秒間反撃できる。
- 回帰は最大HPの25%以上を一撃で失って生き残った場合に一戦一度。回復量はその損失の半分か、最大HPの10%の小さい方。討伐が先に成立すると発動しない。場面をまたいでもHP・クールダウン・光界は引き継ぐ。

## ドット絵と検証

本体は約3.15頭身のラボ用スプライト。先行素材の意匠を読み直し、青い腕、赤いレンズ、金の杖で遠目でも識別しやすくした。大きな月輪と三つの月具はLuaで別描画し、擬影は透過と印で区別する。外界と異界の背景は仮画像。本番の背景は3Dで用意する方針。 [生成と圧縮](../../assets/false-moon-weekly-generation-v1.json)・[先行素材の参照記録](../../evidence/doctor-false-moon-reference-audit.json)

Pで一時停止し、画像・標準矩形・軽量を切り替える。異界で三体を表示する同じ場面は、標準の15,711件から軽量4,281件へ描画コマンドが72.8%減った。軽量では髪と杖の細部が簡略化され、擬影を区別する月具の印が残る。 [画像](../../evidence/false-moon-weekly-png.png)・[標準](../../evidence/false-moon-weekly-standard.png)・[軽量](../../evidence/false-moon-weekly-light.png)
