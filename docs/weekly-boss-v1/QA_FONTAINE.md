## 2. 索引の読み方と例外

- `source_of_truth`の2文書がモーション/幾何/条件の詳細。variantは親の共通条件を継承し、明記した時刻・弾だけ上書き。WV04星座、WV12竜/クラゲが時間割3分岐。WK10の円/Xは同時間割の形状差なので別時間割数に含めない。
- `active_windows`は直接判定、`projectiles`は生成と最大寿命。発射tickを命中tickにしない。WV09は一つの武器が往復し最大2hit。WV12の獣は倒す通常敵でなく一時的な攻撃実体。
- `paired_groups`はWV08の斬りと遅裂を同groupにする指示。六窓でも全cast上限3。WK18も球6個と降下の同時部分を一groupとし、粒子数を攻撃回数にしない。
- WV05の`conditional_success`は眼の破壊後s+36で抜ける別ルート。失敗のt510爆発を後から出してはいけない。H100/HP20%以下が競合したら低HP取消を優先。
- WV11はイベント状態。成功sから96tickの中断姿勢は、遅い成功で標準失敗期限300を越えてもよい。成功済みなら期限処理を解除しWV12へ進まない。S0なら直ちに内部勝利へ。
- `recovery`は全て攻撃可能ではない。WV07/WV14/WK11は移行、WV15末尾は起立で不可。`exposure`を明示したWV15[60,660)、WK17[36,252)が安定した集中攻撃区間。WK17起上がりはHP攻撃可だが安定時間には含めない。
- WK18は中断不可。赤宴3技には中断可の印を付け、WK18に同じ印を表示しない。WK09で動作を止めるのは実ヒット成立時のみ。空振り/受付外/無効でFを消費しない。
- このバッチはcastを越えて敵攻撃の床/弾を残さない。D/F/H/Sは状態として続くが、状態の存在を旧castの残弾継続と混同しない。前バッチ淑女等の独立床例外を無条件に流用しない。

## 4. 返済と中断の実装前チェック

算術例（最大HP100）：HP100/D25へ回復10→HP100/D15、そこへ回復20→HP100/D0/F1。HP40/D25へ回復40→HP55/D0/F1。HP40/D0へ回復10→HP50/D0/F増加なし。この4例を独立式で検査しただけで、既存回復エンジンとの統合を検査したものではない。

F取得後に新しいDが付いた場合、初版は以前のFを1枚まで保持する。古いFで中断しても新しいDは消えず、契約の返済は別に必要。新Dの解除でもFの上限は1。これを無限の無敵や回復とは解釈しない。

物理キーは未決定。`encounter_interact`の実割当と既存のE交代/Q光界/J通常/1〜8マクロの競合をCodexで確認。反撃用通常が既存ロックに拒否されたらFも消費しない。UIに『中断できる』と出しても、本人が攻撃不能な高度にいれば不合格。WK10/14/15の受付中は近接で届く姿勢を維持する。

味方AIは回復を行えるがFを勝手に消費しない。契約はactor、敵意/内部耐久はboss、舞台移動はtrial、F中断済みフラグはenemyCastに属する。同じID空間へ混ぜない。多人数同時中断では最初の成立者だけ消費。中断後の残弾・HP吸収予約・遅延契約が復活しないこと。

## 5. Codexのプレイ受入条件

1. 鯨を近接のみで攻撃でき、二つの遠隔行動の後に低い露出が来る。全長の接触やAoE複数部位の倍ダメージがない。
2. H100、低HP境界、HP0、眼破壊が同時でも捕食は一度。不要な捕食待ちで倒せなくならない。
3. 眼の8hitEventと核の4castを別に数え、普通の攻撃で実際に時間内達成できる。特定の仲間を要求しない。
4. 三種幻形に常に基本移動/ジャンプの回避ルート。本人の追撃予兆が弾に隠れない。核成功後に失敗分岐が出ない。
5. 内外切替で旧攻撃が消え、HP/CT/Dなどを無料リセットしない。観戦者が復活しない。戻った場所に即ダメージがない。
6. Dに回復を先払いし満HPでも返済可。返済灯の範囲と周期・UIが一致し、侵食で回復役なしの編成が必ず詰む調整にならない。
7. Fの見た目、対象大技、実ヒット/空振り/無敵、受付終端、同時マルチの順序を確認。未承認の追加ダメージ数値を出さない。
8. WK11移行中に侵食が止まり、移行後には元の残時間から再開。過去の被弾を巻き戻したり契約を複製しない。
9. WK12六連・WK14内外・WK18空中大技を、原点と基本速度のままで避ける。巨大な翼・鎌・赤月が予兆と自機を覆わない。
10. 中断3.6秒、帰還後10秒で実際に通常連撃/装備技が届く。全形態/全滅/再挑戦/一時停止/再接続/相討ちを確認。
11. PNG/矩形/軽量表示、音なし、reduced_motion、スマホ比率でも必須情報を失わない。FPSと幻境実機費用は別測定。

## 6. 索引の簡易再検査

リポジトリrootから実行する静的例。ゲームを起動するコードではない。

```python
import json
from pathlib import Path
m = json.loads(Path('docs/weekly-boss-v1/MANIFEST_FONTAINE.json').read_text(encoding='utf-8'))
entries = m['entries']
assert len(entries) == 34 and len({x['id'] for x in entries}) == 34
routes = []
for e in entries:
    if e['kind'] == 'fixed':
        routes.append(e)
        routes.extend(dict(e, **v) for v in e.get('variants', []))
assert len(routes) == 31
for r in routes:
    begin, end = r['recovery']
    assert 0 <= begin < end == r['total_ticks']
    assert all(0 <= a < b <= begin for a, b in r['active_windows'])
    assert all(s + p['ttl_ticks'] <= begin for p in r['projectiles'] for s in p['spawn_ticks'])
print('Static timing checks passed; gameplay NOT tested.')
```

設計文書の追加は技ロジック実装保留を解除しない。制作担当は最新CHAT_HANDOFFとAGENTSを優先し、並行している素材/コードを一括上書きしない。
