# Luaラボの「旅路の地図」

[ローカルLuaラボ](http://127.0.0.1:8972/)で「本編ルートへ」を選び、Mキーか「地図」ボタンを押す。最初は現在地の地域を表示する。「全体図」から通常8地域を選べる。別地図、高難度、発見済みの隠し世界は地域欄で選ぶ。地図上の印を押すか、地名・Lvで検索して地点を選ぶと、通行Lvと隣接する門が分かる。EscかMで閉じる。地図を開いている間はラボの進行を停止する。従来Mキーに割り当てていた技3はIキーに移した。

島、森、山並み、道、現在地の印はLuaが描画命令を作り、WebではCanvasに表示する。全体図は地域の関係を読むための略図。地域図は、公式座標がある地点を座標から配置し、創作の区画や航路はラボ内の接続を基準に配置した。ネクソンのガイドのイラストから、地形を先に読み、地名と現在地の印を重ねる構成を参考にした。 [Nexon公式ガイドの地図画面](https://gi.maplestory.nexon.com/Guide/Basic/Region)

## 読み込んだ地図と接続案

- GitHubの設計には24地域・979フィールドがある。ワープ地点・神像873件は既存ステージに対応し、クエスト区画、航路、ボス入口を含む1,165ステージを地図で参照できる。未発見の隠し世界と未解放の隠し入口は現在の進行に応じて表示する。
- 残る106件は「設計中の地点」に表示する。それぞれに現行ルート上の入口候補を指定した。秘境は寄り道の終端とし、入口・階層を未確認の地点には確認待ちを付けた。破線は接続案で、Fキーで通る門は今後の実装時に地形と条件を確かめてから追加する。
- Sites側にしかない421組は、階層をまたぐ徒歩案、Lv差の大きい徒歩案、未対応フィールド、地形の再照合が必要な案として記録した。通行Lvと設計推奨Lvが異なる811地点は地図上で両方を確認できる。安全な町や章の条件があるため、推奨Lvを一律に入場条件へ流用しない。 [入口・Lv・通路の見直し](../design/world/atlas-route-plan.json)

## 今回ラボで通れるように整えた経路

**ドーンマンポート周辺**では、沖の小島から小舟で中央街区へ戻り、灯台側の上段を通ってから遺跡の地下へ降りる。港の安全拠点はLv1のまま、12地点の通行Lvを155〜170の間で調整した。風止み西側の秘境入口（98500）は階層の照合待ちとした。

**フォンテーヌ**では、東岸の石室（50074）を沈水石室に変更した。地上の東岸から潜る水路、サラシアの枝から石室を経由して水中洞道へ進む水路を用意した。周辺4地点の通行Lvは86、87、88、93。Sitesの水中狩場案にある敵の配置や戦闘条件は引き続き検証対象。
