# Luaラボの「旅路の地図」

[ローカルLuaラボ](http://127.0.0.1:8989/)で「本編ルートへ」を押し、Mキーか「地図」ボタンで開く。地図の印を押すか、地名・ボス名・Lvで検索して目的地を選ぶ。「現在地からの道順」に、途中で通る門や乗り物が順に表示される。地図上では同じ地域・階層にある区間が金色で光る。通行にLvや依頼の進行が必要な場合は、その条件が出る。EscかMで地図を閉じると冒険を再開する。技3はIキー。

全体図から通常8地域の位置を見られる。モンドの風車、砂漠の遺跡、ナタの火山など、地域ごとの目印をLuaの描画命令で組み立てた。メイプルストーリーの公式ガイド画像を参照し、地形の絵に地名の札、現在地、移動経路を重ねる構成を取り入れた。地域図では公式座標を持つ地点の相対位置を使い、仮の狩場や航路はラボの接続に沿って配置した。 [ネクソン公式ガイドの地図画像](https://gi.maplestory.nexon.com/Guide/Basic/Region)

空の神殿・南の雲の下の小間にはLv134で入れる。古の聖山・北の遠望台から空の神殿の西の入口へ上がり、南東の小島から雲下に降りる。帰りの昇降機は「南東の小島へ上がる」「古の聖山へ戻る」と表示する。ドーンマンポート・北岸の船溜まりはLv168。港の石段広場で上段の入口に上り、風が抜ける丘を通る。 [M地図に従ったLua往復の記録](../evidence/atlas-regional-approaches-lua.json)

## 途中で降りられる乗り物

M地図で途中の停留所や港を選ぶと、出発から何秒の間に降りられるかが出る。トロッコは1.8〜6.3秒の間に花棚で降りられ、ナタとナド・クライを結ぶ船は30〜50秒の間にオシカ・ナタで下船できる。それぞれ停車・寄港中にFを押す。寄り道のあと同じ方向に乗り直す場合、花棚からは2秒、オシカ・ナタからは40秒で終点に着く。乗り直す門の案内にも所要時間を表示する。 [花棚の案内画面](../evidence/world-voyage-trolley-atlas.png)

船6便、列車1便、トロッコ6便を現地の門から乗り、自動到着と乗車中に保存した場合の復元をLuaで確認した。途中で降りられる4便は、受付開始・終了の前後、再乗車、降りずに終点まで進む動きを確認した。現地の門が閉じる瞬間に地図の道順も変わる。試験では乗り場、必要Lv、二つの切符依頼の報告済み状態を用意した。Chromeでは白虹行き列車の表示・保存・到着と、ヴェルーリヤのトロッコの地図・途中下車・再乗車を確認した。 `python -X utf8 test_world_voyage_routes.py`、ラボ起動中に `node test_world_voyage_routes.mjs` で再現できる。 [Luaの全便ログ](../evidence/world-voyage-routes-lua.json) · [Chromeの試走](../evidence/world-voyage-routes-browser.json)

## 渡し舟・昇降機・水路・位相門

M地図で行き先を選ぶと、渡し舟、昇降機、水路、位相門などの所要時間が道順に出る。乗ったあとに到着予定地を選ぶと「この地点へ移動中」と表示する。ソロでは地図を開いている間は移動を一時停止し、EscかMで閉じると再開する。同じマップ内の沈玉の谷の荷揚げ用昇降台にも、この到着前の表示を使う。 [金リンゴ群島の連絡船で移動中の地図](../evidence/world-timed-boat-atlas.png)

既存のワープ・神像、狩場・脇部屋、長距離便の集計の外にある67地点を対象に、渡し舟12方向、昇降系37方向、水路10方向、位相門24方向をLuaで検証した。入口まで歩く・跳ぶ・泳ぐ操作、門の操作、指定位置への到着、移動中の保存からの復元を確認した。試験は各区間の出発地点、必要Lvと一部の依頼進行を用意して実施した。Chromeでは金リンゴ群島の連絡船と往日の海の水路で地図を開閉し、往復した。 `python -X utf8 test_world_timed_gates.py` と、ラボ起動中の `node test_world_timed_gates.mjs` で再現できる。 [Luaの83方向のログ](../evidence/world-timed-gates-lua.json) · [Chromeの試走](../evidence/world-timed-gates-browser.json)

## ボスの場所を探す

Mキーで地図を開き、**全体図 → 表示「ボス」**を選ぶと、台帳の通常ボス64戦・週ボス16戦・幽境7戦を名前や別名で検索できる。たとえば「トワリン」で「空を裂く魔龍」の挑戦先が出る。目的地を選ぶと地域図と現在地からの道順が開く。「ボス挑戦・全戦闘の制作状況」の「ゲーム内の地図で案内」からも開ける。

Lv1の開始地点から、87戦すべてに通行条件付きの道順が出ることをLuaで確認した。Chromeでは検証用セーブから「波濤の投錨者」と「空を裂く魔龍」を検索し、各2区間を徒歩で通過して、討伐・帰還・依頼報告・保存まで確認した。 [ボス案内の画面](../evidence/wavebinder-field-map.png) · [Luaの検査](../evidence/world-atlas-lua.json) · [通常戦のログ](../evidence/wavebinder-field-browser.json) · [週ボス戦のログ](../evidence/dvalin-weekly-browser.json)

幽境は、各地域の受付へ案内する。現地の入口でFを押し、受付で**難易度と聖遺物セット**を選ぶ。Chromeでは「北斗」から試合甲板へ移動し、極限のLv165条件と、通常戦の勝利・依頼報告・保存からの復元を確認した。 [幽境の案内画面](../evidence/stygian-beidou-atlas.png) · [北斗戦のログ](../evidence/stygian-clear-rewards-browser.json)

## 狩場と脇部屋の入口

M地図の「狩場・任意戦」には、狩場と脇部屋に加えて入口側の地点も出る。璃月・港東の荷揚げ波止場を選ぶと、採石斜面のLv34と港南の征討入口のLv38が並ぶ。行き先を選ぶと、必要Lvと途中の門を確認できる。 [港東の二つの狩場](../evidence/world-hunt-multiple-entrances.png)

## 戦闘中に入る区画

- **呑星の鯨・腹中**は水辺の広場からLv84の星海へ。鯨のHPが20％を超えた状態で敵意が100になると、捕食で腹中へ移る。腹中で星海を選ぶと幻影を倒して戦闘を続ける手順が出る。水辺の広場を選ぶと歩いて撤退する出口が出る。 [呑星の鯨の戦闘](weekly-boss-v1/NARWHAL_WEB.md)
- **偽月の再現戦・異界**はナド・クライの町の広場からLv132の外界へ。裂け目の予告後、中央でHを押す。異界からは擬影3体を倒すか、右端の出口でHを押して外界へ戻る。共闘で裂け目や出口を使うには生存組全員の同意が必要。 [偽月の異端者の戦闘](weekly-boss-v1/FALSE_MOON_WEB.md)

## 璃月から西の雪線道と巨淵の国境洞道を渡る

璃月の雪山南麓の湿地から西の雪線道を通り、西斜面の岩間へ入れる。入場はLv44。ドラゴンスパインの拠点をまだ訪れていなければ、訪問済みの璃月港で再開できる。拠点を訪れたあとは、西斜面で保存するとドラゴンスパインの拠点で再開する。

層岩巨淵の採掘場西の岩棚からは国境洞道を抜けてスメール側の神像へ入れる。入場はLv64。スメール・巨淵・稲妻の近隣拠点が未訪問の場合にも、訪問済みの璃月港を再開先として使える。国境側の神像からスメール入口、木橋を経て北東の神像まで同じ再開先を使う。

Luaで両ルートの1Lv手前の入場拒否、往復、訪問履歴の保存復元を確認した。Chromeでも璃月側のワープ地点からM地図を開き、両ルートを往復して璃月港で再開した。 [Luaの試験](../evidence/subregion-checkpoints-lua.json) · [Chromeの試験](../evidence/subregion-checkpoints-browser.json) · [6地域25地点の試験資料](../design/world/subregions-stage-evidence.json)
