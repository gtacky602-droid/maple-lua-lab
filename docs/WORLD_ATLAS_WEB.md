# Luaラボの「旅路の地図」

[ローカルLuaラボ](http://127.0.0.1:8973/)で「本編ルートへ」を選び、Mキーか「地図」ボタンを押す。最初は現在地の地域を表示する。「全体図」から通常8地域を選べる。別地図、高難度、発見済みの隠し世界は地域欄で選ぶ。地図上の印を押すか、地名・Lvで検索して地点を選ぶと、通行Lvと隣接する門が分かる。EscかMで閉じる。地図を開いている間はラボの進行を停止する。従来Mキーに割り当てていた技3はIキーに移した。

島、森、山並み、道、現在地の印はLuaが描画命令を作り、WebではCanvasに表示する。全体図は地域の関係を読むための略図。地域図は、公式座標がある地点を座標から配置し、創作の区画や航路はラボ内の接続を基準に配置した。ネクソンのガイドのイラストから、地形を先に読み、地名と現在地の印を重ねる構成を参考にした。 [Nexon公式ガイドの地図画面](https://gi.maplestory.nexon.com/Guide/Basic/Region)

## 読み込んだ地図と接続案

- GitHubの設計には24地域・979フィールドがある。ワープ地点・神像873件、座標を持たない設計区画32件、座標付きの狩場71件、照合中の入口手前に設けた見晴らし場3件をラボに接続した。クエスト区画、航路、ボス入口と任意戦を含む1,345ステージを地図で参照できる。隠し世界と門の表示は冒険の進行に応じて変わる。 [設計区画32件](SITES_VIRTUAL_FIELDS_WEB.md) · [座標付き狩場71件](SITES_GEOGRAPHIC_FIELDS_WEB.md)
- 山脊の見守り方面、鷹飛びの浜南側、風止み西側は外の見晴らし場まで行って帰れる。「入口・階層を照合中」にその位置と元の道を表示する。 [別階層と見晴らし場](SITES_LAYER_TRAILS_WEB.md)
- Sites側にしかなかった421組のうち128組はラボに実装し、274組は既存ルートを試走した。残る19組は専用ゲートと地形・階層を照合する。 [帰りの船と寄港](SITES_RETURN_FERRIES_WEB.md) [主要街道と沿岸の往復路](SITES_MAIN_CORRIDORS_WEB.md)通行Lvと設計推奨Lvが異なる地点は、地図上で両方を確認できる。 [入口・Lv・通路の見直し](../design/world/atlas-route-plan.json)

## 今回ラボで通れるように整えた経路

**ドーンマンポート周辺**では、沖の小島から小舟で中央街区へ戻り、灯台側の上段を通ってから遺跡の地下へ降りる。港の安全拠点はLv1のまま、12地点の通行Lvを155〜170の間で調整した。風止み西側には外の見晴らし場まで行く道を追加した。原作の入口と階層は照合中。

**フォンテーヌ**では、東岸の石室（50074）を沈水石室に変更した。地上の東岸から潜る水路、サラシアの枝から石室を経由して水中洞道へ進む水路を用意した。周辺4地点の通行Lvは86、87、88、93。Sitesの水中狩場案にある敵の配置や戦闘条件は引き続き検証対象。
