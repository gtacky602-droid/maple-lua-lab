# Luaラボの「旅路の地図」

[ローカルLuaラボ](http://127.0.0.1:8974/)で「本編ルートへ」を押し、Mキーか「地図」ボタンで開く。地図の印を押すか、地名・Lvで検索して目的地を選ぶ。「現在地からの道順」に、途中で通る門や乗り物が順に表示される。地図上では同じ地域・階層にある区間が金色で光る。通行にLvや依頼の進行が必要な場合は、その条件が出る。EscかMで地図を閉じると冒険を再開する。技3はIキー。

全体図から通常8地域の位置を見られる。モンドの風車、砂漠の遺跡、ナタの火山など、地域ごとの目印をLuaの描画命令で組み立てた。メイプルストーリーの公式ガイド画像を参照し、地形の絵に地名の札、現在地、移動経路を重ねる構成を取り入れた。地域図では公式座標を持つ地点の相対位置を使い、仮の狩場や航路はラボの接続に沿って配置した。 [ネクソン公式ガイドの地図画像](https://gi.maplestory.nexon.com/Guide/Basic/Region)

## 読み込んだ地点と経路

GitHubのマップ設計から取り込んだ24地域・979フィールドを、ラボの1,350ステージに割り当てた。原作の入口を照合中の3地点には、行き帰りできる外の見晴らし場がある。Sitesにしかなかった421候補は、137組をラボに実装し、283組を既存経路で確認した。ドーンマンポートの北岸とナタの空の神殿を直結する1案は保留し、港の街区と古の聖山の昇降機からそれぞれ向かう。 [接続台帳](../design/world/atlas-route-plan.json) · [見晴らし場](SITES_LAYER_TRAILS_WEB.md)

| 区域 | ラボで通る道 |
| --- | --- |
| スメールの南の段丘と北岸 | Lv63のキャラバン小道とLv61の木橋。高いLvの狩場は任意の寄り道として残した。 |
| ドラゴンスパイン西麓 | 璃月の湿地からLv44の雪線道を抜け、西斜面に上がる。 |
| ナタ東端とスネージナヤ南端 | Lv100で砂岩の国境谷を通る。北の断層の別室からは昇降機で地上に出て、Lv140の峠を越える。 |
| トゥニギの黒淵と霜月 | 観測洞と工場下層を保守坑道でつなぐ。霜月では昇降機と消灯で出現する足場を使う。 |
| 淵下宮の外礁灯 | 中央、北西、北東の灯を調べるたびに次の位相門が開く。外礁からは出発した高台へ戻れる。 |
| 隠し世界 | 金リンゴ群島は船着き場、ヴェルーリヤは模様瓶、シムランカは絵本から入る。ナド・クライ特別地域へはレンポ島の町と月光の野を経由する。 |

新設の峠、橋、保守坑道と位相門の移動時間（1.6〜2秒）はラボ用の試作。通行Lvと設計推奨Lvの差は地点欄に表示する。ドーンマンポートの高難度区画やフォンテーヌの沈水石室は、既設の船・昇降機・水路から向かう。 [今回の18組の経路](../sources/map-research/sites-atlas-connections.json) · [既設の船便](SITES_RETURN_FERRIES_WEB.md)

## 検証

- Luaで18組の往復を確認した。位相門の順序と保存、国境や橋の5つの通行Lv、発見後に入れる3つの隠し世界を含む。試走は戦闘の影響を外した状態で行った。稲妻と淵下宮の77地点では212方向の門を再試走した。 [Luaの経路ログ](../evidence/sites-atlas-connections-lua.json) · [稲妻・淵下宮](../evidence/inazuma-waypoint-test.json)
- ChromeでM・Esc、地点検索、階層切替、道順、幅390pxの表示と、淵下宮の位相門の往復を確認した。 [全体図](../evidence/world-atlas-overview.png) · [淵下宮の道順](../evidence/atlas-enkan-phase.png) · [モバイル](../evidence/world-atlas-mobile.png) · [操作ログ](../evidence/world-atlas-browser.json)
