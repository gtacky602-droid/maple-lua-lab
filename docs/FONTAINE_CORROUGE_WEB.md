# エリニュスの根と魔剣クルージュ

[ローカルLuaラボ](http://127.0.0.1:8986/)でフォンテーヌ廷の観測係から「エリニュスの根へ続く水脈」を受ける。依頼はLv94、戦闘はLv100。工房の地下入口で水位標をGで調べると、Fで根の下の水脈に入れる。水脈の上下にある調査点をGで調べて戻り、フォンテーヌ廷で報告する。報告すると、地下水脈の奥にある割れ目の門が開く。Mの「狩場・任意戦」で「エリニュスの根・クルージュの割れ目」を選ぶと、工房地下から水脈を通る道順が出る。

水中では方向キーかWASDで泳ぎ、Jで水撃、SpaceかShiftで急回避する。クルージュは複数の泡をその場に残す。緑のK印が出たら、泡の方向を向いて深さと距離を合わせてKを押す。泡は爆発せずに引き返し、本体へ届いてダメージを与える。オレンジの爆発範囲からは移動して外れる。上下を流れる普通の泡は、二つの深さの間を泳いでかわす。割れ目の入口のFで地下水脈へ退ける。ソロでは入り直すと全快した敵と再挑戦できる。

工房の地下入口と地下水脈で共闘部屋を作れる。各自が依頼を報告すると割れ目の門を通れる。返した泡が届くと操作した人の貢献に加わる。 [共闘の詳細と検証](COOP_WEB_PREVIEW.md#シャサニョンと魔剣クルージュの水中共闘)

原作の地下水域を開く条件と泡の攻撃を参照した。水位標、五つの調査段階、ラボの報告条件、Kによる返球、HPと威力は試作案。背景画像はラボ用。 [配置案](../design/world/encounters.json) · [ゲーム内の姿と地下水域](https://game8.co/games/Genshin-Impact/archives/432217)

## 素材と検証

名前付きの正面・戦闘画像とボウシクラゲの2Dアイコンを照合して、琥珀色の傘、左右に反るひれ、紫の触腕の3ポーズを制作した。 [元PNGと軽量16色](../evidence/fontaine-corrouge-art-poses.png) · [出典](../evidence/fontaine-corrouge-art-sources.json)

LuaでLvと報告の門、5つの調査段階、泡の設置から爆発までの受付、逆向きのK、返した泡の到達時の一度のダメージ、退却・再戦・報酬と保存を確認した。通常入力の単独自動試走は45.35秒で、泡を5回返した。 [Luaの検証](../evidence/fontaine-corrouge-lua.json)

Chromeで実際のG・F操作とMの道順、弾ける前のK、同じ停止フレームで元PNGと軽量16色を確認した。 [Chromeの検証](../evidence/fontaine-corrouge-browser.json) · [元PNGの戦闘画面](../evidence/corrouge-planted-bubbles.png) · [軽量16色](../evidence/corrouge-planted-bubbles-light.png)

配置案にあるフォンテーヌ本域16戦と往日の海のシネアスを含め、17戦の専用試作を登録した。この範囲をLuaで回帰検査した。地方伝説全体は56案のうち18戦。
