# 別階層への道と3つの見晴らし場

[ローカルLuaラボ](http://127.0.0.1:8973/)で本編を始め、Mキーで「旅路の地図」を開く。地点を選ぶと、隣の地点と通行Lv、徒歩・舟・水路・昇降機の別が分かる。「別階層」や「水中」から別の階層の行き先を押すと、すべての階層を表示してその地点を選ぶ。

## 接続の変更

| 地域 | 試作した経路 |
| --- | --- |
| スネージナヤ | 氷壁南端から東の横穴へ降りる昇降台、工区地下から北の林の下へ移る資材用昇降機、東の丘から鞍部へ上る昇降機。 |
| フォンテーヌ | 東湾の岸と水中階段を結ぶ水路、東の水中棚と島の水洞を結ぶ水路。地上から入った場合は水路の先で泳ぎ、岸に戻ると歩行に切り替わる。 |
| ナタ | 東の渡り島から浅瀬の桟橋へ舟で渡る。桟橋の上段に跳び、浅瀬の洞へ入る。 |
| ナド・クライ | 南の荷揚げ路から中央施設の下層へ降りる昇降機。 |

階層違いの徒歩候補83組のうち、7組に新しい往復路を実装した。残る76組は、既存の洞口・船着き場・昇降機を使う。例えば、北西湾の水中から北西岸へはLv88の潜水口を経由し、古都南の沖合から地下道へは港で降りて崖の昇降機へ向かう。モンド2組と沈玉の谷1組のLv差も調べ、段階的にLvが上がる道や、狩場前に安全な入口を通る経路を記録した。 [Sitesの経路台帳](../design/world/atlas-route-plan.json)

## 原作の入口が照合中の地点

山脊の見守り方面（10009）、鷹飛びの浜南（85351）、風止み西側（98500）には、元の道から行って帰れる外の見晴らし場を設けた。敵と報酬は置いていない。ラボでの通行Lvは12、13、160。原作の入口・階層は照合中で、地図の「入口・階層を照合中」に表示する。公式資料の位置情報と、このラボの仮地形・背景はそれぞれ記録した。 [原神公式のテイワットマップ](https://act.hoyolab.com/ys/app/interactive-map/index.html) · [公式の風止み周辺紹介](https://www.hoyolab.com/article/44512633) · [試作区画と接続](../sources/map-research/sites-layer-trails.json)

Sites取込の979地点すべてにラボのフィールドを割り当てた。うち3件は上記の見晴らし場。Sites側にしかなかった421組の経路候補は、106組を実装し、79組は既存の経路を確認した。残る236組は、通常道を増やす必要があるか地形と照合する。

## 試走

- Luaで新規7組、階層の既存経路76組、Lv差のある3組を往復した。見晴らし場3件は帰り道と、保存した後に拠点から再開できることを確認した。合計398方向の門を通過した。移動の検証では被ダメージを抑えた。 [Luaログ](../evidence/sites-layer-trails-lua.json)
- Chromeで氷壁の昇降機、東湾の水路、風止み西側の見晴らし場を往復した。Mキーで地図を開き、階層の絞り込みから地上の行き先を選べることも確認した。 [Chromeログ](../evidence/sites-layer-trails-browser.json) · [氷壁の地図](../evidence/sites-layer-ice-map.png) · [見晴らし場の地図](../evidence/sites-layer-lookout-map.png)

Luaの検査は `python -X utf8 test_sites_layer_trails.py`。そこで作った作業用セーブを使い、`node test_sites_layer_trails.mjs` でChromeの操作を検査する。仮地形と背景での試走結果は、原作や星々の幻境での実測と別に記録する。
