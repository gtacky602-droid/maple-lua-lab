## 2. 三戦共通の契約

60Hz、U=88px、区間は半開 `[start,end)`。技開始を0、LOCK時の本体位置を原点、正面をu、床から上をzとする。通常2回の後に看板1回を選ぶ比較案。同時の親castは一つで、星の攻撃も親の予約枠に置く。強ければ看板前に倒せる。

- 同じactor・HP receiver・付着・DoT・標的を維持する。羽の開閉、監視、岩や星の生成でHPや元素付着を作り直さない。本体のHPシールド・追加軽減は設けず、既存の基礎耐性は別データとして保持する。
- 本体・装置の接触ダメージは0。予告、接続線、羽の残光、壊れた星の残像、回復演出は別のダメージを持たない。
- 全看板の自然RECは**144tick＝2.4秒の静止**。任意中断のdown180＋stand24は別分岐で、自然RECを重ねない。down・立ち上がり中も通常のHP受信で、被ダメージ1.2倍は追加しない。
- 幻月蝶の通常浮遊36px、守護者の通常浮遊32pxを比較値とし、地上でのhurtbox下端は0.45U以下。本体を低く描き、近接で届くことを実表示で確認する。見えない地上箱は置かない。
- 月ヤモリと守護者の移動を伴う空中区間は各36tick。hurtboxを絵と一緒に動かし、着地時の下端は床0。完全潜行・不可視区間は設けない。
- 一つの攻撃groupは `(epoch, actorId, castId, hitEventId, receiverId)` で識別し、同じ窓の連続接触は1回まで。17窓は最大の命中要求数で、既存の被弾無敵・盾などを無視した確定被弾回数ではない。

### 予告と地上退避

全位置と向きをLOCKで固定する。固定矩形は本体LOCK原点基準。対象位置を使う着地は、対象の正面方向への距離を0〜上限へ収めて中心とし、左右端を中心±幅/2で求める。星がownerでも星の位置を再加算しない。LOCK後の追尾、端での突然の反転、個別clampで岩や星を重ねる処理はしない。

LOCK前に、本体の実壁と移動経路、全危険範囲、プレイヤーhurtbox幅＋0.1Uの余白、実移動速度と予告時間を確認する。**本体を通り抜けずに同じ側へ下がれる地上経路**を各参加者に残す。成立しないときは技を始めず、無害な位置調整から新しい予告へ戻る。装置は実壁にしない。細い二つの範囲の間やジャンプだけを唯一の退避先としない。

退避後の戻り時間、段差、低速入力、複数人は実プレイで確認する。静的検査だけで「必ず避けられる」「2.4秒全て殴れる」とは判定しない。

### 同tickの順序

既に終端なら旧世代を片付けて打ち切る。生存中は、そのtick開始の監視窓・装置を接触処理前に用意し、開始tickを受付に含める。その後は**状態の自然期限→既存の正規回復と解除→プレイヤー側ダメージ→本体HP0→監視記録と装置接触→任意中断→期限cleanup→生存している敵の攻撃と繭付与**の順。

窓の終端tickは、オブジェクトが描画用に残っていても受付外。本体がそのtickのダメージでHP0なら、記録・星の攻撃・繭の新規付与を行わない。装置を壊したtickに始まる予定攻撃は取り消せる。既に受けたダメージを遡って取り消すことはない。

### 岩と星はHP敵ではなく接触で削る装置

装置は表示と接触領域・層を持つが、通常敵のHP receiver、元素付着先、敵AI、報酬、クエスト撃破数にはしない。標準自動照準の敵リストへ加えず、見える位置に通常攻撃・弾の実領域を重ねて処理する。プレイヤーの弾や貫通数を消費せず、攻撃が本体にも重なれば本体へ通常HPダメージを一度通す。装置側で付着・on-hitを複写しない。

受付は同epoch、正規プレイヤーまたは活動中の同行、新しい直接cast、実際の装置領域との接触。cast開始は受付開始以降、接触時点は受付内。時刻は共通遭遇tickから親cast開始tickを引き、プレイヤー技のローカル0とは比較しない。反応・DoT・古い弾を新しいcastへ読み替えない。

重複キーは `(epoch,parentCastId,deviceSlot,sourceActorId,castId)`。同じ範囲castが別々の星へ当たる場合は各1層まで、同じ星へ多段通知が来ても1回。実体キーに遭遇と親castとslotを含め、旧負IDだけで再利用しない。破壊は装置ごとに一度、期限退場・親終了・cleanupは破壊成功ではない。本体への反動ダメージを発生させない。

通常の蹴りはu=[0.14,1.92]、z=[0,0.70]、草19ずつ。二打目で向きを変えず、脚を戻す間を見せる。月光弾はLOCKでu=0.85、2.15の二地点、各幅1.00U・高さ0.70Uを固定し、近い順に草22。弾の見た目と二つの局所判定を対応させ、別の飛翔体判定を重ねない。

### 看板の三拍

60〜168tickは緑の羽、168〜240tickは赤い羽、240〜336tickは本体が丸く力を溜める姿へ変わる。最初の二波はu=[0.25,2.25]・高さ0.76U、最後の放出はu=[0.10,2.70]・高さ0.76U。各25を現行比較値とし、**草→炎→炎**の固定イベントにする。最後の放出は左右全域へ広げない。

原作の元素変化は外形へ残す一方、旧`onHit`の炎・水・氷で後続元素を上書きする処理はこの版では外す。攻撃の元素・予告色・姿を一緒に固定することで、予告後の元素だけが変わらないようにする。ボスの基礎耐性や付着を色変更で書き換えない。336〜480tickは羽を閉じて低く静止する。

### プレイヤー側の繭は、最初の波の実被弾にだけ付く

本体が最後に丸まる姿と、プレイヤーの繭状態は別物。**最初の草波が正規に命中し、実HPの損失が正で、その受信者が生存している場合**にのみ繭を付ける。盾で全吸収、被弾無敵、範囲外、致死命中には付けない。旧96tickの周辺一括付与と追加12ダメージは使わない。

| 項目 | 新しい短い繭 |
|---|---|
| 通常操作 | 移動・ジャンプ・攻撃・交代は通常どおり |
| 効果 | 与えるダメージ0.90倍のみ。治療量・会心率などへ追加補正なし |
| 自然期限 | 付与から最大180tick＝3秒 |
| 早期解除 | 正規Healイベントで、上限clamp後の実HP増加が正になったとき。満タン不要 |
| 解除後 | 追加の脱出バフなし |
| 重複 | 同じ親cast・同じ受信者へ1回、非重複・延長なし |
| 終了 | 自然期限、回復、本人死亡、親取消、ボス撃破、撤退、退出、再初期化で該当分を解除 |

0.90は元の攻撃者に対応する通常ダメージ経路の**命中解決時に一度**適用する。既に出ている弾やDoT・反応も、解決時の元の攻撃者を使う。生成時と命中時の二重乗算、旧0.75との併用はしない。解除後に解決するダメージから通常値に戻る。

本人と同行は別のactor世代で管理し、操作交代で効果を譲渡しない。期限は停止し得る親castのローカル時計へぶら下げず、**ゲームの一時停止に従う共通戦闘tick**で保持する。parent/epochを指定して消し、他の発生源の状態まで一括消去しない。死亡・復帰の別世代へ持ち越さない。

回復は既存の回復技・アイテム・継続回復などが正規Heal経路を通り、実HP増加がある場合に限る。overheal0、最大HP変更、復帰時のHP設定は解除用回復と数えない。同tickに先に回復し、その後新しく繭を受けた場合、先の回復では新しい繭は解けない。

最初の波の132〜145tickに受けた繭は312〜325tickで自然に解ける。**看板後REC336には残らない**。UIは「繭：与ダメージ−10%・回復で解除」と残り時間程度にし、操作不能を連想させる入力封鎖表示は付けない。全回復条件・長い弱体・脱出強化を短縮した意図的な翻案である。

### FV01・FV02：槍と本体の着地点を分けて読む

二連はu=[0.10,2.15]、高さ0.68U、物理14ずつ。通常2技の名称・物理属性は本作の設定である。槍落としは中心最大1.50U、幅1.80U、高さ0.74U、物理18。LOCK54で槍と本体の共通着地点を決め、最初に槍を落とし、次に本体が降りる。

FV02は初撃と着地の時刻を変えず、**浮上開始だけ旧112→142tickへ遅らせ、空中[142,178)を36tick**にする。槍の窓[112,126)中は通常の低い姿勢を保つ。移動は空中区間内で一度だけ、178tickでhurtbox下端を床0へ接地し、218〜306tickの静止も床で行う。旧`place`の通常hover32pxを着地へ残さない。槍の落下は見た目の経路を持つが、追加の飛翔体ダメージを生まない。

### FV03：二回の監視を短くし、色と攻撃元素だけを記録

監視窓は**[60,132)、[132,204)**の各72tick。各窓の開始後に始めた炎・水・雷・氷の直接castが、本体へ正の実HPダメージを与えたとき、その窓で最初の有効元素を記録する。正規プレイヤー／活動中同行、同epoch、共通時刻、反応・DoT除外を確認する。同tickに複数来た場合はサーバーが採番するイベント順で一つを決める。

物理・風・岩・草が先に当たっても窓を閉じず、元素が記録されなければ空のまま終了する。同じ元素を2窓で記録してよい。旧3hit／6hitの達成条件や多段の回数加算は使わない。窓1で開始した同じcastの後続hitを窓2へ流用しない。記録は次の親castへ持ち越さない。

216tickで本体正面u=0.80、2.20へ二つの星を出す。記録元素は**星の色とその星が出す攻撃の元素**にだけ使う。空欄なら灰白色で物理攻撃。記録の有無、同元素・別元素にかかわらず、星は各2層・通常の直接castで1層。無効元素、惰性星だけの高耐久、相反元素ボーナスはこの版にはない。

|---|---|---|
| 星1 | u=[0.45,1.15]、z=[0,0.80] | [288,300)、u=[0.30,1.30]、高さ0.72U、比較威力26 |
| 星2 | u=[1.85,2.55]、z=[0,0.80] | [360,372)、u=[1.70,2.70]、高さ0.72U、比較威力26 |

両星の受付は**[216,396)**。片方を壊すとその星の現在・未来の命中要求を取り消し、両方を受付内に壊すとdown180＋stand24へ入る。既に撃った星でも受付内なら破壊して中断へ数えられるが、過去のダメージは戻さない。元の基礎攻撃32の反動、down倍率1.2は外す。

396tickで残った星を退場させ、自然終了では[408,552)の静止へ。未処理の場合も二つの局所攻撃が順に来るだけで、本体HPは攻撃できる。看板の総時間は旧1150tickから552tick、約19.2秒から9.2秒へ短縮する。Lv18で持っている元素の種類によって星の硬さが変わらない設計とする。
