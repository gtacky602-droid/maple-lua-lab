# ボコボコダック

## 通常のラボで試す

ナド・クライの町の広場で試運転調査を受け、月明かりの道から工房裏の試運転場に入る。通常ラボにも放電を中断できる短縮案を入れた。Lv122の本体HPは共闘でも1,135固定で、補修メカは各HP16の試作値。

ミットの二連打は前に出る帯を避ける。跳び込みハンマーは先に表示された着地点から離れる。放電の位置は64tickで床に示す。76tickで補修メカが本体の同じ側に2機現れ、94tickから動き、300tickで到着する。到着で本体のHPは増えない。300tickより前に両機を壊すと放電が止まり、2.4秒の反撃時間ができる。1機だけ壊した場合も340tickから床の印に放電が来るので、印から離れる。

途中保存では本体HPを保持し、攻撃の段階と補修メカを初期化する。討伐報酬は445モラ、調査の報告は8,500EXPと570モラ。床と背景はラボの仮素材で、本番では背景を3Dで配置する方針。 [通常ルートでの検査](../../evidence/knuckle-duckle-field-browser.json) · [Lua試験](../../evidence/knuckle-duckle-field-lua.json)

## 425万HPでの比較試作

`./Start-Lab.ps1 -Port 9101 -DraftFieldMoves -NoOpen` で短縮技案、`./Start-Lab.ps1 -Port 9099 -DraftBalance -NoOpen` で従来技を起動できる。どちらも本体HPは比較用の425万。Lv122の獲得セーブでナド・クライの町から月明かりの道を通り、工房裏の試運転場へ入る。

補修メカ2機は本体の同じ前側に現れ、同じ到着時刻に向けて近づく。放電の準備が終わるまでに2機とも壊すと、放電が止まって2.4秒の反撃時間ができる。1機だけ倒した場合や、到着でメカが退場した場合は、床に出た印から離れて放電を避ける。メカの到着で本体HPは回復せず、召喚中も本体は攻撃できる。メカのHPは1機55,000の試作値。

| Lv122の獲得セーブ | 入場から討伐まで |
| --- | ---: |
| 従来技、通常攻撃と同行AI | 67.08秒 |
| 短縮技、通常攻撃と同行AI | 60.08秒 |
| 短縮技で放電を中断して討伐 | 68.15秒 |

Luaでは4人部屋で本体HPを共有し、補修メカの移動と到着、範囲内だけの被弾、受付の最終tickでの中断を確認した。同行の攻撃を止めた別試走では、放電を歩いて避けてから地上攻撃で反撃。討伐・報告と、途中HPを両比較版に読み込めることも確認した。 [設計票](NOD_KRAI_QUARTET_MOVESETS.md) · [Luaの記録](../../evidence/draft-duckle-moves-lua.json)

Chromeで動く2機を破壊して放電を止めた。同一フレームの描画命令は標準13,368から軽量3,628へ減った。 [Chromeの記録](../../evidence/draft-duckle-moves-browser.json) · [標準描画](../../evidence/short-duckle-mechas.png) · [軽量描画](../../evidence/short-duckle-mechas-light.png)

## 比較モードに残した従来技

ナド・クライの町の広場で試運転調査を受け、月明かりの道から「工房裏の試運転場」へ向かう。試運転場はラボ用の仮背景。本番では背景を3Dで配置する方針。

| 攻撃 | 予告と回避 |
| --- | --- |
| ミットの二連打 | 黄色いミットを引き、同じ前方の帯へ二度打つ。二打目まで帯の外へ出る。 |
| 跳び込みハンマー | 跳ぶ前に着地場所が決まる。着地点の帯から離れる。 |
| メカダックの補修 | バリアを張り、左右から補修用のメカダックが近づく。破壊するとバリアが減り、到着を許すと補修される。 |

二体とも通常攻撃で破壊できる。バリアを割ると次の衝撃波が止まり、約2.4秒のダウンが入る。補修を許した場合は、予告した範囲に雷の衝撃波が一度出る。通常攻撃だけでも、衝撃波を避けながら本体を削り切れる。

既存の月感電技はメカダックへのダメージが増える。この方式は比較モードの `-DraftBalance` で試せる。補修量、バリアの数値、攻撃、地名、難度と報酬はラボの試案。 [原神公式のメカダックとバリアの説明](https://genshin.hoyoverse.com/ja/news/detail/159349)
