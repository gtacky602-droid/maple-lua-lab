# 魔像レガトゥス

フォンテーヌの水辺の広場で討伐調査を受け、色褪せた城の入口から展示広間へ向かう。ノストイ地区と古城はラボのマップで、本番の背景は3D配置を使う方針。

| 攻撃 | 予告と回避 |
| --- | --- |
| 石剣の横薙ぎ | 石剣を引いて前方を予告。向きが決まったら背後か予告の外へ。 |
| 四蹄の突進 | 床に走る区間を表示。突進する機体だけに判定があり、ジャンプで越えられる。 |
| 響奏・共鳴器の炎 | 共鳴器を置き、装甲がある間は直接攻撃のダメージが55%になる。共鳴器を壊すと点火が止まり、魔像が2.4秒ひるむ。炎の外から魔像を攻撃し続けても勝てる。 |

大理石と真鍮の四足、剣、竪琴を模した盾と共鳴器は公式資料を参照。Lv92、HP 1,010、共鳴器HP 14、60秒再出現と報酬はラボの試作値。待機に加え、横薙ぎ、突進、指揮、ひるみの専用姿勢を使う。 [公式図鑑](https://wiki.hoyolab.com/pc/genshin/entry/5609?lang=en-us) ・ [ノストイ地区](https://wiki.hoyolab.com/pc/genshin/entry/5601?lang=en-us)

ローカル共闘では一つの共鳴器のHPを共有する。複数の参加者の攻撃で点火直前に削り切っても炎を止められ、全員が同じ反撃時間に入る。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#山隠れの猊獣と魔像レガトゥス)

並行して追加された動作設計案には、二連の石剣、二拍の火弦、終奏落剣と、3回の別々の攻撃による共鳴器中断がある。現在の試作と各技のIDを共有しているため、IDを使う検査では試作の設定か設計案の時間割かも確認する。採用判断に向けて、突進と火弦、共鳴器HPと命中回数の違いを比較できる。 [動作設計案](DANCE_STONE_MOVESETS.md)
