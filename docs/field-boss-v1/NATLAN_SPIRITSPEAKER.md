# 迷える霊覚の修験者

ナタの谷の集落で討伐調査を受ける。赤岩の採掘路と岩場の道を通り、岩場の道の門から謎煙の修練窟へ入る。討伐後は同じ道で集落へ戻り、報告して進行を保存できる。

色彩の影が出ている間も、修験者本体への通常攻撃と元素攻撃が通る。足元の番号と構える影を見て、順に攻撃範囲から離れる。二撃のあと、本体が筆を下ろす2.4秒が反撃の機会になる。 [二影の試作設計](NATLAN_REMAINING_MOVESETS.md#fsp03色彩の二影順筆)

| 攻撃 | 見分け方と回避 |
| --- | --- |
| 霊筆の二連薙ぎ | 48tickで向きと範囲が決まる。同じ範囲を二度薙ぎ、104・172tickから命中する。 |
| 二つの氷色の筆跡 | 54tickで近い印と遠い印を固定する。112・184tickから番号の順に攻撃する。 |
| 色彩の二影・順筆 | 60tickで同じ側の二地点を固定し、64tickで半透明の二影が現れる。144・216tickから一撃ずつ放つ。240tickで影が消え、384tickまで反撃の時間が続く。 |

## ラボの実装と保存

本体のLv114・HP1,060、既存の二技の時間・威力を引き継いだ。影は二つの攻撃を見せるための描画で、HP・敵判定・自動標的・弾の当たり判定を持たない。以前の4体の分身を壊す方式は、二影が順に攻撃する試作へ切り替えた。攻撃者が増えてもHPは1,060で共通。討伐モラ420、依頼報告は8,600EXPと560モラ。途中保存で本体HPを引き継ぎ、再開時に攻撃の状態を初期化する。 [配置と仮数値](../../content/field-boss-spawns.json) · [Lua実装](../../field-spiritspeaker.lua) · [共闘の試験](../COOP_WEB_PREVIEW.md#迷える霊覚の修験者)

旧版のドット絵を使い、本体を不透明、二影を半透明で描く。HPバーは本体の頭上に表示する。攻撃直前と払い出しで影の姿勢が変わり、床に1、2の番号が出る。元のドット絵の参照画像、切り出し位置、表示高は美術監査に記録している。背景はラボ用の仮画像で、本番は3Dで配置する方針。 [美術監査](../../evidence/spiritspeaker-field-art-audit.json)

`python test_spiritspeaker_field.py` で単独試走、攻撃判定、途中保存を検査する。Lv114・通常攻撃の単独試走は79.22秒だった。`node test_spiritspeaker_field.mjs` は報告137件の育成済みセーブから、Chromeの操作で二影の回避、本体への命中、保存と138件目の報告までを検査する。 [Lua検査](../../evidence/spiritspeaker-field-lua.json) · [通常導線と画質比較](../../evidence/spiritspeaker-field-browser.json)
