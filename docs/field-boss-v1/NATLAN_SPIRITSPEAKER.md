# 迷える霊覚の修験者：Webフィールド試作

> **2026-11-18 詳細設計追補:** [第10回の移行先](NATLAN_REMAINING_MOVESETS.md)と[QA](QA_NATLAN_REMAINING.md)を追加。以下は基点 `6a6fb176` 時点のWeb試作の記録であり、新しい三技版を実装済みとするものではない。新旧の時間割・形態処理を混在させず、移行表に従って接続・再試験する。

ナタ・谷の集落で討伐調査を受け、岩場の道の門（x=850）から謎煙の修練窟へ進む。二連薙ぎ、二つの氷の筆跡、色彩の分身の3技を持つ。討伐後は同じ道で集落へ戻り、報告・保存できる。

原作の「色彩の分身の元素シールドをすべて壊すと、本体が姿を現して弱体化する」特徴は[公式Ver.5.3更新案内](https://genshin.hoyoverse.com/ja/news/detail/127791)を参照した。本作では通常攻撃でも守りを壊せるように翻案している。下記の数値は本作の試案であり、原作のフレーム解析値や本人の最終決定ではない。

| 地域Lv・HP | Lv114・HP1,060。人数では増やさない |

ゲーム上の定義は[配置と仮数値](../../content/field-boss-spawns.json)、制御は[Lua](../../field-spiritspeaker.lua)。Lua検査は `C:/Python314/python.exe test_spiritspeaker_field.py`、Chrome検査は `node test_spiritspeaker_field.mjs`。Chromeは既定で `http://127.0.0.1:8841` を使い、`LAB_URL` で変更できる。

美術は公式の仮面・衣装画像、全身図、実戦画面を直接確認して制作した。大きな仮面、短い胴・膝下、太めの手足と大きな杖を持つ6姿勢を一枚で生成し、同じ縮尺で切り出した。新しい戦闘待機にはready姿勢を使う。旧待機原画とギャラリーは履歴として残す。生成プロンプト、参照URL・ハッシュ、切り出し位置、表示高と矩形数は[美術監査](../../evidence/spiritspeaker-field-art-audit.json)に保存している。

モデル配布ページ（Models Resource / asset 557087）は再取得も403。実際のモデル、背面、立体的な奥行きは未確認。左右は試作の反転表示で、左右別作画・連続モーション・被弾・撃破・音は残っている。背景はラボ用の仮画像で、本番の3D配置は未制作。

Luaでは通常攻撃だけの討伐、4体すべての破壊、炎による2層破壊、旧castと反応の除外、攻撃直前の破壊、時間切れ、隠れた本体の終端処理、退出・保存・一度の報酬を検査する。ChromeではUIでの受注、歩行と門、実入力による通常攻撃・炎技、分身の中断、報告・保存を検査し、同じtickのPNG・標準矩形・軽量矩形を比較する。証拠は `evidence/spiritspeaker-field-{lua,browser}.json` と比較PNG。現在の4分身戦をローカル共闘にも接続した。装備差のバランスと幻境実機は未検証。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#迷える霊覚の修験者)

今回の検査では、通常攻撃のみ・同行戦闘不能・回復なしで112.35秒、Chromeの放浪者同行・炎技使用で51.58秒。単独の物理ルートは45〜90秒の目標より長く、バランス調整が残る。4体が並ぶ同一tickの描画指示はPNG36件、標準矩形28,331件、軽量矩形7,621件（標準から約73%減）。これはラボ内の指示数で、実機の処理時間や品質の保証ではない。
