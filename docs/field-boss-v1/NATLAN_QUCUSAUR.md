# 暴君・金焔のクク竜

ナタの谷の集落で討伐調査を受け、岩場の道にある門から「金焔の岩窟」に進む。岩窟にはラボ用の仮画像を使う。本番の背景は3D配置の方針。

| 攻撃 | 予告と回避 |
| --- | --- |
| 翼爪の横薙ぎ | 前へ構えた翼の帯から離れるか、跳んで越える。 |
| 炎羽の二連 | 向きが決まった低い射線へ二発。背後か射線の外へ動く。 |
| 金焔・羽根と降下 | 床に羽根が刺さり、二つの着地点に番号が出る。羽根を壊すと降下攻撃が止まり、クク竜が地上に戻る。羽根が残った場合も二度の降下で着地する。 |

原作の金焔形態と地上の羽根を短い横画面戦に翻案した。羽根は通常攻撃で壊せる。Lv102、HP 1,020、羽根HP 14、金焔中の直接ダメージ65%、再出現60秒、報酬はラボ用の調整値。 [公式図鑑](https://wiki.hoyolab.com/pc/genshin/entry/6584?lang=en-us) ・ [Ver.5.0更新の敵紹介](https://genshin.hoyoverse.com/ru/news/detail/125553)

並行の動作設計案には、金焔の飛行を一度の短い滑空へ絞る構成がある。今回の試作では、羽根を含む構成の討伐時間と回避を測った。技名・時間割の採用は引き続き検討する。 [ナタ初期4戦の動作設計案](NATLAN_ORIGINS_MOVESETS.md)
