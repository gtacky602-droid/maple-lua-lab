# 不滅の副産物：Webフィールド試作

## 短縮技案をラボで試す

雪の町で討伐調査を受け、凍った街道から「赤葉の根洞」へ進む。短縮技案はポート9101、比較元は9099。同じLv145の獲得セーブで、どちらも最大HP650万。 [比較版の起動手順](../balance/FIELD_BALANCE_DRAFT_WEB.md#ナドクライの短縮技案を比較)

翼と胸の花が光り始め、技の120tick目から中断の受付が始まる。299tickまでに新しい直接攻撃で本体HPを三回減らせば、残りの波と開花を中断できる。二打まででは波の時刻や威力は変わらない。二波と本開花を横へ避けた場合も、中断した場合も2.4秒の反撃時間に入る。看板技では本体のHPを消費せず、攻撃が当たっても回復しない。 [技票](SNEZHNAYA_QUARTET_MOVESETS.md#5-不滅の副産物--赤い翼が開いたら開花前に崩す)

獲得Lv145の同じ装備で、通常攻撃と同行AIを使った討伐は従来69.87秒、短縮案89.57秒。短縮案では旧来の自傷ダメージとダウン中の与ダメージ増加を外した。別試走では翼が光り始めた時点で同行の攻撃を止め、二波と開花を横へ避け、150.10秒で討伐した。どの試走も報告と保存再開まで確認した。 [Luaの実測](../../evidence/draft-immortal-construct-moves-lua.json)

Chromeでは、翼と花が先に光り、120tickで残り三打の表示が出た。通常攻撃で開花を中断し、反撃時間に入った。同一フレームの描画命令は標準19,098、軽量5,131。軽量表示でも花と翼の形、残り打数が見分けられる。 [Chromeの記録](../../evidence/draft-immortal-construct-moves-browser.json) · [標準](../../evidence/short-immortal-construct-bloom.png) · [軽量](../../evidence/short-immortal-construct-bloom-light.png) · [中断時](../../evidence/short-immortal-construct-interrupted.png)

獲得Lv145のルートセーブを用意してLuaの試験を実行すると、ブラウザー試験用セーブも作成する。

```powershell
python test_draft_immortal_construct_moves.py
node test_draft_immortal_construct_moves.mjs
```

## 従来技

雪の町で討伐調査を受け、凍った街道のx=1210の門から「赤葉の根洞」へ進む。根爪の二連掻き・赤葉の二粒・輝かしき命の姿を持つ。守りの一層破壊で小波を止め、すべて壊すと灼焔の華を中断できる。左の門で街道へ戻り、雪の町で報告・保存する。

[公式Ver.7.0更新案内（タイ語）](https://genshin.hoyoverse.com/m/th/news/detail/165655)の検索索引本文で、自分のHPを消費して多層の守りを得ること、**その間にボスの攻撃が命中すると回復する**こと、層数低下または時間経過で大技を準備し、全層の破壊で中断できることを確認した。直接取得では本文を読めていない。日本語の転載には回復の主語が曖昧なものがあるため、公式タイ語と繁体字の説明を照合して攻撃側の回復とした。原作の星反応による無効化は、本作の採用技との対応未確定のため未接続。

下記の物理代替、各元素の同率扱い、HP消費・回復上限、時刻・報酬は、本作の比較用試案。原作の正確なフレーム値や本人の最終決定ではない。

[配置と仮数値](../../content/field-boss-spawns.json)、[Lua制御](../../field-immortal-construct.lua)が実行定義。通常攻撃で全層を破壊する猶予を確保するため、最終詠唱を初案120tickから156tickへ延ばした。特定元素、新しい入力、必須の回復は要求しない。看板技を必ず見せるためのHP停止も追加しない。

美術は紹介画像・ゲーム内の側面寄り画像・既存の待機原画を直接確認して生成参照へ渡した。5体勢と赤葉の種を一枚で生成し、共通縮尺と接地位置で切り出した。赤い葉翼・クリーム色の目模様・桃色の花・小さい象牙色の冠付き植物・根の四肢・鉤爪を維持する。非人型の獣なので人間の頭身に変換しない。新readyを戦闘待機に使い、旧ギャラリー待機は保持する。

[Models Resource / asset 604015](https://models.spriters-resource.com/pc_computer/genshinimpact/asset/604015/)には同名のDAE/FBXと `Monster_Zharptitsa` の花・胴・翼テクスチャの掲載があるが、ローカルZIP取得は今回も403。実形状、背面と葉翼の取り付けの奥行きは未確認。左右別の作画、連続動作、被弾・撃破・音も残る。根洞は参照画像の色と環境から作ったラボ仮背景であり、正確な原作地理や本番3D配置の完成ではない。参照URL・ハッシュ・プロンプト・切り出し・共通縮尺・矩形数は[美術監査](../../evidence/immortal-construct-field-art-audit.json)に保存した。

検査は `C:/Python314/python.exe test_immortal_construct_field.py` と `node test_immortal_construct_field.mjs`。Chromeの既定接続先は `http://127.0.0.1:8845`、`LAB_URL` で変更できる。Luaでは固定範囲、多段・旧cast・反応の除外、全元素の削り、一層と全層の中断、命中と空振りの回復差、早期詠唱・通常詠唱、締切直前の破壊、未破壊時の有限終了、HP0優先、保存・退出・一度の報酬・再出現を検査する。

通常攻撃のみ・同行戦闘不能・回復なしのLua通し検査は75.75秒、HP140で討伐し、守りの全破壊も確認した。単独戦の証拠は `evidence/immortal-construct-field-{lua,browser}.json` とready・命の姿・軽量・ダウンの画面。現行の蘇生の守りはローカル共闘でも検証済み。幻境実機は未検証。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#游雪のブレードガーディアンと不滅の副産物)

Chromeは放浪者同行・炎技使用で35.47秒、HP140・帰還0。UI受注→門→守り全破壊→討伐→帰還→報告→再出現待ち保存を通過した。同じtickの命の姿は、描画指示がPNG30件、標準18,597件、軽量5,109件（72.5%減）。葉翼・花・胴・鉤爪の輪郭を確認したが、軽量版の細い根や小さい植物の線は省略される。実機FPS改善の保証ではない。同行と技を使う場合は45〜90秒目標より短く、装備別・成長後の周回バランスの調整は残る。
