# 重量級陸巡艦「バトルシップ」

> **2026-11-18：次設計への移行注記。** 最新の短いフィールド戦仕様は [ナド・クライ4戦](NOD_KRAI_QUARTET_MOVESETS.md) と [索引](MANIFEST_NOD_KRAI_QUARTET.json)、[QA](QA_NOD_KRAI_QUARTET.md) を参照。炎4castの割込みを外して通常3枠へ統合し、低い冷却板の任意中断へ移す。 以下は参照基点のWeb試作・既存試験の履歴で、新設計の実装／合格報告ではない。配置・報酬・保存の既存規則は保持する。

ナド・クライの町の広場で調査を受け、月明かりの道から「陸巡艦の整備庫」へ進む。整備庫の背景はラボ用の仮画像。本番では背景を3Dで配置する方針。

| 攻撃 | 予告と回避 |
| --- | --- |
| 歯車刃の薙ぎ払い | 橙色の歯車を持ち上げ、正面の帯を薙ぐ。 |
| 冷却砲の二連射 | 青い砲口を向け、先に近い地点、次に遠い地点を撃つ。 |
| 氷バリア・冷却放出 | 陸巡艦が冷却に入り、予告した一か所から冷気を放つ。バリアを割れば放出が止まる。 |

炎攻撃と燃焼で熱がたまり、二目盛りから装甲が赤くなって本体に攻撃が通りやすくなる。四目盛りで氷バリアを張る。バリアは通常攻撃でも削れ、炎攻撃なら二目盛り分削れる。多段技は一つの攻撃と数え、燃焼は時間ごとのダメージを一回ずつ数える。破壊すると約2.8秒間、陸巡艦が止まる。炎を使わず、通常攻撃で討伐することもできる。

熱とバリアの数値、技の寸法と時刻、地名、Lv124・HP1,170、報酬はラボの試案。再読込時はHPと討伐状態を保持し、熱とバリアを初期化する。 [原神公式の氷バリアに関する告知](https://genshin.hoyoverse.com/m/ja/news/detail/162806)
