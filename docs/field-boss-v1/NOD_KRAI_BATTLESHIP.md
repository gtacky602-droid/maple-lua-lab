# 重量級陸巡艦「バトルシップ」

## 通常のラボで試す

ナド・クライの町の広場で調査を受け、月明かりの道を通って陸巡艦の整備庫に入る。Lv124の本体HPは共闘でも1,170固定。通常ラボは、歯車刃の薙ぎ払い、冷却砲の二連射、冷却板が開く局所放出の順に進む試作を使う。

冷却砲は二つの着弾地点を足元の番号で示す。冷却放出では、60tickで前方の低い冷却板と放出範囲が決まる。板が開いてから出した直接攻撃が板に当たると、通常攻撃で1層、炎で2層削れる。多段技は一回の発動として数える。板と本体の命中はそれぞれ判定するので、板が開いていても本体HPは削れる。

300tickより前に5層を削り切れば、放出が止まり2.8秒の反撃時間ができる。板が閉じたら床の印から離れると、放出のあとに2.4秒の反撃時間ができる。途中保存では本体HPを保持し、再開時に攻撃順と冷却板を初期化する。討伐は455モラ、調査報告は8,800EXPと590モラ。 [通常ルートと保存](../../evidence/battleship-field-browser.json) · [Luaの検査](../../evidence/battleship-field-lua.json)

## 450万HPでの比較試作

`./Start-Lab.ps1 -Port 9101 -DraftFieldMoves -NoOpen` で短縮技案、`./Start-Lab.ps1 -Port 9099 -DraftBalance -NoOpen` で従来技の比較版を起動できる。どちらも本体HPは比較用の450万。Lv128のセーブでナド・クライの町から月明かりの道を通り、陸巡艦の整備庫へ入る。

短縮技案では薙ぎ払いと二連射のあと、陸巡艦が冷却に入る。低い位置に出る冷却板は、板が見えてから発動した直接攻撃で削れる。物理を含む通常の攻撃は1層、炎の攻撃は2層。多段技は一つの発動として数える。露出中に5層すべてを削ると放出を止め、2.8秒の反撃時間ができる。板が閉じたら床の印から離れ、放出のあとに本体へ戻る。板の表示中も本体HPを削れる。

| Lv128の獲得セーブ | 入場から討伐まで |
| --- | ---: |
| 従来技、通常攻撃と同行AI | 60.83秒 |
| 短縮技、通常攻撃と同行AI | 62.63秒 |
| 短縮技で冷却板を破壊して討伐 | 68.72秒 |

Luaでは板だけに当たる攻撃と、本体だけに当たる攻撃、両方に当たる攻撃を確認した。両方に当たる場合も、本体に入るダメージはその命中の一回分。途中HPを両方の比較版で復元できた。4人部屋では盤面と本体HPを共有し、放出は床の印に入った人だけに当たった。同行の攻撃を止めた試走でも、放出を横に避けてから地上攻撃で反撃できた。 [設計票](NOD_KRAI_QUARTET_MOVESETS.md) · [Luaの測定](../../evidence/draft-battleship-moves-lua.json)

Chromeでは冷却板の露出から、攻撃で5層を削って反撃時間に入るまでを確認した。同一フレームの描画命令は標準24,070から軽量6,322へ減った。 [Chromeの記録](../../evidence/draft-battleship-moves-browser.json) · [標準描画](../../evidence/short-battleship-plate.png) · [軽量描画](../../evidence/short-battleship-plate-light.png)

## 比較モードに残した従来技

ナド・クライの町の広場で調査を受け、月明かりの道から「陸巡艦の整備庫」へ進む。整備庫の背景はラボ用の仮画像。本番では背景を3Dで配置する方針。

| 攻撃 | 予告と回避 |
| --- | --- |
| 歯車刃の薙ぎ払い | 橙色の歯車を持ち上げ、正面の帯を薙ぐ。 |
| 冷却砲の二連射 | 青い砲口を向け、先に近い地点、次に遠い地点を撃つ。 |
| 氷バリア・冷却放出 | 陸巡艦が冷却に入り、予告した一か所から冷気を放つ。バリアを割れば放出が止まる。 |

炎攻撃と燃焼で熱がたまり、二目盛りから装甲が赤くなって本体に攻撃が通りやすくなる。四目盛りで氷バリアを張る。バリアは通常攻撃でも削れ、炎攻撃なら二目盛り分削れる。多段技は一つの攻撃と数え、燃焼は時間ごとのダメージを一回ずつ数える。破壊すると約2.8秒間、陸巡艦が止まる。炎を使わず、通常攻撃で討伐することもできる。

熱と氷バリアを使う方式は `-DraftBalance` で試せる。再読込時はHPと討伐状態を保持し、熱とバリアを初期化する。 [原神公式の氷バリアに関する告知](https://genshin.hoyoverse.com/m/ja/news/detail/162806)
