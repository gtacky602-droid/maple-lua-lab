# 游雪のブレードガーディアン：Webフィールド試作

> **2026-11-18：次設計への移行注記。** 最新の短い仕様は[スネージナヤの4戦](SNEZHNAYA_QUARTET_MOVESETS.md)・[索引](MANIFEST_SNEZHNAYA.json)・[QA](QA_SNEZHNAYA.md)を参照。HP55%で一度の氷棺とcoffinUsedの保存を維持し、全属性3回の任意中断・回復なし・三つの命中窓・REC144へ。旧元素免疫・0.75/1.2・期限回復を置換し、再予告は同じactivationとして扱う。 以下は参照基点の試作と既存試験の履歴で、新仕様の実装／合格報告ではない。配置・報酬・保存の既存規則を保持する。

雪の町で討伐調査を受け、凍った街道のx=1030の門から「氷冠の雪庭」へ進む。氷剣の二連薙ぎ・二条の氷剣・HP低下時の氷の棺を持つ。棺は通常攻撃でも壊せて、壊すと反撃の好機になる。左の門で街道へ戻り、雪の町で報告・保存できる。

[公式Ver.7.1更新案内](https://genshin.hoyoverse.com/m/ja/news/detail/166383)の検索索引本文で、HP低下時の棺、周期的な氷範囲攻撃、未破壊時の回復・氷剣反撃、破壊時の弱体化を確認した。直接取得では本文を読めていない。公式の星反応と雷・風による破壊促進は、本作の採用技との対応を未確定のまま残す。下記の物理代替、炎雷風の同率優遇、一戦一度、数値と時間割は本作の試案であり、原作の正確な挙動や本人の最終決定ではない。

[配置と仮数値](../../content/field-boss-spawns.json)、[Lua制御](../../field-drifting-snow.lua)が実行定義。特定の元素や新しい入力を必須にせず、通常攻撃のみでも討伐できる。看板技を必ず見せるためのHP停止や、HP0からの復活は追加しない。

保存には、このボスだけの真偽値 `flags.coffinUsed` を追加した。棺の失敗でHPが55%より上へ戻っても、保存・再開やマップの出入りで棺と回復を再使用しない。途中保存・退出では棺の層、残る範囲攻撃、回復、ダウンを取り消し、HPと使用済み状態を保持する。旧形式にこのフラグがない場合も読み込み可能で、HP55%以下なら使用済みと推定する。他ボスへの持ち込み、未定義キー、整数や文字列を真偽値として使う保存は拒否する。ローカル保存の検証であり、不正改変防止やWebマルチの権威サーバーを実現したものではない。

美術は紹介画像・ゲーム内の立ち姿・既存の待機原画を直接確認して生成参照へ渡した。5体勢と氷剣を一枚で生成し、共通縮尺と接地位置で切り出した。頭を大きく、胴と膝下を短くし、手・靴・剣を太めに整理した。readyの概測は頭部約122pxに対して頭頂から靴底が約361pxで、冠の突起を除いて約2.96頭身。境界は目視の概測で、3Dモデルの計測値ではない。新readyを戦闘待機に使い、旧ギャラリー待機を保持する。
