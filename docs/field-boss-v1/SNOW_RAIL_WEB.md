# 雪線の積替場と蒸気留置庫

スネージナヤの広場から始まるラボ独自の探索ルート。凍った街道を通って雪線の積替場と蒸気留置庫へ行ける。開放レベルと報酬は試作用。

1. Lv140で「積替場の安全確認」を受注する。街道の左寄りの門から積替場へ入り、保線カートを3台止めて広場で報告する。
2. Lv142で「止まらない除雪機」を受注する。積替場の右側の信号箱を `G` で操作すると、右端の門から蒸気留置庫に入れる。
3. 鉱殻除雪機を倒し、留置庫の奥の圧力計を `G` で確かめてから、広場で報告する。

積替場や留置庫から共闘の部屋に入れる。留置庫の門を開けるには、参加者それぞれが信号箱を操作する。 [共闘の攻撃判定と報酬](../COOP_WEB_PREVIEW.md#鉱殻除雪機と稜風の帆塔機)

## 鉱殻除雪機

橙の予告線は排雪突進の進路。薄緑の予告線は蒸気が床を覆う範囲。どちらも上段の足場やジャンプで避けられる。攻撃後に排気弁が開くと冷却に入り、通常攻撃を含むダメージに1.25倍の補正がかかる。試作HPは345、再出現待ちは60秒。攻撃と報酬の数値は `content/field-boss-spawns.json` にある。

作業車と除雪機の正面・側面ラフを参照して車体を制作した。本体は待機、突進、排気弁が開いた状態の3枚で、左右の車輪が接地する位置を揃えている。原画のハッシュ、切り出し範囲、各描画モードの矩形数は [美術記録](../../evidence/snow-rail-art.json) を参照。背景はラボ用の仮画像。本番で使う3D配置は検証対象外。

## ラボでの確認

`python test_snow_rail.py` で門、討伐、回避、報酬、保存を検査する。同じラボを開いた状態で `LAB_URL` を設定し、`node test_snow_rail.mjs` を実行すると、Chromeで移動、受注、報告、保存と再開を確認し、冷却姿勢を同一時刻でPNGと軽量16色の矩形描画に切り替えて比較できる。
