# 合成獣・フリューゲルレーヴェ：Webフィールド試作

スネージナヤの雪の町で討伐調査を受け、凍った街道のx=440の門から「古獣の氷原の西谷」へ進む。結晶刃の二連薙ぎ、翼刃の跳び込み、招雷／使風の3技を持つ。左の門で街道へ戻り、雪の町で報告・保存できる。

## 短縮技案をラボで試す

短縮技案はポート9101、比較元は9099。同じLv145の獲得セーブを読み込むと、どちらも最大HP600万で戦える。 [比較版の起動手順](../balance/FIELD_BALANCE_DRAFT_WEB.md#ナドクライの短縮技案を比較)

二連薙ぎと36tickの跳び込みに続き、正面への雷刃から風の放出へ移る。低い風球が出ている間に新しい攻撃を二打当てると、風の放出を止めて2.4秒の反撃時間に入る。横へ避けた場合も、放出後に同じ時間だけ反撃できる。本体には予告中も通常攻撃が通る。壁際で横へ抜ける余地が足りない場合は、少し移動してから範囲を予告し直す。 [技票](SNEZHNAYA_QUARTET_MOVESETS.md#3-フリューゲルレーヴェ--雷を避け風球を崩す)

Lv145の同じ装備で通常攻撃と同行AIを使った討伐は従来84.25秒、短縮案83.60秒。風球の破壊から始めた試走は92.10秒で、いずれも依頼報告と保存再開まで通った。Luaの4人部屋で雷25と風34の個別判定、風球の192〜323tick受付、時刻切れ、二打での中断、同じ多段攻撃の重複除外を確認。同行の攻撃を止めた別試走では、風を横へ避けてから地上で反撃した。 [Luaの記録](../../evidence/draft-flugel-moves-lua.json)

Chromeでは紫の雷の範囲から緑の風へ表示が変わり、通常攻撃で風の放出を止められた。同一フレームの描画命令は標準23,241、軽量6,434。軽量表示でも翼の輪郭、風球、床の予告が判別できる。 [Chromeの記録](../../evidence/draft-flugel-moves-browser.json) · [標準](../../evidence/short-flugel-orb.png) · [軽量](../../evidence/short-flugel-orb-light.png) · [中断時](../../evidence/short-flugel-interrupted.png)

獲得Lv145のルートセーブを用意してLuaの試験を実行すると、ブラウザー試験用セーブも作成する。

```powershell
python test_draft_flugel_moves.py
node test_draft_flugel_moves.mjs
```
