# 秘源機兵・統御デバイス

> [第10回の詳細設計](NATLAN_REMAINING_MOVESETS.md)の三技と冷却時間をLuaラボで試せる。数値はラボの試作値。 [検査項目](QA_NATLAN_REMAINING.md)

ナタの谷の集落で討伐調査を受ける。赤岩の採掘路と岩場の道を通ってアトクパンの溶岩棚へ入り、入口側の分岐から「統御の遺構」へ向かう。遺構はラボ用の仮背景で、本番では3D配置を使う方針。

| 攻撃 | 見分け方と回避 |
| --- | --- |
| 水刃の三連 | 開いた輪から水刃を三度振る。攻撃帯の外へ出るか、一打ずつ跳び越える。 |
| 滑走水刃 | 足元に低い水刃が進む。予告した進路から離れるか、刃が届く前に跳ぶ。 |
| 掃討・三連噴流 | 固定した三地点から順に噴流が上がる。次の番号を見て範囲から離れる。 |

掃討モードでは三つの着弾地点を足元の番号で示す。地点が確定してから50tickごとに液流が一目盛りたまり、噴流の威力が上がる。確定後に出した氷攻撃を直撃させると、一技につき一目盛り減り、蓄積が72tick（1.2秒）止まる。別の氷攻撃が当たると停止時間は1.2秒に戻る。発生済みの噴流は最後まで続き、発生時の威力を使う。三連噴流が終わって輪が沈むと2.4秒の反撃時間がある。通常攻撃だけでも、噴流を避けて討伐できる。

三種の攻撃、液流の数値と冷却時間、地名、Lv112・HP1,125、難度と報酬はラボ用の試案。公式告知の液流蓄積と氷による抑制を題材にした。 [原神公式Ver.5.6告知](https://genshin.hoyoverse.com/zh-tw/news/detail/155739)

現行試作のローカル共闘では、参加者の氷攻撃が同じ液流を減らす。噴流の発生時に威力が確定し、後から同じ噴流に入った参加者にもその威力を適用する。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#輝ける溶岩の龍像と秘源機兵統御デバイス)
