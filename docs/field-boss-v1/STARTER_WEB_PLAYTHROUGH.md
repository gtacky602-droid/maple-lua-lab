# モンドからスメールまでのフィールドボス4戦

画面のボス名の横に「反撃の隙」が出たら、攻撃後の立て直し中。急凍樹の核が割れたときは「核を破壊・ダウン」と表示される。4体の攻撃のタイミングは既存の設計票に照合した。 [4体12技の設計](STARTER_MOVESETS.md)

| ボス | プレイヤーLv | 入場ルートの最後 | 討伐まで |
| --- | ---: | --- | ---: |
| 急凍樹 | 16 | 国境の道 → 挑戦入口 → 霜花の洞窟 | 43.35秒 |
| 無相の風 | 16 | 南の街道 → 挑戦入口 → 風鳴りの広場 | 38.55秒 |
| 無相の雷 | 18 | 南の街道 → 挑戦入口 → 雷紋の岩棚 | 36.68秒 |
| マッシュラプトル | 60 | 雨林の道 → 菌傘の谷 | 17.10秒 |

新規冒険から獲得した記録を読み込み、現地の門を通過。各戦の接敵後から撃破までをLua内の時間で計測した。モンド3戦は初期剣を使用。マッシュラプトル戦では旅の途中で拾った花と羽を装備した。4体とも各3技の発動と反撃の隙への命中を見届け、報告と報告済みセーブの復元まで行った。急凍樹は首落としの予告を見て回避し、地上近接で根元を攻撃してダウンを取った。 [Luaの実測](../../evidence/earned-starter-bosses-lua.json)

マッシュラプトルの依頼「菌傘の谷の討伐調査」は、Lv60でスメール・樹陰の広場から受注できる。雨林の道の門を通り、菌傘の谷で討伐して広場へ戻る。初回報告の試作値は4,000 EXPと300モラ。討伐後の再戦は既存のフィールドボスと同じく再出現を待つ。Chromeでも実際に受注し、現地で「反撃の隙」を見て討伐し、報告後の保存を開き直した。 [Chromeの実測](../../evidence/jadeplume-commission-browser.json) · [反撃の隙の表示](../../evidence/jadeplume-commission-recovery.png)
