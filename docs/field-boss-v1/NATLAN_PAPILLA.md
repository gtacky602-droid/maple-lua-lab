# 深遠なるミミックパピラ・I型

ナタの谷の集落で討伐調査を受け、岩場の道から「紫影の石窟」へ向かう。石窟はラボ用の仮画像で、本番の背景は3D配置を使う方針。

| 姿と攻撃 | 予告と回避 |
| --- | --- |
| 樹影の首落とし | 紫の花冠が持ち上がり、正面の帯へ一度落ちる。 |
| 機竜影の刃翼二連 | 刃翼を交互に振る。二打目まで予告の帯から離れる。 |
| 菌獣影の跳ね落ち | 低く身を縮め、着地位置を先に示して短く跳ぶ。着地後は2.4秒の反撃時間がある。 |

変身中も根に攻撃が当たり、姿が変わってもHP・付着・継続ダメージ・標的は続く。討伐で得る報酬は一回。離脱や再読込で暗い花へ戻った場合も、削ったHPを維持する。

三形態だけを選んだラボの試案。名称、Lv108、HP 1,050、難度と報酬もラボ用の調整値。 [動作設計案](NATLAN_ORIGINS_MOVESETS.md) ・ [原神公式の紹介](https://genshin.hoyoverse.com/en/news/detail/126992)

ローカル共闘では擬態した個体のHP・付着・着地点を共有する。擬態前に発動した攻撃が変身後に届いても、同じHPから減る。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#秘源機兵機巧デバイスと深遠なるミミックパピラi型)
