# 守護者・堕天：風息山のフィールド試作

ドーンマンポートの入口拠点で討伐調査を受け、x=970の門から風息山の石庭へ進む。金槍の二連攻撃、槍落としと降下、元素監視の3技を持つ。討伐後は左の門から入口拠点へ戻り、報告・保存できる。

## 短縮技案をラボで試す

短縮技案のラボはポート9101、比較元は9099。同じ獲得Lv18のセーブで、最大HP700の守護者・堕天と戦える。槍を落とす間は低い位置を維持し、そのあと36tickだけ浮上して床へ着地する。 [比較版の起動手順](../balance/FIELD_BALANCE_DRAFT_WEB.md#ナドクライの短縮技案を比較)

二回の監視で、それぞれ最初に当たった炎・水・雷・氷の直接攻撃が星の色と攻撃元素に反映される。未記録の星は灰白色で物理攻撃。星はどの元素でも2層あり、通常攻撃1回で1層を削る。片方の破壊で対応する落光が消え、両方を壊すと3秒の反撃時間が開く。本体には監視中も攻撃できる。看板技の全長は約19.2秒から9.2秒。 [技票](RADIANT_VIGIL_MOVESETS.md#5-守護者堕天--受けた元素が二つの星へ映る)

モンドから入口拠点へ歩いたLv18のセーブで、同じ装備と通常攻撃・同行AIを使った討伐は従来技32.72秒、短縮案33.48秒。両版で討伐・依頼報告・保存再開を確認した。Luaの4人部屋では、二回の監視で炎と水を記録し、それぞれの範囲で26ダメージを確認した。未記録の星では片方だけを予定攻撃と同じtickに壊して、その攻撃だけを止めた。最終受付395tickと、396tickに解決した攻撃の失効も確認した。 [Luaの実測](../../evidence/draft-fallen-vigil-moves-lua.json)

Chromeではアンバーの炎を一つ目だけに記録し、朱色の星と灰白色の未記録の星を表示した。旅人へ交代し、通常攻撃の入力で二つとも壊して反撃時間に入った。同一フレームの描画命令は標準20,525、軽量5,451。軽量表示でも星の色と輪郭が判別できる。 [Chromeの記録](../../evidence/draft-fallen-vigil-moves-browser.json) · [標準](../../evidence/short-fallen-vigil-stars.png) · [軽量](../../evidence/short-fallen-vigil-stars-light.png) · [中断時](../../evidence/short-fallen-vigil-interrupted.png)

Lv18のルートセーブがあれば、Luaの試験がChrome用セーブも作成する。

## 従来技

[公式「月の六」更新案内](https://genshin.hoyoverse.com/en/news/detail/163454)で、炎・水・雷・氷の被ダメージ回数を記録すること、2回の監視後に2つの元素星を出し、すべて壊すと大技を中断できることを確認した。原作の元素制約をそのまま進行ロックにせず、本作では物理通常でも星を壊して勝てる。以下は本作の試案で、原作のフレーム解析値や本人の最終決定ではない。

実行定義は[配置と仮数値](../../content/field-boss-spawns.json)、制御は[Lua](../../field-fallen-vigil.lua)。本体HPは監視・星の処理中も攻撃でき、HP0を最優先する。星破壊の反動でHP0になった場合も、一度の討伐・報酬と全召喚物の片付けで終える。必ず看板技を見せるためのHP停止は加えていない。

美術は公式紹介とゲーム内画像を直接確認し、既存待機原画も生成参照に使った。1枚で5体勢と星の部品を生成し、本体5体勢を同じ縮尺で切り出した。片側の大きな白翼、金の眼状装甲、赤黒の分割体、金の長槍を保つ。人間ではない構造体なので、人体の頭身へ強制変形しない。新しい戦闘待機はready姿勢を使い、旧ギャラリー待機は履歴として保持する。隣の絵へはみ出した槍と翼は、間の空間で切り出しを分けている。

モデル一覧には `Nihilita / The Open-Eyed`（Models Resource / asset 602345）と `Monster_Watcher_Primo_01` テクスチャ名があった。ただし、このモデルが今回の基本外観に対応するかは確定していない。ローカルでのページ・ZIP取得は403で、実形状や背面・立体的な奥行きは未確認。画像の反転では大翼の側も反転する。左右別・連続モーション・被弾・撃破・音は残る。背景はラボ用の仮画像で、本番3D配置の完成ではない。参照URL・ハッシュ、プロンプト、切り出し・縮尺・矩形数は[美術監査](../../evidence/fallen-vigil-field-art-audit.json)に保存している。

検査コマンドは `C:/Python314/python.exe test_fallen_vigil_field.py`、`node test_fallen_vigil_field.mjs`。Chromeは既定で `http://127.0.0.1:8842` を使用し、`LAB_URL` で変更できる。Luaでは3/6hit、別元素3hit、旧cast・反応除外、活性・惰性の差、物理代替、片方だけの中断、最終tickの破壊、致死反動、時間切れ、退出・保存・報酬を検査する。

今回のLua検査では、通常攻撃のみ・同行戦闘不能・回復なしで54.15秒、HP140で討伐。Chromeではアンバーを操作して炎を2回記録（3hit→6hit）し、通常攻撃で2つの活性星を壊した後に旅人へ交代して34.33秒で討伐。UIで受注→門→戦闘→帰還→報告→再出現待ち保存まで通過。2つの活性星がある同じtickの描画指示はPNG30件、標準20,533件、軽量5,459件（約73%減）。実機の処理時間や品質を保証する値ではない。
