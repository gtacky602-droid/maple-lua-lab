# 波濤の投錨者：Webフィールド試作

## 短縮技案をラボで試す

ノヴォキッチェヴの入口拠点で討伐調査を受け、探索路から「西港の潮洞」へ進む。ポート9101で短縮技案、9099で従来技を試せる。同じ獲得Lv160のセーブなら、両方とも最大HP680万。 [通常4戦の比較](../balance/FIELD_BALANCE_DRAFT_WEB.md#スネージナヤ4戦の短縮技案)

通常技の投錨では、錨の着地点と引き戻す鎖の通り道に、水属性の命中判定が一回ずつある。看板技では60〜239tickの間、本体にHPダメージを与える新しい直接攻撃で飲み物を止められる。物理は4打、雷は2打。同じ技の多段は一打分。飲み切った場合は288・354・420tickに正面へ三連錨が来る。中断しても、三連錨を外へ避けても、2.4秒の反撃時間が開く。 [技票](SNEZHNAYA_QUARTET_MOVESETS.md#6-波濤の投錨者--飲み物を止めるか三連錨を読む)

獲得Lv160の同じ装備で、通常攻撃と同行AIを使うと従来87.30秒、短縮案86.73秒。飲み物を狙って中断した試走は93.37秒。飲み始めから同行の攻撃を止めて三連錨をよけた試走は153.25秒。すべて討伐・依頼報告・保存再開まで確認した。Luaの4人部屋では、着地と引き戻しが別々の位置にいるプレイヤーに当たり、被弾で強制移動しないことを確認した。 [Luaの実測](../../evidence/draft-wavebinder-moves-lua.json)

Chromeでは、錨が飛んで床へ戻る動きと、通常攻撃での飲み物の中断を確認した。同一フレームの描画命令は標準15,852、軽量4,321。軽量表示でも杯を掲げる姿勢と中断の残り枠が判別できる。 [Chromeの記録](../../evidence/draft-wavebinder-moves-browser.json) · [引き戻す錨](../../evidence/short-wavebinder-returning-anchor.png) · [標準](../../evidence/short-wavebinder-drink.png) · [軽量](../../evidence/short-wavebinder-drink-light.png) · [中断時](../../evidence/short-wavebinder-interrupted.png)


Luaの試験は獲得Lv160のルートセーブから、ブラウザー試験用のセーブも作成する。

```powershell
python test_draft_wavebinder_moves.py
node test_draft_wavebinder_moves.mjs
```

## 従来技

ノヴォキッチェヴの入口拠点で討伐調査を受け、探索路のx=1030の門から「西港の潮洞」へ進む。錨の薙ぎ払い・投錨と鎖の引き戻し・熱い飲み物の3種類を持つ。飲み物を妨害すれば強化を遅らせられ、強化された場合も雷または時間経過で解除できる。左の門で探索路へ戻り、入口拠点で報告・保存する。

[公式Ver.7.2更新案内](https://genshin.hoyoverse.com/ja/news/detail/167187)の検索索引本文で、飲み物による豪胆値の蓄積、満タン時の勇躍、攻撃と全元素・物理耐性の上昇、時間消費と雷による豪胆値の減少を確認した。星反応による飲み物の妨害は本作の採用技との対応が未確定のため未接続。下記の通常攻撃による代替、雷の優遇値、時刻・報酬・攻撃の翻案は本作の比較用試案で、原作の正確な値や本人の最終決定ではない。

| 項目 | 試作値・挙動 |

| 登録 | `boss-25134601` / `wavebinder-tide-cavern` / `wavebinder-commission` |

[配置と仮数値](../../content/field-boss-spawns.json)、[Lua制御](../../field-wavebinder.lua)が実行定義。勇躍を雷なしでも終えられる物理経路を残し、無敵や必須元素を追加しない。強化中の薙ぎ払いと投錨の両方が通常の時間内に発動するよう、豪胆値の消費間隔を初案50tickから60tickへ調整した。勇躍中の飲み物の順番では60tickの息継ぎを選び、再強化で時計を延長しない。

美術は紹介画像・実戦画像・既存待機原画を直接確認して生成参照へ渡した。5体勢と独立した錨を一枚で生成し、共通縮尺と接地位置で切り出した。船乗り帽、青白いヒレ、鎖の首飾り、白い丸い腹とシアンの紋、太い手足、鉤爪、二股の尾、大きな錨を維持する。非人型の海の獣として、人体の頭身へ変換しない。新readyは戦闘待機に使い、旧ギャラリー待機を保持する。

英語名でModels Resource等の3Dモデルを検索したが、利用できる同名モデルは見つからなかった。背面と尾全体の形状、左右別の作画、連続動作、被弾・撃破・音は未完。反対向きはミラー表示。仮背景と配置名は港の西側の洞窟を参考にした独自の2D配置で、原作地理・地下構造・本番3Dの完成ではない。既存ノヴォキッチェヴ分岐の正式な地形の照合も残る。参照URL・ハッシュ・プロンプト・切り出し・共通縮尺・矩形数は[美術監査](../../evidence/wavebinder-field-art-audit.json)に保存した。

検査は `C:/Python314/python.exe test_wavebinder_field.py` と `node test_wavebinder_field.mjs`。Chromeの既定接続先は `http://127.0.0.1:8846`、`LAB_URL` で変更できる。固定範囲と着地点、同cast・旧cast・反応の除外、物理と雷による妨害、部分豪胆値、勇躍中の3連薙ぎと投錨/鎖、有限終了、早期満タン後の再充填防止、次の命中直前の雷解除、HP0優先、保存・退出・一度の報酬・再出現をLuaで検査する。

通常攻撃のみ・同行戦闘不能・回復なしでは89.55秒、HP140で討伐し、飲み物を3回妨害、勇躍の自然終了を2回確認した。飲み物を意図的に妨害せず雷も使わない場合は125.88秒、HP140・自然終了6回で討伐できるが、45〜90秒目標より長い。装備・成長・周回バランスは調整が残る。証拠は `evidence/wavebinder-field-{lua,browser}.json` と、待機・飲み物・各中断・勇躍・軽量の画面。幻境実機と全体の完成判定は未確認。Webマルチには現行試作を接続した。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#波濤の投錨者)

Chromeは放浪者同行・雷技使用で46.35秒、HP140・帰還0。UI受注→門→飲み物中断→勇躍→雷で解除→討伐→帰還→報告→保存を通過。同じtickの勇躍場面は、描画指示がPNG37件、標準14,502件、軽量4,060件（約72%減）。帽子・腹の紋・錨・鎖・太い四肢と接地を目視した。軽量版は細い鎖穴や装飾が粗くなる。実機FPS改善の保証ではない。
