# 秘源機兵・機巧デバイス

ナタの谷の集落で討伐調査を受け、岩場の道から「秘源の機構室」へ向かう。機構室はラボ用の仮画像で、本番の背景は3D配置を使う方針。

| 攻撃 | 予告と回避 |
| --- | --- |
| 鉤爪の交差打ち | 鉤爪が交互に開き、同じ帯を二度薙ぐ。予告された帯から離れる。 |
| 照準・二連線 | 二つの砲口が同じ低い帯を狙う。二段とも範囲外へ出るか、跳んでかわす。 |
| 集積・球雷砲 | 予告された着弾範囲に一発落ちる。範囲外へ退くか、集積器を先に壊す。 |

集積器は、明るい目盛りが出てから別々の攻撃を3回当てると壊れる。通常攻撃も有効で、多段技は一つの攻撃として数える。壊すと球雷砲が止まり、約3秒のダウンと短い立ち直りが入る。立ち直り後20秒は再び壊せる状態にならない。

地上の集積器一つ、部屋の名称、Lv106・HP 1,020・報酬はラボの試案。通常攻撃で討伐できる。機体は参照画像から作画した待機姿勢と戦闘用5姿勢で表示する。 [動作設計案](NATLAN_ORIGINS_MOVESETS.md) ・ [原神公式の紹介](https://genshin.hoyoverse.com/m/en/news/detail/126305)
