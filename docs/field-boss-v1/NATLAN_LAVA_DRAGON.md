# 輝ける溶岩の龍像

現行のWebラボは、岩と熔焰の各2技に、加熱・過燃焼・冷却を組み合わせる試作。[第10回の詳細設計](NATLAN_REMAINING_MOVESETS.md)には、熱を使わず看板技の中で自発的に変形する三技版の案がある。

ナタの谷の集落で討伐調査を受け、赤岩の採掘路と岩場の道を経由して「アトクパンの溶岩棚」へ向かう。溶岩棚の画像はラボ用の仮背景。本番では3D配置を使う方針。

| 状態 | 攻撃と見分け方 |
| --- | --- |
| アースゴーレム | 両腕に岩の装甲が見える。腕の打ち下ろしと、足元から順に走る二連の地割れを使う。 |
| 熔焰の龍 | 上体が起き、胴に橙色の溶岩が流れる。進路を予告して突進し、二つの地点から順に溶岩を噴出させる。 |
| 過燃焼 | 核が白く光り、体を伏せる。進行中の攻撃が止まり、最大3秒の反撃時間ができる。 |

機体の上の目盛りは熱を表す。別々の炎攻撃を2回当てると熔焰の龍へ変わり、さらに2回で過燃焼になる。水・氷は熱を一つ下げ、過燃焼中なら岩の姿へ戻す。過燃焼は時間経過でも解ける。多段攻撃は一回と数え、温度が変わっても同じHPを削り続ける。

HUDには熱と反撃できる残り時間が出る。地割れと熔岩噴出の「1」「2」は、足元の下に表示する。

通常攻撃だけでも討伐できる。熱の目盛りと閾値、3秒の過燃焼と被ダメージ補正、技の寸法・時刻、地名、Lv110・HP1,100と報酬はラボの試案。再読込では削ったHPと討伐状態を保持し、熱は初期値へ戻す。 [原神公式の形態説明](https://genshin.hoyoverse.com/ja/news/detail/155172)

現行試作のローカル共闘では、参加者の炎攻撃を一つの熱目盛りに加算し、形態・過燃焼と噴出地点を共有する。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#輝ける溶岩の龍像と秘源機兵統御デバイス)
