# 集光の月ヤモリ

ナド・クライの町の広場で討伐調査を受け、月明かりの道の東側から「波追いの峠の月石洞」へ進む。洞窟の背景画像と横方向の道はラボ用の仮素材。本番では背景を3Dで配置する方針。

## 短縮技案をラボで試す

短縮技案のラボはポート9101。比較元はポート9099。同じ獲得Lv133のセーブを読み込むと、両方とも最大HP450万で戦える。 [比較版の起動手順](../balance/FIELD_BALANCE_DRAFT_WEB.md#ナドクライの短縮技案を比較)

二連の尾と跳び込みのあと、前方の低い位置に「錨月の岩」が出る。通常攻撃で1層、岩攻撃で2層を削り、5層を壊すと掃蕩を中断して3秒の反撃時間が開く。岩の受付は84〜299tick。残った場合は300tickで岩が消え、324tickから正面の予告範囲を掃蕩する。横に避けても2.4秒の反撃時間を取れる。どちらのルートでも本体へ通常攻撃が通る。 [技票](RADIANT_VIGIL_MOVESETS.md#4-集光の月ヤモリ--低い岩を壊して掃蕩を止める)

獲得Lv133の同じ装備、通常攻撃と同行AIで、討伐まで従来技79.55秒、短縮技案63.17秒。岩を狙って中断した試走は70.53秒。すべて依頼報告と保存再開まで確認した。別試走では同行の攻撃を止め、岩を残して掃蕩を横へ避けてから反撃した。Luaの4人部屋では、同じ多段castの層削りが1回、299tickの命中は有効、300tickに解決した予約攻撃は期限切れになることを確認した。 [Luaの測定](../../evidence/draft-moongecko-moves-lua.json)

Chromeでは通常攻撃で岩を壊し、反撃時間の表示を確認した。同一戦闘フレームの描画命令は標準14,956、軽量3,981。 [Chromeの記録](../../evidence/draft-moongecko-moves-browser.json) · [標準](../../evidence/short-moongecko-anchor.png) · [軽量](../../evidence/short-moongecko-anchor-light.png) · [中断時](../../evidence/short-moongecko-interrupted.png)

獲得Lv133のルートセーブを用意してからLuaの試験を実行すると、Chromeの試験用セーブも作成する。短縮技案のラボを起動してブラウザー試験を実行する。

```powershell
python test_draft_moongecko_moves.py
node test_draft_moongecko_moves.mjs
```

## 従来技

| 試作用の攻撃 | 予告と回避 |
| --- | --- |
| 月石尾の二連薙ぎ | 前方に固定した帯を二度薙ぐ。範囲外へ出るか、タイミングを合わせて跳ぶ。 |
| 岩尾の跳び込み | 予告した地点へ跳び込む。浮いている間は本体の当たり判定も上がる。 |
| 月石の錨・空虚の残響 | 付近の相手に集光の繭を付け、月石の錨を置く。錨が残ると、予告範囲へ一度攻撃する。 |

錨は新しく出した通常攻撃なら一回につき一層、岩攻撃なら二層削れる。多段技は一回と数え、錨が出る前に使った技と元素反応は層数を進めない。五層を壊すと本体へ岩ダメージが入り、残響を止めて約3秒の反撃時間を作れる。本体のHPは錨が残っていても削れる。

集光の繭は、与えるダメージが75%、受ける回復量が70%になる試作。各キャラがHPを満タンまで回復すると繭が外れ、8秒間のダメージ強化を得る。月ヤモリへの岩ダメージも8秒間通りやすくなる。幻月蝶と回復・解除・退出処理を共有する。

五層、反動の基礎威力80、倍率、技の時間、地名、Lv132・HP1,160、報酬は試案。保存では本体HPと再出現待ちを保持し、進行中の錨と繭を初期化する。対応する3Dモデルは確認できず、裏側と尾の奥行きは未確認。 [原神公式の敵紹介](https://genshin.hoyoverse.com/m/ja/news/detail/162806)
