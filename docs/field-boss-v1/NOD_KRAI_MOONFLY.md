# 集光の幻月蝶

ナド・クライの町の広場で討伐調査を受け、月明かりの道の西側から「幻月蝶の岩窟」へ進む。岩窟の画像と横方向の道はラボの試案。本番では背景を3Dで配置する方針。

## 短縮技案をラボで試す

短縮技案のラボはポート9101。比較元はポート9099。同じLv130のセーブを読み込むと、両方とも最大HP410万で比較できる。 [比較版の起動手順](../balance/FIELD_BALANCE_DRAFT_WEB.md#ナドクライの短縮技案を比較)

二連の回し蹴りと二つの月光弾の後、羽から草・炎・炎の三波が来る。予告した正面の範囲に各25ダメージ。第一波でHPが減った生存キャラだけに繭が付き、与ダメージが10%下がる。最大3秒で解け、HPが少しでも回復すればその場で解ける。最後の波から羽を閉じると2.4秒の反撃時間に入る。 [技票](RADIANT_VIGIL_MOVESETS.md#3-集光の幻月蝶--緑の羽赤い羽最後の放出)

獲得Lv130の同じ装備と通常攻撃・同行AIで、入場から討伐まで従来技63.42秒、短縮技案57.65秒。両版で討伐報酬と依頼報告が一致した。Luaの4人部屋では、範囲内でも無敵・盾の全吸収・致死ダメージで繭が付かず、別の発生源の繭を保持したうえで撃破時に対象の繭が消えることを確認した。 [Luaの測定と状態検査](../../evidence/draft-moonfly-moves-lua.json)

Chromeでは部分回復が見えるよう旅人の開始HPを減らした獲得セーブを使用。水の領域でHPが9,886から10,155.275に増え、最大HP10,771に届く前に繭が解けた。同じ戦闘フレームの描画命令は標準11,723、軽量3,078。 [Chromeの記録](../../evidence/draft-moonfly-moves-browser.json) · [PNG](../../evidence/short-moonfly-first-wing-png.png) · [標準](../../evidence/short-moonfly-first-wing.png) · [軽量](../../evidence/short-moonfly-first-wing-light.png)

獲得Lv130のルートセーブを用意してから Lua の試験を実行すると、Chromeの試験用セーブも作成する。短縮技案のラボを起動してブラウザー試験を実行する。

```powershell
python test_draft_moonfly_moves.py
node test_draft_moonfly_moves.mjs
```

## 従来技

| 試作用の攻撃 | 予告と回避 |
| --- | --- |
| 二連の回し蹴り | 前方の印の内側を二度蹴る。範囲の外へ出るか、タイミングを合わせて跳ぶ。 |
| 二つの月光弾 | 近い印、遠い印の順に月光弾が落ちる。 |
| 集光の繭・羽の解放 | 翼を開いて付近の相手に集光の繭を付ける。二度の羽の攻撃後、繭の形に集光し、予告範囲で爆発する。 |

集光の繭にかかったキャラは、与えるダメージが75%、受ける回復量が70%になる。HPを満タンまで回復すると繭が外れ、8秒間、与えるダメージが120%になる。旅人と同行者の解除は個別に判定する。旅人の既存の回復技・料理・回復する防御技を同じ回復処理へ接続した。

羽の解放中に炎を当てると炎の羽へ、水か氷を当てると草の羽へ変わる。姿、予告の色、攻撃の元素を一緒に切り替える。物理攻撃だけでもHPを削れ、回復を使わずに討伐できる。

繭付与時のHP減少12、倍率、時刻、地名、Lv130・HP1,050、報酬はラボの試案。退出・討伐時に繭と強化を片付け、保存では本体HPと再出現待ちを保持する。対応する3Dモデルは確認できず、羽の奥行きと裏側は未確認。 [原神公式の敵紹介](https://genshin.hoyoverse.com/ja/news/detail/159349)
