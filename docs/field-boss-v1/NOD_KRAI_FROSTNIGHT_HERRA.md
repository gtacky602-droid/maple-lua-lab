# 霜夜の空を巡る霊主

## 短縮技案をラボで試す

`./Start-Lab.ps1 -Port 9100 -DraftFieldMoves -NoOpen` で短縮技案を起動できる。比較元は `./Start-Lab.ps1 -Port 9099 -DraftBalance -NoOpen`。同じLv128セーブを読み込み、ナド・クライの町から月明かりの道を通って霜夜の石壇に入る。どちらのラボも本体HPは比較用の450万。 [設計票](NOD_KRAI_QUARTET_MOVESETS.md#5-霜夜の空を巡る霊主--黒い翼の波を二度読む)

短縮技案では、暗い翼を広げたときに床の両端の印が示す範囲を確認する。一波目と二波目は同じ位置に来るので、跳ぶか端の外へ移動してかわす。二波目が消え、白い姿に戻ると「反撃の隙」が2.4秒続く。薄闇でも本体に通常のダメージが通り、氷や月の技を用意する必要はない。飛翔は36tick（0.6秒）で着地する。

| Lv128の獲得セーブ | 入場から討伐まで |
| --- | ---: |
| 比較版HP＋従来技、通常攻撃と同行AI | 68.42秒 |
| 比較版HP＋短縮技、通常攻撃と同行AI | 63.37秒 |
| 短縮技案で二波を回避し、反撃して討伐 | 72.98秒 |

Luaでは、一波目をジャンプ、二波目を歩いて避け、324tickから始まる反撃時間に地上攻撃を当てた。途中セーブを双方の比較版に読み込み、HP・経過時間・出現世代を確認した。4人部屋でも最大HPは450万で、同じ範囲に入った人だけが被弾した。Chromeでは一波目のジャンプ、二波目の範囲外移動、反撃表示を確認。同じフレームの描画命令数は標準の22,481から軽量表示の5,558へ減った。 [Lua](../../evidence/draft-herra-moves-lua.json) · [Chrome](../../evidence/draft-herra-moves-browser.json) · [標準描画](../../evidence/short-herra-wave.png) · [軽量描画](../../evidence/short-herra-wave-light.png)

## 従来技の比較元

ナド・クライの町の広場で調査を受け、月明かりの道の西側から「霜夜の石壇」に入る。石壇の背景はラボ用の仮画像。本番では背景を3Dで配置する方針。

| 試作用の攻撃 | 予告と当たり判定 |
| --- | --- |
| 銀翼の二連薙ぎ | 翼を構え、正面の同じ帯を二度薙ぐ。地面の白い印で範囲を確認できる。 |
| 飛翔からの着地 | 地面の印へ飛び込む。飛翔中はボスの当たり判定も上がり、着地時は印の内側が危険範囲になる。 |
| 薄闇の二連波 | 紫の姿に変わり、受けるダメージが65%になる。予告範囲に二度の波を放つ。 |

薄闇は氷または月のダメージを与える技を三回当てると解除できる。多段技は一回と数え、解除後は残りの波が止まって約2.4秒の反撃時間ができる。自然に明けると、薄闇中に最も多くダメージを受けた通常元素に3.5秒間適応し、その元素のダメージが58%になる。通常攻撃だけでも討伐できる。

地名、解除条件、耐性の割合、攻撃のタイミング、Lv126・HP1,200、報酬はラボの試案。再読込ではHPと討伐後の再出現待ちを保存し、戦闘中の姿勢と薄闇を初期化する。 [ゲーム内チュートリアルの収録](https://gi.gachabase.net/tutorials/enemies/3099/frostnight-herra/release?lang=en)
