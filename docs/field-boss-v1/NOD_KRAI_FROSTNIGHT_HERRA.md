# 霜夜の空を巡る霊主

ナド・クライの町の広場で調査を受け、月明かりの道の西側から「霜夜の石壇」に入る。石壇の背景はラボ用の仮画像。本番では背景を3Dで配置する方針。

| 試作用の攻撃 | 予告と当たり判定 |
| --- | --- |
| 銀翼の二連薙ぎ | 翼を構え、正面の同じ帯を二度薙ぐ。地面の白い印で範囲を確認できる。 |
| 飛翔からの着地 | 地面の印へ飛び込む。飛翔中はボスの当たり判定も上がり、着地時は印の内側が危険範囲になる。 |
| 薄闇の二連波 | 紫の姿に変わり、受けるダメージが65%になる。予告範囲に二度の波を放つ。 |

薄闇は氷または月のダメージを与える技を三回当てると解除できる。多段技は一回と数え、解除後は残りの波が止まって約2.4秒の反撃時間ができる。自然に明けると、薄闇中に最も多くダメージを受けた通常元素に3.5秒間適応し、その元素のダメージが58%になる。通常攻撃だけでも討伐できる。

地名、解除条件、耐性の割合、攻撃のタイミング、Lv126・HP1,200、報酬はラボの試案。再読込ではHPと討伐後の再出現待ちを保存し、戦闘中の姿勢と薄闇を初期化する。 [ゲーム内チュートリアルの収録](https://gi.gachabase.net/tutorials/enemies/3099/frostnight-herra/release?lang=en)
