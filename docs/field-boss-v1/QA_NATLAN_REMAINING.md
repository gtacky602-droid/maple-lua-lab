## 2. 再現コマンド

リポジトリのルートから、標準ライブラリだけで実行する。

```bash
python docs/field-boss-v1/validate_natlan_remaining.py --self-test
python -O docs/field-boss-v1/validate_natlan_remaining.py --self-test
python docs/field-boss-v1/validate_natlan_remaining.py --self-test --check-runtime-source
python -m py_compile docs/field-boss-v1/validate_natlan_remaining.py
```

今回の出力:

```text
PASS: 3 encounters / 9 attacks / 17 direct windows / 2 proxy routes
PASS: catalog IDs and declared migration IDs checked; Lua behavior not tested
PASS: current runtime-source IDs match the migration snapshot
PASS: 28 invalid fixtures rejected
```

3行目は `--check-runtime-source` を付けた場合だけ。通常検査は宣言内の移行ID整合とencountersのID存在を確認する。このオプションは**旧試作の技IDと移行元スナップショットの完全一致**を確認するもので、将来FLD04を実際に退役させた後は省略する。移行後の新ランタイムの正しさはLua/ブラウザの専用試験で確認する。

最新検査器に対する実績は通常／`-O`とオプション確認、コンパイル。旧ファイルに対する別の起動オプションの実績を、最新版で再実行したものとして足さない。

### 龍像

岩2技＋熔焰2技を3パターンに整理する。FLD01/02の主な時間割を保持し、FLD03を自発変身付き看板へ。FLD04は独立攻撃から外す。旧`onHit`の熱加算/水氷の形態復帰、`preempt`の過燃焼、`damageFactor`、熱UIをまとめて置換する。HP、付着、継続損傷、既存画像と報酬は別に保持する。
