# 氷風組曲

フォンテーヌの水辺の広場で討伐調査を受け、氷風の舞台入口から演目を選ぶ。どちらもコッペリアとコペリウスの二体が登場し、一つのHPを共有する。倒した演目だけ依頼が進む。舞台はラボ用の仮背景画像で、本番は3D配置を使う方針。

| 演目 | 攻撃 | 回避の目印 |
| --- | --- | --- |
| コッペリアの葬送 | 風扇の横払い、交差の二歩、三つの旋風 | 横払いの向きが決まったら背後へ。交差は着地点の番号順に発生する。旋風の予告線は三箇所に固定される。 |
| コペリウスの劫罰 | 氷杖の双弾、氷風の交差、氷装甲と二振り | 氷弾は発射線から離れる。装甲がある間はコッペリアを狙える。 |

装甲中のコペリウスは直接攻撃のダメージを60%に抑える。別々の攻撃を3回当てると解除できる。コッペリアへの攻撃は装甲の影響を受けない。原作の風と氷の終幕を参考にした2D用の試作で、Lv90、共有HP 1,030、報酬と再出現時間もラボでの調整値。

両者に待機、攻撃、構え、お辞儀の4姿勢を使用。姿勢ごとの切り出しと軽量化の数値は [美術記録](../../evidence/icewind-field-art-audit.json) に記載。 [原神公式の紹介](https://genshin.hoyoverse.com/en/news/detail/112690)
