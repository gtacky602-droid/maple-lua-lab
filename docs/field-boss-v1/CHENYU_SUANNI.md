# 山隠れの猊獣

沈玉の谷の入口拠点で討伐調査を受け、探索路の右端から懸練山の石庭に入る。石庭の背景はラボ用の仮画像。本番では3D配置を使う方針。

| 攻撃 | 予告と回避 |
| --- | --- |
| 前爪・風尾 | 前の爪、後ろの尾の順。踏み込む前に両方の範囲と順番が見える。 |
| 双水刃 | 決まった方向へ低い水刃を二発放つ。射線から外れるか、跳んで越える。 |
| 風環・飛泉落とし | 緑の風環から外れ、青い着地点の帯と前方へ流れる水波を避ける。着地と水波は一人につき合わせて一度まで命中する。 |

空中では姿勢と当たり判定が一緒に上がる。着地後は頭を下げて2.4秒の反撃時間がある。氷の技を持たない旅人でも通常攻撃で削れる。Lv32、HP 738、水・風耐性45%、60秒再出現、報酬はラボ用の調整値。 [動作設計案](DANCE_STONE_MOVESETS.md) ・ [HoYoverseの地域紹介](https://www.hoyoverse.com/en-us/news/122237)

ローカル共闘では、着地印と実際の着地点を共有する。着地と水波を一回に数えるのは参加者ごと。着地に当たった人がいても、別の参加者には水波が当たる。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#山隠れの猊獣と魔像レガトゥス)
