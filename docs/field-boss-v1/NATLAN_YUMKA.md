# 山の王・貪食のユムカ竜

ナタの谷の集落で討伐調査を受け、岩場の道から山王の峡谷へ向かう。峡谷はラボ用の仮画像で、本番の背景は3D配置を使う方針。

| 攻撃 | 予告と回避 |
| --- | --- |
| 重尾の一回し | 足元の帯を予告して尾を一度振る。帯の外へ出るか跳び越える。 |
| 山王の腹落ち | 跳ぶ前に着地点が決まる。着地を避けたら、腹を床につけている2.4秒に攻める。 |
| 二果の火吐き | 花飾りが橙色に変わり、炎の実を二発吐く。①②の着弾地点が順に爆発する。 |

飛んでいる実は予告として見え、着弾の範囲にだけ攻撃判定が出る。通常攻撃だけで戦える。Lv104、HP 1,035、草耐性45%、報酬と再出現60秒はラボ用の調整値。 [動作設計案](NATLAN_ORIGINS_MOVESETS.md) ・ [公式図鑑](https://wiki.hoyolab.com/pc/genshin/entry/6583?lang=ja-jp)

ローカル共闘では、腹落ちの着地点と二つの実の着弾地点を共有する。命中は着弾ごとに、範囲内の参加者へ一回ずつ判定する。 [共闘の遊び方と検証](../COOP_WEB_PREVIEW.md#暴君金焔のクク竜と山の王貪食のユムカ竜)
