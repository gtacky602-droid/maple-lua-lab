# 謎煙の主の崖道と花翼の集の夜魂の試練

**M → ナタ → 狩場・任意戦** から目的の戦闘を選ぶ。リライは地上の道、晨星の霊と鉄髭は黒曜石の柱を経由する案内が出る。3戦とも入場はLv120。

| 戦闘 | 入口 |
| --- | --- |
| リライ | クァワカン断崖周辺・西の石段の右の棚 → 海を望む崖道 → 地上の広場 |
| 墜落せし晨星の霊 | 西の石段の右の棚 → 海を望む崖道 → 2段上の海沿いの柱 |
| 鉄髭 | ナタ・花翼の集付近の港の右端 → 鍛冶場跡の崖 → 2段上の柱 |

岩棚の左端が重なる場所で **Space** を使う。広場への入口や柱の近くで **F**。リライは待機中にそばへ寄っても交戦せず、旅人の **J** が当たると戦闘になる。夜魂の試練からは来たときと同じ高さの柱へ戻る。3戦の討伐記録はそれぞれ保存され、再挑戦時はHPが全快する。

ナタ拠点で「崖道の道しるべ」を受けると、地上と上段で **G** を押して各入口の印を調べられる。依頼を受ける前にも戦闘へ行ける。リライの氷砲と氷弾、晨星の霊の滑空と落星、鉄髭の火花と炉打ちはラボ用の試作。崖はラボ独自の地形で、背景には仮画像を使用する。 [共闘の道順と検証](COOP_WEB_PREVIEW.md#リライ墜落せし晨星の霊鉄髭) · [リライの広場](https://game8.jp/genshin/655680) · [晨星の霊の柱](https://game8.jp/genshin/655681) · [鉄髭の柱](https://game8.jp/genshin/655684)

## ドット絵と検証

第5稿A案で好まれた大きな色面を参考に、リライは藤色の外套と太い短砲、晨星の霊は二股の冠と地面に広がる翼、鉄髭は青白い霊体と四角い大槌で描き分けた。各3枚の床位置をそろえた。構えと動作の差分は見た目を確認するための素材。 [全9ポーズと16色比較](../evidence/natlan-northwest-legends-poses.png) · [参照記録](../evidence/natlan-northwest-legends-art-sources.json)

Luaで入口のLv制限、中立からの交戦、報酬と討伐記録の保存、柱からの退出・再入場を確認した。Chromeでは地図から3戦を選び、現地へ移動して、同じフレームの元PNGと軽量16色を比べた。標準の矩形描画から軽量16色に切り替えたとき、画面全体の描画命令数はリライで6,184から1,675、晨星の霊で8,795から2,272、鉄髭で8,293から2,217に減った。 [Luaテスト](../evidence/natlan-northwest-legends-lua.json) · [ブラウザテスト](../evidence/natlan-northwest-legends-browser.json) · [実画面の比較](../evidence/natlan-northwest-legends-comparison.png)
