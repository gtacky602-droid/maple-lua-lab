# ナド・クライ北部の海岸・半島・湖畔

**M → ナド・クライ → 狩場・任意戦** から戦闘を選ぶ。各入口は指定Lvに達すると通れる。「北部三つの見回り」は任意の依頼。

| 戦闘 | 入場Lv | 入口 |
| --- | ---: | --- |
| 十六倍マンドラゴラ | 138 | 南西の並木道の左の棚から、ピラミダ西の崖を海岸まで下りる |
| ハイジェード | 138 | 東岸の小桟橋、または北東の岸の右の棚から半島へ入り、キャンプへ進む |
| 故郷を偲ぶ孤独の狼 | 140 | 高地東の割れ岩の右の棚から湖の東の尾根へ。岩棚を二段登って広間へ |

入口は **F**、登りは足場の重なる場所で **Space**。マンドラゴラの海岸から帰るときは、下ってきた二段の棚を登る。狼の広間からは尾根の上段へ戻る。戦闘から退出して再挑戦するとHPが全快する。

南の港の神像でLv133の依頼「北部三つの見回り」を受ける。崖下、半島、尾根の道しるべを **G** で調べられる。回る順番は自由で、途中でセーブして続けられる。

戦闘地点は固有名を照合した公式マーカーをもとに配置した。接続経路、足場、見回りはラボ用の試作で、背景は仮画像。固有技は仕様待ち。 [ピラミダ西の海岸](https://game8.jp/genshin/755801) · [半島のキャンプ](https://game8.jp/genshin/755802) · [湖に近い広間](https://game8.jp/genshin/755803)

## ドット絵と検証

金色の大きな花、白い前髪と赤いフード、青白い結晶毛のある四足を基に、3体を描き分けた。各体の待機に加え、構えと動作の確認用素材を制作した。 [全9ポーズと16色比較](../evidence/nod-north-field-legends-poses.png) · [参照画像の記録](../evidence/nod-north-field-legends-art-sources.json)

LuaでLv制限、半島の両方の経路、崖と尾根の帰還、見回りの途中セーブと報告、討伐報酬と再挑戦を確認した。Chromeで地図、上り下り、見回り、元PNGと軽量16色の表示を確認した。標準の矩形描画から軽量16色に切り替えると、画面全体の描画命令数はマンドラゴラで5,338から1,369、ハイジェードで6,073から1,597、孤独の狼で7,675から2,065に減った。 [Luaテスト](../evidence/nod-north-field-legends-lua.json) · [ブラウザテスト](../evidence/nod-north-field-legends-browser.json) · [実画面での比較](../evidence/nod-north-field-legends-comparison.png)
