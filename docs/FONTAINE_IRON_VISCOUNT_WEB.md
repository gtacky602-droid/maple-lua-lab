# ベリル地下の排熱水洞と鉄皮の子爵

[ローカルLuaラボ](http://127.0.0.1:8982/)で、フォンテーヌ廷の排熱設備の巡回係から「ベリル地下の排熱門」（Lv94）を受ける。地下の見張り棚で温度計と排熱弁を順にGで調べ、Fで水洞へ降りる。二つの調査を済ませて戻り、フォンテーヌ廷で報告すると鉄皮の子爵の水洞が開く。戦闘はLv100。報告後にMを開き「狩場・任意戦」で選ぶと、見張り棚から排熱水洞を経由する道順が出る。

戦闘中は上下左右で泳ぎ、Jで水撃。薄緑の波が当たる直前にKを押すと受け止め、次のJが装甲を通す反撃になる。黄橙色の熱水は上下への移動やSpace・Shiftの急回避で外れる。入口側のFから退ける。水底にはラボ用の仮背景を使用。敵HP、予告の長さ、報酬は試作値。

見張り棚と排熱水洞で共闘部屋を作成・参加できる。依頼の報告、Kでの受け止め、次のJでの反撃は各自で行う。 [共闘の操作と報酬](COOP_WEB_PREVIEW.md#オーシャン巡回法官と鉄皮の子爵の水中共闘)

待機・構え・攻撃の3枚は、名付きゲーム画面の複数角度と重甲ヤドカニの姿を見比べて描いた。巡回法官の橙色の爪に対して、幅の広い鉄色の殻と板状の爪が見える。 [待機素材の比較](http://127.0.0.1:8982/bosses-art.html?q=鉄皮の子爵) · [3ポーズの比較](../evidence/iron-viscount-art-poses.png) · [参照資料](../evidence/iron-viscount-art-sources.json)

Luaで依頼6段階、Lv・報告の門、移動する圧力波、熱水の二つの深さ、反撃、退路、入り直し、討伐・保存を確認した。装甲が閉じた試験では通常水撃5、反撃63。移動と水撃を使った自動入力で最大HPから28.02秒。 [Luaの検証ログ](../evidence/iron-viscount-lua.json)
