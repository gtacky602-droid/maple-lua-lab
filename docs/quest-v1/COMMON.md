# 共通ルール・接続仕様

状態：2026-11-17設計案。実行コード・現行セーブの変更なし。

## 1. 体験の軸

明るい冒険、集団狩り、装備の成長、好きなキャラとの短い交流を優先する。設計書の長さをゲーム内会話の長さにしない。一場面の通常会話は2〜4吹き出しを目安とし、詳細は任意の再会話へ。起承転結は歩く・戦う・調べる・選ぶ・景色が変わる行動で見せる。会話スキップで目標が分からなくならない。

初回は発見、再訪は効率的な狩り。解決済みの迷路、長い移動演出、同じ謎解きを周回のたびに強制しない。通常狩場は横2〜3画面・主に二段足場、一画面12〜20体、倒して約6秒復活という既存草案を維持。安全拠点や観賞区画をその密度で埋めない。

## 2. 人物・加入・二人編成

旅人＋選択した仲間1人が存在し、非操作側は積極戦闘AI。共通レベル・経験値、HP/CT/装備は個別。8人の加入候補はアンバー、北斗、神里綾華、放浪者、エミリエ、カチーナ、コロンビーナ、ミティヤ。依頼主になれることと、戦闘プレイアブルとして実装することを分ける。

各国到着早期の短い依頼で加入。原則その地域のサブ5本中1本を加入枠にし、章クリアを待たせない。モンドのみ既存会話ではアンバー加入の具体枠が欠けているため、Q-MON-M01の初回協力完了で加入する補完案を明記する。高所サブQ-MON-S05を加入条件にしない。

加入時は共有Lvに同期し、売却・継承不可の初期武器/入門聖遺物を既存方針に従って配る。レベル同期は装備Lvの自動更新を意味しない。初期品は強化教材用の使い捨て素材にしない。

物語の相棒が非編成なら会話・安全地点のイベントに登場。戦闘AIの二人目にしない。同行中の同名キャラを受付NPCとして二重表示しない。ボスとして本人と戦う候補は、本人を仲間に選べるかの対応を個別確認し、勝手に新しい仲間登録を増やさない。

## 3. レベル・技・物語の条件

地域開始Lv草案は1/20/40/60/80/100/120/140。必要Lvで次地域へ向かえる方向を守り、前地域の全メイン・全サブ完了を一律の鍵にしない。港や実到達などの地図接続条件は別。各地域のM01→M02→M03はその章を読む順序であり、世界全体の進行封鎖ではない。

新元素は到達Lv＋対応国メイン開始で解放。ナド・クライは月、スネージナヤは氷・星の設計。技は60技の既存表を参照し、新たなスキルポイント、同行者ごとの経験値、転職の必須周回を足さない。成長クエストは既存の習得を教える導線で、技能取得の追加の鍵ではない。

後半はクエストだけで次地域Lvに届くと保証しない。通常狩り・装備更新・任意の日課を挟む既存ペースを維持し、翌日の更新待ちだけで足止めしない。この会話の各章末にあった『メイン＋サブ数本で次Lvを目標』は報酬調整案であり、既存経験値方針の撤回として採用しない。

## 4. 光界の二種類の数値

- 光界値：旅人と現在の仲間の聖遺物5部位ずつ、計10部位の刻印星の合計。最大50という既存案。非編成仲間・他人の装備を加算しない。死亡しても減らさない。編成変更で実値は変わる。
- 光界ゲージ：戦闘中の共通最大100。光界解放と七律開天で分けない。解放60消費/12秒/CT60秒、七律100消費/CT90秒は既存暫定値。蓄積速度は既存比較案のまま、本文で確定しない。

高難度の基準光界値は3/8/10/13/25/30/35/40/50を保存。入口の警告と障壁対策に使い、硬い入場ロックにしない。敵Lvとは別。高難度入場前に光界解放Lv160を必須にしない。刻印の紹介は解放技とは別に早期から置ける。

## 5. 報酬の考え方

基本は既存モラ・EXP・固定武器候補・指定セット聖遺物・素材・近道・会話差分・見た目。新しい強化通貨や素材階級をこの物語のためだけに追加しない。光界刻印の★上昇は既存の数値成長と強化画面を使う。強化・継承手数料や抽選確率は本書で変えない。

高難度産の専用素材がなければその高難度に耐えられない、という循環を禁止。全10部位★5や最高ランク追加効果は光界解放・反響・七律の習得条件にしない。最難関報酬は称号・見た目・追加効率中心で、基本成長を独占させない。

報酬額は未確定。クエストの内容帯に固定されたreward_profileを実装前に校正し、報告時Lvによる無制限増額を避ける。選択報酬は受取前にプレビュー。バッグ満杯で消失・自動売却・受取済みフラグだけの消費を起こさず、保留状態と再受取を扱う。収集品はバッグ個体ではなく進行カウンタで足りるものを優先。

## 6. 高難度・隠し・週ボス・幽境を分ける

高難度分岐は、昔の国へ戻って装備と技を試す場所。隠し世界は発見のご褒美であり、すべてを最高難度にしない。通常/週ボスの全種制作範囲は維持。週ボスを長い物語で一体ずつ解放する義務を追加しない。

幽境は別の専用戦闘。最新の優先候補はファルカ、隊長、レリル、シュバランケ、ロノヴァ。旧coverageの北斗・放浪者は削除せず保留候補として扱う。技・復活は既存マスターに委譲。ロノヴァ最高峰/有限復活の例外を、全クエストへ転用しない。原作で本人を倒した歴史を物語に捏造しない。

## 7. 失敗・再挑戦・協力

通常探索の落下やミニゲーム失敗でEXP/モラ/装備を失わない。戦闘敗北後は既存の安全地点へ。友好的な競技は参加完了と最高記録を分ける。メインの標準戦闘クリアは必要でも、無被弾・最速・極限難度は通常章や技解放に不要。

マルチ参加人数でボスHPを増やさない。他の実プレイヤーの蘇生は設けない。自分の旅人/仲間の救助は既存候補に従う。ホストの受注/選択だけで他人のクエストを完了しない。近くで受注し戦闘へ参加した人の討伐は共有対象とし、ドロップ・選択・初回報酬・発見は個別保存。距離/支援貢献の境界は実機試験待ち。
