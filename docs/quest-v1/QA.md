## 実行した静的検査

`MANIFEST.json`と`validate_manifest.py`をローカルの独立作業ディレクトリで作成し、Pythonで次を実行した。ゲーム本体を起動・変更した検査ではない。

```sh
python docs/quest-v1/validate_manifest.py --index-only
```

結果：PASS。展開されたIDは153件、重複0、主要な物語依存37辺、未定義参照0、循環0。内訳はメイン24、通常サブ40、日次候補40、高難度27、隠し世界6、成長16。地域の開始レベル、8人の加入先、高難度の基準値、日次の全地域共通1+2枠、月/星の仲間条件、光界の50と100の区別、160/170/180の技節目もチェックした。

検査した内容とGitHubへ書き込んだ内容が一致することを、Git blob SHAで照合：

- MANIFEST（UTF-8 compact JSON＋改行）：`3b55138dfb548e0e7215a01ddc9d115eb3fe9b69`
- 検査スクリプト：`c74ca5ea3ed669ef89dd980898555346b4a2f9b0`

追加の異常系8例はすべて検出：重複ID、依存循環、不明な依存先、高難度の光界値を入場鍵に変更、成長クエストで新しい技条件を追加、奥義ゲージを分離、七律のLvを変更、アンバー加入をLv16高所サブへ遅延。

これらは索引の検査。マニフェストが拒否する異常を、ゲームエンジンが既に防いでいるという意味ではない。

## 今回は実行していない検査

`--index-only`を外すと、本文12文書内の全クエスト見出し/日次表とタイトルを照合する機能もある。ただし今回のPython実行では本文全体をローカルに展開していないため、**本文照合モードは未実行**。作成時の見出し対応は目視で確認したが、機械的な本文一致をPASSと報告しない。

ゲームの起動、ブラウザプレイ、幻境への導入、マルチ、保存API、入力応答、敵の実時間、報酬経済、画像/音/実際の地形は未試験。公式人物・最新地理の再検証も今回の範囲外。原作設定との照合が必要な箇所は[SOURCES_AND_MIGRATION](SOURCES_AND_MIGRATION.md)を読む。
