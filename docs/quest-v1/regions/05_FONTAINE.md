# フォンテーヌ：消えた荷物と、幕裏の大冒険

region-05 / Lv80開始草案 / 相棒エミリエ / 華やかな街の舞台裏に居場所を作る章。[共通仕様](../COMMON.md)。重大裁判でなく調査・装置・共同制作。施設、事件、台詞は創作。

## 背景・配役

劇場の月飾り、布、花、香料が『配達完了』なのに届かない。水路の整備で再稼働した古い運搬設備に旧劇場の行先が残り、現代の荷物を舞台袖へ送っていた。運搬手順と舞台準備が切り離されず、誰もいない客席へ月・波・幕が動く。機械が心を持って公演を夢見た事件ではなく、記録不足の設備問題。

エミリエは香りだけで断定せず包装・素材・記録を照合。フリーナは演出の腕、ナヴィアは人をつなぐ気配り、リネ/リネットは驚きを作る裏方、フレミネは得意な水中で頼れる姿。整備士と大道具係の2NPCが現場を担当。

街路→荷揚げ場→整備回廊→旧劇場裏→主舞台機関室。上から見た水路を横/下から辿る。水流弾80、回復領域84、水圧螺旋槍87、潮の押し波90、珊瑚壁91、導電水路95、水鏡の盾96、開花花園97、超開花大星群98を既存表参照。終盤技を必須にしない。エミリエはナタの旅人炎解放前でも働く既存基礎設計を使い、燃焼強化の倍率を本書で変更しない。

## Q-FON-M01 お届け先は、どちらですか？

受注：エミリエ。条件：地域到着。

**起**：大道具係『月は届いたことになっている。でも空には上げられない』。エミリエの受取札にも同じ金縁と歯車印があり、受付へ。

**承**：受渡台・メカ停車位置・案内板を調べる。古い印、濡れていない布、搬送時刻。水没説と証拠を照らす。香りは経路の手掛かりで、結論を一発で当てる能力にしない。

**転**：時刻になった運搬メカが倉庫でなく古い搬入口へ曲がり、壁の向こうに道が開く。追跡と故障警備メカの短い戦闘。

**結**：機械の拍手と音楽、上下する月飾り。『少なくとも、月の行方は分かったようですね』。整備士へ古い記録を確認してもらい、地下を調べる。

体験/報酬：調査→動く対象の追跡→戦闘→裏口発見。回廊狩場・往復口。エミリエ加入依頼は初対面で開く。

## Q-FON-M02 客席の下は、大忙し！

受注：エミリエ。条件：M01。

**起**：海の風景が横へ滑り、街の書き割りが出る。床は昇降台、波は回転板、月は吊り装置。景色が歩ける仕掛けへ変わる。

**承**：幕を上げて階段発見、昇降台で上下移動、波板を遮蔽物に投射物を避ける。各装置は2〜3状態。広い作業床で戦い、細い可動足場に長時間閉じ込めない。

**転**：保管室に荷物と旧劇場宛の受領記録。札/行先板/受領記録を選び、誤配送が確定。『盗んだ』のでなく誤った配達先で受け取っていた。

**結**：荷物を一部返し現行配送を別系統へ。旧舞台の準備が止まらず、制御盤へ行く必要が残る。大搬送メカが動いているため作業員は入れない。

体験/報酬：動く地形と短い証拠整理。地下チェックポイント・昇降台、安全な別稽古場を開く。フリーナ/リネサブはこちらで行い、暴走主舞台へ客を招かない。

## Q-FON-M03 大舞台機関、ただいま暴走中！

受注：エミリエ。条件：M02。

**起**：作業員を監視位置へ退避。エミリエ非編成時も監視側で関わり、戦闘AIは旅人と選択仲間のみ。幕の間から中央へ進む。

**承**：創作舞台搬送メカ『グラン・フィナーレ』。大車輪、可動腕、太陽/雲の飾り。警告灯と歯車の予兆から横薙ぎ/荷台押し出し、後隙を攻める。

**転**：作業メカ増援と二段舞台。操作盤で大道具を遮蔽にするか広い攻撃床を作るか選ぶ。押し波は小敵を集め、巨大本体は押せない。水の回復/盾は立て直す選択肢。最後は外装を止め制御部を露出させる。

**結**：停止盤を押すと機械停止、一拍遅れて紙吹雪。『終わりの合図だけは、見事でしたね』。点検後の短い公演で、旅人が今度は合図に合わせて幕を上げる。

体験/報酬：装置を使うボス戦→同じ場所で公演。全破壊でなく安全停止。劇場は交流/ミニゲーム拠点、再戦は整備後の試験運転扱い。固定育成報酬。公演へ全サブを要求しない。

## Q-FON-S01 旅の香りを、ひとしずく

受注：エミリエ。条件：初対面。加入枠。

**起**：依頼は『海から帰り、家の扉を開けた時のような香り』。**承**：花・乾燥材・木素材を集め、一点で短い戦闘。爽やか/甘い/落ち着く等の絵と短文で表現し、現実の香料知識を要求しない。**転**：海を強くした試作ではなく帰宅の安心感が欲しいと聞き取る。**結**：配合を変えて依頼主が喜び、エミリエも旅人の傾聴を認め水路調査への協力を申し出る。

体験/報酬：採集・小戦闘・聞き取り。加入/初期装備、記念小瓶。香りの選択で加入や強さを変えない。

## Q-FON-S02 拍手は、まだ早い！

受注：フリーナ。条件：M02。

**起**：安全な稽古場の幕/照明/波を扱う人が足りない。**承**：視覚的合図で3装置を操作。**転**：全部正しく動くが騒がしく、フリーナが『待つ一瞬』を提案。静かな台詞の後、光と幕が同時に動く。**結**：自然な拍手が起こり、『表に立っていた人だけのものじゃないよ』と裏方へも言う。

体験/報酬：短い合図操作と間の演出。音なし可、失敗場面だけやり直し。完璧判定必須なし。章末公演に演出追加、後受注でも次公演へ反映。

## Q-FON-S03 集合写真は、まだ撮れない！

受注：ナヴィア。条件：M01。

**起**：水路で働く人々の集合写真を撮りたい。**承**：近所の3人の箱移動/札仕分けなどを助け、椅子と台を配置して全員の顔を見せる。**転**：撮影係が写れないため、整備士が時限式作動装置を付け、旅人も位置へ戻る。**結**：きっちりした一枚と菓子を囲む自然な一枚、掲示する方を選ぶ。

体験/報酬：短い交流と配置。基本報酬と閲覧可能な写真。自由撮影全機能を作らず固定構図/表情差分で成立。撮影に遅れた場合は再試行で永久失敗なし。

## Q-FON-S04 秘密を知っても、驚ける？

受注：リネ、リネット協力。条件：M02。

**起**：表は二人、裏の箱と幕は旅人が担当。**承**：客席から見えない通路と箱の動線を確認し、表の消失演出を支える。**転**：車輪故障でその演目は安全のため中止し、使える幕と光から別手順2案を選ぶ。失敗を旅人へ押しつけない。**結**：本番で予想外の小仕掛けが現れ、裏を知る旅人も驚く。『秘密を一つ知ったからって、驚きがなくなるとは限らない』。

体験/報酬：視点差と短い舞台パズル。終演後に客席から見られ、章末へ演目追加。秘密を暴いて勝つ話ではない。

## Q-FON-S05 小さな潜航艇の、初めての海

受注：フレミネ。条件：M01。

**起**：試作潜航玩具の帰路を浅い試験区画で確認。**承**：上下左右移動と調べるで泡/岩/見通しを辿り、フレミネが流れを示す。**転**：強い流れで止まるが動力増加でなく緩い側道へ誘導し、3候補から目印を置く。**結**：帰還した玩具に『次はもう少し遠くまで』。最後に静かな自由観賞を残す。

体験/報酬：水中は1〜2画面の試作枠。酸素切れ、専用装備、戦闘を追加せず、外れても近くへ復帰。通常戦闘同行をイベント中だけ安全に外してフレミネが案内。メイン/日常狩りは陸上を維持。玩具展示・水中観賞点。

## 継続

劇場へフリーナの演出、リネの演目、ナヴィアの写真、フレミネの玩具、エミリエの小瓶が重なる。全サブなしでも開く。香りは会話と小瓶で表現し会場強制散布にしない。Lv100進行に最高公演記録/日次待ち不要。装置の安全状態、誤配解決後の会話、現行配送停止の復旧、水中イベント出入りの編成保持を検査する。
