# 稲妻：灯りを追って、化かされて

region-03 / Lv40開始草案 / 相棒神里綾華 / 不思議を確かめる好奇心が寄り道になる。[共通仕様](../COMMON.md)。事件・化け狸集団・区画・台詞は創作。

## 背景・配役

森の灯籠が歩く、鳥居をくぐると同じ場所へ戻る、海が森へ変わるという噂。怪我人や戦争ではなく、驚いて帰った人と木の実を貰った人がいる。原作の大規模な政争を再演しない。

化け狸たちは海と森の見える岬へ客を招きたいが、道案内へかくれんぼと巨大な影を盛り込みすぎ、遊びが伝わっていない。旅人は綾華と正体を知り、最後は正式な勝負を受ける。綾華は観察と判断の相棒、宵宮は誰かに届く景色、早柚は隠れ道、一斗は賑やかな競技、平蔵は戦わない推理を担当。

離島→城/花見坂→灯隠れの小径→迷い鳥居の森→海へ抜ける洞穴→潮見の岬。鳴神島周辺の雰囲気へ集中し全島を詰め込まない。雷撃40、連鎖する落雷44、帯電の風衣47、雷光突進50、蓄電標56。雷光突進へ勝手に空中移動・崖越えを追加しない。高所は風と岩を活かす。

## Q-INA-M01 その灯籠、今、動きました？

受注：綾華。条件：地域到着。

**起**：綾華との会話の背景で灯籠が少しずつ近づき、振り返ると止まる。『……今、動きましたよね？』。説明より先に違和感を見せる。

**承**：灯りを追い、箱の葉っぱ、揺れる石像の影、木の実の食べ跡を調べる。道中の敵で雷撃を使い、調査を攻撃連打の作業にはしない。

**転**：灯籠が3つになる。一つだけ葉が落ちるという綾華の指摘を受け、調べると狸が現れる。逃げるのでなく踊り、『鳥居・大灯籠・海』の絵を渡す。

**結**：招待と理解するが、町の人を驚かせないよう伝える。狸は絵に笑顔を足す。意図が少し伝わり、先へ行きたくなる。

体験/報酬：観察・追跡・戦闘。森ルート、絵を収める簡単な『稲妻みちくさ帳』。綾華加入依頼は初対面で開く。

## Q-INA-M02 くぐって、戻って、もう一度？

受注：綾華。条件：M01。

**起**：鳥居を抜けると入口のような広場へ。灯籠の数、木の実、笑い声が違い、最初の一回で仕掛けだと分かる。無限ループには閉じ込めない。

**承**：3広場で見破り方を覚える。地面の足跡を見る、上下する石像を見る、水面の姿を見る。それぞれ狸と葉の印を発見。画面内に証拠があり、原作知識や長文暗記は不要。

**転**：次の物陰には本当の魔物が入り込む。狸も慌て、旅人が群れを処理。綾華は退路確保。連鎖落雷/帯電の風衣などで観察から爽快な戦闘へ切り替える。

**結**：狸が隠れず近寄り、奥の道を開く。大灯籠と勝負の絵。『最後は、勝負をしてほしいということでしょうか』。

体験/報酬：短い観察と集団戦の交互配置。解いた仕掛けは再訪時解除済み。森と海岸の近道、追加サブを開く。ヒントは短い任意会話。

## Q-INA-M03 今宵、化かし合いの大勝負！

受注：綾華。条件：M02。

**起**：洞穴の先で巨大な灯籠と狸の囃子。親分の創作ボス『千化け大灯籠』が自慢の化け術で勝負を求める。綾華『最後までお付き合いしましょう。ただし、勝負は真剣に』。

**承**：腕振り・踏みつけを葉の集まる予兆で避け、化け術の外殻を削る。後隙へ雷光突進、遠距離なら雷撃、小投射物なら岩壁。多様な構成で戦える。

**転**：3体へ分裂。戦闘を一時止め、葉のしっぽ/水面の違いから本物を『調べる』。AIや設置攻撃が偽物を殴って誤答にならない。間違いは紙吹雪程度で戦闘全やり直しなし。

**結**：短い最終攻防で『化け力』が尽き、親分が尻もち。葉の幕が開き、夕暮れの海と町の灯り。狸は普通の道標を置くが少し尻尾が出ている。倒して追放する結末にしない。

体験/報酬：予兆戦闘・観察・眺望。岬は常設展望地点。親分へ再戦を申し込めるので事件再発ではない。夜はクエスト演出、現実時刻待ちなし。

## Q-INA-S01 絵図にない、ひとつの景色

受注：綾華。条件：初対面。加入枠。

**起**：有名建物だけでなく町を歩く楽しさも案内絵図に載せたい。**承**：桜並木・海の坂・屋根越しの高台を巡り、綾華が暮らしを、旅人が脇道を紹介。**転**：立派な高台より途中の橋から人と船がよく見える。綾華が戻る提案。**結**：好きな景色へ印を付け、綾華も好きな場所を教えて同行を申し出る。

体験/報酬：探索と選択、綾華加入/初期装備/みちくさ帳。旅人の氷技解放とは別。イベント同行が2人目AIを増やさない。

## Q-INA-S02 遠くの人にも、届く一発

受注：宵宮。条件：M01。

**起**：家族の仕事で見に行けなかった子の窓から見える花火を作る。**承**：3高台の見通しを調べ、海・夕焼けなどの色と形を選ぶ。**転**：最も高い場所は崖に遮られ、低い海岸側の方が窓から見える。**結**：先に窓の家族を映し、その後プレイヤーの色と形の一発が開く。

体験/報酬：戦闘を休む高所探索・視線確認・演出選択。記録と再観賞操作。性能差、現実の夜待ち、素材の過剰収集なし。

## Q-INA-S03 最短ルートは、静かなルート

受注：早柚。条件：M01。

**起**：見回りを終えて昼寝したい。**承**：草むら/洞穴/木の裏で敵を避け3確認点を巡る。早柚は分岐で先回りし地形を教える。**転**：最後の穴は早柚しか通れず、彼女が裏から柵を開けて旅人を助ける。**結**：帰ると昼寝中で、お礼の木の実がそばにある。

体験/報酬：隠密は速く終わる手段。発見されたら通常戦闘から続行、即失敗なし。以後の移動用近道を開放。旅人へ忍術を新スキル追加しない。

## Q-INA-S04 荒瀧天下一・本気の三番勝負！

受注：一斗。条件：M02。

**起**：狸の試練を抜けた旅人へ三番勝負。**承**：足場上の旗集め、訓練的のまとめ破壊。既存移動/攻撃を競技に使う。**転**：見物の子どもも遊びたがり、最終戦は一斗と旅人がそれぞれ子どもを支える競技へ。**結**：どちらが勝っても表彰。勝てば再戦の約束、負けても景品を受け取る。

体験/報酬：短いミニゲーム。勝敗を会話に残し、基本報酬は同じ。好記録は称号、育成必須品を勝利限定にしない。訓練的は日次撃破対象外。

## Q-INA-S05 歩く茶屋の事件簿

受注：平蔵。条件：M02。

**起**：同じ茶屋が別々の場所に現れる噂。『全部同じ原因とは限らないよ』と調査へ。**承**：包み紙・車輪跡・異なる時間帯の証言を絵札で集める。**転**：客の多い場所へ移動する屋台だった。証拠を選んだあと店主が実際に押して現れる。**結**：茶を飲み、噂が広まった理由を確かめる。平蔵は答えを先回りせず旅人の発見を認める。

体験/報酬：戦闘なし、誤答は見直し可。茶屋の休憩利用と地図表示。毎回所在探しを義務にしない。

## クリア後

橋・花火海岸・早柚の道・競技広場・茶屋に思い出が散らばる。同行綾華の一言、親分が自分で化け姿を解く仕草を追加。謎解き後も不思議を楽しめるが、日常狩りへ迷路は持ち込まない。Lv60進行に全サブ/全記録不要。水面反射の視認性、音なしヒント、設置攻撃と分身判定の独立を検査する。
