# ナド・クライ：月の道と、寄り道の宝箱

region-07 / Lv120開始草案 / 相棒コロンビーナ / 自分から噂を確かめに行き、街で顔見知りが増える章。[共通仕様](../COMMON.md)。月の道・宝物庫・魔物・台詞は創作。原作の月の歴史を解決する話ではない。

## 背景・配役

ナシャタウンで『月が出ると海岸に階段』『奥に探検家の宝』『宝箱が歩く』という噂。ネフェルは見てきた情報を対価に手掛かりを渡す。昔の探検家が後続へ残した素材庫は実在する本作設定だが、周囲の大型魔物が金属箱と結晶を背に集め、歩く箱に見えていた。

コロンビーナは何でも知る案内役でなく一緒に寄り道を選ぶ相棒、アイノ/イネファは拾い物の使い道、ネフェルは情報の価値、ラウマは人間以外の暮らし、フリンズは夜道から帰る安心を担当。名前や配役は既存会話案を保存し、公式性能・実装時点を本書で再検証していない。

ナシャタウン→工房脇海岸→月映しの浅瀬→林の迂回路/海岸旧道→月渡りの岩窟。月雷遊星Lv127、月晶輪舞Lv133はコロンビーナ同行条件。月開花は独立新技を増やさず既存草技派生案。月反応で戦えることと、物語の道を通れる条件は分ける。

## Q-NOD-M01 その宝の話、確かめてみる？

受注：ネフェル。条件：地域到着。

**起**：漁師の光、商人の金属片、旅人の歩く箱という3証言から最初の聞き先を選ぶ。どれも海岸へ届き、誤選択でモラを失わない。

**承**：目印の先は海だけ。コロンビーナ『あそこ。月の光が途中で止まっている』。古い反射板を決まった方向へ切り替え、結晶へ光を渡して折り畳み足場を開く。マップ装置であり編成条件なし。

**転**：足場の先から小型敵。手前の広い岩場へ誘導して群れ処理。同行コロンビーナなら月連携、別仲間でも従来構成で突破。

**結**：小箱から確定素材と奥の貯蔵所の札。噂の一つが本当だと実感。コロンビーナ『まだ先へ行く？』と同行の楽しみを残す。

体験/報酬：聞き込み選択・短い光操作・戦闘・最初のお宝。海岸狩場と帰路。加入サブは海岸の初対面で受けられる。夜はイベント内で切替、現実月齢待ちなし。

## Q-NOD-M02 近道、寄り道、月の道

受注：コロンビーナ。条件：M01。

**起**：林の群れ狩りルートと、海岸の上下/小箱ルートが同じ岩窟へ続く。メインは片方でよい。

**承**：林はラウマが動物休息地と敵区域を区別し、海岸はフリンズが灯りと足場を示す。イベント案内で二人目AIを増やさない。群れへ月雷/設置、上下へ追尾など自分の構成で進む。

**転**：対岸の金属箱の山が動き、爪跡と留め具が落ちている。月が当たる瞬間、箱の下の大きな脚が見える。全部はまだ見せない。

**結**：安全足場と街への往復を開く。大型魔物らしいと分かり、横に転がる小箱には少量素材。『これは歩かないね』という一言。

体験/報酬：選んだ経路で体験が変わる。もう一方は任意探索として残す。岩窟への準備、好みの狩場、任意小箱。

## Q-NOD-M03 宝箱には、脚がある！

受注：コロンビーナ。条件：M02。

**起**：創作危険個体『月殻の大ヤドカニ』が金属箱/結晶を背に現れる。貯蔵所はさらに奥。友好的な動物を宝目当てに追う話にしない。

**承**：横移動、ハサミ、箱落としの予兆を見て側面へ。正面は硬いが常時無敵なし。岩の重攻撃、火柱、月晶輪舞など構成で攻略。

**転**：崩れた殻から結晶が出て、床へ走る反射光の後に時間差攻撃。色だけでなく形ある予告を表示。移動と継続攻撃で対処し、コロンビーナ必須の殻解除にしない。

**結**：奥の動かない宝箱に到着。石板『ここまで来た者へ。次の冒険の足しに。帰ったら、少し大げさに話してもいい』。確定素材/モラ/選択育成品/月模様記念品を持ち帰りネフェルへ報告。

体験/報酬：装備更新に役立つ本物のお宝を渡し、『思い出だけが宝』にしない。初回箱は一度きり、周回強敵/狩場とは分離。受取満杯/再送で重複しない。

## Q-NOD-S01 宝探しの前に、寄り道を

受注：コロンビーナ。条件：初対面。加入枠。

**起**：露店へ少し寄りたいと彼女から誘う。**承**：菓子/風に鳴る飾り/飲み物を見て自由に選び、海岸の小戦闘後に休める場所へ。**転**：目的地と反対の海が見える、宝探しには役立たない場所でも、飾りが鳴り一緒に食べられる。『宝物を探していない時にも来られるね』。**結**：宝探しへ同行を申し出る。

体験/報酬：選ぶ交流・短い戦闘・休憩。加入/初期装備、選んだ飾りを休憩点に表示。無知な子ども扱いにせず自分で目的外の楽しみを選ぶ。選択で加入/能力差を付けない。

## Q-NOD-S02 お宝判定機は、今日も正直！

受注：アイノ、イネファ協力。条件：M01。

**起**：回収品の材料/形を調べる試作機へ部品を集める。**承**：歯車・飾り金属板・変形石を狩場の固定位置で入手し測定。**転**：旅人の好きな月形板は加工部品として不向き。故障でなく、部品価値と好きかどうかが別と分かる。**結**：修理用/展示/灯りの飾りへ使い分け、イネファの用途に『持ち主が気に入っています』が加わる。

体験/報酬：回収と3種程度の仕分け。強化素材と小灯り。アイノが価値を理解できない話ではなく機械と人の判断の分担。

## Q-NOD-S03 月を盗んだ旅人？

受注：ネフェル。条件：M02。

**起**：自分が月を取ったと噂される。**承**：3人を辿ると光る石→月のような石→月から取った石へ変化。挿絵も大げさになる。**転**：現物は月明かりなしでは普通色。反射板で光を当て、何を見たのか実演する。**結**：『小さな月』など題名を選び、確認できた冒険談として情報料と掲示を得る。

体験/報酬：短い聞き込み/実演/題名選択。冤罪事件に拡大しない。世界の噂が自分の体験へ反応する差分。

## Q-NOD-S04 花見の席が、埋まっています

受注：ラウマ。条件：M01。

**起**：月下に開く創作の花を見に行く。**承**：外周の危険敵を退けたあと観賞区画へ。動物を避け、落ちた花びらや実を拾う。**転**：前の席は動物で埋まり、追い払わず高所へ移る。上向きに開く花の内側がよく見える。**結**：違う位置から一緒に花を眺める。

体験/報酬：戦闘区画と静かな区画を明確分離。現実の夜待ち・速さ競争なし。休憩点と花飾り。毎日収穫しないと損になる施設へしない。

## Q-NOD-S05 夜道の先に、温かい一杯

受注：フリンズ。条件：M02。

**起**：灯りが見えづらい曲がり角の敵を調べ、戻ったら一服へ招かれる。**承**：灯台の光で海岸を辿る。敵輪郭と予兆は暗闇でも明瞭。**転**：先に高所投射敵を倒すと地上群れを見渡せる。フリンズは別経路を守り、旅人側の巡回路がつながる。**結**：帰って飲み物と菓子を囲み、道の様子を話す。

体験/報酬：上下の位置取り、素材、近道、帰る場所。灯台や墓地を宝採掘場所にしない。

## 継続

月の仕掛けは解決後いつでも再訪、突然足元を消さない。林/海岸/岩窟に異なる狩り方を残し、新技を覚えて試す目的地にする。コロンビーナ以外の相棒も有効。後半Lv140まで物語だけで足りる保証はせず通常狩り/装備更新を残すが日次更新待ち禁止。二経路の片側完了、非月編成、初回箱と再戦報酬の独立、装置状態保存を検査する。
