# モンド：風待ち街道の大冒険

region-01 / 開始Lv1草案 / 相棒アンバー / 明るい冒険・初めて外へ出る楽しさ。以下は本作の創作案。共通条件は[COMMON](../COMMON.md)。

## 背景・配役・道

強風で倒木が発生し、商人が旧道へ積荷を残した。ヒルチャールが木材・布・看板を持ち去って丘の見張り台を増築し、通行が減った街道に魔物が居着いた。今は晴れ。救助と迂回路の確保は済んでおり、旅人はアンバーと元の街道を取り戻す。世界規模の黒幕や悲劇へ拡大しない。

アンバーは対等な案内役、リサは観察、ノエルは帰る場所、ベネットは予定外の発見、フィッシュルとオズは大げさな噂の調査を担当。新規NPCは看板に愛着のある行商人トビアス（仮）1人。

演出区画：城前→風車の草地→木漏れ日の旧道→風見の丘→丘の見張り台。屋根・休憩所・洞窟へ分岐。既存技の節目は旋風斬りLv1、竜巻6、風の加速11、上昇気流16。必須経路は固定足場でも通れる。

## Q-MON-M01 配達は、スライム待ち！

受注：アンバー。条件：地域到着。加入補完：初回協力の完了時にアンバー加入。高所サブまで待たせない。

**起**：城門前の荷馬車がスライムに囲まれる。商人は荷台、アンバーは反対側を担当し、旅人が手前の敵を倒す。挨拶より先に移動・通常攻撃・旋風斬りを一度使う。

**承**：地上の食料籠、低い足場の工具箱、敵の向こうの荷箱を3個回収。配置で移動・ジャンプ・戦闘を覚える。

**転**：赤い布の荷箱と店の看板が足りない。ヒルチャールが布を引きずって旧道へ逃げ、追う途中で群れと戦う。

**結**：荷馬車は城へ戻る。アンバー『初仕事、大成功！ ……看板まで持っていかれるのは珍しいね』。商人『荷物もだよ！』。次は旧道の調査へ。

体験/報酬：車輪が回り、城前に店が出る。経験値・モラ・入門消耗品。アンバー初期装備は共通仕様に従う。受注時に任意の日次主依頼も案内し、以後の対象撃破が200体へ進む。自動受注はしない。旅人自身の炎解放とは別。

## Q-MON-M02 看板の向こうに、何がある？

受注：アンバー。条件：M01。舞台：旧道。

**起**：矢印看板が木の上や行き止まりを指す。アンバーが車輪跡と枝の赤い布を見つけ、『看板より、こっちの跡の方が信用できそうだね！』と促す。

**承**：下段は敵と素材が多く進みやすい。上段は足場渡りと痕跡探し。どちらでも進める。竜巻で群れ処理、風の加速で再訪が快適になる。

**転**：丘の見張り台が見える。木材は足場、布は旗、車輪は飾り、商人の看板は逆さに掲げられている。最後の目標を背景で先に見せる。

**結**：入口の敵を退け柵を開け、森と丘のショートカットを確保。準備に戻るか寄り道するか選べる。盾と赤布をまとった大きな敵を一瞬見せる。

体験/報酬：一本道から経路選択へ。新狩場、帰路短縮、ベネット/フィッシュル依頼の開放。復路は同じ探索を強制しない。

## Q-MON-M03 街道を取り戻せ！

受注：アンバー。条件：M02。

**起**：旅人と相棒が上の敵を引き受け、下では修理班が倒木を片づける。ノエルの休憩所が完成済みなら出発時に寄れる差分。

**承**：低い入口から上下の足場へ。竜巻で群れ、風の加速で移動、上昇気流で近道。未習得時は梯子。高所の追加宝箱は任意。

**転**：木盾のヒルチャール暴徒を土台にした『街道の大親分』（創作個体候補）。盾突進を障害物へ誘って隙を作る。アンバーの炎も有効だが唯一の解除法にしない。小型増援を群れ処理し、盾が壊れた後は大振りを通常ジャンプでも避ける。

**結**：旗が下り、荷馬車が通る。落書き付き看板に商人が『目立つようにはなったな』。丘で差し入れを食べ、遠くの道を見る。璃月へはLv20の既存条件を参照。

体験/報酬：主街道の背景は安全で人が歩き、道外側に周回狩場を残す。章ボスは設計候補で既存通常・週ボス登録を置換しない。固定報酬と近道、日常会話を残す。

## Q-MON-S01 休憩するための大仕事

受注：ノエル。条件：M01。

**起**：荒れた休憩所を整える手伝いを頼まれる。**承**：敵を退け資材を集め、落葉を掃除。ノエルはベンチを修理。**転**：完成後も彼女だけお茶や荷物を運び続け、自分の席がないと分かる。**結**：最後の操作で椅子を一脚置くと、ノエルも座る。『私の分まで……？ では、少しだけご一緒させてください』。

体験：倒す・回収・配置で場所が変わる。報酬：回復できる休憩地点と通常報酬。回復条件/量は既存回復仕様へ。『この人も休ませてあげた』という操作を残す。

## Q-MON-S02 返却箱の小さな逃亡者

受注：リサ。条件：M01。

**起**：図書館への返却箱が勝手に移動する噂。**承**：栞、跳ねた泥、草の跡を追う。**転**：箱の下にスライムの群れが潜り、跳ねて運んでいた。短い追跡から戦闘へ。**結**：箱を止め、本を返す。リサ『貸し出し先に「スライム」とは書けないものね』。

体験：観察→追跡→集団戦。竜巻/加速で楽になるが必須ではない。本の永久破損・時間切れロストなし。報酬：素材と短い魔物観察記録。図鑑は任意閲覧。

## Q-MON-S03 大当たりは、帰り道

受注：ベネット。条件：M02。

**起**：強風で露出した小洞窟に宝箱を発見。**承**：崩れる足場と落石を進む。ベネットは危険を読み、経験ある冒険者として助ける。**転**：箱は空だが、帰路の床が崩れ、下に鉱石と別の出口を見つける。**結**：旧道への近道が開く。『宝箱は空だったけど、道は当たりだったな！』。

体験：足場探索と予定外の発見。演出落下は体力/持ち物ロストなし。空箱でも強化素材を確定で渡す。洞窟狩場・近道が報酬。古い地図片を連続寄り道の将来種にしてよいが本話だけで完結。イベント同行は常時二人目AIにしない。

## Q-MON-S04 断罪の皇女と、夜の大怪鳥

受注：フィッシュル（オズ補足）。条件：M02。

**起**：丘で巨大な黒い鳥を見た噂。**承**：影の投影位置、風の通り道、黒い布を調べる。**転**：古い幟に風スライムが絡まり、一羽の鳥のように見えていた。**結**：一団を処理して幟を回収、丘へ修繕して立てる。皇女の調査は成功として扱い、勘違いを嘲笑する落ちにしない。

体験：痕跡調査→浮いた敵との戦闘。通常攻撃・アンバー援護など複数手段。夜はイベント内演出で現実時刻待ちなし。報酬は素材・修繕された幟・追加会話。

## Q-MON-S05 風車の上まで、あと一跳び！

受注：アンバー。条件：M02＋Lv16。加入依頼ではない。

**起**：城の屋根の巡回へ誘われる。**承**：屋根と風車の3目印を調べ、上昇気流を試す。**転**：最後の目印が高い足場へ飛ばされる。アンバーは安全な道を示し、旅人が登る。**結**：城門・草地・丘を見渡す。『あそこも、その向こうも、もう君が通ってきた場所だよ！』。

体験：戦闘なしの縦移動。滑翔システムの新規導入は不要。落下は直前足場へ。完走で基本報酬、速さは記録/称号だけ。展望地点の近道を開く。
