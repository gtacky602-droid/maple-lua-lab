# 滝つぼと海崖の夜魂の試練

**M → ナタ → 狩場・任意戦** で試練を選ぶ。黒曜石の柱の近くで **F** を押すと入れる。

| 試練 | レベル | 柱までの道 |
| --- | ---: | --- |
| ポタポの応援 | 118 | クァワカン断崖周辺・断崖南の道の左の棚 → 聖火競技場の西の滝 → 岩棚を下りて滝つぼへ |
| トゥパヨの協力 | 120 | クァワカン断崖周辺・西の崖の神像の右の棚 → 神像裏の海崖 → 3段上の柱へ |

滝つぼへの道は上段から入る。右へ進んで棚の端から順に下りる。帰りは二つの岩棚を **Space** で登って元の入口へ戻る。神像裏の海崖は足場の重なりを使って **Space** で登る。途中退出・全滅時は柱の高さへ戻る。ソロの再挑戦時は敵のHPが全快する。 [共闘の再戦ルール](COOP_WEB_PREVIEW.md#ポタポの応援とトゥパヨの協力)

ナタ拠点の「滝つぼと海崖の柱」を受けると、滝つぼと海崖の上で道しるべを **G** で調べられる。依頼は任意。岩棚と依頼はラボ用の試作で、背景は仮画像。回復と連動する加護の霊や燃素の風域などの戦闘ギミックは仕様待ち。 [聖火競技場の西の柱](https://game8.jp/genshin/655682) · [神像の西の柱](https://game8.jp/genshin/655683) · [両方の柱の現地写真](https://neko-gamebook.com/nata-legend/)

## ドット絵とソロ検証

ポタポは細い頭冠と水平に張った氷色の肩、トゥパヨは上へ開く三つの花弁と左右に反る朱色の下身で見分けられる。二体とも床から浮く位置をそろえた。各3枚のうち構えと動作は見た目の確認用。 [全6ポーズと16色比較](../evidence/natlan-wayob-duo-poses.png) · [画像の参照記録](../evidence/natlan-wayob-duo-art-sources.json)

LuaではLv117と119での入場制限、指定Lvでの入場、2戦の報酬、セーブ復元後の討伐記録、全滅時の帰還位置、依頼の報告を確認した。Chromeでは **M** の地図、現地での **G** と **F**、各試練の元PNGと軽量16色を同じフレームで比較した。標準の矩形描画から軽量16色に切り替えると、画面全体の描画命令数はポタポで6,454から1,652、トゥパヨで7,026から1,887に減った。 [Luaテスト](../evidence/natlan-wayob-duo-lua.json) · [ブラウザテスト](../evidence/natlan-wayob-duo-browser.json) · [実画面比較](../evidence/natlan-wayob-duo-comparison.png) · [滝つぼの柱](../evidence/natlan-potapo-waterfall-pillar.png) · [海崖の柱](../evidence/natlan-tupayo-sea-cliff-pillar.png)
