# モンド南の街道の協力プレイ

ローカルラボの通常の冒険を、別々のブラウザプロフィールで開く。両方でモンドの町から南の街道に出る。画面下の「協力プレイ（ローカル試作）」を開き、一人が「部屋を作る」を選ぶ。もう一人は同じラボの画面で合言葉を入力し、「参加」を押す。参加した相手とその同行者が狩場に表示される。

2人の入力をサーバーのLuaへ送り、同じ敵のHP、攻撃、再出現を60Hzの共通の刻みで進める。相手の操作キャラには水色の名前が出る。地図を開いたプレイヤーの入力は止まり、部屋の戦闘は続く。双方が画面を離れている間は更新を休止する。

装備、依頼、同行者、EXP、モラは各人の冒険のデータを使う。現行の参加判定は、12秒以内に敵へ有効なダメージを与え、撃破時に横420px・縦180px以内にいること。自分の同行者の攻撃も含める。対象者ごとにEXPとモラを付け、受注済みの討伐依頼だけを進める。聖遺物は各自の指定セットと抽選記録を使い、各自の画面で回収する。閾値は試作設定。 [設定](../content/coop-preview.json)

画面を再読み込みすると、60秒の離席猶予の間は同じ部屋に復帰できる。「部屋から出る」、別のマップへ移る、保存を読み込むと部屋を退出する。保存は各自が行い、読み込みは通常どおり町から再開する。協力部屋はローカルサーバーが起動している間に使える。ランキング対象の冒険からは通常の冒険を開いて参加する。

## 確認したこと

- HTTPで、既存の敵6体とHP15の先頭の敵を確認した。2人の有効打を同じ敵に入れ、1回の撃破から双方への個別報酬、受注の有無による討伐カウント、異なる指定セットの落下品を確認した。ドロップ試験は抽選シードを指定した。 [試験の記録と応答計測](../evidence/coop-local-http.json)
- Chromeの2つのプロフィールを各々町から徒歩で進め、相手と同行者の表示、共通の敵の撃破、M地図を開いている間の進行、再読み込み、部屋にいる間の保存、退出、390px幅を確認した。 [2人と同行者の表示](../evidence/coop-local-browser.png) · [Chromeの検証](../evidence/coop-local-browser.json)

今回の対応マップはモンド南の街道。4人、部屋を保ったまま別のマップに移動すること、週ボス・幽境の共闘、回復や支援による参加判定、別端末からの通信、星々の幻境実機は次の検証範囲。人数でボスHPを増やさない方針は [11月16日の採用仕様](../sources/20261116-amendment.md) に従う。
