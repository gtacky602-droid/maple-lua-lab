# 地方伝説と通常敵の見た目の比較

名前付きの戦闘・プロフィール画像と、対応する通常敵の画像を照合する。通常個体と同じ見た目なら、ラボの通常敵とドット絵を共用し、名前や演出で区別する。見た目に差がある場合は衣装、装備、色などの実際に確認できた差を残す。

| 地方伝説 | 資料で確認したこと | 制作時に照合する点 |
| --- | --- | --- |
| 故郷を偲ぶ孤独の狼 | 集光の凛狼と青白い額・頬、濃紺の顔が共通。名前付き画面では四足の体と背の毛束も見える | 通常個体の背・尾・脚を含む全身の一致 |
| ハイジェード | 名付きは赤い頭巾と白い前髪。通常の拳術家は短い髪と顔を覆う布。拳を使う点を比較できる | 同じ体型やモーションを使うか |
| 十六倍マンドラゴラ | 名前付き資料で大きな金の花弁と淡緑の顔を確認 | 同じ姿の通常個体の有無 |
| チュリン | 名前付き資料に白灰の髪、尖った耳、眼鏡、淡い服が見える | 同系統のフェイ・小さき者の全身と、固有の装備 |
| バンダースナッチ | バロウビーストと耳状の突起と外殻が共通。画像では目の色に違いが見える | 通常個体の胴と足元、色差が照明によるものか |
| フュリオサ | 蒼狼の追跡者の図鑑と比較。フュリオサには赤い頭装飾と明るい胸元がある | 近距離の全身、足元、尾と武器 |

調査画像はプロフィール、現地のゲーム画面、通常種の図鑑を区別して記録した。通常種の全身と名前付き個体の両方が読める画像が増えた時点で、共用できる部位を決める。資料の出典と画像URLは比較記録を参照。 [画像と確認箇所](../evidence/legend-base-visual-references.json) · [制作方針](../ART_REFERENCE_POLICY.md)

フォンテーヌ9戦は、通常敵と名前付き個体の見た目を公開画像24点で照合した。濁水幻霊2型の待機絵はラボで共用した。 [フォンテーヌの比較](FONTAINE_LEGEND_BASE_REFERENCES.md)

フォンテーヌで通常型の図鑑全身と現地近景を追加し、ファデュイ従者2型、宝盗団の特殊個体2人、ボウシクラゲ2体、ルケア、濁水幻霊2体を照合した。 [追加した画像と作画指示](FONTAINE_LEGEND_REFERENCE_EXPANSION.md)

ナタでは、先遣隊3型、デットエージェント、コホラ竜戦士、テントガメを比較した。先遣隊は型ごとに同じ素材を使う方針で、氷銃・炎銃の待機候補を通常敵側にも登録した。 [ナタの比較](NATLAN_LEGEND_BASE_REFERENCES.md)

ナド・クライ4体の図鑑・現地画像16点を照合し、ファイアーブレイドをラスコルニコフと共用する待機候補に追加した。カニ皇帝の殻、シグルドの帽子と顔、孤独の狼の目元は各個体の資料で確認する。 [ナド・クライの比較](NOD_LEGEND_BASE_REFERENCES.md)

赤璋巡岳府君の移即・天虞はヴィシャップ・岩、シネアスはアビサルヴィシャップ・原種と照合した。シネアスの改稿を通常型の待機候補にも登録し、赤璋の2体は岩の体型を共通にして前脚の元素差を残す作画方針を記録した。 [ヴィシャップ3体の比較](VISHAP_LEGEND_BASE_REFERENCES.md)
