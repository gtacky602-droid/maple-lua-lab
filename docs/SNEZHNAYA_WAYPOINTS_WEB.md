# スネージナヤのワープ地点・神像

[ローカルLuaラボ](http://127.0.0.1:8969/)の「本編ルートへ」から開始。Lv140でナド・クライの町から雪原の入口へ進める。門の近くでF、調査の目印の近くでG。到達した地点は地区・階層別のワープ一覧から選べる。

公式地図のスネージナヤ108地点を、既存8ステージと新設100ステージに割り当てた。うち37地点に階層IDがある。雪原、町と白虹峠、南東の氷壁、北の氷塔、東の工業区、東端の城壁を138本の往復路でつないだ。 [HoYoLAB公式テイワットマップ](https://act.hoyolab.com/ys/app/interactive-map/index.html) · [地図との照合記録](../sources/map-research/snezhnaya-marker-review.json)

氷塔と東の尾根は、吹雪が弱まる間に高い足場の門から渡る。氷塔の四層は昇降機で移動。東の工業区では昇降機で地下に入り、同じ階層にある旧線を徒歩で行き来する。港から西沖の氷舟へは小舟で渡る。白虹峠の終着駅へ行く既存列車は、乗車券クエストの報告後に利用できる。徒歩でも終着駅へ行ける。

## 終盤の狩場への再訪

Lv180の「星脈坑・凍てた坑口」とLv200の「極地の暁晶原」に、ラボ用のワープ地点を設けた。初回は狩場をつなぐ門から入り、到達後はM地図で「ワープ登録済み」と表示される。保存からは雪原の終着駅で再開し、ワープ一覧から登録済みの狩場へ戻れる。 [M地図の登録表示](../evidence/snez-endgame-warp-atlas.png)

LuaでLv160〜200の9狩場を往復し、必要Lvの一つ手前では地図と現地の門が入場を止めることを確認した。駅裏の保守歩廊、南東岸と谷を結ぶ橋、旧線の連絡坑も往復した。ブラウザでは未訪問の地点がワープ一覧に出ず、訪問済みのセーブで2地点へワープし、終着駅へ戻れることを確認した。試験では出発地点と必要Lvの前後を用意した。 [Luaの試走](../evidence/snez-endgame-access-lua.json) · [Chromeの記録](../evidence/snez-endgame-access-browser.json)

ワープ・神像、狩場・脇部屋、長距離便、短い乗り物の既存集計に入っていない42地点を、本編、日次、通常ボス、地方伝説、幽境の試験資料に対応付けた。一部のボス試験は会場内から開始している。 [42地点の検証資料索引](../design/world/snez-stage-evidence.json)

## 調査クエスト

| 依頼 | 受注場所 | 必要Lv | 調査 |
|---|---|---:|---|
| 線路沿いを歩いて終着駅へ | 雪の町 | 148 | 凍った街道と高架下を通り、駅の標識を確認 |
| 氷塔の四層に刻まれた目印 | 雪の町 | 153 | 吹雪を待って氷塔に渡り、中層と最上層に残る刻みを記録 |
| 工区の地下に残る旧線 | ノヴォキッチェヴの入口拠点 | 153 | 貨物口から地下に降りて配線札を確認 |
| 東門の下の回廊を見回る | 東の町の広場 | 158 | 見張り台から回廊へ降りて水跡を調査 |

公式地図と照合した項目はID、座標、種別、階層。地点名、ノヴォキッチェヴの割り当て、通路、足場、必要Lvはラボ用の仮設定。ラボでは既存の仮背景画像を共用し、本番は3Dで背景を配置する方針。

## 検証

- Luaでスネージナヤ108地点と276方向の門を往復し、ナド・クライからの到着、調査4件の報告、訪問と報告の保存復元を確認した。白虹峠の列車、徒歩ルート、既存章の報告も回帰検証した。 [Lua検証](../evidence/snezhnaya-waypoint-test.json)
- Chromeで吹雪中は門を通れないこと、風が弱まってからの通過、氷塔四層の昇降機と調査、報告、ロード後の最上層へのワープを確認した。 [Chrome検証](../evidence/snezhnaya-waypoint-browser.json) · [吹雪の門](../evidence/snezhnaya-waypoint-wind.png) · [氷塔の最上層](../evidence/snezhnaya-waypoint-tower.png)
- 地図台帳873件すべてを別々のステージに割り当て、種別・階層・足場または水中の位置を確認した。通行条件を除いた経路データでは、モンドの町から全873地点への行きと帰りの経路がある。ワープと訪問済み限定の門はこの経路検査から外した。地図台帳の検証は、全クエスト・全ボスの通し検証とは別に進める。 [全地域の経路検査](../evidence/world-map-connectivity.json)

Luaは `python -X utf8 test_snezhnaya_waypoints.py`、地図台帳は `python -X utf8 test_world_map.py`。Lua検証が生成する `work/snezhnaya-waypoint-browser-save.json` をラボの「JSONを読み込んで再開」で開くと、Lv160で雪の町から北の線路にワープできる。Chromeは `node test_snezhnaya_waypoints.mjs`。別ポートの場合は `LAB_URL` を指定する。
