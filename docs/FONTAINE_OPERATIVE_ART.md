# イゾルトとディアンナラの通常型との比較

対応する通常敵の図鑑と、それぞれの地方伝説が写った現地画像を見比べた。17点を目視し、先行するフォンテーヌの2本の調査記録に未収録だった13点を追加した。図鑑の顔、現地の全身、横顔、戦闘中の画像は、見える部分に合わせて使った。 [確認した17点と用途](../evidence/fontaine-operative-references.json) · [先行調査](FONTAINE_LEGEND_REFERENCE_EXPANSION.md)

| 組み合わせ | ドット絵で共用する形 |
| --- | --- |
| イゾルトとファデュイ・氷霜の従者 | 二本の尖りがある濃紺の仮面、片側に寄る明るい茶髪、白い袖、足元まで伸びる青い裾、細い剣。横から見ると仮面の突起と髪の量がよく分かる。 [通常型の側面](https://www.hoyolab.com/article/23249455) · [図鑑の顔](https://wiki.biligame.com/ys/%E6%84%9A%E4%BA%BA%E4%BC%97%C2%B7%E9%9C%9C%E5%BD%B9%E4%BA%BA) · [イゾルトの現地](https://altema.jp/gensin/yseut) |
| スネージヴナのディアンナラとファデュイ・烈風の従者 | 高い濃色の帽子、目元を覆う仮面、白い脚衣、背から伸びる青緑の布、細い刃。戦闘の発光を外しても帽子と布で氷霜型と見分けられる。 [通常型の正面と側面](https://www.hoyolab.com/article/23249455) · [図鑑の顔](https://wiki.biligame.com/ys/%E6%84%9A%E4%BA%BA%E4%BC%97%C2%B7%E9%A3%8E%E5%BD%B9%E4%BA%BA) · [ディアンナラの現地](https://gamewith.net/genshin-impact/article/show/42449) |

確認できた仮面、服、装備は、どちらの地方伝説も対応する通常型と共通する。待機絵は型ごとに一枚を共用する。ゲーム上で見分ける必要がある場合は、名前表示やHP欄を使う。撮影場所によって青みが変わるディアンナラの服は、明るい場所で撮った通常の従者を色の基準にした。名前付き個体の真正面から裏側までの一周と、単体3Dモデルでの確認は今後の資料収集に残る。 [名前付き2体の近景](https://note.com/fancy_dunlin4414/n/nf067be3c378d)
