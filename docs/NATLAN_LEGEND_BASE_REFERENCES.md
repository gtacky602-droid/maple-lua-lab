# ナタの地方伝説と通常個体の見た目

異色三連星、バラチコ、波のジャプー、コシーホの4戦・6体を画像21点で照合した。通常個体の全身、名前が見える現地画面、戦闘中の別角度、装備が読める図鑑・図解を使った。同じ図鑑画像の転載は1点として数え、戦闘中の発光と装備そのものの色を分けて確認した。 [画像ごとのURLと見えた特徴](../evidence/natlan-legend-base-references.json)

| 地方伝説 | 対応する通常個体 | ドット絵に反映する点 |
| --- | --- | --- |
| シドレンコ | ファデュイ先遣隊・重衛士・氷銃 | 青い帽子、幅のある胴、背の冷却タンク、太い銃の構成が対応。既存の待機絵を共用候補にする。青白い装甲の明暗と銃身の形は次稿で見直す。 |
| ノモンコノフ | ファデュイ先遣隊・前鋒軍・雷ハンマー | 暗い兜と肩鎧、紫の角形の大槌が対応。現行試作の兜の角と明るい襟を整理してから、通常型と待機絵を共用する。 |
| ヴァシリ | ファデュイ先遣隊・遊撃兵・炎銃 | 赤系の細身の上着、帽子と長銃が対応。既存の待機絵を共用候補にする。帽子の下の顔は覆面の色と前髪の境界を近景から拾う。 |
| バラチコ | ファデュイ・デットエージェント・炎 | 通常型の図鑑では前傾した体、二股に流れる暗い外套、短い湾曲刃が読める。名付きの洞窟画面では赤い分身が重なるため、外套の色・丈は通常型資料を作画の軸にし、本体の近景で残りを照合する。 |
| 波のジャプー | コホラ竜戦士・裂波のスロワー | 青黒い兜と橙の差し色が対応。演奏中の画像では胸の前に構えた装備が特徴。水弾を撃つ通常型の全身と、演奏時・戦闘時の持ち替えが分かるカットを揃えてから共用範囲を決める。 |
| コシーホ | テントガメ（野生生物） | 四足と角張った甲羅の形が対応。通常型は黄緑の甲羅、コシーホは紫の甲羅に淡い星形が見える。輪郭は共通の型を使い、甲羅の色・模様と額の差し色を残す。 |

三連星は同じ体型に縮めず、氷銃の丸い胴、雷槌の幅広い肩、炎銃の細いシルエットを保つ。人型の頭身は2.8〜3.2を目安にし、帽子・兜の突起と武器を計測から外す。コシーホは四足の比率と接地を保つ。単体3Dモデルの回転と背面の細部は確認待ち。 [低頭身の制作方針](../ART_REFERENCE_POLICY.md) · [名前付きの戦闘画面](https://game8.jp/genshin/655669) · [通常先遣隊の戦闘画面](https://game8.jp/genshin/366637)

## ラボで見比べる

通常敵の素材比較で「ファデュイ」と入力すると、氷銃・炎銃の待機候補が見つかる。地方伝説側と同じ素材を110px高で表示する。両方のギャラリーで元PNGと軽量16色を比べられる。 [通常敵の素材比較](http://127.0.0.1:8989/enemies-art.html?q=ファデュイ&profile=h32c16&zoom=1) · [異色三連星の素材比較](http://127.0.0.1:8989/bosses-art.html?q=異色三連星&profile=h32c16&zoom=1)

軽量16色では、氷銃が3,207から951矩形、炎銃が2,817から792矩形に減った。110px表示で武器の輪郭と体格差は読み取れる。炎銃は顔の明暗と服の細線が潰れやすい。Chromeで共用した2型のキャンバスが通常敵と地方伝説の両画面で一致し、390px幅でも収まることを確認した。Luaの待機絵テストは24素材の3設定で通過した。 [表示画像](../evidence/natlan-legend-base-preview.png) · [Chromeの比較結果](../evidence/natlan-legend-base-browser.json)
