# 主要街道と沿岸の往復路

[ローカルLuaラボ](http://127.0.0.1:8973/)で本編を始め、Mキーで地図を開く。追加した道を選ぶと、区画の通行Lvと両側の行き先が見える。国境洞道では、スメール側の行き先を押すと地図の地域も切り替わる。

## 追加した道

| 地域 | 試作した往復路 |
| --- | --- |
| モンド | 南の街道の上段から森の斜面を通り、北の湖へ抜ける小道。 |
| 璃月 | 天衡山の山腹で折り返す坂と、荻花洲の湿地沿いの石橋。 |
| 稲妻 | ヤシオリ島の尾根から干潟へ下りる浜道。 |
| フォンテーヌ | ベリルの西斜面を登る道と、中央湖から市街東の水中門へ抜ける水路。 |
| スメール | ガンダ丘の木橋と、地上の層岩巨淵から森林へ抜けるLv64の国境洞道。 |
| ナタ | クァワカン断崖の階段、神像へ続く草地の道、アトクパンの崩れ谷から火山下の東口へ降りる足場。 |
| ナド・クライ | パハ島とレンポ島を結ぶ連絡舟、北部沿岸の中央の林から東の林間道へ続く地上道。 |
| スネージナヤ | 氷壁南東岸から谷へ入る橋、森から凍った街道へ下る坂、旧線の下層で東西をつなぐ保守坑。 |

16組の往復路のうち、11組は間に歩ける区画を設けた。国境洞道はLv63だと巨淵側で止まり、Lv64で開く。洞道で保存した場合は、訪問済みの出発側の拠点から再開する。新しい地形・背景・通行条件はラボ用の試作。 [元の設計IDと接続](../sources/map-research/sites-main-corridors.json)

## 確認した範囲

Luaで新しい16組と、以前から通れる195組を実際に往復した。重複を除いて895方向の門を通り、依頼の状態が維持されることを確認した。試走では戦闘ダメージを抑えた。Chromeでも国境洞道とパハ島・レンポ島間の連絡舟を往復した。 [Luaログ](../evidence/sites-main-corridors-lua.json) · [Chromeログ](../evidence/sites-main-corridors-browser.json) · [国境洞道の地図](../evidence/sites-corridor-border-map.png)

Siteの経路候補421組は、試作として実装した122組、既存ルートで確認した274組、保留25組。保留は発見・専用ゲートの8組、乗り場と帰航を見直す6組、屋外の道筋や階層を照合する11組。原作の入口を照合中の見晴らし場3件は引き続き地図に表示する。 [全体の接続台帳](../design/world/atlas-route-plan.json)

モンドの開始地点で、ローカルHTTPの12フレームを計測した。1フレーム約1.21 MBのうち、地点・経路・依頼のデータが約1.19 MBを占めた。地図が変わらない間もこのデータを毎回送っている。

検査は `python -X utf8 test_sites_main_corridors.py`。そこで生成する作業用セーブを使い、`node test_sites_main_corridors.mjs` でChromeの往復を確認できる。
