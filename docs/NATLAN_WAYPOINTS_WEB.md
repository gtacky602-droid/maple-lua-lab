# ナタ・古の聖山・空の神殿のワープ地点と神像

[ローカルLuaラボ](http://127.0.0.1:8967/)で「本編ルートへ」を選ぶ。ナタの入口はLv100。門は近くでF、上段の門は足場にジャンプしてF。調査の目印の近くではGを押す。ワープ一覧は到達済みの地点を地区と階層で分けて表示する。

公式地図のナタ135地点、別地図の古の聖山19地点、空の神殿20地点を、既存6ステージと新設168ステージに割り当てた。49地点の階層IDを照合し、昇降機・水路・同じ階層の回廊でつないだ。 [HoYoLAB公式テイワットマップ](https://act.hoyolab.com/ys/app/interactive-map/index.html) · [座標と階層の照合記録](../sources/map-research/natlan-marker-review.json)

火山の入口台から古の聖山、聖山の北の遠望台から空の神殿へ昇降機を使って進む。空の神殿の中央では、昇降台に乗ったキャラクターが上段・下段の間を移動する。上段通路から戻るときは、地上から中段、上段と二度ジャンプして乗る。

オシカ・ナタへはナタ港発の既存航海で寄港中に下船する。寄港地から再乗船して先へ進める。ナタと往復する小舟はリゾート行きにも設けた。地図点と航海デッキを含め、211本の経路を両方向に通れる。

M地図の「狩場・任意戦」から、段丘の赤土棚Lv110と東谷の岩棚Lv115を探せる。通常敵は赤土棚に42体、岩棚に48体。どちらもラボ用の試作。東谷の岩棚と既設の「東の秘境周辺」Lv119は、東の谷へ入る坂から出入りできる。 [育成の試走記録](../evidence/natlan-fresh-route.json)

## 調査クエスト

| 依頼 | 受注場所 | 必要Lv | 調査 |
|---|---|---:|---|
| 集落から岩の窪地まで | ナタ・谷の集落 | 105 | 上段の門と岩棚を通り、窪地への道標を調べる |
| 寄港地から北の外壁へ | オシカ・ナタ・寄港地 | 123 | 寄港して遺構の北へ歩き、荷受けに使える桟橋を探す |
| 水車から運河まで | のびのびリゾート・南の連絡桟橋 | 117 | 神像と水車を経由して、運河の水の高さを調べる |
| 聖山の三つの高さ | 古の聖山・南の入口拠点 | 124 | 第一層から第三層までの目盛りを読む |
| 雲上の昇降台を点検する | 空の神殿・西の入口拠点 | 136 | 昇降台で上り、展望棚の留め具を調べ、上段から台で戻る |

公式資料と照合したのは地点ID、座標、種別、階層ID。地点名、通行条件、足場、昇降機の位置と必要Lvはラボ用の仮設定。背景は既存の仮画像を共用し、本番は3D配置で制作する方針。

## 検証

- Luaで全174地点と航海デッキを訪ね、211経路の両方向、調査クエスト5件の報告、報酬の二重払い防止、訪問・依頼状況の保存復元を確認した。寄港前の下船が拒否され、寄港中に下船し、再乗船できることも確認した。 [Luaの検証結果](../evidence/natlan-waypoint-test.json)
- Chromeで古の聖山と空の神殿の依頼を報告した。空の神殿ではキャラが昇降台とともに移動し、帰りは二段のジャンプで上の乗り場に着いた。再読み込み後、聖山の第三層にワープできた。 [Chromeの検証結果](../evidence/natlan-waypoint-browser.json) · [上段に着いた画面](../evidence/natlan-waypoint-sky-lift.png)

Luaの検証は `python -X utf8 test_natlan_waypoints.py`。そこで用意される `work/natlan-waypoint-browser-save.json` を「JSONを読み込んで再開」で開くと、Lv138の古の聖山・南の入口拠点から確認できる。Chromeの検証は `node test_natlan_waypoints.mjs`。別ポートの場合は `LAB_URL` を指定する。
