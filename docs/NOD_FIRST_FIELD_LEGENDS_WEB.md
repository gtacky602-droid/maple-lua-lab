# ナド・クライの墓道・地下宮殿・実験設計局

**M → ナド・クライ → 狩場・任意戦** で戦闘を選ぶ。入口へ向かう前に、ナシャタウンで対応する依頼を受ける。入口を開けたら、報告の前でも戦闘に入れる。

| 戦闘 | 入場Lv | 入口と依頼 |
| --- | ---: | --- |
| シグルド | 132 | 東の灯台下の右の岩棚 → 墓道。「浜辺の供え物」 |
| カニ皇帝 | 136 | 東の林の地下の庭の右の岩棚 → 鏡の回廊。「地下庭の二つの鏡」 |
| ラスコルニコフ | 140 | 中央施設の上層の右の岩棚 → 上層の搬入口。「上層の搬入口の点検」 |

### シグルドの墓前

墓道で鈴、笛、羽飾りを **G** で拾う。笛は中段の岩棚にあるので **Space** で上がる。奥の供え台で **G**、墓前で **F** を押して身構える。 [墓と供え物の参照](https://game8.jp/genshin/720566) · [シグルドの現地画面](https://game8.jp/genshin/720984)

### カニ皇帝の地下宮殿

下段と石棚の鏡を、**G** で刻線の結晶へ向ける。二つの照射がそろうと回廊の奥に足場が現れる。足場に上がり、**F** で宮殿へ入る。鏡の途中の向きと、開いた足場はセーブから復元される。 [地下の探索の参照](https://gamewith.jp/genshin/article/show/518143) · [カニ皇帝の現地画面](https://game8.jp/genshin/720995)

### ラスコルニコフの最上層

搬送札と上段の操作盤を **G** で点検し、同じ段の右端から **F** で昇降機に乗る。最上層の入口から戻ると、搬入口の上段に着く。 [実験設計局の現地画面](https://game8.jp/genshin/720999)

## ドット絵と検証

地図の戦闘地点は、固有名を照合した公式マーカーをもとに配置した。依頼の手順と足場はラボ用の試作。背景は仮画像で、今回の固有技は仕様待ち。待機に加え、各体の構えと動作を確認できる素材を用意した。 [全9ポーズの比較](../evidence/nod-first-field-legends-poses.png) · [画像の参照記録](../evidence/nod-first-field-legends-art-sources.json)

LuaでLvと依頼の制限、鏡と足場のセーブ復元、入退場、再挑戦、討伐記録と報酬を確認した。Chromeで地図、三つの依頼、入退場、元PNGと軽量16色の表示を確認した。標準の矩形描画から軽量16色へ切り替えると、画面全体の描画命令数はシグルドで5,709から1,528、カニ皇帝で7,768から1,932、ラスコルニコフで6,719から1,766に減った。 [Luaテスト](../evidence/nod-first-field-legends-lua.json) · [ブラウザテスト](../evidence/nod-first-field-legends-browser.json) · [実画面での比較](../evidence/nod-first-field-legends-comparison.png) · [鏡の足場](../evidence/nod-crab-tsar-open-bridge.png) · [最上層への昇降機](../evidence/nod-raskolnikov-lift.png)
