# ナタの地方伝説・波のジャプーと異色三連星

ラボで **M → ナタ → 狩場・任意戦** を開くと、二つの入口と経路を表示する。入口では **F** で入場し、左端の出口から来た道へ戻れる。枝道の向こうに任意戦を置いているので、Lv102の通過ルートはそのまま進める。

| 任意戦 | レベル | 入口 |
| --- | ---: | --- |
| 波のジャプー | 112 | テケメカンの谷・谷東の横道から、テペアカク坂の演奏場へ |
| 異色三連星 | 120 | 万火のほとぎ周辺・北の地ならし場から、ウィッツトリの丘の野営場へ |

ジャプーは演奏中に近づいても中立で、既存の通常攻撃が当たると挑戦が始まる。三連星には氷銃・雷槌・炎銃がいて、HPは個別に減る。3人目の討伐で一組の討伐記録、モラ、経験値を付与する。退出して入り直すと全員のHPが戻り、達成済みの討伐記録はセーブに残る。

ジャプーには弦鳴りのさざ波と、二拍の水柱の試作を追加した。協力部屋では仲間のうち一人が攻撃すると戦闘が始まり、両方の攻撃予告を共有する。参加レベル、HP、攻撃はラボの試作で、原作のアチーブメント条件は別途扱う。背景にはナタの仮画像を使用する。 [ジャプーの共闘と検証](COOP_WEB_PREVIEW.md#波のジャプーバラチココシーホ)

## ドット絵と軽量化

第5稿A案でユーザーが好んだ大きな色面を踏まえ、4人の武器を弦楽器、太い氷銃、角のある大槌、細長い炎銃として描き分けた。名前付きのゲーム画面に加え、標準種の2D画像と装備の見える画像も参照した。待機とテスト用差分の計12枚を約3頭身にそろえ、床ピボットを統一した。 [波のジャプーの戦闘画像](https://www.hoyolab.com/article/34450690) · [異色三連星の戦闘と武器](https://game8.jp/genshin/655669) · [参照記録](../evidence/natlan-first-legends-art-sources.json)

同じフレームを停止し、元PNG、標準矩形、軽量16色で比較した。標準矩形から軽量16色に切り替えると、画面全体の描画命令数はジャプーの場面で7,097から1,827、三連星で13,788から3,761に減った。 [元PNGと軽量16色の比較](../evidence/natlan-first-legends-comparison.png)

## 検証

- LuaでLv不足時の入口、地図からの経路、通常攻撃による中立解除、退却と再挑戦を確認した。
- 三連星の各個体を通常攻撃で倒し、最初の2人で報酬が発生せず、最後の1人で一度だけ報酬・討伐記録が付くことを確認した。セーブ後の討伐記録と、途中HPが再入場で初期化されることを確認した。 [Luaテスト](../evidence/natlan-first-legends-lua.json) · [セーブの共通テスト](../evidence/field-save-contract.json)
- ChromeでMの地図、Fの往復、元PNGと軽量16色、ジャプーへの通常攻撃を確認した。 [ブラウザテスト](../evidence/natlan-first-legends-browser.json)
