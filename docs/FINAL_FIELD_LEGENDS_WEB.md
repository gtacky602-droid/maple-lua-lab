# ドーンマンポート、空の神殿、霜月の地方伝説

**M → 狩場・任意戦** で、ドーンマンポート、空の神殿、霜月の各地域から戦闘を選ぶ。ムーシュ＝テヒルは霜月の地下表示でも選べる。入口は **F**、足場に乗るときは **Space**、調査と装置は **G**。

| 戦闘 | Lv | ラボでの行き方 |
| --- | ---: | --- |
| チャルデリック | 175 | 北の丘の東路の左の足場からシールドル湖北の見張り道へ。右の炊事場に入る。 |
| マハーヴァスデーヴァヤプトラ太子 | 185 | 空の神殿の拠点で「砂上の楼閣の調査記録」を受ける。北の展望棚の右側から昇降機で回廊へ降り、石碑と見取り図を調べてマーダヴァに話す。 |
| プリズムスライム | 188 | 霜月の拠点で「ウージエン生態圏の通路」を受け、拠点と赤い丘の南棚の通行標を調べて報告。南の渡り台の右の岩棚から生態圏の南に出る。 |
| ムーシュ＝テヒル | 190 | 同じ通路の調査を報告し、拠点で「地下広間の装置」を受ける。赤い丘の北端の下層の右の足場から広間へ入り、下記の二戦を進める。 |

チャルデリックには事前依頼の条件がない。太子は原作で楼閣の調査とマーダヴァの案内が必要。霜月の2戦も原作の生態圏への到達条件に合わせ、ラボの調査報告で道を開く。調査の細かな手順と背景はラボ用の仮仕様。戦闘地点には公式マップの印 `2:95658`、`37:96413`、`40:99930`、`40:99929` の座標を使った。 [チャルデリックの出現場所](https://gamewith.jp/genshin/article/show/555365) · [楼閣の解放条件](https://gamewith.jp/genshin/article/show/555352) · [霜月の生態圏](https://gamewith.jp/genshin/article/show/566710) · [地図の印](../design/world/encounters.json)

チャルデリックの炊事場と太子の中庭は共闘に対応する。湾の小舟と空の神殿の昇降機で同じ部屋を維持し、太子の中庭へは各自が楼閣を調査してから入る。 [共闘の道順と検証](COOP_WEB_PREVIEW.md#チャルデリックとマハーヴァスデーヴァヤプトラ太子)

## 地下広間の二つの試験

共闘でも、ウージエン生態圏の通行報告と地下広間の二つの試験は各自で進める。報告した仲間から南の水たまりと北西の装置の広間へ入れる。コマンダー戦では各自の進行を保ったまま、最深室で再び合流できる。 [霜月の共闘経路](COOP_WEB_PREVIEW.md#プリズムスライムとムーシュテヒル)

中央の装置を **G** で起動し、左上の入口から第一試験へ。先駆秘源コマンダー陣形を2体倒して広間へ戻る。同じ装置で第二試験を起動し、今度は右上から入って2体を倒す。中央の装置を三度目に調べると右端の扉が開く。試験の完了状態は保存され、奥の扉から本戦だけ再挑戦できる。移動と帰り道を試せるよう、試験は隣の区画に分けた。 [原作の装置と二つの試験](https://game8.jp/genshin/794290) · [各試験の敵編成](https://wikiwiki.jp/genshinwiki/敵一覧/地方伝説/ナド・クライ)

## 通常個体との照合

4体について、名前付きの肖像、通常個体の全身、照明が異なる戦闘画面など25枚を照合した。 [出典と個体差の記録](../evidence/final-field-legends-art-sources.json) · [4体の全ポーズ](../evidence/final-field-legends-poses.png)

- **チャルデリック**は岩シャーマンの体格と杖を基に、桃色に光る仮面と額の角、淡い鬣を描いた。
- **太子**は通常のトコトコ岩マッシュロンと傘、眼、襟、脚の形が共通。スメール14狩場の通常個体272枠も、太子の待機絵を共用し、通常の大きさで表示する。
- **プリズムスライム**は大型水スライムに似た輪郭を残し、頭上の輪、額の模様、半透明の青い胴を描いた。
- **ムーシュ＝テヒル**は通常機に共通する円形の中核、左右の湾曲した外殻、金の縁と緑の発光を描いた。外殻は名前付きの肖像を基準に暗い灰色にした。前哨戦の通常機も同じ輪郭で、公式図鑑と戦闘画面を基に外殻を象牙色にした。 [前哨戦の通常機の資料](../evidence/final-field-legends-normal-commander-sources.json)
