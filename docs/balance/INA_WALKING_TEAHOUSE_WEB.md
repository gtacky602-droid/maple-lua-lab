# 歩く茶屋の事件簿

稲妻第2話「くぐって、戻って、もう一度？」を報告すると、城下の広場で平蔵の依頼（Q-INA-S05）を受けられます。Lv40から遊べます。 [企画書](../quest-v1/regions/03_INAZUMA.md#q-ina-s05-歩く茶屋の事件簿)

1. 広場で平蔵から噂を聞き、菱印の包み紙を G で調べます。分かれ道の門の近くで F を押すと移動できます。
2. 昼陰の分かれ道で二筋の車輪跡を調べ、Space で石段に上がって昼の証言を読みます。夕灯りの船着き場で夕方の証言を読むと、絵札が四枚そろいます。
3. 絵札台に近づくと四枚の絵札が表示されます。茶屋が移動した証拠を二枚選び、「二枚を照合する」を押します。手がかりが足りない組み合わせには平蔵がヒントを出すので、札を選び直せます。 [絵札の画面](../../evidence/ina-tea-case-evidence-board.png)
4. 店主が屋台を押してくるので、止まったら茶器の近くで G を押してお茶を飲みます。右の門から広場へ戻って報告すると、145,027 EXPと試作値の1,750モラを一度受け取れます。 [屋台の到着](../../evidence/ina-tea-case-arrival.png)

報告後は本編地図の「休憩へ：船着き場の茶屋」と、地図上の茶屋の丸印から茶器のそばに移動できます。G を押すたびに操作中のキャラクターのHPが最大35回復します。屋台の到着時間と回復量は試作値です。到着中に保存した場合は広場から再開し、船着き場に戻ると屋台は停まっています。

店主は約3頭身の自作モデルを3方向から確認してドット絵にしました。ラボでは店主の一枚絵を屋台と一緒に横へ動かし、到着中は上下に揺らしています。平蔵は台詞で登場します。背景2枚はラボ用の仮画像で、本番では3Dで配置する方針です。 [形状モデル](../../evidence/ina-tea-case-views.png) · [素材の記録](../../evidence/ina-tea-case-art.json)

屋台が止まった同一フレームで、PNG表示は25件、標準の矩形描画は10,043件、軽量16色は2,470件の描画命令を出しました。軽量16色で矩形描画の命令が約75％減り、屋根や菱印の輪郭は読めます。顔や茶器の色の細部は粗くなります。 [PNG](../../evidence/ina-tea-case-parked-png.png) · [軽量16色](../../evidence/ina-tea-case-parked-light.png)

`python server.py --port 8915` でラボを起動し、`python -X utf8 test_ina_walking_teahouse.py`、`node test_ina_walking_teahouse.mjs` の順で実行すると、絵札集め、推理、報告、再読み込み後の休憩を確認できます。 [Lua検証](../../evidence/ina-tea-case-lua.json) · [Chrome検証](../../evidence/ina-tea-case-browser.json)
