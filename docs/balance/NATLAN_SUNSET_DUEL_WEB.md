# ナタ本編最終話の夕映え会場

Lv100で高台と水辺の試練（Q-NAT-M02）を報告すると、夕映え会場の控え広場で本編最終話（Q-NAT-M03）を始められます。

1. 受付で対戦札を確認し、控えの確認所へ進みます。上段の確認盤を調べると会場への門が開きます。
2. 会場へ入ると模擬戦が始まります。水走者は地上に示した線に沿って往復します。岩棚に上がってやり過ごし、水走者が中央に戻ったら地上へ降りて反撃します。次の水柱は予告した二地点に番号順に立ちます。岩棚の高さまで届くので、印から横へ離れます。
3. 模擬戦に勝つと、初回の勝利で6,826,100 EXPを獲得します。右奥で勝負を確認し、記録台へ進むと報告で8,024,394 EXP、10,800モラ、強化鉱6を一度受け取れます。
4. 報告後は控え広場から会場と記録台へ戻れます。会場の鐘で練習を開始できます。練習では報酬は発生しません。

共闘では受付と点検を各自で済ませてから会場で合流します。突進の位置と水柱の番号は部屋で共有します。報告後に練習する場合も、各自が合図台を調べると同じ勝負に参加できます。 [共闘の入口と検証](../COOP_WEB_PREVIEW.md#夕映えの水走者)

全滅した場合は同じ会場で再試行できます。初回の対戦中に保存した残りHPと経過時間は、町から会場へ戻ると引き継ぎます。攻撃は予告から始まります。往復突進の仮設定は予告1.48秒、往路と復路が各0.76秒、折り返し0.42秒です。水柱は予告開始1.28秒後と1.90秒後に出ます。どちらの攻撃の後にも2.12秒の反撃時間があります。
