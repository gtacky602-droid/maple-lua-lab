# ナタ本編最終話の夕映え会場

Lv100で高台と水辺の試練（Q-NAT-M02）を報告すると、夕映え会場の控え広場で本編最終話（Q-NAT-M03）を始められます。

1. 受付で対戦札を確認し、控えの確認所へ進みます。上段の確認盤を調べると会場への門が開きます。
2. 会場の開始位置を調べます。地上の水路は予告した側から流れ、反対側で折り返します。上段から流れを見て、水が引いたら地上へ降りて反撃します。
3. 模擬戦に勝つと、初回の勝利で6,826,100 EXPを獲得します。右奥で勝負を確認し、記録台へ進むと報告で8,024,394 EXP、10,800モラ、強化鉱6を一度受け取れます。
4. 報告後は控え広場から会場と記録台へ戻れます。会場の鐘で練習を開始できます。練習では報酬は発生しません。

全滅した場合は同じ会場で再試行できます。最初の対戦中に保存した相手のHPは、読み込み後も引き継ぎます。水路の仮設定は予告1.48秒、往路と復路が各0.76秒、折り返し0.42秒、反撃2.12秒です。水のダメージは通過方向ごとに1回です。
