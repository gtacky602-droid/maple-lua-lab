# 教科書にない、大発見

スメール第2話「森の上にも、森がある」の報告後、樹陰の広場で Q-SUM-S05 を受注できます。広場の絵地図台で G を押してナヒーダと話し、もう一度 G を押すと絵地図が開きます。

- 第1話で見た葉の橋、第2話で見た根の階段と枝間水路は、依頼を受けた時点で選べます。第3話で大枝の見晴らしを調べると、樹上の景色も候補に加わります。
- ナヒーダと話したあと、広場から幹の中継所へ向かうと朝露のくぼみに入れます。低い根の段に跳び上がり、葉のそばで G を押すと朝露が候補に加わります。
- 三つまで選び、それぞれに見つけ方を添えます。下書きは冒険の保存に含まれます。報告後は、選んだ三つを広場の掲示板で読み返せます。
- 初回報告報酬は全組合せで 386,920 EXP、2,600 モラです。モラと見つけ方の文面は試作設定です。メイン第3話は既存の条件で進められ、専門調査図もそのまま使えます。

絵地図の目印と掲示板には、自作の形状を正面・斜め前・斜め後ろから確認して起こした6点のドット絵を使っています。朝露のくぼみの背景はブラウザで読み込む仮画像です。本番の背景は3D配置を想定しています。朝露の表示、調査の高さ、発見記録を Lua で処理します。 [形状資料](../../evidence/sum-nahida-map-views.png) [画像・変換記録](../../evidence/sum-nahida-map-art.json)

## ブラウザでの確認

朝露を調べた場面を停止し、同じ位置とクエスト進行で表示を切り替えました。Lua の描画指示は PNG 14件、標準矩形5,602件、軽量16色1,426件でした。軽量16色では標準矩形から約75%減り、葉と水滴の輪郭を見分けられます。 [PNG](../../evidence/sum-nahida-map-glade-png.png) [軽量16色](../../evidence/sum-nahida-map-glade-light.png)

ブラウザでは下書きの復元、幅390pxでの絵地図表示、報告した絵地図の再表示も確認しました。Lua の試験では、寄り道の有無と三つの選択を変えても報酬が等しいことを確認しました。 [絵地図の掲示](../../evidence/sum-nahida-map-posted.png) [ブラウザ試験](../../evidence/sum-nahida-map-web.json) [Lua試験](../../evidence/sum-nahida-map-lua.json)
