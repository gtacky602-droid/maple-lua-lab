# ヴェルーリヤ・ミラージュの模様瓶とトロッコ

[隠し世界の設計](../quest-v1/HIDDEN_WORLDS.md) の Q-H02-01〜02 をラボにつないだ。Lv60から、スメール・地域の入口で「砂に埋もれた瓶」の近くに立って G を押すと、模様瓶の庭への門が現れる。

| 依頼 | 受注・報告 | 操作 |
|---|---|---|
| 瓶の向こうの、特別な切符 | 模様瓶の庭 | 地上で瓶の模様を記録し、上段で G で円盤を回す。瓶と同じ印で確定すると広場への門が現れる |
| トロッコを降りた、その先に | 入口広場 | F で乗車し、花棚の停留所で降りる。低い棚から展望台へ行き、記念箱の切符を広場行きの便で持ち帰る |

花棚の停留所では発車から1.8秒後に停車し、6.3秒になるまで F で降りられる。そのまま乗ると8.4秒で終点に着く。終点から乗る戻り便も花棚に停まる。停留所からは両方向の便に乗れ、発車は乗車操作で始まる。乗車中のセーブからは入口広場で再開する。二つ目の依頼は戻り便で広場に着くと進み、報告後は記念切符を読み返せる。

瓶の円盤で確定した状態と、訪れた拠点はセーブに残る。入口広場に到達済みのデータでは、スメール側の従来の近道も使える。

車体は側面・斜めの形状スケッチを参考に生成した。原画と矩形描画を切り替えられる。二つの依頼の報酬は順に 13,400 EXP・510 モラ・強化鉱石2個、18,100 EXP・680 モラ・強化鉱石3個の試作値。地形と背景はラボ用の仮配置で、本番の背景は3Dで配置する想定。

Chrome で瓶の模様合わせ、終点からの途中下車、展望台の箱、帰りの乗車、セーブ後の再読を確認した。車体単体の矩形は標準 2,484 件から軽量16色の 599 件に減った。乗車中の同一画面では Lua の描画指示が標準 5,930 件から 1,486 件になった。[Chrome の結果](../../evidence/veluriyam-trolley-browser.json) ／ [PNG](../../evidence/veluriyam-trolley-ride-png.png) ／ [軽量16色](../../evidence/veluriyam-trolley-ride-light.png)
