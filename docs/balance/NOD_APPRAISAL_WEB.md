# お宝判定機は、今日も正直！

ナド・クライで第1話「その宝の話、確かめてみる？」を報告すると、町の広場からアイノの部品工房へ入れます。工房で依頼（Q-NOD-S02）を受け、判定機のそばで G を押すと始まります。

1. 工房の右の門から潮風の部品回収場に出ます。歯車と月形板は地面にあり、青い石は右の岩棚にあります。石には通常ジャンプで届きます。三つとも G で拾え、順番は自由です。
2. 工房に戻り、お宝判定機で G を押すたびに一つずつ測ります。歯車は規格が揃い、月形板は薄く、青い石には珍しい層があります。画面下の「判定機の測定記録」で、測った部品の特徴を見返せます。
3. 歯車は修理用の箱、月形板は灯りの台、石は展示の棚に置きます。違う場所を選ぶとイネファが手掛かりを伝え、同じ部品で選び直せます。測定記録に「仕分け済み」と表示される部品は、保存から再開しても仕分けが済んだ状態で残ります。
4. 工房の右端で小灯りをともすと、依頼手帳から報告できます。報酬は4,382,501 EXP、4,100モラ、強化鉱6個です。報告後も灯りが残り、G で「持ち主が気に入っています」と記した用途記録を読めます。

アイノとイネファは会話で登場します。判定機、歯車、月形板、石、小灯りは、自作のモデルを三方向から確認してドット絵にしました。工房と回収場の背景はラボ用の仮画像です。本番では3Dで配置する方針です。 [小物の三方向モデル](../../evidence/nod-appraisal-views.png) · [透過と変換の記録](../../evidence/nod-appraisal-art.json)

判定機と月形板が見える同じフレームの描画命令は、PNGが20件、標準矩形が6,480件、軽量16色が1,557件でした。軽量16色は標準矩形より76.0%少なく、計器の丸い輪郭と月形板のシルエットが残ります。計器の目盛りや金属の陰影は簡略化されます。 [PNG](../../evidence/nod-appraisal-png.png) · [軽量16色](../../evidence/nod-appraisal-light.png) · [再訪時の小灯り](../../evidence/nod-appraisal-lamp.png)

月感電の依頼を終えたLv128のセーブでも、岩棚での回収、測定と仕分けの途中保存、報告後の読み返しと回収場への再訪をChromeで確認しました。月形板を間違った箱に置こうとした後に再開しても、歯車の仕分け済みの印が残ります。幅390pxで3部品の測定記録を確認でき、報告後はLv129でコロンビーナの同行と所持品80点を引き継ぎました。この試走の判定機は元PNG14件、標準矩形7,253件、軽量16色1,829件で、標準矩形より74.8%少ない描画命令でした。 [Lv128からの通し検証](../../evidence/earned-nod-appraisal-browser.json)

`python -X utf8 test_nod_appraisal.py` で回収順、途中保存、誤った仕分け後の再試行、報酬の重複防止、再訪を確認できます。サーバーを8904で起動し、続けて `node test_nod_appraisal.mjs` を実行すると、Chrome 上で受注から再訪までを確認できます。到着港から続ける場合は `LAB_APPRAISAL_CHECKPOINT` にセーブを、`LAB_APPRAISAL_OUTPUT` に出力先の接頭辞を指定します。 [Luaの結果](../../evidence/nod-appraisal-lua.json) · [Chromeの結果](../../evidence/nod-appraisal-browser.json)
