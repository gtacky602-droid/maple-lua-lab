# ドラゴンスパインの霜筋観測

モンド南の境界からドラゴンスパインの入口拠点に入れます。入口拠点の右側から新しい観測棚へ向かいます。Lv1から入れる既存の探索路も使えます。岩筋、観測小屋、稜線はラボ独自の地形案です。背景はラボ用の画像で、本番は3D配置を想定しています。

| 設計ID | 依頼と受注場所 | Lv | 初回報告（EXP / モラ / 強化鉱石） |
| --- | --- | ---: | ---: |
| Q-B01-01 | 雪に消える、昼の絵（入口拠点） | 42 | 12,100 / 540 / 1 |
| Q-B01-02 | ベネット式・吹雪の抜け方（入口拠点） | 52 | 20,400 / 920 / 2 |
| Q-B01-03 | 頂上より、もう一枚（峰下の観測小屋） | 60 | 6,649 / 153,675 / 3 |

1. 霜筋の観測棚で岩殻虫3体を追い払い、正面、高い棚、横の順に岩筋を写します。観測した場所には印が残ります。入口拠点では光界3の障壁を任意で試打できます。
2. 風待ちの岩棚で埋もれた目印を調べます。上の門は風が止んだ間だけ渡れます。下の風よけ道では敵を避けて進むこともでき、どちらも峰下の観測小屋へ出ます。小屋に固定標識を置くと、入口拠点へ直接戻れます。
3. 小屋で依頼を受け、霜紋の稜線へ。霜紋の岩兎を退け、右奥の高い棚の下から谷と模様を写します。小屋に戻って記録を飾り、その場で報告します。

風の周期はラボ内の時間で7.2秒です。岩棚に入ってから3.8秒以上6.0秒未満の間が凪です。門の表示に切替までの秒数が出ます。吹雪の間に門を使うと、体力や道具を失うことなく手前の足場で待機します。凪の間に渡り始めれば、風が変わっても小屋まで到着します。

## 霜紋の岩兎

「片側の岩薙ぎ」では向いている側に広い予告が出ます。逆側へ回り込むか段差を使って避けられます。「霜棚の二拍」では左右の地面が順に光り、中央に安全地帯ができます。予告が終わって動きが止まると、光界障壁が外れます。光界0でも攻撃が通り、この間のダメージは1.22倍です。値と報酬額は試作値です。

討伐では通常報酬を受け取り、表の初回報酬は依頼を報告した時に一度だけ受け取ります。小屋の観測記録は保存後も表示されます。
