# フォンテーヌの日次依頼

Lv80でフォンテーヌの水辺の広場へ行き、「日次依頼」を開きます。この広場で受注と報酬の受取ができます。エミリエが同行中の場合は、同行中のエミリエから採集前の見回りを受注できます。受注枠は全地域で主依頼一件・追加依頼二件です。 [日次依頼の設計案](../quest-v1/DAILIES.md) · [日付更新と保存の仕様](DAILY_MONDSTADT_WEB.md)

| 設計ID | 依頼主 | 目標 | 試作の報酬 |
| --- | --- | --- | --- |
| Q-FON-D01 | ナヴィア | フォンテーヌ・往日の海の実戦の敵200体 | 138,080 EXP・3,050モラ |
| Q-FON-D02 | エミリエ | 水路沿い・郊外の搬入口の陸上の敵60体 | 41,420 EXP・1,000モラ |
| Q-FON-D03 | フリーナ | 地域の入口・郊外の搬入口の実戦の敵80体 | 55,230 EXP・1,350モラ |
| Q-FON-D04 | リネ | 郊外の搬入口の故障メカ50体 | 43,150 EXP・1,150モラ |
| Q-FON-D05 | フレミネ | 水路沿いの重甲ヤドカニ・郊外の搬入口の指定精鋭メカ3体 | 25,890 EXP・1,400モラ |

郊外の搬入口は、水路沿いの左側から入れる陸上の狩場です。故障メカ5体のうち、精鋭に近づくと名前とHPが表示されます。精鋭メカを倒すと、受注中のリネとフレミネの依頼がそれぞれ一回進みます。倒した精鋭は復活します。リネの対象は郊外の搬入口に限ります。

郊外の搬入口は試作の狩場で、既存の運搬メカ停車場の背景と警備メカのドット絵を流用しています。配置比較画面では、同じ敵配置を元画像と軽量設定で見比べられます。対象地点と報酬額は試作値です。

Luaで5件の必要数、精鋭の復活、対象範囲を確認しました。Chromeでは徒歩移動と通常攻撃、三つの依頼への同時加算、報酬受取、古いセーブでの重複受取防止を確認しました。通常操作で200体を倒す所要時間は未計測です。 [Luaの検証結果](../../evidence/daily-fon-lua.json) · [Chromeの検証結果](../../evidence/daily-fon-web.json)
