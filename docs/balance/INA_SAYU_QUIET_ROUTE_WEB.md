# 最短ルートは、静かなルート

稲妻第1話「その灯籠、今、動きました？」の報告後、城下の広場で早柚の依頼（Q-INA-S03）を受けられます。見回り札で話を聞き、木陰の見回り道へ進みます。

- 草むら、石段の途中にある洞穴、大木の裏で、葉の印を G で調べます。足元の点線は見回り役が向いている側に出ます。隠れ場所では発見ゲージが下がります。洞穴へは Space で登ります。
- 見回り役に発見されたら、通常戦闘で退けて同じ確認点を調べられます。途中で保存しても、その確認点の戦闘が続きます。倒した後の記録も保存されます。
- 三か所を終えたら、狭い抜け穴で早柚に声をかけます。葉の動きで先回りを示し、裏の柵が上がります。城下の広場に戻ると、昼寝場所にお礼の葉と木の実があります。

報告で78,355 EXPと試作値1,050モラを一度受け取ります。開いた近道は保存後も両方向から使えます。見回り役の巡回周期、発見までの猶予、戦闘HPはラボの試作値です。

草むら、洞穴、大木、竹柵、葉、昼寝場所の小物は自作モデルを正面・斜め前・斜め後ろから確認してドット絵にしました。見回り役には既存の野伏絵を使い、早柚の先回りは台詞と葉で描きます。森はラボ用の仮背景で、本番は3D配置の方針です。 [形状モデル](../../evidence/ina-sayu-route-views.png) · [素材の記録](../../evidence/ina-sayu-route-art.json)

草むらの同一フレームで、描画命令はPNGが35件、標準の矩形描画が16,846件、軽量16色が4,413件でした。軽量16色は標準の矩形描画より約74％少なくなります。葉や服の細部は粗くなりますが、草むらに隠れた位置、見回り役の輪郭、視線を示す点線は分かります。 [PNG表示](../../evidence/ina-sayu-route-cover-png.png) · [軽量16色](../../evidence/ina-sayu-route-cover-light.png) · [開いた裏柵](../../evidence/ina-sayu-route-open.png)
