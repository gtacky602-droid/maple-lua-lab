# ノヴォキッチェヴの遠征（仮構造）

スネージナヤの雪原からノヴォキッチェヴの入口拠点へ入れます。安全な拠点で準備し、凍止設備の通路、吹き溜まりの連絡坑、氷殻の最深室へ進みます。地形はラボ独自の仮案です。背景は既存の地下水路の仮画像を共用し、本番では3D配置を想定します。

| 設計ID | 依頼 | レベル | 初回報告（EXP / モラ / 強化鉱石） |
| --- | --- | ---: | ---: |
| Q-B09-01 | 最深部へ、急がずに | 196 | 19,500,000 / 9,200 / 2 |
| Q-B09-02 | 凍った設備に、通り道 | 198 | 26,800,000 / 10,800 / 4 |
| Q-B09-03 | 雪の向こうの、帰還報告 | 200 | 17,133,467 / 882,270 / 8 |

1. 拠点の装備台で、旅人と同行者それぞれの5部位と光界値を確認します。試打では、威力100のうち、今の装備で障壁50を通る分を表示します。装備の購入・変更や試打は任意です。装備を確認して報告すれば、刻印0でも先へ進めます。
2. 左の地上で巻き上げ機を停止して足場に乗り、上段の見張りを退けます。右へ降りて送風輪を止め、下段の見張りを退けたら、右の足場で標識を固定します。その下の地上の門が拠点への近道です。
3. 連絡坑の下段2体と上段1体を順不同で倒して、最深室へ。氷継ぎの岩這いを退け、右奥の高台で帰路を確認します。さらに右の地上の門から直接拠点へ戻って報告できます。

足場と討伐の途中経過は保存されます。今回の遠征の初回報酬は報告時に一度だけ入り、通常の討伐EXPとモラは討伐時に入ります。

## 氷継ぎの岩這い

「足元の氷圧」は地面に広い予告が出ます。「氷柱の断面」は予告時に固定された範囲を攻撃します。攻撃後に後方の甲殻が開くと障壁50が外れ、1.28倍の反撃時間になります。この間は光界0の通常攻撃も通ります。強さと報酬額は試作値です。

拠点で協力部屋を作れます。連絡坑の見張り3体を各自で倒したあと、最深室で合流します。討伐後の高台の確認と報告も各自で行います。 [共闘の道順と検証](../COOP_WEB_PREVIEW.md#玻璃根の歩行晶と氷継ぎの岩這い)

## 装備と光界刻印

通常強化を上限まで進めた聖遺物は、町で刻印できます。レア度★3／4／5の刻印上限は1／3／5星です。次の星数×20万モラを消費する試作値を使います。刻印は該当部位の主効果を上げ、装備時は旅人5部位と現在の同行者5部位の星数が光界値に加わります。控えの同行者の装備は持ち主に残ります。従来セーブの同行枠の装備は、保存時に編成されていた同行者へ引き継ぎます。

固定値・割合の上昇率は11月16日の比較案、障壁には既存の仮式を使用しています。障壁の手動検証値も町で使えます。手動値はセーブ対象外です。「装備の光界値を使う」で装備計算に戻れます。刻印のランダム追加効果、振り直し、継承、報酬素材の選択は今後の対象です。
