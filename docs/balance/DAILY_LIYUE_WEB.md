# 璃月の日次依頼

Lv20で璃月の港の広場に着いたら「日次依頼」を開けます。受注と報酬の受取はこの広場で行います。北斗が同行中なら、主依頼は同行中の北斗から受けます。主依頼一件と追加依頼二件の枠は、モンドと璃月で共通です。 [日次依頼の設計案](../quest-v1/DAILIES.md) · [日付更新と保存の仕様](DAILY_MONDSTADT_WEB.md)

| 設計ID | 依頼主 | 目標 | 試作の報酬 |
| --- | --- | --- | --- |
| Q-LIY-D01 | 北斗 | 璃月・沈玉の谷・層岩巨淵の実戦の敵200体 | 4,200 EXP・760モラ |
| Q-LIY-D02 | 刻晴 | 港外の仮置き場・川沿いの荷運び道・岩間の狩場の実戦の敵80体 | 1,700 EXP・340モラ |
| Q-LIY-D03 | 行秋 | 港外の仮置き場・岩間の狩場・石門裏の拠点の宝盗団40体 | 1,550 EXP・310モラ |
| Q-LIY-D04 | 香菱 | 岩間の狩場と川沿いの荷運び道で仕込み用の素材20個 | 1,080 EXP・265モラ |
| Q-LIY-D05 | 鍾離 | 北の入口・岩間の狩場・奥の保管区画の指定精鋭3体 | 1,830 EXP・380モラ |

香菱の依頼を受けている間は、指定の狩場で水スライムか炎スライムを倒すごとに、依頼欄へ素材を一個加算します。素材は依頼欄で管理します。条件が重なる場合は、同じ撃破で北斗と刻晴の依頼も一件ずつ進みます。岩間の狩場と港外の仮置き場に、サブクエスト報告後も繰り返し討伐できる宝盗団を配置しました。

鍾離の依頼は、北の入口と岩間の狩場で復活する遺跡守衛が対象です。本編で奥の保管区画の番人が出現している間は、その撃破も数えます。

Luaでは、配置済みの敵を使って五候補の必要数、地域をまたいだ枠、素材の加算条件、宝盗団の復活を確認しました。Chromeでは実際の移動・攻撃・受取と、同じプロフィールの古いセーブで報酬が重複しないことを確認しました。報酬額と対象地点は試作値です。通常操作で200体を討伐する所要時間は未計測です。 [Luaの検証結果](../../evidence/daily-liyue-lua.json) · [Chromeの検証結果](../../evidence/daily-liyue-web.json)
