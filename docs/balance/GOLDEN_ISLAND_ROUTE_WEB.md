# 金リンゴ群島の小舟と重なり岩

[隠し世界の設計](../quest-v1/HIDDEN_WORLDS.md) の Q-H01-01〜02 をローカル Lua ラボにつないだ。Lv1の新規データでは、モンド・南の街道にある「古い船着き場の跡」の近くで G を押すと入口を発見できる。発見すると東側の門から潮だまりの船着き場へ行ける。

| 依頼 | 受注・報告 | 操作 |
|---|---|---|
| 地図のすみの、小さな船 | 本土の潮だまり | 海岸の絵、上段の赤い布、浜の二本杭を調べる。F で小舟に乗り、島で魚に見えた岩、戻り舟、休憩台を調べる |
| 宝箱まで、影をたどって | 島の入口広場 | 高台、海辺、岩穴の順に見え方を記録する。道が見える地点で G を押すと洞窟の門が現れる。群れを退け、宝箱の記念札を見晴らし台に飾る |

小舟の移動は片道2.1秒。初めて来るデータでは、三つの目印を記録してから乗れる。島を訪れたことのある旧データは、引き続きモンド・南の街道の近道を使える。島は拠点移動先として記録される。

M地図には、船着き場の手掛かりを調べると金リンゴ群島が加わる。岩の切れ目を確かめると小洞窟が地図に現れ、依頼を報告すると奥の小浜も表示される。セーブから再開しても両方の地点を選べる。 [地図と依頼のLua試験](../../evidence/golden-island-route-lua.json)

岩の見え方には、共通の岩の座標と幅、各地点の角度を使う。Lua が視点ごとの投影幅を計算し、ブラウザがその輪郭を表示する。高台からの重なり、海辺からの狭い隙間、岩穴からの通れる幅を比べられる。洞窟への門は、通れる幅が見える地点を選んでから現れる。報告後は記念札を読み返し、小洞窟の奥の小浜へ寄り道できる。

新しい4マップはラボ用の仮配置。船着き場と小洞窟の背景は、既存の島の配色を参考に別構図で生成した。背景はブラウザが仮画像として表示し、本番では3Dに差し替える。群れ戦には既存の敵の絵と共通戦闘を使う。依頼報酬は順に 220 EXP・120 モラ・強化鉱石1個、420 EXP・210 モラ・強化鉱石2個の試作値。

Chrome でLv1から発見と小舟の往復を行い、岩の見え方を比べて洞窟を開けた。セーブから再開すると記念札を読み返せる。洞窟の同一フレームでは、描画指示が標準矩形 8,520 件から軽量16色 2,173 件になった。[Chrome の結果](../../evidence/golden-island-route-browser.json) ／ [PNG](../../evidence/golden-island-route-cave-png.png) ／ [軽量16色](../../evidence/golden-island-route-cave-light.png)
