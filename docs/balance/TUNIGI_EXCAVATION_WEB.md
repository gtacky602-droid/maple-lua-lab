# トゥニギの黒淵の発掘ルート

[高難度分岐の設計](../quest-v1/HIGH_DIFFICULTY.md) の Q-B04-01〜03 をローカル Lua ラボにつないだ。入口拠点の右側に「風鳴りの棚」「風よけ板の工房」「発掘隊の風よけ所」へ進む門が並ぶ。奥地へ続く従来の Lv60 の門も使える。

| 依頼 | ラボの試作レベル | 操作 |
|---|---:|---|
| 風が鳴らす、古い返事 | 118 | 見張り3体を退ける。通気口ごとに G で向きを変え、表示と目印の図形を合わせる |
| 入口よりも、出口の設計 | 124 | G で風よけ板の位置を切り替える。昇降台の脇に固定し、風が弱まる時間帯に F で乗る。風よけ所で停止点と野営地への道を調べる |
| 出口までが、発掘だ | 130 | 地上と上段の精鋭を退け、記録庫へ進む。割輪機を退けると往路が崩れる。記録片を拾い、右端の退路から風よけ所を通って野営地へ帰る |

装置音は「装置音を聞く」で有効になる。○は中くらいの音が一度、△は上がる2音、□は低い音が二度鳴る。Lua が記号と音のパターンを同じ選択肢から送り、ブラウザが選択したときだけ音を再生する。

風よけ板は3か所の候補を試せる。選択中の板は紫、固定した板は緑。固定前の配置は部屋を出ると解ける。固定済みの板、停止点、退路の記録はセーブに残る。報告後は入口拠点から風よけ所へ直接行ける。

地形、仮背景、割輪機はラボ用に制作した。割輪機は正面と斜めの形状スケッチから作ったドット絵を使う。背景はブラウザが画像として描画し、本番では3D配置に置き換える想定。

## 風礫の割輪機

「溝を走る砂風」は割輪機が向いた側の床に広がる。黒い端線と砂色の目印が出たら、横へ退くか **Space** で跳び越える。「記録床の噴き上げ」は予告が出た時点の位置に立ち上がる。緑の予告線から横へ出ると避けられる。どちらも攻撃が止まったあとに反撃できる。その間は与えるダメージが試作値で1.35倍になる。

討伐後は往路が崩れる。記録片を拾い、右端の退路から風よけ所を通って帰る。討伐記録はセーブに残る。経験値364,882、モラ461,918、強化鉱石6個は初回の依頼報告で受け取る。

共闘は各自が発掘通路の精鋭を退けてから記録庫で合流できる。往路の崩落と退路の開通は各自の依頼に従う。 [共闘の入口と検証](../COOP_WEB_PREVIEW.md#風礫の割輪機と潮鐘の門像)

## 検証

Luaで砂風のジャンプ回避、噴き上げの固定位置、反撃時間、初回報告の額を確認した。Chromeでは装置音の切り替えと昇降台の往復に続けて、2種類の攻撃と反撃時間を確認した。討伐後は右端の退路から戻って報告し、セーブを読み直して展示した記録片を読めた。 [Luaの結果](../../evidence/tunigi-excavation-lua.json) · [Chromeの結果](../../evidence/tunigi-excavation-browser.json)

割輪機単体の矩形数は標準4,866件から軽量16色で1,344件に減った。攻撃を予告した同じフレームでは、記録庫全体のLua描画指示が標準9,130件から2,431件になった。 [PNG](../../evidence/tunigi-excavation-boss-png.png) · [軽量16色](../../evidence/tunigi-excavation-boss-light.png) · [素材の内訳](../../evidence/wind-ring-art.json)
