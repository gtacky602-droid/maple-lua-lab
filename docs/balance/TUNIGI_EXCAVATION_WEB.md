# トゥニギの黒淵の発掘ルート

[高難度分岐の設計](../quest-v1/HIGH_DIFFICULTY.md) の Q-B04-01〜03 をローカル Lua ラボにつないだ。入口拠点の右側に「風鳴りの棚」「風よけ板の工房」「発掘隊の風よけ所」へ進む門が並ぶ。奥地へ続く従来の Lv60 の門も使える。

| 依頼 | ラボの試作レベル | 操作 |
|---|---:|---|
| 風が鳴らす、古い返事 | 118 | 見張り3体を退ける。通気口ごとに G で向きを変え、表示と目印の図形を合わせる |
| 入口よりも、出口の設計 | 124 | G で風よけ板の位置を切り替える。昇降台の脇に固定し、風が弱まる時間帯に F で乗る。風よけ所で停止点と野営地への道を調べる |
| 出口までが、発掘だ | 130 | 地上と上段の精鋭を退け、記録庫へ進む。割輪機を退けると往路が崩れる。記録片を拾い、右端の退路から風よけ所を通って野営地へ帰る |

装置音は「装置音を聞く」で有効になる。○は中くらいの音が一度、△は上がる2音、□は低い音が二度鳴る。Lua が記号と音のパターンを同じ選択肢から送り、ブラウザが選択したときだけ音を再生する。

風よけ板は3か所の候補を試せる。選択中の板は紫、固定した板は緑。固定前の配置は部屋を出ると解ける。固定済みの板、停止点、退路の記録はセーブに残る。報告後は入口拠点から風よけ所へ直接行ける。

地形、仮背景、割輪機はラボ用に制作した。割輪機は正面と斜めの形状スケッチから作った静止ドット絵で、体力と討伐後の進行を確認できる。主人公・ボスの新規技は追加していない。ボスからの経験値とモラの獲得は無効。初回報告時に試作値として経験値 364,882、モラ 461,918、強化鉱石 6 個が入る。背景はブラウザが画像として描画する。本番では3D配置に置き換える想定。

## 検証

Chrome で装置音を切り替え、風よけ所と工房を昇降台で往復した。崩落で往路が塞がった後は、退路を使って報告できた。セーブから再開すると展示した記録片を読める。[Chrome の結果](../../evidence/tunigi-excavation-browser.json)

割輪機単体の矩形数は標準 4,866 件から軽量16色で 1,344 件に減った。記録庫の同一フレームでは、Lua の描画指示が標準 9,110 件から 2,411 件に減った。[PNG](../../evidence/tunigi-excavation-boss-png.png) ／ [軽量16色](../../evidence/tunigi-excavation-boss-light.png) ／ [素材の内訳](../../evidence/wind-ring-art.json)
