# 遠くの人にも、届く一発

稲妻の第1話「その灯籠、今、動きました？」の報告後、城下の広場で宵宮の依頼（Q-INA-S02）を受けられます。花火帳のところで話を聞き、潮の見晴らし道へ向かいます。

1. 松の高台、崖の高台、海岸の高台で G を押し、家の窓から花火が見えるか調べます。Space で石段に上がれます。一番高い崖の高台は手前の崖に遮られ、低い海岸側なら見通しが通ります。
2. 三か所を調べると、右の門から窓灯りの花火浜へ進めます。打ち上げ台で色を「海の青・夕焼けの橙・藤の紫」から、形を「輪・菊・扇」からそれぞれ選びます。選んだ組み合わせは空の小さな見本で確認できます。
3. G か打ち上げボタンで、窓辺の家族、光の上昇、花火が開く場面の順に再生します。打ち上げ後は浜の右門から広場へ戻り、宵宮に報告できます。

両地点は戦闘のない探索区画です。初回報告で57,595 EXPと試作値850モラを受け取ります。色と形は記録され、広場から浜へ直接戻って観賞できます。途中で保存して読み込むと、選んだ色と形を使って打ち上げを最初から見られます。

窓・目印・打ち上げ台は自作モデルを三方向から確認してドット絵にしました。見通しは窓から花火までの線と障害物の交差を断面図で表します。海岸の背景画像と断面図の寸法はラボ用の仮素材・試作値です。本番では3D配置を使う方針です。 [形状モデル](../../evidence/ina-fireworks-views.png) · [素材記録](../../evidence/ina-fireworks-art.json)

窓辺の同一フレームで、描画命令はPNGが21件、標準の矩形描画が8,680件、軽量16色が2,135件でした。軽量16色では標準の矩形描画より約75％減ります。木枠や格子の細部は粗くなりますが、灯りと二人の輪郭は読み取れます。 [PNG表示](../../evidence/ina-fireworks-window-png.png) · [軽量16色](../../evidence/ina-fireworks-window-light.png) · [夕焼けの橙の扇](../../evidence/ina-fireworks-burst.png)
