# シムランカの絵本と三枚板

[隠し世界の設計](../quest-v1/HIDDEN_WORLDS.md) の Q-H03-01〜02 をローカル Lua ラボにつないだ。Lv80から、フォンテーヌの広場で不思議な絵本の近くに立って G を押すと、折り目の読書室への入口が現れる。

| 依頼 | 受注・報告 | 操作 |
|---|---|---|
| 開いたページの、その向こう | 折り目の読書室 | 絵本の折り目を調べる。表と裏を切り替えて足場を出し、確定後に上段の門へ。広場で休憩台と戻り方を記録する |
| 折り目ひとつで、道になる | 入口広場 | 三枚の板の高さを合わせる。谷を渡って二体を退け、灯りのそばの箱を開ける。鳥、小舟、灯りから一つ選んで広場に飾る |

折り方は G で切り替える。試している足場は紫、確定して残る足場は緑。確定前の形は部屋を離れると元に戻る。確定後はセーブから再開しても残る。長い橋だけでは向こう岸の高さに届かない。小さな階段、短い橋、遮蔽付きの踏み台をつなげれば通常ジャンプで渡れる。紙の壁には衝突判定があり、飛び道具を遮る。谷に落ちたときは手前の足場に戻る。

記念の飾りを選ぶと、広場への近道が開く。報告後は広場側からも近道を使え、選んだ飾りを確かめられる。報酬は順に 25,500 EXP・790 モラ・強化鉱石2個と、33,400 EXP・1,060 モラ・強化鉱石3個の試作値。

紙の谷には仮背景を使用。灯りは正面と斜めから見た形状スケッチを参照した生成ドット絵で、原画と軽量矩形描画を切り替えられる。地形と背景はラボの試作。本番の背景は3D配置に差し替える想定。

Chrome で通常ジャンプによる谷越え、宝箱、折り紙の小舟の選択、セーブ後の再表示と近道を確認した。灯りの場所の同一フレームでは、Lua の描画指示が標準 4,905 件から軽量16色 1,324 件になった。[Chrome の結果](../../evidence/simulanka-folds-browser.json) ／ [PNG](../../evidence/simulanka-folds-lantern-png.png) ／ [軽量16色](../../evidence/simulanka-folds-lantern-light.png)
