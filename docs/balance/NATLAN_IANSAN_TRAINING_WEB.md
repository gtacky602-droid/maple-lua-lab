# 昨日の自分に、挑戦状！

ナタの高台と水辺を終えて「得意な道だけじゃ、もったいない！」を報告すると、Lv100からイアンサの依頼を受注できます。谷の集落でイアンサに話を聞き、そばの門から訓練路へ入ります。

1. 記録台でGを押し、いつもの進め方で一周します。ジャンプを長押しして上段の印に触れ、地上に並ぶ訓練的を三つ壊します。色が変わる床は予告を見て越えます。二つの床の間の水場で、一周につき一度Gで回復できます。
2. 右の旗に着くと記録台へ戻ります。最初の記録から、イアンサが注目する点を一つ示します。「移動技を段差まで取っておく」「的をまとめて攻撃する」「予告を見てから回復地点を使う」から一つ選びます。
3. 記録台からもう一周し、初回と再試行の時間・被弾・区間ごとの停止時間を比べます。再試行が遅くても、完走すれば集落で報告できます。
4. 報告後も記録台から走れます。その場で今回の結果と保存した二周の記録を比べられます。

停止時間は、地上で操作キャラの横位置がほぼ動かなかった時間です。一時停止中は計測を止めます。訓練的は自分で操作するキャラの通常攻撃や既存の技で壊せます。同行AIの自動攻撃対象と通常の討伐・報酬対象からは外しています。水場で回復したHPと訓練で変化したゲージは、試走の完了や中断で元に戻ります。

初回報告は2,991,093 EXPと6,300モラです。モラ、床の周期とダメージは試作値です。イアンサは台詞で登場します。訓練的、床の器具、水場、記録台、印、旗は、オリジナルの形状モデルを三方向から確認して描き起こしました。訓練路の背景は本番の3D配置を想定した仮画像です。 [設備の3D形状](../../evidence/nat-iansan-training-views.png) · [素材の変換記録](../../evidence/nat-iansan-training-art.json)

同じ場面でのLuaの描画指示は標準矩形12,913件、軽量16色3,125件、PNG表示20件でした。軽量16色では約76%少なく、訓練的の輪郭、赤い的、上段の印を見分けられます。藁の編み目と装備の細部は簡略化されます。幻境実機での描画性能は未検証です。 [PNG表示](../../evidence/nat-iansan-training-course-png.png) · [軽量16色](../../evidence/nat-iansan-training-course-light.png)
