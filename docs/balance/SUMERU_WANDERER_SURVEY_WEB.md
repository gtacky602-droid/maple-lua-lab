# 上から見るだけじゃ、分からない

Lv60でスメール第1話「地図には、道があるんだけど？」を受け、川辺の幹の見上げ台で放浪者に会います。樹陰の広場に戻ると、放浪者の加入依頼（Q-SUM-S01）を受けられます。 [企画書](../quest-v1/regions/04_SUMERU.md#q-sum-s01-上から見るだけじゃ分からない)

1. 広場で放浪者の見取り図を G で調べ、門を F で通って大樹の裏道へ向かいます。地上の二股の根、中段の三日月の石、上段の金色の輪を順に調べます。 [根の足場と目印](../../evidence/sum-wanderer-sign-trail.png)
2. 上段の右端から下り、幹の裏を調べると、枝切れの洞穴が地図と門に現れます。
3. 洞穴で途切れた枝を見上げ、地上のレバーを入れます。放浪者が上を横切り、飛んでいるキノコン二体を追い払うと、足場が出ます。この援護はクエストの演出です。討伐数や討伐報酬は増えません。 [レバーと援護](../../evidence/sum-wanderer-sign-assist.png)
4. 足場を二段登って観測標識を調べます。地上で見つけた入口と樹上の目印を一枚の見取り図で確認して、右下の門から広場へ報告に戻ります。 [観測標識](../../evidence/sum-wanderer-sign-record.png)

報告すると153,247 EXPと試作値の1,850モラを一度受け取れます。編成は引き継がれ、依頼手帳の「放浪者を同行に選ぶ」を押すと放浪者に切り替わります。初期装備の試作値は入門法器がATK+1、記録花がHP+10です。記録花は花の装備枠が空いている間に作用します。旧加入依頼を受注済みのセーブでは、その依頼も報告できます。

レバー操作中に保存すると、再開後は発見済みの洞穴に戻ってレバーから再開できます。足場を出した後に保存すると足場も復元されます。報告後も同じ道を通って観測標識を読み返せます。

目印と装置は自作3Dモデルを三方向から確認してドット絵にしました。放浪者とキノコンは既存の待機絵を使い、援護はスプライトの移動と短い風の表示で表現しています。援護時間は試作値です。二つの背景はラボ用の仮画像で、本番は3Dで配置する方針です。 [形状モデル](../../evidence/sum-wanderer-sign-views.png) · [素材の記録](../../evidence/sum-wanderer-sign-art.json)

枝切れの洞穴で同じフレームを止め、PNG・標準矩形・軽量16色を切り替えました。軽量16色ではレバーの持ち手や放浪者の笠の輪郭が残り、衣装やキノコンの色の細部が粗くなります。各方式の描画命令数はChrome検証の `commands` に記録しています。 [PNG表示](../../evidence/sum-wanderer-sign-hollow-png.png) · [軽量16色](../../evidence/sum-wanderer-sign-hollow-light.png)

`python server.py --port 8916` でラボを起動し、`python -X utf8 test_sumeru_wanderer_survey.py`、`node test_sumeru_wanderer_survey.mjs` の順で実行すると、初対面から加入・保存・初期装備の復元まで検証できます。 [Lua検証](../../evidence/sum-wanderer-sign-lua.json) · [Chrome検証](../../evidence/sum-wanderer-sign-browser.json)
