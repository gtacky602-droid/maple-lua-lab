# 日次依頼とモンドの五つの候補

本編ルートを開始し、モンドの城門広場で「日次依頼」を開きます。主依頼を一件、追加依頼を二件まで受注できます。この枠は地域をまたいで共通です。受取を済ませた枠も、その日の更新までは使用済みとして数えます。

アンバーが同行している場合、主依頼は同行中のアンバーから受注できます。ベネットの候補は洞窟のサブ依頼を報告すると開きます。

| 候補 | 目標 | 試作の報酬 |
| --- | --- | --- |
| 街道の安全確認 | モンドと指定の周辺地域の敵200体 | 640 EXP・480モラ |
| 今日の観察記録 | 対象スライム60体 | 230 EXP・195モラ |
| 皇女の巡察 | 国境の道、旧道の下段、丘の見張り台、精鋭部屋6室から計3体 | 280 EXP・220モラ |
| 休憩所の、その周り | 南の街道、休憩所、旧道の地上で80体 | 250 EXP・220モラ |
| 今日も一つ、道を開こう | 洞窟の奥と旧道の地上で60体 | 260 EXP・220モラ |

受注後の撃破を数えます。城門広場で受取まで進めます。条件を満たすスライム一体の撃破は、主依頼、スライムの依頼、指定区域の依頼に各一回加算されます。同行AIの撃破も加算されます。訓練的、週ボス、フィールドボス、登録のない演出用の対象は日次討伐から外しています。

フィッシュルの「皇女の巡察」は、受注欄で9か所から目的地を選んでM地図を開けます。中央塔では木盾の野営地が対象で、見晴らし台の希少遭遇は対象外です。鷹の門の狂風のコアは精鋭として数えます。風スライムの絵を仮に共用しているため、リサのスライム討伐では種類を別に判定します。[6室の戦闘と報酬の検証](../../evidence/mondstadt-daily-spur-elites.json) · [受付から地図を開く](../../evidence/mondstadt-daily-spur-map.json)

ローカルラボの仮設定では、サーバーの時刻を基準に毎日04:00（日本時間）に更新します。

- 受取済みの枠は新しい日の枠に切り替わります。
- 達成した未受取分は翌日の更新まで、受注先で受け取れます。
- 進行途中の依頼は更新時に終了します。

日次の進行と受取記録はローカルラボのSQLiteに保存します。同じプロフィールで古い冒険セーブを読み込んでも、新しい日次記録を使います。セーブに未反映の受取分は残高へ反映し、反映済みの受取分は重ねて加算しません。通常の冒険や装備は従来どおりチェックポイントで保存します。別のPCでログインする共通アカウントや幻境の保存APIは未接続です。

`test_daily_mondstadt.py` では配置済みの敵の撃破で五候補すべてを達成し、枠、重複、日付更新、翌日の受取、サーバー再起動後の古いセーブを確認しました。`test_daily_mondstadt.mjs` ではChromeで受注、実際の攻撃、加算、報酬受取、再読み込みと幅390pxの表示を確認しました。200体を通常操作で回り切る所要時間は未計測です。 [LuaとHTTPの検証](../../evidence/daily-mond-lua-http.json) · [Chromeの検証](../../evidence/daily-mond-web.json)
