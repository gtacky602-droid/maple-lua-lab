# コロンビーナ「宝探しの前に、寄り道を」

Lv120のナド・クライで第1話「その宝の話、確かめてみる？」を受け、工房脇の海岸でコロンビーナと初めて話すと、加入の寄り道（Q-NOD-S01）を受けられます。第1話を報告する前に始められます。

1. 海岸で寄り道の誘いを聞き、右寄りの門から工房裏の夜店へ進みます。焼き菓子、月貝の風鈴、香草茶のうち気になるものを一つ選びます。どれを選んでもモラはかかりません。
2. 岬へ曲がる道で三体の魔物を退け、沖を眺める腰掛けに進みます。岩棚へジャンプし、コロンビーナと休みます。選んだ物によって一緒に過ごすときの台詞と、腰掛けに残る小物が変わります。
3. 右の見晴らしで同行の申し出を聞き、海岸に戻って報告します。報酬は3,406,620 EXPと3,200モラです。依頼手帳の「コロンビーナを同行に選ぶ」で編成できます。海岸から腰掛けへ戻る近道も開きます。

初期装備の試作値は法器の攻撃力+1と、花を未装備のときのHP+10です。三つの選択で同じ初期装備を使います。元の依頼「コロンビーナと道を確かめる」は、以前に受注済みの保存データから進行・報告できます。

夜店と休憩点にはラボ用の仮背景を追加しました。本番の背景は3D配置で制作する方針です。焼き菓子、風鈴、香草茶は自作の形状モデルを三方向から確認してドット絵にしました。 [小物の三方向モデル](../../evidence/columbina-detour-gifts-views.png) · [小物の透過と変換記録](../../evidence/columbina-detour-gifts-art.json)

コロンビーナの待機絵は、既存の衣装案をもとに頭を大きく、胴と膝下を短くしました。羽飾りを除いて目視で約2.8頭身です。表示高は88pxで、加入前の案内役と加入後の同行者に使います。動作は待機絵の試作段階で、向きを変えると左右の装飾も反転します。 [待機絵の参照と変換記録](../../evidence/columbina-detour-idle-art.json)

海辺で風鈴を飾った同一フレームの描画命令は、PNG33件、標準矩形6,218件、軽量16色1,665件でした。軽量16色は標準より73.2%少なく、羽飾りと風鈴の輪郭は残ります。 [PNG](../../evidence/columbina-detour-bench-png.png) · [軽量16色](../../evidence/columbina-detour-bench-light.png) · [夜店](../../evidence/columbina-detour-market.png)
