# ナド・クライ「その宝の話、確かめてみる？」

Lv120でナド・クライの町の広場から受けられます。現地到着後に遊べる本編の一話目です（Q-NOD-M01）。

1. 広場で漁師、商人、旅人のうち、気になる噂の持ち主に近づいて `G` で聞きます。どの証言からも右側の門で工房脇の海岸へ進めます。聞き込みにモラはかかりません。
2. 海岸でコロンビーナと待ち合わせ、右の門から月映しの浅瀬へ。浅瀬はイベント内で月が見える状態になっています。
3. 水際の反射板に近づいて `G` で向きを変えます。菱形の刻線のある結晶に光が届くと足場が開きます。少し手前から右へジャンプして、足場に乗ってください。落水しても手前の岸へ戻ります。反射板の向きと開いた足場は、町から再開しても引き継がれます。
4. 引き潮の岩場では、奥の魔物に近づいてから手前へ戻ると、地上の広い場所まで引き寄せられます。三体を退けたら右奥の小箱を開け、強化鉱5個と貯蔵所の札を受け取ります。
5. 右端の近道からネフェルへ報告すると、初回に9,733,199 EXPと8,700モラを獲得します。報告後は岩場で再び狩りができ、宝箱では札を読み返せます。

反射板はマップ設備です。アンバーなど、月反応を使わない編成でも進めます。魔物には既存の小型スライム素材を使い、追跡範囲と速度はこの岩場用に設定しました。コロンビーナはこの話では台詞で登場します。加入の寄り道と札の先の二経路は別の依頼です。

浅瀬と岩場の背景は、既存のラボ用港町画像を色調と景観の参考にした仮画像です。本番は3D配置で制作する方針です。足場の当たり判定はLuaが持ち、仮背景と足場の表示はブラウザが担当します。 [背景の生成記録](../../assets/nod-moon-shallows-background-generation-v1.json)

Luaの検査では、三つの聞き込み、反射板と橋の復元、落水時の帰還、アンバー編成での移動、魔物の誘導、討伐途中からの再開、初回報酬と再訪を確認しました。 [Luaの検査結果](../../evidence/nod-shallows-lua.json)

Chromeでは町のLv120検証データから受注し、商人の証言、反射板の途中保存、二人での橋の通過、戦闘、小箱、報告までを確認しました。橋の上で同じフレームを比較した描画命令数はPNG20件、標準矩形3,453件、軽量16色894件です。軽量16色では陰影が簡略化され、標準矩形より74.1%少ない命令数でした。 [Chromeの検査結果](../../evidence/nod-shallows-browser.json) · [PNG](../../evidence/nod-shallows-png.png) · [軽量16色](../../evidence/nod-shallows-light.png) · [反射板](../../evidence/nod-shallows-mirror.png)

`python -X utf8 test_nod_shallows.py` でLua側の検証とブラウザ用保存データを生成します。ローカルサーバーを8897で起動して `node test_nod_shallows.mjs` を実行すると、Chromeで同じルートを再現できます。
