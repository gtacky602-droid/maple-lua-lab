# ナド・クライの日次依頼

Lv120でナド・クライの町の広場へ行き、「日次依頼」を開きます。この広場で受注と報酬の受取ができます。コロンビーナが同行中なら、海岸の依頼は同行中のコロンビーナから受けます。受注枠は全地域で主依頼一件・追加依頼二件です。 [日次依頼の設計案](../quest-v1/DAILIES.md) · [日付更新と保存の仕様](DAILY_MONDSTADT_WEB.md)

| 設計ID | 依頼主 | 目標 | 試作の報酬 |
| --- | --- | --- | --- |
| Q-NOD-D01 | フリンズ | ナド・クライと特別地域の実戦の敵200体 | 742,560 EXP・4,850モラ |
| Q-NOD-D02 | アイノ | 月浜の部品置き場・潮風の部品回収場の実戦の敵60体 | 222,770 EXP・1,820モラ |
| Q-NOD-D03 | ネフェル | 月浜の部品置き場・トウヒ林の外周の指定精鋭3体 | 139,230 EXP・2,380モラ |
| Q-NOD-D04 | ラウマ | トウヒ林の外周・花見道の外周の実戦の敵80体 | 297,020 EXP・2,140モラ |
| Q-NOD-D05 | コロンビーナ | 月浜の部品置き場・灯りの海岸旧道の実戦の敵60体 | 222,770 EXP・1,690モラ |

月浜の部品置き場は月明かりの道の中ほど、トウヒ林の外周は町の広場の中ほどから入れます。どちらもLv120から繰り返し狩れます。精鋭は置き場の遺跡機兵と林の牙獣です。近づくと名前とHPが表示され、撃破後に復活します。

月浜の部品置き場では、フリンズ・アイノ・コロンビーナの依頼を同時に進められます。潮風の部品回収場と灯りの海岸旧道は、既存クエストでそれぞれ入口を開いてから使えます。新しい二つの狩場は既存の背景画像と敵のドット絵を使った試作です。配置比較画面で元画像と軽量設定を見比べられます。

Luaで5件すべての達成、対象範囲、精鋭の復活を確認しました。Chromeでは二つの狩場への徒歩移動と通常攻撃、同時加算、報酬受取、古いセーブでの重複受取防止を確認しました。配置・報酬額は試作値です。通常操作で200体を倒す所要時間は未計測です。 [Luaの検証結果](../../evidence/daily-nod-lua.json) · [Chromeの検証結果](../../evidence/daily-nod-web.json)
