# 往日の海の共鳴石と音の絵本

[高難度分岐の設計](../quest-v1/HIGH_DIFFICULTY.md) の Q-B05-01〜03 をローカル Lua ラボにつないだ。新しい5地点へは往日の海の入口拠点から進める。従来の Lv80 探索路にも引き続き入れる。

| 依頼 | ラボの試作レベル | 操作 |
|---|---:|---|
| 沈黙の楽譜を、拾いに | 148 | F で短い水路を渡り、地上と上段にある三つの石の印を G で写す。床の調整機で裏向きの石を戻す |
| 見える音と、聞こえる道 | 154 | 壁の印と同じ順で石を照らす。現れた橋を渡り、観賞路の案内板と上段の腰掛けを調べる |
| 最後の一音は、帰ってから | 160 | 潮鐘の門像を退け、上段にある最後の記録を持ち帰る。報告後は桟橋で音の絵本を開き、G で頁をめくる |

水路は往復1.6秒ずつの移動区間。共鳴石を調べると画面に印が表示され、「装置音を聞く」が有効なときは対応する音も鳴る。裏向きの石は静かで、調整機で表にすると鳴る。回廊の順序は壁に表示する。順を間違えると石の灯りが消えて、すぐに最初から照らせる。正しい順で出した橋はセーブ後も残る。絵本には三つの頁の文章と印があり、音は好きなときに切り替えられる。

## 潮鐘の門像

「左右に響く二つの鐘」は青く光る床を片側ずつ攻撃する。門像の近くの中央に移動するか、光った床を跳び越える。「鐘の真下へ落ちる響き」は足元に紫の予告が出るので、横へ移動して避ける。攻撃のあと門像の動きが止まり、反撃できる。その間は与えるダメージが試作値で1.35倍になる。

門像は、独自の形状モデルを正面、斜め前、斜め後ろから見た画像を参照して制作した既存のドット絵で表示する。背景はブラウザの仮画像を使い、本番は3D配置に置き換える想定。上段の記録を持ち帰って報告すると、試作報酬として経験値2,297,237、モラ660,060、強化鉱石7個を初回に受け取る。

## 検証

Luaで左右の攻撃の時間差、狙った位置に残る攻撃範囲、反撃時間を確認した。Chromeでは共鳴石の順序を解いて橋を渡り、2種類の攻撃と反撃時間を試した。討伐後は上段から最後の記録を持ち帰り、報告後のセーブから絵本の3頁を開いて音を再生した。 [Luaの結果](../../evidence/bygone-resonance-lua.json) · [Chromeの結果](../../evidence/bygone-resonance-browser.json)

門像単体の矩形は標準4,665件から軽量16色で1,094件になった。攻撃を予告した同じフレームでは、記録室全体のLua描画指示が標準8,918件から2,170件になった。 [PNG](../../evidence/bygone-resonance-boss-png.png) · [軽量16色](../../evidence/bygone-resonance-boss-light.png) · [3D参照と素材の内訳](../../evidence/bellgate-art.json)
