# 往日の海の共鳴石と音の絵本

[高難度分岐の設計](../quest-v1/HIGH_DIFFICULTY.md) の Q-B05-01〜03 をローカル Lua ラボにつないだ。新しい5地点へは往日の海の入口拠点から進める。従来の Lv80 探索路にも引き続き入れる。

| 依頼 | ラボの試作レベル | 操作 |
|---|---:|---|
| 沈黙の楽譜を、拾いに | 148 | F で短い水路を渡り、地上と上段にある三つの石の印を G で写す。床の調整機で裏向きの石を戻す |
| 見える音と、聞こえる道 | 154 | 壁の印と同じ順で石を照らす。現れた橋を渡り、観賞路の案内板と上段の腰掛けを調べる |
| 最後の一音は、帰ってから | 160 | 潮鐘の門像を退け、上段にある最後の記録を持ち帰る。報告後は桟橋で音の絵本を開き、G で頁をめくる |

水路は往復1.6秒ずつの移動区間。共鳴石を調べると画面に印が表示され、「装置音を聞く」が有効なときは対応する音も鳴る。裏向きの石は静かで、調整機で表にすると鳴る。回廊の順序は壁に表示する。順を間違えると石の灯りが消えて、すぐに最初から照らせる。正しい順で出した橋はセーブ後も残る。絵本には三つの頁の文章と印があり、音は好きなときに切り替えられる。

潮鐘の門像は、独自の形状モデルを正面、斜め前、斜め後ろから見た画像を参照して制作した。ラボには静止ドット絵、体力、討伐後の進行を実装した。技と連続アニメーションは保留。最後の報告の試作報酬は経験値 2,297,237、モラ 660,060、強化鉱石 7 個。報酬素材の選択は未実装。背景はブラウザが仮画像として描画し、本番は3D配置に置き換える想定。

## 検証

Chrome で、水路を通って三つの石を調べ、裏向きの石を直して鳴らした。消音で回廊を解き、セーブから再開して橋を渡った。最後の記録を持ち帰り、報告後のセーブから絵本の三頁を開いて音を再生した。[Chrome の結果](../../evidence/bygone-resonance-browser.json)

門像単体の矩形は標準 4,665 件から軽量16色で 1,094 件になった。記録室の同一フレームでは、Lua の描画指示が標準 8,912 件から 2,164 件になった。[PNG](../../evidence/bygone-resonance-boss-png.png) ／ [軽量16色](../../evidence/bygone-resonance-boss-light.png) ／ [3D参照と素材の内訳](../../evidence/bellgate-art.json)
