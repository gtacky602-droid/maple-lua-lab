# 秘密を知っても、驚ける？

フォンテーヌ第2話を報告したあと、水辺の広場で受注できます。窓明かりの別稽古場から小劇場へ入ります。

1. 舞台裏の上段へ跳び上がり、箱の通り道を調べます。客席側に回ると、通り道を覆う引き幕と舞台の縁が見えます。
2. 舞台裏に戻って箱を送り出します。車輪が傾くと箱は止まり、リネが演目の中止を決めます。安全に使える「二重の幕」と「逆光の影絵」から、代わりの演目を選びます。
3. 合図灯の表示を待ち、Gで幕か照明を動かします。客席側からも、最後に現れる金色の折り鳥まで見届けて、水辺の広場で報告します。
4. 報告後は小劇場の客席で再演できます。主舞台の第3話の公演にも演目が加わります。第3話の公演が済んでいれば、主舞台の下段にある「追加演目」の台で再演できます。

合図の受付に締切はなく、早く押すと同じ合図を待てます。どちらの手順でも、初回報告は1,028,841 EXPと4,200モラです。モラと演出の時間は試作値です。

箱の通常姿勢と故障姿勢、影絵の幕、折り鳥を、自作の形状を三方向から参照して作りました。リネとリネットは台詞で登場します。舞台裏と客席の背景は、本番の3D配置を想定したラボの仮画像です。 [形状資料](../../evidence/fon-lyney-magic-views.png) [素材記録](../../evidence/fon-lyney-magic-art.json)

Luaでは二つの手順の保存、早押しとポーズ、初回公演への追加と再演を確認しました。Chromeでは上段に跳び上がって箱の道を調べ、保存から再開して逆光の影絵を進め、客席から見たあとに主舞台で再演しました。 [舞台裏](../../evidence/fon-lyney-magic-broken-wheel.png) [客席](../../evidence/fon-lyney-magic-audience-before.png) [主舞台の再演](../../evidence/fon-lyney-magic-chapter-encore.png) [Lua検証](../../evidence/fon-lyney-magic-lua.json) [Chrome検証](../../evidence/fon-lyney-magic-web.json)

客席から折り鳥を見上げる場面を止め、三つの描画方式を比較しました。Luaの描画指示はPNG表示22件、標準矩形17,690件、軽量16色4,121件でした。軽量16色にすると標準矩形より約77%減り、折り鳥の翼と舞台道具の輪郭を見分けられます。 [PNG表示](../../evidence/fon-lyney-magic-audience-png.png) [軽量16色](../../evidence/fon-lyney-magic-audience-light.png)
