# 成長クエスト Q-G13〜16 のWeb試作

[成長クエストの設計](../quest-v1/GROWTH.md)と[企画追補の70〜77](../../sources/20261116-amendment.md)を基に、モンド・城門広場に挑戦受付を設けた。成長クエスト16件を依頼手帳に接続した。報告は各一回で、ボス・螺旋の通常の挑戦は繰り返せる。

| ID | 達成条件 | 仮報酬 |
| --- | --- | --- |

| Q-G16 | Lv180から、装備の更新・寄り道の発見・ボスの自己記録のうち一つを選び達成 | 20,000モラ、強化鉱石3 |

## 深境螺旋の入門層

一層に「群れの回廊」「上下の交差路」「精鋭の広間」の三戦を置いた。現在の装備・技枠・同行仲間で入り、区画を越えてHP、共通ゲージ、CTを引き継ぐ。区画間にも制限時間が進む。入門180秒・精鋭240秒、星3の目安は入門65秒・精鋭90秒。数値と敵配置は[試作設定](../../content/abyss-settings.json)にまとめた。

報酬セットは入場前に指定する。三戦を突破すると入門650モラと★3聖遺物1個、精鋭2,400モラと★4聖遺物1個。部位は難度ごとにクリア回数で一巡する。バッグが満杯なら拠点の未回収品として取り寄せられる。途中退出・時間切れ・途中セーブからの再開は受付に戻る。クリア済みの成長記録と個人記録は保存する。

## 幽境・週ボスと次の目標

ファルカは既存の通常模擬戦で、突進と低い斬撃の予兆、回復の隙を使う。週ボス一覧は既存4戦の入口とLv、登録済みの自己記録を表示する。勝利記録には最速タイムとそのときの仲間、勝利回数を保存する。Lv180の目標は達成前なら選び直せる。聖遺物は狙うセットで主能力が上がる更新を判定する。寄り道は新しい分岐への到達か隠し入口の発見、ボスは初勝利か最速更新で達成する。

螺旋の追加階層・精鋭固有能力、幽境の残り候補と4難度、週ボスの追加候補・最終周回報酬は後続工程。受付・三戦の背景はラボ用の画像で、本番の3D配置は移植時に行う。
