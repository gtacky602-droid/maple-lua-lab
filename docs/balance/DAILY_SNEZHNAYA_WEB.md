# スネージナヤの日次依頼

Lv140で雪の町へ行き、「日次依頼」を開きます。この町で受注と報酬の受取ができます。ミティヤが同行中なら、観測の依頼は同行中のミティヤから受けます。主依頼一件と追加依頼二件の枠は全地域で共通です。 [日次依頼の設計案](../quest-v1/DAILIES.md) · [日付更新と保存の仕様](DAILY_MONDSTADT_WEB.md)

| 設計ID | 依頼主 | 目標 | 試作の報酬 |
| --- | --- | --- | --- |
| Q-SNE-D01 | バレリー | スネージナヤとノヴォキッチェヴの実戦の敵200体 | 1,840,640 EXP・6,500モラ |
| Q-SNE-D02 | ミティヤ | 郊外の観測路・雪棚の見晴らしの実戦の敵60体 | 552,190 EXP・2,400モラ |
| Q-SNE-D03 | アリョーシャ | 雪原の入口・雪線の切通し・白虹峠の樹林の道の実戦の敵80体 | 736,260 EXP・3,000モラ |
| Q-SNE-D04 | オデット | 凍った街道・郊外の観測路の実戦の敵60体 | 552,190 EXP・2,350モラ |
| Q-SNE-D05 | タルタリヤ | 切通し・観測路・中央の獣道・西の雪囲い跡で指定精鋭3体 | 345,120 EXP・3,300モラ |

郊外の観測路へは、駅脇の観測小屋の中央にある入口から入れます。バレリー・ミティヤ・オデットの依頼を受注していれば、同じ撃破で三件が進みます。精鋭は観測路の霜鎧の敵と切通しの暴走カートです。近づくと名前とHPが表示され、撃破後に復活します。観測路は既存の仮背景と敵のドット絵を使った試作で、対象地点・敵配置・報酬額は試作値です。

タルタリヤの依頼欄で4地点から行き先を選べます。切通しと観測路はLv140、中央の氷壁の獣道と西の雪囲い跡はLv160で開きます。2つの脇部屋には同じ設計種の精鋭が1体ずついます。[2室の討伐加算](../../evidence/sne-domains-terrain-lua.json) · [日次依頼から中央の獣道を表示](../../evidence/snezhnaya-daily-spur-map.json)

## 検証

Luaで全八地域の40候補を設計台帳と照合しました。各候補の開始レベルと受注条件を満たして受注し、配置された敵を倒すと進むことを確認しました。同一プロフィールで八つの受注拠点を移動しても、使用済みの主一件・追加二件の枠が保持されます。 [40候補の照合結果](../../evidence/daily-catalog.json)

Lv140の旅人とアンバーで、雪の町から雪線の切通しに入り、歩行と通常攻撃の入力を自動再生しました。200体の達成はシミュレーション内で136.5秒、雪の町まで戻ると148.0秒でした。途中で一度全滅して戻り、再出発後も討伐数が引き継がれました。この数値はこのルートの一回の計測です。 [Luaの検証結果](../../evidence/daily-sne-lua.json)

Chromeでは郊外の観測路への徒歩移動・通常攻撃・三件の同時加算・報酬受取を確認しました。古いセーブを読み込んでも報酬は重複せず、配置比較で元画像と軽量設定を切り替えられます。 [Chromeの検証結果](../../evidence/daily-sne-web.json)
