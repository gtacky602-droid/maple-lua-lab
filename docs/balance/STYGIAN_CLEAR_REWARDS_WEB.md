# 幽境の勝利報酬とボス戦の検証

幽境の挑戦入口で難易度を選ぶと、勝利ごとのEXP・モラ・聖遺物と、初回分のEXP・モラを確認できる。勝利画面には今回受け取ったEXP、モラ、聖遺物のセットが出る。初回の判定は相手と難易度ごとに独立している。

## ラボのEXP計算

勝利ごとのEXPは、各戦闘の現在の入場Lvを基準にした試作値。通常・ハード・マスター・極限の周回時間を順に3・4・5・6分と置き、通常狩場の想定EXPの90％を使う。狩場の想定討伐数はLv100未満で毎分50体、Lv100から139で55体、Lv140以上で60体。初回追加EXPは、入場Lvで次のレベルまでに必要なEXPの3・4・5・6％。Lv200だけはLv199から200への必要EXPを基準にする。 [周回報酬の設計案](BOSS_FARM_REWARDS_V01.md)

EXPは討伐EXPと基礎EXPに加算し、Lv200では超過EXPに記録する。バッグが満杯でもEXPとモラは受け取り、聖遺物は拠点で回収できる。途中で離脱した試行や時間切れには勝利報酬が入らない。以前のセーブですでに勝利記録がある難易度は、再戦分のEXPを受け取れる。初回分は既存の勝利記録で判定する。

## 確認結果

- 7戦×4難易度で、初回とセーブ再読み込み後の再戦、EXP・モラ・指定セット聖遺物、上位難易度を先に倒した場合を確認した。報酬の全組み合わせは、テストで勝利時の状態を用意して検証した。 [全28組の報酬](../../evidence/stygian-clear-rewards-lua.json)
- Chromeでは北斗の通常を操作してクリアし、挑戦前の初回追加EXP、勝利時のEXP増加、再戦時の初回表示、保存後の記録を確認した。 [Chromeの試走](../../evidence/stygian-clear-rewards-browser.json)
- 通常ボス48系統49戦、週ボス14戦、幽境7戦の個別Luaテストを実行した。各テストの開始位置やHPなどは、検証対象に合わせて設定している。 [戦闘ごとのテスト](../../evidence/boss-roster-lua-audit.json)

週ボスの難易度選択と初回報酬は、週ボスの門で確認できる。 [週ボスの難易度挑戦](WEEKLY_DIFFICULTY_WEB.md)
