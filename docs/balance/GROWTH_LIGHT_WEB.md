# 成長クエスト Q-G09〜12 のWeb試作

[成長クエストの設計](../quest-v1/GROWTH.md)に沿い、既存の光界解放・光界反響・七律開天と高難度分岐を依頼手帳へ接続した。本編では対象レベルと、元素を覚える七地域に到達した記録から技を解放する。章の討伐、光界値50、他の成長クエストの報告を追加条件にしない。

| ID | 受注・報告 | 達成条件 | 仮報酬 |
| --- | --- | --- | --- |
| Q-G09 | Lv160、モンドのアルベド | 共通ゲージ60で光界解放し、強化通常攻撃を当てる | 1,150,000 EXP、10,000モラ、強化鉱石1 |
| Q-G10 | Lv160、モンドのアンバー | 任意の高難度地域で観測地点を調べるか、通常敵を一体倒す | 1,300,000 EXP、12,000モラ、強化鉱石1 |
| Q-G11 | Lv170、雪の町のミティヤ | 光界解放中に対応する直接攻撃・照射を写し、反響を当てる | 1,700,000 EXP、15,000モラ、強化鉱石1 |
| Q-G12 | Lv180、雪の町のミティヤ | 共通ゲージ100を消費して七律開天を放つ | 2,400,000 EXP、20,000モラ、強化鉱石1 |

光界解放・光界反響・七律開天には各依頼の拠点から入れる任意の練習場がある。入場時に練習専用のHP・ゲージ・技枠と無報酬の標的を用意する。開始ゲージは光界解放・反響が55、七律が90で、標的への攻撃でためる。本編の戦闘時間や装備を進めず、課題の達成記録だけを進行に引き継ぐ。途中で保存しても再開先は本編の拠点になる。本編でも同じ技で達成でき、受注前の達成記録も使える。

観測地点は既存の光界障壁を持つ9地域の探索路に置いた。受注後、標識の近くで調べる。高難度へ入るための既存の発見・移動条件はそのまま使う。

## 白虹峠を終えたセーブでの実戦と探索

終着駅のLv160セーブでモンドに戻って二つの依頼を受注し、氷の切通しで `Q` を押して共通ゲージ60を使った。発動中に `J` で通常攻撃を当てるとアルベドに報告できる。発動中は旅人の周りに四つの光が回り、一時停止するとその位置で止まる。

同じ発動中のフレームを比較すると、描画命令は元PNG32件、標準矩形14,083件、軽量16色3,808件だった。軽量16色は標準矩形より73.0%少なく、四つの光の座標と残り時間は全画質で一致した。

アンバーの依頼ではドラゴンスパインの探索路へ歩き、測量台を調べた。Chromeで実戦と観測を別々の操作で達成し、報告して読み直した。報告はアルベドが1,150,000 EXPと10,000モラ、アンバーが1,300,000 EXPと12,000モラで、強化鉱石はそれぞれ1個。 [実戦と観測のChrome検証](../../evidence/earned-light-aurora-browser.json)

報告済みのChromeセーブから氷の切通しでLv165まで狩った。M地図に従って終着駅から切通しを経由し、敵28体の氷棚に入った。氷棚で保存して読み直すと終着駅から再開し、氷棚を訪れた記録と二つの報告は残る。 [Lv165までのLua試走](../../evidence/earned-light-ice-shelf-lua.json) · [入場と保存のChrome検証](../../evidence/earned-light-ice-shelf-browser.json)
