# ナド・クライ「近道、寄り道、月の道」

Lv120で第1話「その宝の話、確かめてみる？」を報告すると、町の広場で第2話（Q-NOD-M02）を始められます。コロンビーナと貯蔵所の札を読み、二つの道を開きます。

- **林の迂回路**は広場の左側から。ラウマに動物が休む場所を聞き、戦闘のない木陰を通って東のトウヒ林へ進みます。追ってくる小型の敵を広場へ引き寄せ、四体を退けると右端から入江へ進めます。
- **海岸旧道**は広場の右側から。フリンズに灯りの合図を聞き、中段へ跳んで留め具の箱から強化鉱2個を取得します。上段へもう一度跳び、灯りの先の右端から入江へ進めます。敵は地上、中段、上段に分かれています。

片方を通れば第2話を進められます。もう一方は報告後も通れ、途中まで退けた敵と開けた箱は保存されます。林のルートを終えてから再訪すると、広場で再び狩りができます。ラウマとフリンズは台詞で案内し、編成中の同行者と戦えます。

入江では爪跡と留め具を調べ、岩棚の上から月明かりが届く瞬間を見ます。箱が動いたら、隣の通行台で安全足場を開きます。右の岩窟口にある小箱で強化鉱3個を受け取ると、町への往復の近道が使えます。初回の報告は13,612,730 EXPと10,600モラです。安全足場と小箱は保存後も元の状態を保ちます。

林と岩窟口にラボ用の仮背景を追加しました。海岸と入江は第1話の浅瀬背景を使用しています。箱の下の脚は短いシルエット演出です。本番の背景は3D配置で制作する方針です。岩窟の奥と大型個体の戦闘は第3話に続きます。 [仮背景の生成記録](../../assets/nod-moon-paths-background-generation-v1.json)

`python -X utf8 test_nod_moon_paths.py` で両経路、保存復帰、報告後の任意探索を検査します。ローカルサーバーを8899で起動して `node test_nod_moon_paths.mjs` を実行すると、Chromeで林経由を確認できます。環境変数 `NOD_PATH=coast` で海岸経由を確認できます。 [Luaの結果](../../evidence/nod-moon-paths-lua.json)

Chromeでは第1話を報告済みのLv120データから、林・海岸をそれぞれ単独で通り、岩窟口への到着、報告、保存からの再開を確認しました。入江で箱の脚が見えた同一フレームでは、PNG52件、標準矩形3,485件、軽量16色926件の描画命令が発生しました。軽量16色は標準より73.4%少なく、箱と脚の演出は同じ形で残ります。 [林の検査](../../evidence/nod-moon-paths-wood-browser.json) · [海岸の検査](../../evidence/nod-moon-paths-coast-browser.json) · [PNG](../../evidence/nod-moon-paths-glimpse-png.png) · [軽量16色](../../evidence/nod-moon-paths-glimpse-light.png)
