# 通常敵・武器・一部のボスのバランス比較版

同じ冒険のJSONを二つのラボで読み込み、狩場へ出て比較できる。比較版の画面上部には調整対象の敵の数と最大HPの範囲を表示する。ランキング集計の対象外で、日次依頼のサーバー側記録は再起動時に初期化される。

```powershell
./Start-Lab.ps1 -Port 9081 -NoOpen
./Start-Lab.ps1 -Port 9084 -DraftBalance -NoOpen
```

各画面で「JSONを読み込んで再開」を選び、同じセーブを読み込む。Lv1から進めたセーブを作る場合は、リポジトリの測定手順を使える。 [獲得セーブの作り方](EQUIPMENT_PROGRESSION_WEB.md)

## 比較版の仮設定

- 既存フィールドの通常敵に、敵Lvで決まるHPを適用する。設定の節目の間は倍率で補間し、個体ごとの元HPの差も残す。装備、同行者、協力人数はHPに影響しない。
- 日次の精鋭、光界障壁のある敵、依頼によって段階的に配置される敵、攻略後に敵が消える依頼マップは既存のHPを使う。通常敵の討伐経験値とモラも既存式を使う。
- アンドリアス、若陀龍王、雷電将軍、呑星の鯨、蝕まれし源焔の主、偽月の異端者の上級・最上級には試作の固定HPを適用する。門で難易度を選ぶと「HP …（比較版）」と表示する。 [週ボスの測定結果](WEEKLY_DIFFICULTY_WEB.md#獲得装備で週ボス14戦と幽境7戦を試す)
- 幽境の北斗は極限にだけ試作の固定HPを適用する。 [解放直後とLv200の比較](../stygian-motion-v1/BEIDOU_WEB.md#獲得装備で極限の待ち方を比較)
- 璃月の報酬剣は未強化でATK16。初期剣を+10にしたATK14を上回る。報告済み依頼から入手判定を復元し、同じアイテムIDと強化段階で比較できる。 [試作設定値](../../content/field-balance-draft.json)

## 測定結果

旅人を敵の50px手前に置き、敵と同行者の動きを止め、通常攻撃を押し続けた。装備と使用できるモラはルート上のセーブを使用した。下の表は試した地点から抜粋している。 [通常版の全9地点](../../evidence/equipment-progression-lua.json) · [比較版の全9地点と月縁の報酬剣](../../evidence/equipment-progression-draft-lua.json)

| Lv | フィールド | 敵HP 通常→比較 | 測定した装備 | 撃破時間 通常→比較 |
| ---: | --- | ---: | --- | ---: |
| 20 | 璃月・岩間の狩場 | 15 → 32 | 旅の初期剣+0 | 0.750秒 → 1.950秒 |
| 40 | 稲妻・海辺の街道 | 15 → 72 | 港の護送剣+0 | 0.617秒 → 1.217秒 |
| 80 | フォンテーヌ・水路沿い | 15 → 182 | 森の観測剣+0 | 0.617秒 → 1.217秒 |
| 120 | ナド・クライ・月明かりの道 | 15 → 3,600 | 聖遺物5部位、初期剣+0 | 0.017秒 → 0.617秒 |
| 160 | 極光谷・氷の切通し | 11 → 4,767 | 聖遺物5部位、白虹峠の剣+0 | 0.017秒 → 0.150秒 |
| 200 | 極地の暁晶原 | 16 → 554,667 | 聖遺物5部位、白虹峠の剣+0 | 0.017秒 → 0.750秒 |

Lv200まで進めたセーブから、比較版で月縁の反射板・照合・歩行晶の戦闘・報告を確認し、月縁の帰路剣を取得した。歩行晶の試験では、ギミック確認用の攻撃を使った。続く暁晶原の測定では、同じ聖遺物で白虹峠の剣+0は0.750秒、月縁の帰路剣+0は0.617秒、+5は0.150秒。+5に使ったモラは120万。 [月縁の依頼試験](../../evidence/moonlit-garden-draft-route.json)

Chromeでは比較版の璃月で配達を報告し、港の護送剣を+1にして保存と再開を確認した。その編成で狩場へ歩いて入り、通常敵を倒した。Luaでは同じ敵を倒すと両版で23 EXPと10モラを受け取り、再出現時もそれぞれのHPになることを確認した。 [Chrome](../../evidence/liyue-m01-browser-draft.json) · [Lua](../../evidence/field-balance-draft-lua.json)

Lv20到達時のセーブで、旅人の聖遺物なしから初期剣を+5に強化し、モンドへ戻って「山脊の見守りⅠ」を2周した。獲得した蒼白の炎の花と羽を装備するとATKが8から82、最大HPが140から236になり、保存から再開して維持された。序盤の狩りでは強い伸び幅なので、報酬剣と両方を使った進行も測る。 [秘境2周の測定](../../evidence/field-balance-draft-lua.json)

Lv120の試験セーブから聖遺物を外し、初期剣に戻した条件では180秒以内に倒せなかった。装備を拾い損ねた場合のナタからLv120までの入手経路は、別の試走で確認した。その冒険は比較版でLv200に到達した。11月20日の全敵設計表との照合、全コンテンツの通し試験、星々の幻境の実機は未検証。 [手持ちが足りない場合のナタの試走](NATLAN_GEAR_RECOVERY_WEB.md) · [Lv200到達の試走](CAP_AND_STOPOVER_WEB.md)

## スネージナヤの通常ボス4戦

比較版の獲得Lv165セーブでは、従来のHPだと4戦とも1ヒットで終わった。4戦に試作の固定HPを設定し、戦闘画面に「比較版HP」と表示する。ブレードガーディアンの回復と不滅の副産物が蘇生の守りで使うHP・回復量は、最大HPに対する割合を保つ。攻撃力、討伐報酬、通行条件はこの設定の対象外。 [従来HPの実測](../../evidence/earned-snezhnaya-bosses-lua.json)

| ボス | 通常版HP | 比較版HP | Lv145〜160での討伐 | Lv165での討伐 |
| --- | ---: | ---: | ---: | ---: |
| フリューゲルレーヴェ | 1,180 | 6,000,000 | Lv145・84.25秒 | 15.37秒 |
| ブレードガーディアン | 1,200 | 5,000,000 | Lv160・64.92秒 | 12.77秒 |
| 不滅の副産物 | 1,260 | 6,500,000 | Lv145・69.87秒 | 15.30秒 |
| 波濤の投錨者 | 1,160 | 6,800,000 | Lv160・87.30秒 | 15.17秒 |

時間は入場から撃破までのLua内の経過。各セーブの獲得装備と同行者を使い、表は通常攻撃と同行AIで測った。別試走ではLv165の装備で、雷の守りと風の球、氷の棺、蘇生の守り6層、飲み物の中断を通して討伐した。4人で入場した場合もソロと同じ最大HPを共有することをLuaで確認した。 [比較版の実測](../../evidence/draft-snezhnaya-boss-hp-lua.json)

短縮技案のポート9101では、フリューゲルレーヴェに雷から風へ移る看板技を追加した。ポート9099と同じLv145・HP600万で、従来84.25秒、短縮案83.60秒。低い風球を二打で壊した試走、横に避けて反撃した試走も確認した。 [フリューゲルレーヴェの比較](../field-boss-v1/SNEZHNAYA_FLUGEL.md#短縮技案をラボで試す)

游雪のブレードガーディアンも同じ二つのラボで比較できる。Lv160・HP500万で、従来64.92秒、短縮案64.97秒。一戦に一度の氷棺から、直接攻撃三打での中断か、三つの氷攻撃を避けたあとの反撃を選べる。 [ブレードガーディアンの比較](../field-boss-v1/SNEZHNAYA_DRIFTING_SNOW.md#短縮技案をラボで試す)

不滅の副産物は同じLv145・HP650万で、従来69.87秒、短縮案89.57秒。三打で開花を中断する短縮案では、従来技で本体が消費していたHPもプレイヤー側が削る。 [不滅の副産物の比較](../field-boss-v1/SNEZHNAYA_IMMORTAL_CONSTRUCT.md#短縮技案をラボで試す)

途中セーブを別の版で開くと、残りHPの割合でその版のHPに換算する。同じ版での復元はHPを維持し、討伐済みの再出現待ちも引き継ぐ。Chromeでは氷の棺発動済みのセーブを通常版の625 / 1,200から比較版の2,604,167 / 5,000,000へ移し、書き出したセーブを通常版で開いて625 / 1,200に戻ることを確認した。 [Chromeの往復記録](../../evidence/draft-snezhnaya-boss-hp-browser.json)

## ナド・クライの通常ボス6戦

Lv120で町に着いたセーブでは、6会場すべてで必要Lv122〜132が地図と門に表示され、入場できなかった。本編を続けて得たLv122〜133のセーブでは、同じ旅人ATK9,314・同行ATK6,652で、従来のHPだと6戦とも1ヒットで終わった。比較版で試作HPを設定し、門から入場して通常攻撃と同行AIで測った。

| ボス | 試走Lv | 比較版HP | 討伐時間 |
| --- | ---: | ---: | ---: |
| ボコボコダック | 122 | 4,250,000 | 67.08秒 |
| 重量級陸巡艦「バトルシップ」 | 128 | 4,500,000 | 60.83秒 |
| 霜夜の空を巡る霊主 | 128 | 4,500,000 | 68.42秒 |
| 昏き魘夢の主 | 128 | 3,100,000 | 85.00秒 |
| 集光の幻月蝶 | 130 | 4,100,000 | 63.42秒 |
| 集光の月ヤモリ | 133 | 4,500,000 | 79.55秒 |

ボコボコダックの補修メカ、魘夢の主の暗黒のシールドと闇の漁師は、比較版で本体HPに合わせて耐久を調整する。熱量や錨の層数は既存値を使う。通常版と比較版で討伐・依頼報告の報酬が一致した。 [ルートを進めて得たセーブと比較結果](../../evidence/draft-nod-boss-hp-lua.json)

個別の試走では補修メカ2機の破壊、炎で過熱させた陸巡艦の冷却中断、氷3回で霊主の薄闇解除、闇の漁師の撃破と暗黒のシールド破壊、幻月蝶の羽の元素切り替えと繭からの脱出、月石の錨の破壊を経て討伐した。霜夜の空を巡る霊主はLv128のセーブでも綾華の氷攻撃3回で薄闇を解除し、撃破から依頼報告と保存復元まで通した。集光の繭は命中時に実際にHPが減ったキャラクターに付く。回避無敵で範囲内に残っても付かず、ChromeではLv130の旅人が水の領域で回復して脱出できた。次期技票の短縮版は、今回の比較版とは別の試作案として扱う。 [Chromeの繭](../../evidence/draft-nod-boss-hp-browser.json)
