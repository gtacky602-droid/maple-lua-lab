# 白虹峠の成長ルート

スネージナヤ編の[企画書](../quest-v1/regions/08_SNEZHNAYA.md)から、雪道の発見、列車、岩棚、白虹の高原をローカルラボに接続した。地形、敵HP、門、台詞は試作。通常狩場は到着後のレベル条件で進める。

| レベル | 狩場 | 入り方 |
|---:|---|---|
| 136 | 冬越えの折返し道 | ナド・クライの町の中央付近 |
| 140 | 雪線の切通し | スネージナヤの凍った街道 |
| 148 | 白虹峠・樹林の道 | 切通しの右端、または雪原の終着駅 |
| 155 | 白虹峠・雪棚の道 | 樹林の道の右端 |

各狩場は二段足場を使い、二画面に計28体を置く。倒した敵は約6秒で再出現する。元の街道と通常狩場の比較は [90秒実測](../../evidence/white-pass-hunts.json) に記録した。既存の凍った街道は12体/分、Lv140の切通しは約61体/分。Lv159の雪棚の道は約53体/分だった。

## 章の進め方

1. 雪の町で「この切符は、冒険行き！」を受注する。切通しの観測器を `G` で使い、標識の前の保線カートを止める。上段の標識までジャンプし、町へ戻って報告する。広場の中央から乗車すると9秒で雪原の終着駅に着く。
2. Lv148で「雪の向こうに、道が続いてる」を受注する。樹林で林の目印、岩棚の印、右端の案内を調べる。岩棚へは通常ジャンプで上がれる。終着駅で報告する。
3. Lv156で「終着駅の、その先へ！」を受注する。雪棚の道から白虹の高原に入り、霜鎧の大角獣を撃退する。高原の奥で白虹を観測し、終着駅で報告する。

ボスは角薙ぎ、前脚叩き、短突進を使う。床に出る範囲から離れるか、低い攻撃はジャンプで回避する。予告の後に胸の継ぎ目が開く間は、通常攻撃を含むダメージに1.25倍の補正がかかる。HP615、再出現待ち60秒は試作値。初回の撃退時に61,667,202 EXP、章の報告時に72,834,160 EXPを一度ずつ受け取る。

「相棒の仕事、見ていくか？」「旅する足取り、踊る雪」「定刻どおりの、ひと休み」も受注できる。メイン3件と今回のサブ3件、ボス初回の固定報酬は計255,211,391 EXP。報告EXPは [既存の校正表](EXPERIENCE_MONSTER_QUEST_V02.json) から読み込む。

## 検証

Lv139から始めた[通し試験](../../evidence/white-pass-pacing.json)では、討伐と6件の報告でLv160に到達した。Lv140→160の戦闘と列車はLua内で5時間56分59秒。仲間の戦闘不能に伴う帰還が2回、未回収品を整理する帰還が1回あった。後者は町の売却と取り寄せで再開した。戦闘が止まったときは画面下の「拠点へ戻って整理」から聖遺物バッグを開ける。

- `python measure_white_pass_hunts.py` で同じ編成と自動戦闘を使い、既存ルートと新規ルートを90秒ずつ比較する。
- `python test_white_pass_chapter.py` でLv140・160の境界、門、乗車、ボスの初回報酬と重複防止、保存を検査する。
- `python test_white_pass_pacing.py` は、Lv139の開始データから自動戦闘と依頼報告でLv160まで進める。位置合わせは試験コードが行い、戦闘、経験値、再出現はLuaの実時間ステップで処理する。
- ラボを起動して `LAB_URL` を指定し、`node test_white_pass_chapter.mjs` でブラウザのキー操作、乗車、報告、保存からの再開を検査する。

背景はラボ用の仮画像で、狩場4地点は同じ雪道画像を使う。効果の連続作画、車窓の動き、章の追加演出、企画書の残りのサブ依頼、本番3Dと実機の性能は未検証。装備整理や通常の歩行を含む人間のプレイ時間も計測が残る。
