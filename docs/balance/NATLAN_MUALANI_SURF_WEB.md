# もう一回！ 水しぶきの寄り道

ナタの旗取りを報告したら、谷の集落でムアラニの依頼を受注します。Gで話を聞き、練習瀬の門を通ります。

1. 左の浜でGを押すと練習ボードに乗れます。左右に進み、Spaceかジャンプボタンで波と輪を越えます。波に当たると直前の浅瀬から続けられます。輪は三つあり、いくつ通っても右の浜まで行けば進みます。
2. 右の浜に着くとコホラ竜がボールを持っていきます。右の門から入り江に入り、Gで返球遊びを始めます。「返球！」と出たらJか返球ボタンを押します。左右に動いてボールに寄れます。取りこぼしたボールはコホラ竜が拾って投げ直します。
3. 一度打ち返したら、その場でもう一回遊ぶか、右の門から集落へ戻って報告できます。ボードと返球は報告後も遊べます。

初回報告は1,404,867 EXP、4,900モラ、集落に飾る「水しぶきの波札」です。ボードの速さ、波の間隔、返球の受付時間とモラは試作値です。ムアラニは台詞で登場し、コホラ竜はオリジナル形状の友好個体として表示します。波の折り返しは夕映えの模擬戦を読む手がかりです。水遊びの成績は本編の進行条件に含めていません。

小物とコホラ竜の仮絵は、オリジナルの形状モデルを複数方向から見て描き起こしました。練習瀬と入り江の背景は本番の3D配置を想定した仮画像です。 [形状モデル](../../evidence/nat-mualani-surf-views.png) · [素材の変換記録](../../evidence/nat-mualani-surf-art.json)

入り江でボールを投げた同じフレームを比較すると、Luaの描画指示は標準矩形4,325件、軽量16色1,242件、PNG表示19件でした。軽量16色では約71%少なく、コホラ竜の青い体とオレンジのボールの輪郭を見分けられます。目と甲羅の陰影は粗くなります。 [PNG表示](../../evidence/nat-mualani-surf-cove-png.png) · [軽量16色](../../evidence/nat-mualani-surf-cove-light.png)
