# 深境螺旋の上層

比較版でLv160以上のセーブを開き、モンド・城門広場の挑戦受付で聖遺物セットを選び、「深境螺旋・上層（比較版）」を押す。上層はソロの試作。各区画を突破したら「次の区画へ」で進む。制限は3区画で合計180秒。星3は48秒以内、星2は80秒以内。報酬の試作値は30万モラと指定セットの★5聖遺物1個（装備Lv184）。

| 区画 | 敵の数 | 立ち回り |
| --- | ---: | --- |
| 二段の前哨 | 16 | 下段を進みながら棚の敵を片づけ、降りて奥の群れを倒す |
| 棚を渡る回廊 | 18 | 左右の棚と下段を移動して群れを分ける |
| 精鋭の関門 | 13 | 通常敵を倒し、物理耐性65%の精鋭2体には元素技を使う |

足場から降りる操作は S を押しながら Space。次の区画へ移ると戦闘中の設置物や残っているマクロ入力を消去する。味方HPと再使用待ち時間は続くため、回復や技を使う順番もタイムに影響する。

白虹峠とLv200までの進行で得た装備を使い、各段へ実際に移動しながら通常攻撃、旋風斬りと地面の衝撃波のマクロ、炎風竜巻、過負荷連爆、回復する水の領域を使った。Lv140の入口拒否、時間切れでの報酬なし、第1区画からの再挑戦、クリア報酬と自己記録の復元を確認。通常版に上層の戦闘は表示されないが、比較版で達成した記録を含む保存データを読み込める。入門・精鋭の既存試作も引き続き利用できる。 [Luaの記録](../../evidence/abyss-upper-lua.json)
