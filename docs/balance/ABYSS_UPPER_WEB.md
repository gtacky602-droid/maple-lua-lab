# 深境螺旋の上層

Lv160以上でモンド・城門広場の挑戦受付を開く。聖遺物セットを選び、「深境螺旋・上層（試作）」を押す。標準版と比較版のどちらでもソロで挑戦できる。各区画を突破したら「次の区画へ」で進む。制限は3区画で合計180秒。星3は48秒以内、星2は80秒以内。報酬の試作値は30万モラと指定セットの★5聖遺物1個（装備Lv184）。

| 区画 | 敵の数 | 立ち回り |
| --- | ---: | --- |
| 二段の前哨 | 16 | 下段を進みながら棚の敵を片づけ、降りて奥の群れを倒す |
| 棚を渡る回廊 | 18 | 左右の棚と下段を移動して群れを分ける |
| 精鋭の関門 | 13 | 通常敵を倒し、物理耐性65%の精鋭2体には元素技を使う |

足場から降りる操作は S を押しながら Space。次の区画へ移ると戦闘中の設置物や残っているマクロ入力を消去する。味方HPと再使用待ち時間は続くため、回復や技を使う順番もタイムに影響する。

## 標準版の獲得セーブでの測定

| Lv | 区画1まで | 区画2まで | 突破 | 星 |
| ---: | ---: | ---: | ---: | ---: |
| 160 | 13.87秒 | 40.28秒 | 57.02秒 | 2 |
| 200 | 6.45秒 | 14.18秒 | 25.52秒 | 3 |

Lv160到達時の装備では第2区画で敗退した。旅人の聖遺物5部位を、同じセーブのバッグにあった品に替えて再挑戦した。Lv200では到達までに使った装備で挑戦した。両方とも足場を移動し、通常攻撃、旋風斬りと地面の衝撃波のマクロ、炎風竜巻、過負荷連爆、回復する水の領域を使った。

Lv140と共闘中は入場できないこと、時間切れ時に報酬を受け取れないこと、第1区画から再挑戦できることをLuaで確認した。報酬と自己記録は標準版の保存から再開し、比較版にも引き継いだ。 [Luaの記録](../../evidence/abyss-upper-lua.json)

標準版を配信したChromeではLv140の受付表示とLv200の入場、第1区画の突破、第2区画への移動と拠点への帰還を確認した。上層の敵HP、報酬、星の基準時間は試作値。長時間の周回バランスと星々の幻境への移植は未検証。 [Chromeの記録](../../evidence/abyss-upper-browser.json)
