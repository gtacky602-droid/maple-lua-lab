# 試作品、思い切り使ってみて

ナタの高台か水辺の挑戦を一つ終えると、谷の集落で受注できます。Gでシロネンと話し、近くの門から試作工房へ進みます。

1. 工房の高い型と低い型にそれぞれGで乗り、Spaceか画面のジャンプボタンで跳ね上がりを試します。設計台の画面で、二つの実測値を見比べられます。
2. 設計台で「高い段差」「低い天井」「横に離れた足場」に使う型を選びます。三か所を選ぶと、その組み合わせの最速記録を確定前に確認できます。選択中に保存した場合も、工房に戻ると選択が残っています。配置を確定したら右の門へ進みます。
3. 試走路の入口でGを押し、色のついた踏み台の上でジャンプして右の足場へ進みます。画面に今の区間と復帰回数が出ます。低い天井に当たったり、対岸に届かなかったりしたら直前の踏み台へ戻ります。Gで試走を中断し、工房で組み替えられます。
4. 三か所を通って最後の旗に着いたら、右の門から集落へ戻って報告します。報告後も場内を走れます。最速記録は踏み台の配置ごとに残ります。

高い段差には高い型、低い天井には低い型が向いています。三つ目はどちらでも通過でき、低い型を使う場合は踏み台の右寄りで跳ぶと届きます。初回報告は2,325,046 EXPと5,900モラです。モラと跳ぶ高さ、コース寸法は試作値です。シロネンは台詞で登場します。

二つの踏み台、天井の緩衝材、設計台、旗、計測器は、オリジナルの形状モデルを三方向から確認して描き起こしました。工房と試走路の背景は本番の3D配置を想定した仮画像です。 [設備の3D形状](../../evidence/nat-xilonen-course-views.png) · [素材の変換記録](../../evidence/nat-xilonen-course-art.json)

低い天井の前で同じフレームを比較すると、Luaの描画指示は標準矩形6,679件、軽量16色1,557件、PNG表示23件でした。軽量16色では標準矩形から約77%減り、踏み台の高さと色、天井の緩衝材は見分けられます。細い金属の反射などは簡略化されます。幻境実機での描画性能は未検証です。 [PNG表示](../../evidence/nat-xilonen-course-course-png.png) · [軽量16色](../../evidence/nat-xilonen-course-course-light.png)
