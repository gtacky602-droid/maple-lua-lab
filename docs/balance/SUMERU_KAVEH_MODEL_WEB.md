# 模型の中では、大冒険

Lv60でスメール第2話「森の上にも、森がある」を報告すると、樹陰の広場でカーヴェの依頼（Q-SUM-S04）を受けられます。模型工房の机のそばで G を押して話を聞き、もう一度押すと拡大した模型が開きます。 [企画書](../quest-v1/regions/04_SUMERU.md#q-sum-s04-模型の中では大冒険)

- 模型の移動ボタンで駒を隣の場所へ進め、入口・棚・席・窓を巡ります。棚、机、窓はそれぞれの場所で候補を切り替えられます。
- 高い棚を窓の前に置くと眺めが遮られます。窓の下に低い棚だけを置くと、収納が4枠になり、必要な6枠に届きません。高い棚を壁沿いに移し、低い棚を窓の下に置くと、収納が8枠になって景色も見えます。 [窓を塞ぐ配置](../../evidence/sum-kaveh-room-blocked.png)
- 机を窓に向けた場合は、外開きの窓にすると戸が机に当たりません。通路の横に机を置く場合は内開きも選べます。 [戸が机に当たる配置](../../evidence/sum-kaveh-room-clearance.png)
- 四か所を巡り、三つの条件がそろうと「この配置を記録する」を押せます。閉じたり途中で保存したりしても、駒の位置と選んだ部品は残ります。 [確定できる模型](../../evidence/sum-kaveh-room-layout.png)

広場で報告すると293,808 EXPと試作値の2,450モラを一度受け取れます。依頼とスメール第3話を両方報告したあと、空の観測所の右の門から閲覧室に入れます。報告する順番はどちらでも構いません。選んだ棚、机の向き、窓が置かれ、G で調べられます。 [完成した閲覧室](../../evidence/sum-kaveh-room-room-png.png)

家具と模型台は自作3Dモデルを三方向から確認してドット絵にしました。カーヴェは台詞で登場し、模型の読者は木の駒で表現しています。収納枠と家具の間隔はラボの試作値です。背景画像2枚はラボ用で、本番は3Dで配置する方針です。 [家具のモデル](../../evidence/sum-kaveh-room-views.png) · [素材の記録](../../evidence/sum-kaveh-room-art.json)

完成した閲覧室の同一フレームでは、Luaの描画命令がPNG表示で17件、標準矩形で18,144件、軽量16色で4,393件でした。軽量16色で矩形命令は約76％減りました。棚・机・窓の輪郭は判別でき、本の背表紙や窓枠の彫り模様は粗くなります。 [PNG表示](../../evidence/sum-kaveh-room-room-png.png) · [軽量16色](../../evidence/sum-kaveh-room-room-light.png)

`python server.py --port 8919` でラボを起動し、`python -X utf8 test_sumeru_kaveh_model.py`、`node test_sumeru_kaveh_model.mjs` の順で実行すると、模型の条件判定、保存復元、閲覧室への配置を検証できます。 [Lua](../../evidence/sum-kaveh-room-lua.json) · [Chrome](../../evidence/sum-kaveh-room-browser.json)
