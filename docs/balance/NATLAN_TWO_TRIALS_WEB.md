# ナタの高台と水辺の試練

Lv100で旗取りの依頼を報告すると、谷の集落で「得意な道だけじゃ、もったいない！」（Q-NAT-M02）を受けられます。頂上に戻って分岐札を読み、上の門から高台へ、地上の門から水辺へ進みます。高台と水辺の途中経過は個別に保存され、好きな順で進められます。

- **高台**は低い棚と高い棚の標的を調べ、地上・中段・高段の三体を退けます。奥の岩棚で高台の達成印を受け取ります。
- **水辺**は岸で止まった浮き台に通常ジャンプで乗ります。浮き台は乗ったキャラを運び、対岸にも停まります。最初の岸の三体、次の岸の二体を退け、折り返しの水の跡を見て水辺の達成印を受け取ります。二つ目の瀬は途中まで岩棚を渡り、最後だけ浮き台に乗る経路も使えます。
- 二つの印が揃うと頂上から夕映え会場の控え広場へ進めます。三つ目の印を受け取り、上段で「旅人 対 ムアラニ」の対戦札を読みます。報告で4,363,734 EXP、7,300モラ、強化鉱5を一度受け取れます。

落水時はHPを失わず近い岸へ戻ります。戦闘途中に保存しても、その枝で退けた敵は依頼の途中では復活しません。報告後は高台・水辺の狩場と会場への近道を使えます。狩場では練習用の敵が再び出現します。キィニチとムアラニは台詞と水の跡の演出で案内します。対戦は次の依頼の制作範囲です。
