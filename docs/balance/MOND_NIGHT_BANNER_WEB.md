# 断罪の皇女と、夜の大怪鳥

モンド第2話「看板の向こうに、何がある？」を報告すると、城門広場でフィッシュルとオズの依頼（Q-MON-S04）を受けられます。二人から話を聞き、月影の風見丘の門を通ります。丘に入った時点で夜の場面が始まります。

- 石垣に映る影、石段の風、地上の黒い布を順に G で調べます。石段には Space で上がれます。
- 古い幟に絡んでいた風スライム3体が現れます。2体は地上近く、1体は奥の石段の上で浮き沈みします。石段に上がって通常攻撃を当てられます。
- 地上で幟を回収し、奥の足場で修繕して立て直します。城門広場で報告すると、丘の幟のそばで二人の調査記録を読めます。

途中で帰還しても、調べた痕跡と討伐済みの個体は記録されます。初回報告で967 EXP、試作値の170モラと強化鉱3個を受け取ります。幟と調査記録は保存して再開したあとも残ります。

幟と風スライムは自作モデルを三方向から見てドット絵にしました。敵HPと浮遊の高さ・周期はラボ内で比較するための試作設定です。夜景はラボ用の仮背景で、本番は3D配置の方針です。 [形状モデル](../../evidence/mond-night-banner-views.png) · [素材の記録](../../evidence/mond-night-banner-art.json)

影を見つける同一フレームでは、PNG描画が16命令、標準の矩形描画が5,909命令、軽量16色が1,503命令でした。軽量16色では標準の矩形描画より約75％少なく、布のひだは簡略になりますが、左右に張った影の輪郭は読み取れます。 [PNG表示](../../evidence/mond-night-banner-shadow-png.png) · [軽量16色](../../evidence/mond-night-banner-shadow-light.png) · [修繕した幟](../../evidence/mond-night-banner-repaired.png)
