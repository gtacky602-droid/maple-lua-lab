# スメールの葉橋と空の観測所

スメール広場でLv60から本編の三つの依頼を順に受けられます。門のそばで `F`、記録台や操作盤のそばで `G` を使います。移動は `A`・`D`、ジャンプは `Space` です。

| 依頼 | 進め方 | 初回報告の報酬 |
| --- | --- | --- |
| Q-SUM-M01 地図には、道があるんだけど？ | 川辺の地図台を調べ、幹の上で葉を見上げる。操作盤で葉を開き、対岸に渡る。地上と上段の敵を退け、地図に高さを記録する。 | 437,849 EXP、1,600モラ、強化鉱2 |
| Q-SUM-M02 森の上にも、森がある | 上段の操作盤で葉を開いて種羽根を回す。地上の根道と樹上の枝道を歩き、中継所で合流を確認する。点検後は昇降台で往復できる。 | 526,257 EXP、2,200モラ、強化鉱3 |
| Q-SUM-M03 空の観測所へ！ | 大枝の地上と上段の敵を退け、枝傘の大キノコンがいる止まり台を通る。観測所の記録台で地図を完成させる。 | 1,033,165 EXP、3,800モラ、強化鉱4 |

葉の橋と固定した足場はセーブして再開しても使えます。観測所に入るとHPが回復します。報告後は広場から観測所へ戻り、完成した地図を読めます。ルートの高低と合流点は、地点を調べると表示する側面図で確認します。

## 仮素材と描画比較

河畔と樹冠にラボ用の仮背景画像を用意しました。本番は3D配置で背景を作る方針です。枝傘の大キノコンは、傘と葉をオリジナルのモデルで組み、正面と斜め二方向からの画像をドット絵の参照にしました。[参照画像](../../evidence/canopy-fungus-views.png) · [素材記録](../../evidence/canopy-fungus-art.json)

止まり台で `P` を押し、描画方式をPNG、標準矩形、軽量16色に切り替えると、同じフレームを比較できます。素材単体の矩形数は標準3,393件、軽量16色1,120件です。Chromeで止まり台を停止したときの描画命令数はPNG28件、標準矩形7,641件、軽量16色2,191件でした。[PNG](../../evidence/sumeru-canopy-fungus-png.png) · [軽量16色](../../evidence/sumeru-canopy-fungus-light.png)

キノコンは表示と撃破後の門を検証する仮個体です。技、連続アニメーション、本番の台詞と配役は今後の制作範囲です。
