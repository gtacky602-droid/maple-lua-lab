# 武器と聖遺物の地域別試算

Lv1からのルートで獲得した9つのセーブを使い、現行ラボで武器の入手と強化が旅人の攻撃力にどう効くか測った。お試し配布の装備は使わず、各セーブにあるモラ、報告済み依頼、装備中の聖遺物を使用した。武器の強化と付け替えは町で通常の操作を実行した。 [測定コード](../../measure_equipment_progression.py) · [全測定結果](../../evidence/equipment-progression-lua.json)

撃破時間は旅人を敵の50px手前に置き、仲間と敵の動きを止め、通常攻撃を押し続けたときのLua内時間。0.017秒は最初の1フレームで倒れたことを示す。道中の移動、敵の挙動、精鋭戦、ボスの無敵時間を含むプレイ時間は、この測定の範囲外。

- Lv20〜80のセーブで旅人の聖遺物は0枠だった。初期剣+10は1,650モラでATK14になり、Lv80の森の観測剣+5と同じ値になる。Lv20に到着した時点で6,120モラを持っていたため、Lv20から初期剣の最大強化が可能だった。
- Lv120では、道中の聖遺物5部位で初期剣時のATKが4から1,244になった。水路の配達剣+5に替えると1,261。今回の敵はどちらも一撃だった。
- Lv160の白虹峠の剣は+0でATK1,537、+5で1,816。Lv200では同じ強化でATK141,986から142,301に上がった。後半の武器差を調べるには一撃で終わらない相手が必要。
- 今回の本編ルートでは、ナタの古壁と月縁の寄り道の固定武器は未取得だった。両方とも個別シナリオで依頼を報告して入手を確認している。 [古壁の調査剣](../../evidence/natlan-cliff-trials-lua.json) · [月縁の帰路剣](../../evidence/moonlit-garden-lua.json)

再測定する場合は、リポジトリ直下で `python test_cap_fresh_route.py --replay` を実行してLv1からのセーブを作り、`python measure_equipment_progression.py` を実行する。集計には入力セーブのSHA-256を含む。
