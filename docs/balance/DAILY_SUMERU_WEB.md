# スメールの日次依頼

Lv60でスメールの樹陰の広場へ行き、「日次依頼」を開きます。受注と報酬の受取はこの広場で行います。放浪者が同行している場合は、同行中の放浪者から精鋭の依頼を受けます。受注枠は全地域で主依頼一件・追加依頼二件です。 [日次依頼の設計案](../quest-v1/DAILIES.md) · [日付更新と保存の仕様](DAILY_MONDSTADT_WEB.md)

| 設計ID | 依頼主 | 目標 | 試作の報酬 |
| --- | --- | --- | --- |
| Q-SUM-D01 | ティナリ | スメール・トゥニギの黒淵の実戦の敵200体 | 63,920 EXP・1,860モラ |
| Q-SUM-D02 | コレイ | 雨林の道・工房の資材置き場・葉橋の向こう岸の実戦の敵80体 | 25,570 EXP・760モラ |
| Q-SUM-D03 | 放浪者 | 指定精鋭3体（計11地点） | 11,990 EXP・800モラ |
| Q-SUM-D04 | カーヴェ | 工房の資材置き場の実戦の敵60体 | 19,180 EXP・640モラ |
| Q-SUM-D05 | ナヒーダ | 雨林の道のキノコン・水スライム・炎スライムを各1種 | 9,590 EXP・410モラ |

ナヒーダの依頼を受けたら、雨林の道で生きている対象に近づいて `G` または「観察する」を押します。対象の撃破でも同じ種類を記録できます。観察と撃破は一つの記録にまとまり、日次依頼の欄で各種類の記録状況を確認できます。途中でセーブを読み直した場合も、記録した種類が残ります。

工房の資材置き場は雨林の道の左側から入れます。既存の模型工房とは別の試作狩場で、背景にはスメールの共用仮画像を使っています。Lv60からは雨林の道の大キノコンと、資材置き場の牙獣が対象です。Lv80になると雨林4室と砂漠5室でも、入口の奥にいる指定精鋭を討伐数に加えられます。手前の狩場にいる通常の敵は討伐数に含みません。受注後、依頼欄の「討伐・調査地点」から行き先を選ぶと、その場所をM地図で確認できます。 [9室での討伐と報酬受取](../../evidence/sumeru-daily-spur-elites.json) · [依頼から王墓の地図を開く](../../evidence/sumeru-daily-spur-map.json)

Luaで5件すべてを達成し、不正な観察記録の読み込み拒否と翌日の報酬受取を確認しました。Chromeでは `G` による観察、通常の攻撃による記録、資材置き場への移動と戦闘、報酬の重複防止を確認しました。対象地点・配置・報酬額は試作値です。通常操作で200体を倒す所要時間は未計測です。 [Luaの検証結果](../../evidence/daily-sum-lua.json) · [Chromeの検証結果](../../evidence/daily-sum-web.json)
