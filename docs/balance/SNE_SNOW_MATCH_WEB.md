# 今日は、雪玉で勝負しよう

スネージナヤの「雪の向こうに、道が続いてる」を報告すると、雪原の終着駅でタルタリヤの依頼（Q-SNE-S05）を受けられます。駅で誘いを聞き、右寄りの門から雪合戦広場へ。合図台で一度目の G はルール確認、二度目の G で開始です。

- A・D か矢印で移動、Space でジャンプ、J で雪玉を投げます。雪壁は雪玉を止めます。岩棚に上がると、壁越しに高い旗を狙えます。
- 相手や旗への命中で1点です。旗は両者で一つにつき一度だけ得点できます。試作ルールでは先に5点、または36秒で決着します。広場では通常技が使えません。試合中は操作キャラクターが固定されます。
- 相手が視線を向けたときの黄色の予告はフェイントです。腕を上げたあとの白い点線で実際の狙いが分かります。17秒経過かどちらかが3点取ると雪壁が崩れ、地上から投げ合えます。
- 飛んでいる雪玉は旅人側が水色、タルタリヤ側が橙色の軌跡です。相手や旗に当たると命中した位置に「+1」が出ます。

初回は勝ち・負け・引き分けのどれでも報告でき、結果に合わせて台詞が変わります。初回報告は27,085,203 EXPと試作値12,600モラです。報告後は合図台で再戦でき、前回の点数、勝敗、最高得点が残ります。途中退出・読込では、終わっていない試合を記録せず、合図台から新しく始められます。

雪壁、崩れた雪塊、旗は自作の形状モデルを三方向から確認してドット絵にしました。タルタリヤは既存ラボの待機絵を使い、予告の着色と雪玉の位置で動きを示します。広場の背景はラボ用の仮画像です。本番では3D配置を使う方針です。 [形状モデル](../../evidence/sne-snow-match-views.png) · [画像と変換の記録](../../evidence/sne-snow-match-art.json)

予告中の同じ場面では、1フレームの描画命令はPNGで37件、標準の矩形描画で13,978件、軽量16色で3,560件でした。軽量16色は標準の矩形描画より約75％少なくなります。キャラクターの服や髪の細部は簡略になりますが、雪壁の輪郭、旗、黄色の予告線は判別できます。 [PNG表示](../../evidence/sne-snow-match-feint-png.png) · [軽量16色](../../evidence/sne-snow-match-feint-light.png) · [雪壁が崩れたあとの広場](../../evidence/sne-snow-match-open.png)

`python -X utf8 test_sne_snow_match.py` で雪壁と命中の判定、勝敗に共通の報酬、再戦記録を確認できます。サーバーを8909で起動して `node test_sne_snow_match.mjs` を実行すると、Chromeで受注から対戦、報告、保存後の再戦まで確認できます。 [Luaの結果](../../evidence/sne-snow-match-lua.json) · [Chromeの結果](../../evidence/sne-snow-match-browser.json)

白虹峠の剣を装備したLv149セーブから、Chromeで壁越しの旗と雪壁が崩れたあとの命中を確認し、5対2で勝ちました。フェイントの同じフレームで標準矩形は13,591命令、軽量16色は3,497命令で、74.3%減りました。途中でやめた再戦は勝敗に加わらず、Lv153で待合室の依頼を報告したあとも勝数1、最高5点の記録が残りました。 [獲得セーブからの雪合戦](../../evidence/earned-white-pass-snow-browser.json) · [待合室の保存後の記録](../../evidence/earned-white-pass-rest-browser.json)
