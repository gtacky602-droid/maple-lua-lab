# 沈玉の谷の茶葉配達

璃月の北の入口から沈玉の谷の入口拠点へ向かいます。拠点の右側に茶畑の段丘道があります。展望亭と茶畑の地形はラボ独自の仮案です。茶亭の背景はラボ用の画像で、本番は3D配置を想定しています。

| 設計ID | 依頼と受注場所 | Lv | 初回報告（EXP / モラ / 強化鉱石） |
| --- | --- | ---: | ---: |
| Q-B02-01 | 茶葉より速く、帰り道（入口拠点） | 82 | 122,000 / 2,100 / 2 |
| Q-B02-02 | 雲の上にも、置き場所を（入口拠点） | 88 | 191,000 / 2,800 / 3 |
| Q-B02-03 | 一杯ぶんの、大冒険（谷を望む茶亭） | 95 | 55,165 / 290,472 / 4 |

1. 段丘道で地上、上段、奥の地上の三つの目印を順に読みます。奥の上段から登り道を抜けるか、地上から荷車道を回り、茶亭の荷受け台へ茶葉を届けます。帰りは茶亭の左の地上門から荷車道に入り、車輪跡を記録して拠点へ報告します。茶葉を運ぶ間も、いつも通りの速度で走ったり跳んだりできます。
2. 昇降台で上向きの試験位置に合わせ、中央の乗り口から高い台へ上がります。着地を確かめたら地上に降り、方向盤を横向きにします。台が右側の中段に移るので、通常ジャンプで乗って茶亭横へ渡ります。茶亭の上段で台を固定すると、同じ高さの門から拠点へ戻れます。切り替えた後の足場は保存されます。
3. 茶亭で依頼を受け、右の門から段丘の岩陰へ出ます。苔衣の踏石獣を遠ざけて茶亭に戻り、小さな器に茶を分け、一服して報告します。茶席の器と記録は再訪時にも表示されます。

既存の探索路はLv20から使えます。Lv82に達したら、配達を受ける前でも茶畑の段丘道から茶亭へ行けます。地上の荷車道を使う往路もあります。

## 苔衣の踏石獣

「谷を走る岩脈」は左か右に直線の予告を出します。ボスと自分の間に岩があれば、攻撃範囲は手前の岩までで止まります。「近場の石払い」は本体の両側を攻撃するため、予告の外へ離れて避けます。攻撃後は光界障壁8が外れ、1.24倍の反撃時間になります。光界0でもこの間に通常攻撃が通ります。戦闘数値と報酬は試作値です。通常討伐報酬は討伐時に入り、表の初回分は報告時に一度だけ受け取れます。
