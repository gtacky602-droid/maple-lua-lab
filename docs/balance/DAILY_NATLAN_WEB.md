# ナタの日次依頼

Lv100でナタの谷の集落へ行き、「日次依頼」を開きます。この集落で受注と報酬の受取ができます。カチーナが同行中の場合は、同行中のカチーナから岩場の見回りを受けます。受注枠は全地域で主依頼一件・追加依頼二件です。 [日次依頼の設計案](../quest-v1/DAILIES.md) · [日付更新と保存の仕様](DAILY_MONDSTADT_WEB.md)

| 設計ID | 依頼主 | 目標 | 試作の報酬 |
| --- | --- | --- | --- |
| Q-NAT-D01 | イアンサ | ナタ・オシカ・ナタの実戦の敵200体 | 339,840 EXP・3,850モラ |
| Q-NAT-D02 | カチーナ | 岩場の道・赤岩の採掘路の実戦の敵80体 | 135,940 EXP・1,640モラ |
| Q-NAT-D03 | ムアラニ | 川沿いの浅瀬道の陸上の敵60体 | 101,950 EXP・1,320モラ |
| Q-NAT-D04 | キィニチ | 岩場の道・赤岩の採掘路・川沿いの浅瀬道の指定精鋭3体 | 63,720 EXP・1,880モラ |
| Q-NAT-D05 | シロネン | 赤岩の採掘路の実戦の敵60体 | 110,450 EXP・1,460モラ |

川沿いの浅瀬道は谷の集落の左側、赤岩の採掘路は岩場の道の中ほどから入れます。浅瀬道の戦闘は陸上で行います。キィニチの対象は岩場の遺跡機兵、採掘路の牙獣、浅瀬道の帆殻の魔物です。近づくと名前とHPが表示され、倒した精鋭は復活します。

二つの狩場は試作です。既存の岩場・川辺の仮背景と敵のドット絵を流用し、配置と報酬に試作値を使っています。配置比較画面では、同じ敵配置を元画像と軽量設定で見比べられます。

Luaで5件の必要数、対象範囲、精鋭の復活を確認しました。Chromeでは二つの狩場への徒歩移動と通常攻撃、採掘路の三つの依頼への同時加算、報酬受取、古いセーブでの重複受取防止を確認しました。通常操作で200体を倒す所要時間は未計測です。 [Luaの検証結果](../../evidence/daily-nat-lua.json) · [Chromeの検証結果](../../evidence/daily-nat-web.json)
