# ナド・クライ「宝箱には、脚がある！」

Lv120で第2話「近道、寄り道、月の道」を報告すると、ナド・クライの町の広場で第3話（Q-NOD-M03）を受けられます。右の近道で岩窟口へ移動し、コロンビーナと箱の引きずり跡を調べると月殻の広間が開きます。

## 月殻の大ヤドカニ

広間の奥へ進むと大ヤドカニが横歩きで近づきます。殻がある間の正面補正は0.62で、背面側からは通常どおり攻撃が通ります。ハサミは正面の低い帯、箱は予告時にいた位置へ落ちます。通過方向と距離を見て、反対側や上段へ移動できます。箱が落ちる範囲に上段も入る場合は、横へ避けます。

HP半分で殻が割れ、水晶を露出した姿に変わります。水晶の光は床のひし形で予告し、近い部分から遠い部分へ時間差で当たります。上の岩棚や帯の外から攻撃できます。アンバー同行でも殻は割れます。HP228、移動速度、予告時間とダメージはラボの試作値です。対戦中の保存からはHPと殻の状態を復元し、攻撃の進行は再開後に組み直します。

## 貯蔵所と報酬

初めて大ヤドカニを退けると章の21,294,130 EXPを獲得し、右の貯蔵所が開きます。石板のそばにある宝箱から強化鉱8個、14,500モラ、月模様の記念札と、Lv140の★4育成品を一つ受け取れます。左の札で攻撃力の剣闘士の羽、右の札でHPの劇団の花を選べます。

バッグが満杯なら、石板を読んだあとに町へ戻る近道から空きを作ってください。空きを作って戻ると、選択と素材をまとめて一度だけ受け取れます。ネフェルへの報告は25,032,225 EXPです。報告後は広間に戻って約60秒間隔の再出現で狩りができ、討伐や石板の再読で章報酬や宝箱の中身は増えません。

## 美術と検証

共闘では広間のHP・殻・攻撃を共有します。入口の調査と貯蔵所での報酬選択は各自の進行に沿って行います。 [部屋の作り方と報酬条件](../COOP_WEB_PREVIEW.md#月殻の大ヤドカニ)

大ヤドカニは自作の形状モデルを正面と前後の斜めから確認し、殻がある姿と水晶が露出した姿のドット絵を作りました。箱が外れた後は絵の高さを122から99に下げ、足元と胴体の横幅をそろえています。専用の連続作画と装備差の調整は制作中です。背景はラボの仮画像で、本番は3D配置で制作する方針です。 [形状モデル](../../evidence/moon-crab-views.png) · [素材の変換と透過検査](../../evidence/moon-crab-art.json)

反射光の予告中に同じフレームを停止し、PNG72件、標準矩形8,713件、軽量16色2,269件の描画命令を計測しました。軽量16色は標準矩形比で74.0%減です。水晶、ハサミ、床のひし形の輪郭が残り、殻や金具の細かな陰影が簡略化されます。 [PNG](../../evidence/nod-moon-vault-cracked-png.png) · [軽量16色](../../evidence/nod-moon-vault-cracked-light.png) · [宝箱受領後](../../evidence/nod-moon-vault-cache.png)
