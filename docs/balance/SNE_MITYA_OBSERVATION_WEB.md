# 休憩のためなら、ひと工夫

スネージナヤの雪の町（Lv140）から「駅脇の観測小屋」に入ります。ミティヤに会い、依頼手帳から受注して作業机の前で G を押すと始まります。本編の切符を受け取る前にも進められます。

1. 広場の屋根下と広場端で、一か所ずつ見通しと安定を測ります。右の門から雪棚へ進み、魔物を二体退けて岩棚を二段登ります。高所は遠くまで見えますが、風で観測器の針がぶれます。
2. 高所の右端から一段下り、風裏の段差を調べます。観測器のそばで G を押すたびに、直置き、脚を長く伸ばす、段差と留め具を使う、の順に設置を切り替えられます。下の表示で見通しと安定の両方が3/3になったら「この設置で確定する」を押します。条件が足りないと、その理由が表示されて選び直せます。
3. 毛布の腰掛けで休むと、ミティヤが遠い岩の向こうの反応に気づきます。右の近道から観測小屋に戻り、報告します。依頼手帳の「ミティヤを同行に選ぶ」で、旅人と共通のレベルで編成できます。近道から戻ると、固定した観測器と記録を見返せます。

初回報告は10,267,605 EXPと、試作値として9,200モラです。初期装備の試作は「観測用の入門法器」で攻撃力+1、「雪見の入門の花」で花を未装備のときHP+10です。旧加入依頼を受注済みの保存データでは、元の依頼を報告して同行に選べます。ラボの町にある試用ボタンも引き続き使えます。

ミティヤは既存の低頭身待機絵を使っています。観測器、留め具、毛布は自作の形状モデルを三方向から確認してドット絵にしました。小屋と雪棚の風景はラボ用の仮画像です。本番では3D配置を使う方針です。 [形状の比較](../../evidence/sne-survey-views.png) · [画像と変換の記録](../../evidence/sne-survey-art.json)

固定後の観測台の同じフレームでは、描画命令はPNG41件、標準矩形7,360件、軽量16色1,952件でした。標準矩形より73.5%少なく、ミティヤの髪と外套、観測器の輪郭は残ります。留め具や毛布の細かな陰影は簡略化されます。 [PNG表示](../../evidence/sne-survey-fixed-png.png) · [軽量16色](../../evidence/sne-survey-fixed-light.png) · [二か所の測定値](../../evidence/sne-survey-yard.png) · [安定が不足する試行](../../evidence/sne-survey-unstable.png)

`python -X utf8 test_sne_mitya_observation.py` で三つの観測結果、設置途中の保存、報告と編成、旧依頼の互換性を確認できます。サーバーを8908で起動して `node test_sne_mitya_observation.mjs` を実行すると、Chromeで受注から報告後の再訪までを確認できます。 [Luaの結果](../../evidence/sne-survey-lua.json) · [Chromeの結果](../../evidence/sne-survey-browser.json)

終着駅に着いたLv142のセーブから巡回まで試す場合は、`test_snez_fresh_route.py --footprints-source` にセーブを渡します。ラボ起動後に `LAB_MITYA_CHECKPOINT` に同じセーブを指定してブラウザー検査を実行すると、保存した設置方法の再開と、Lv145の足跡の依頼も確認できます。 [雪線の巡回路](WHITE_PASS_PROGRESSION_WEB.md#ミティヤとトゥガリンの足跡)
