# フォンテーヌの月飾りと旧搬入口

Lv80でフォンテーヌの水辺の広場から「お届け先は、どちらですか？」（Q-FON-M01）を受けます。門の近くで `F`、調査地点で `G`、移動は `A` と `D`、ジャンプは `Space` です。

1. 荷受け窓口と停車場で、受取札の印、乾いた荷覆い、旧式の搬送時刻を調べます。照合台で行先を切り替え、「記録を照合する」を押します。
2. 停車場で搬送メカのベルを鳴らし、出発を待って右へ追います。離れるとメカが止まり、近づくと再び進みます。旧搬入口に着くと扉が開きます。
3. 回廊の地上と上段で警備メカを止め、吊り場の上段で月飾りを調べます。右端から広場へ戻って報告すると、1,329,885 EXP、3,100モラ、強化鉱3と吊り場への近道を一度受け取れます。

セーブ後は広場から再開します。追跡の途中ならベルからやり直せます。開いた扉、退けた警備メカ、発見した月飾りの記録は保存されます。報告後も吊り場で搬送記録を読めます。

搬送メカはオリジナルの形状モデルを横と斜め二方向で確認し、荷箱、大小の車輪、青緑のランプをドット絵にしました。`P` で止め、PNG、標準矩形、軽量16色を切り替えて比較できます。素材単体は標準3,162矩形、軽量834矩形です。警備メカはラボの既存整備カートの外見と通常挙動を使用しています。荷受け場と劇場裏は仮背景画像です。本番は3D配置で作る方針です。[参照モデルの三方向](../../evidence/parcel-meka-views.png) · [素材記録](../../evidence/parcel-meka-art.json)

同じ時刻の停車場で記録した描画命令数は、PNG51件、標準矩形6,645件、軽量16色1,758件でした。実機での速度は別途測定します。[PNG版](../../evidence/fontaine-delivery-cart-png.png) · [軽量16色版](../../evidence/fontaine-delivery-cart-light.png)

この区間は月飾りを探す最初の依頼です。続く舞台下の作業場と大舞台機関、ベルや拍手の音は制作途中です。
