# 荒瀧天下一・本気の三番勝負！

稲妻第2話「くぐって、戻って、もう一度？」を報告すると、城下の広場で一斗の依頼（Q-INA-S04）を受けられます。競技札で案内を聞き、競技広場の合図台を G で調べます。

1. **旗集め**。地上と二段の足場にある旗5本に触れます。高台の旗は、低い石段からもう一度 Space で跳ぶと届きます。
2. **訓練的**。地上と石段に並ぶ的6個を、J の通常攻撃や既存技で壊します。複数に同時に当てられます。的の破壊は競技の得点に入り、討伐数や討伐報酬には入りません。
3. **子どもの応援競走**。旅人組と一斗組がそれぞれのレーンで進みます。子どもが応援印で止まるたびに、旅人が近くで G を押して先へ送り出します。最初に三つ目まで応援するか、時間切れ時点で得点の多い組が勝ちます。

三種目を終えると勝敗に応じた表彰になり、初回報告ではどの結果でも106,600 EXPと試作値1,550モラを受け取れます。三種目すべてに勝った記録があると、競技広場に称号「荒瀧三番勝負・全勝」が表示されます。報告後は合図台から再戦できます。途中で帰ると、初回は終えた種目まで、再戦では前回の完走記録までが残ります。

旗、的、合図台、景品と二人の走者は自作モデルを三方向から見てドット絵にしました。走者は約3頭身を目安にして、走る一枚絵を移動に合わせて上下させています。一斗は台詞と一斗組の得点で参加します。競技時間、的のHP、一斗組の速度は試作値です。背景はラボの仮画像で、本番は3D配置の方針です。 [形状モデル](../../evidence/ina-itto-games-views.png) · [素材の記録](../../evidence/ina-itto-games-art.json)

応援競走の同一フレームで、描画命令はPNGが26件、標準の矩形描画が5,492件、軽量16色が1,415件でした。軽量16色は標準の矩形描画より約74％少なく、髪と衣装の細部が粗くなります。二人の組の色と、応援を待つ位置は見分けられます。 [PNG表示](../../evidence/ina-itto-games-relay-png.png) · [軽量16色](../../evidence/ina-itto-games-relay-light.png) · [表彰](../../evidence/ina-itto-games-awards.png)
