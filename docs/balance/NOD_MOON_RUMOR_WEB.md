# 月を盗んだ旅人？

ナド・クライで第2話「近道、寄り道、月の道」を報告すると、町の広場から「噂の波止場」へ入れます。ネフェルの依頼（Q-NOD-S03）を受け、入り口の情報帳で G を押すと聞き込みが始まります。

1. 舟守、配達人、絵描きの順に話を聞きます。挿絵は、手のひらに載る小石から、水面に浮かぶ月のような石、手を伸ばして取った月へと変わります。聞いた話は同じ人のそばで読み返せます。
2. 右の門から「月映しの再現台」へ進みます。G で反射板を回し、「現物の石」を選びます。画面下の案内に沿って消灯し、灰色の石を確かめます。同じ向きで点灯すると、月明かりを受けた石の縁が光ります。再点灯した状態で「照合する」を押します。
3. 波止場の右側で「小さな月」「波止場のひと光り」「小石が旅した話」から題名を一つ選び、依頼手帳から報告します。報告後は入り口の掲示と到着港の旅日誌から冒険談を読み返せます。再現台にも戻れます。

受注は第2話に合わせてLv120からです。初回報告で5,637,939 EXPと、試作値として情報料5,400モラを受け取ります。

三人の待機絵は、低頭身スタイルガイドの旅人B案の比率を参照して作った波止場の住人です。ネフェルは会話で登場します。背景は夜店と浅瀬の画像を仮に使っています。本番では3D配置を使う方針です。 [スタイルガイド](../../DESIGN_MAPLE_CHIBI_STYLE_GUIDE_V01.md) · [挿絵と待機絵の変換記録](../../evidence/nod-rumor-art.json)

住人三人と三枚の挿絵が見える同一フレームの描画命令は、PNGが29件、標準矩形が17,073件、軽量16色が4,139件でした。軽量16色は標準矩形より75.8%少なく、帽子・封筒・絵の月は見分けられます。小石の青みや衣装の細かな陰影は薄れます。 [PNG](../../evidence/nod-moon-rumor-png.png) · [軽量16色](../../evidence/nod-moon-rumor-light.png) · [消灯](../../evidence/nod-moon-rumor-stone-dark.png) · [点灯](../../evidence/nod-moon-rumor-stone-light.png) · [掲示](../../evidence/nod-moon-rumor-posted.png)

照合前に保存すると、反射板は選んだ向きで再開します。再開時は点灯するので、改めて同じ向きで消灯・点灯して照合します。

アイノの工房を終えたLv129セーブでは、反射板が「現物の石」を向いた状態を復元し、消灯・点灯をやり直して報告しました。選んだ「小石が旅した話」は波止場の掲示と到着港の旅日誌の両方に残っています。聞き込みを終えた同じフレームの描画命令は、元PNG23件、標準矩形18,155件、軽量16色4,511件でした。軽量16色は標準より75.2%少ない描画命令です。 [Lv129からの通し検証](../../evidence/earned-nod-moon-rumor-browser.json)
