# 月を盗んだ旅人？

ナド・クライで第2話「近道、寄り道、月の道」を報告すると、町の広場から「噂の波止場」へ入れます。ネフェルの依頼（Q-NOD-S03）を受け、入り口の情報帳で G を押すと聞き込みが始まります。

1. 舟守、配達人、絵描きの順に話を聞きます。挿絵は、手のひらに載る小石から、水面に浮かぶ月のような石、手を伸ばして取った月へと変わります。聞いた話は同じ人のそばで読み返せます。
2. 右の門から「月映しの再現台」へ進みます。G で反射板を回し、「現物の石」を選びます。画面下のボタンで消灯と点灯を切り替え、灰色の石が月明かりを受けたときだけ縁を光らせることを見比べます。再点灯した状態で「照合する」を押します。
3. 波止場の右側で「小さな月」「波止場のひと光り」「小石が旅した話」から題名を一つ選び、依頼手帳から報告します。報告後は入り口の掲示から冒険談を読み返せます。再現台にも戻れます。

受注は第2話に合わせてLv120からです。初回報告で5,637,939 EXPと、試作値として情報料5,400モラを受け取ります。

三人の待機絵は、低頭身スタイルガイドの旅人B案の比率を参照して作った波止場の住人です。ネフェルは会話で登場します。背景は夜店と浅瀬の画像を仮に使っています。本番では3D配置を使う方針です。 [スタイルガイド](../../DESIGN_MAPLE_CHIBI_STYLE_GUIDE_V01.md) · [挿絵と待機絵の変換記録](../../evidence/nod-rumor-art.json)
