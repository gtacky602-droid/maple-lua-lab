# ナド・クライ特別地域「月映りの庭」（仮）

ナド・クライの到着港から月明かりの道へ出て、中央の門から特別地域の入口拠点へ進みます。拠点の右側に「照り返しの波打ち際」への入口があります。「月映りの庭」は企画書の演出仮称です。舞台は湖畔のラボ独自案で、背景は既存の仮画像を使います。本番の背景は3D配置を想定しています。

| 設計ID | 依頼と受注場所 | レベル | 初回報告（EXP / モラ） |
| --- | --- | ---: | ---: |
| Q-B08-01 | 水面に続く、もう一つの道（入口拠点） | 188 | 15,000,000 / 6,400 |
| Q-B08-02 | 月の光を、しまう箱（入口拠点） | 192 | 21,000,000 / 8,700 |
| Q-B08-03 | 帰り道にも、月はある（町の広場） | 195 | 14,095,746 / 853,650 |

1. 波打ち際の反射板は地上、中央の石棚、右の地上の3か所にあります。そばで `G` を押すたび照射先が変わります。刻線のある結晶を全部照らすと、右端にジャンプで乗れる足場が現れ、足場の門から庭へ進めます。庭で帰路の目印をつけて入口拠点へ報告します。
2. 庭の記録箱を `G` で回し、消灯すると刻線、点灯すると今の照射像を確認できます。二つを見比べて「照合する」を押し、三つの像を順番に記録します。庭の奥で受光台を調べると、上段に入口拠点へ戻る近道が開きます。照射済みの結晶と照合済みの順番は保存されます。操作中の角度と点灯状態は、再入場すると初期位置に戻ります。
3. 町の広場で最後の依頼を受け、庭の右端から外周へ進みます。歩行晶を退けて右奥の高台を調べると、その先の地上の門から広場へ戻れます。

## 玻璃根の歩行晶

ゲーム内では足元に一本線がある方が本体です。反射像には二本に分かれた線があり、反射像の位置に攻撃しても本体に当たりません。地面の予告が出た範囲から離れ、反射が消えたら反撃できます。被ダメージが増える反撃時間の倍率は1.25倍です。ボスのHP、予告時間、報酬は調整用の試作値です。光界40は表示上の目安で、既定の編成の通常攻撃で攻略できます。

討伐では通常の経験値とモラが入り、表の初回報酬は依頼の報告時に一度だけ受け取れます。滞在途中から再開した場合は拠点に戻り、進めた依頼と倒したボスの状態は保存に残ります。
