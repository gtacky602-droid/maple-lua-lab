# 集合写真は、まだ撮れない！

フォンテーヌ第1話を報告すると、水辺の広場でナヴィアの依頼を受けられます。広場の左寄りの門から、並木の写真広場へ行きます。

1. 荷受け係の箱を荷置き場へ運び、菓子屋の札を仕分け、整備士がカメラに時限装置を付ける間は台を支えます。
2. カメラの構図を開きます。椅子を左側へ動かすか、台を高くすると、荷受け係と菓子屋の顔が両方見えます。調整中の配置も冒険の保存に含まれます。
3. 旅人でタイマーを巻き、右の白い目印でシャッターを待ちます。遅れた場合は、カメラに戻って同じ構図で撮り直せます。
4. 広場の掲示板で、仕事仲間の記念写真と菓子を囲む休憩写真を見比べます。飾りたい一枚を選び、水辺の広場に戻って報告します。報告後は写真広場の掲示板で選んだ一枚を読み返せます。

どちらを選んでも初回報告は799,743 EXPと3,600モラです。モラと4.6秒の撮影タイマーは試作値です。写真はLuaで確定した配置と表情差分から組み立てる固定構図です。

水路で働く三人は新規のキャラクターです。普段の姿と、菓子を囲むときの表情を作りました。撮影道具も含め、形状を正面・斜め前・斜め後ろから参照してドット絵を起こしています。ナヴィアは台詞で登場します。写真広場の背景は本番の3D配置を想定した仮画像です。 [三人の形状資料](../../evidence/fon-navia-people-views.png) [撮影道具の形状資料](../../evidence/fon-navia-photo-views.png)

写真広場の同じフレームでは、Lua の描画指示は PNG 24件、標準矩形16,929件、軽量16色4,311件でした。軽量16色は標準矩形に比べて約75%少なく、三人の輪郭や服の色を見分けられます。 [PNG表示](../../evidence/fon-navia-photo-terrace-png.png) [軽量16色](../../evidence/fon-navia-photo-terrace-light.png)

Luaでは失敗後の撮り直し、ポーズ中のタイマー停止、両方の掲示結果と同じ報酬を検証しました。Chromeでは配置の復元、390px幅の写真選択、歩いてタイマー撮影、再開後の掲示を通しました。 [二枚を見比べる場面](../../evidence/fon-navia-photo-selection.png) [掲示した一枚](../../evidence/fon-navia-photo-posted.png) [Lua試験](../../evidence/fon-navia-photo-lua.json) [Chrome試験](../../evidence/fon-navia-photo-web.json)
