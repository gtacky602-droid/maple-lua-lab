# Lv160〜180の狩り場とドーンマンポートの寄り道

雪原の終着駅の右寄りからLv160の門へ入る。極光谷と湯気谷は、通常狩りでLv165、170、175に上がると次の門を通れる。各マップには横二画面と上下の足場があり、通常敵28体が約6秒で再出現する。

| Lv | 狩り場 | 編成 |
| ---: | --- | --- |
| 160 | 極光谷・氷の切通し | 雪殻の小型敵 |
| 165 | 極光谷・氷棚 | 雪殻の小型敵 |
| 170 | 湯気谷・温泉水路 | 雪殻の小型敵と帆殻の運搬機 |
| 175 | 湯気谷・鉱泉段丘 | 雪殻の小型敵と帆殻の運搬機 |

## ドーンマンポートで受ける3件

ドーンマンポートの入口拠点はモンド南の街道から行ける。新しい探索区画の門はレベルで開き、依頼の受注順は報告で進む。設計IDは [高難度分岐の企画](../quest-v1/HIGH_DIFFICULTY.md) の Q-B06-01〜03 に対応する。

1. **帰ってきた旅人の、新しい港（Lv160）**。入口拠点の右側から潮風の見晴らし道へ。海側、荷場側、岬側の台にジャンプで上がり、各地点を `G` で調べる。
2. **向かい風でも、届けます（Lv168）**。合図旗の渡り廊下には入口拠点の地上の門と、見晴らし道の右端にある昇降台の両方から入れる。旗を渡し、右側の上段で見え方を確かめて報告する。
3. **大団長の、寄り道採点（Lv175）**。渡り廊下の右端から潮風の機関室に入り、稜風の帆塔機を倒す。奥の通行確認を済ませてから港に帰る。

渡り廊下と機関室で共闘の部屋を作れる。通行の確認と報告は、依頼を受けた人が自分で進める。 [共闘の攻撃判定と報酬](../COOP_WEB_PREVIEW.md#鉱殻除雪機と稜風の帆塔機)

帆塔機は床を走る横風と、予告位置に吹く縦風を交互に使う。横風はジャンプ、縦風は横へ移動して避けられる。排気口が開くと約2.8〜3秒だけ障壁が消え、光界の検証値0でも通常攻撃が通る。光界値30は障壁に対する目安。検証値はラボの手動比較設定で、装備からの加算は今後の接続対象。

最終報告は1回限りで **5,312,539 EXPと741,600モラ**。Lv175の候補値を [ボス報酬の試算](BOSS_FARM_REWARDS_V01.md) から使用した。討伐そのものでは通常のフィールドボスEXPが入る。調査と配達の報告は6,500,000・9,250,000 EXPの仮値で、3件の固定報酬合計は21,062,539 EXP。

## 検証

Lv160からLv180までは、初回報酬と日課なしで30,423体を倒し、戦闘時間はLua内で10時間6分59秒だった。狩り以外の歩行と荷物整理にかかる時間は計測していない。Lv175で同じ編成の90秒を比べると、従来の雪棚の道は2,933,191 EXP、新しい鉱泉段丘は11,204,338 EXP。 [通し試験と90秒比較](../../evidence/endgame-160-180.json)

- `python test_endgame_160_180.py` はLv160から通常狩りのみでLv180まで進める。経験値、復活、攻撃をLuaで処理し、門への位置合わせには試験コードを使う。未回収品の取り寄せと売却は通常の操作を使う。
- `python test_windward_branch.py` はレベル条件、徒歩と昇降台、障壁と排気口、初回払い出しと再開を検証する。
- `node test_windward_branch.mjs` はChrome上で3件を通しで操作する。帆塔機が停止した同じ場面をPNG、標準矩形、軽量16色で比較できる。
- `python test_earned_branch_quests.py` は獲得Lv180の比較版セーブから、見晴らし台3か所、配達途中の保存復元、見晴らし道からの昇降機、実戦での帆塔機討伐、報告と再出現待ちの復元を確認する。3件の報告で合計21,062,539 EXPと752,600モラを受け取った。 [獲得セーブの試走](../../evidence/earned-branch-quests-lua.json)

狩り場と港の背景は四枚の仮画像を使用。敵の密度、HPと報酬は試験値。Lv180以降、全分岐の固定報酬配分と連続アニメーション、実機の3Dと性能は今後の検証対象。
