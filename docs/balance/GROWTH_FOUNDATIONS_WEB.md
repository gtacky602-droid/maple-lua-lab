## 聖遺物バッグの試算

拠点で聖遺物バッグを開きます。「教材で装備を比較」「教材で強化を試算」「教材で継承を試算」は手持ちが空でも使えます。教材の品はバッグや売却・強化の対象に入りません。手持ちの品は、各行の「装備と比較」「強化を試算」から、メイン能力、セット、サブ能力、強化後の能力や費用を確認できます。

実際に継承するときは同じ部位の二品を選び、「選んだ品で継承を試算」を押します。表示で結果を確かめ、「継承を確定して元の品を消費」を押したときに実行します。継承元は未装備でロック解除済みの品を使い、継承先もロック解除します。継承先の上限を超える組み合わせや、現在の強化値・星数を下げる組み合わせは選べません。継承先のアイテムLv・レア度・セット・通常のメインとサブ能力は保持し、強化値と刻印の星数を移します。

手数料は通常強化と刻印の規定累計費の60%を試作値にしています。たとえば★5 +20・刻印5星の継承は198万モラです。試算だけでQ-G04を報告できます。比較・強化・継承の表示は、このラボの聖遺物の数値モデルを使っています。 [継承に関する本人方針と比較値](../../sources/20261116-amendment.md)

Luaで手動攻撃の遅延命中とAI攻撃を区別できること、装備教材による消費がないこと、旧セーブ・報告・継承の再実行を確認しました。Chromeでは四件の報告、手持ちの二品の継承と読戻、モバイル幅での試算表示を確認しました。 [Lua試験](../../evidence/growth-foundations-lua.json) · [Chrome試験](../../evidence/growth-foundations-web.json)
