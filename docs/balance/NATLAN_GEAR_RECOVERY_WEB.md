# ナタの装備案内とLv100〜120の試走

ナタ・谷の集落で、旅人の花か羽が空いていると案内が出る。バッグに候補があれば「手持ちから旅人の空き枠を埋める」で装備する。既に装備した部位の更新は聖遺物バッグで行う。このボタンが使うのは、他のキャラが装備していない品のうち、該当部位の主能力が最も高い品。売却、強化、モラ消費は伴わない。 [Chromeの確認](../../evidence/natlan-gear-guide-browser.json) · [Luaの枠・同行者の確認](../../evidence/field-balance-draft-lua.json)

不足する部位がバッグにない場合は「モンドへ戻って秘境への道順を見る」を使う。モンド城から地図に南の街道、国境の道、石門の岩棚、山脊の見守りへの経路が表示される。秘境の報酬は難度ごとに花、羽、時計、杯、冠の順で巡る。 [スマートフォン幅の地図](../../evidence/natlan-gear-recovery-atlas-mobile.png) · [秘境の難度と報酬](../ARTIFACT_DOMAINS_WEB.md)

## 試走の条件

Lv1から進めた冒険がナタに着いた時点のセーブを使った。片方はバッグにあった花と羽を装備し、もう片方は試験用コピーの聖遺物を取り除いて、拾い損ねた場合を再現した。どちらも前地域で得た水路の配達剣を持ち、ナタの3章とカチーナ・ムアラニ・キィニチの依頼を、門の移動と通常の操作で進めた。狩場の周回にはゲームの自動戦闘を使った。

装備なしの場合、Lv110の赤土棚で75秒間の自動戦闘を試したときは討伐できなかった。山脊の見守りⅡを2周し、蒼白の炎の花と羽を装備してから再開した。「壁に刻まれた道しるべ」はLv110で受注でき、上段へ上がるにはLv112が必要。先に赤土棚でLv112に上げ、滝裏の刻印から上段へ進んで報告すると、古壁の調査剣を入手できる。

赤土棚と東谷の岩棚で拾った上位装備は、Lv119で集落へ戻ったときに更新した。試作比較版で更新せずに東の秘境周辺へ入ったときは、旅人が戦闘不能となり、操作が同行者に移ったあとも自動戦闘が続いていた。初期の聖遺物で進む場合は、出発前に旅人の回復と、バッグにある花・羽を確認する。

## ナド・クライ到着までの比較

| 条件 | 道中装備の更新 | 回復での帰還 | Lv120の町へ着くまでのLua内時間 |
| --- | --- | ---: | ---: |
| 到着時に手持ちの花と羽を装備 | Lv110・119 | 0回 | 1時間24分38秒 |
| 空のバッグから秘境Ⅱで花と羽を入手 | Lv110・112・115・119 | 34回 | 1時間53分37秒 |
| 同じ立て直しから、道中装備の更新を遅らせる | Lv110・119 | 65回 | 2時間20分30秒 |

3条件とも東の秘境周辺を経てLv120になり、90秒の船便でナド・クライへ到着した。全滅は0回。保存から出航港・到着先への再開を確認し、到着後の初回依頼を受注した。荷物整理だけの帰還は表の回復回数に含めていない。実際に人が遊ぶ所要時間は未計測。 [持ち込み](../../evidence/natlan-fresh-route-draft-carried.json) · [早めの更新](../../evidence/natlan-fresh-route-draft-empty.json) · [遅めの更新](../../evidence/natlan-fresh-route-draft-empty-late-refresh.json)

立て直し条件では、秘境で花と羽を取ると旅人ATKが65から155に上がった。さらに古壁の調査剣で160から538、Lv115で獲得品を付け直すと664から3,900になった。装備は実際に獲得した品を使用した。3条件は同じ入力セーブのSHA-256を記録している。
