# 稲妻の日次依頼

Lv40で稲妻の城下の広場に着いたら「日次依頼」を開きます。この広場で受注と報酬の受取ができます。綾華が同行中なら、主依頼は同行中の綾華から受けます。主依頼一件と追加依頼二件の枠は、モンド・璃月・稲妻で共通です。 [日次依頼の設計案](../quest-v1/DAILIES.md) · [日付更新と保存の仕様](DAILY_MONDSTADT_WEB.md)

| 設計ID | 依頼主 | 目標 | 試作の報酬 |
| --- | --- | --- | --- |
| Q-INA-D01 | 神里綾華 | 稲妻・淵下宮の実戦の敵200体 | 17,600 EXP・1,100モラ |
| Q-INA-D02 | 宵宮 | 潮風の浜・海辺の街道の実戦の敵80体 | 7,040 EXP・480モラ |
| Q-INA-D03 | 早柚 | 潮風の浜・灯隠れの小径の実戦の敵60体 | 5,280 EXP・390モラ |
| Q-INA-D04 | 荒瀧一斗 | 計9地点の指定精鋭から3体 | 3,300 EXP・520モラ |
| Q-INA-D05 | 鹿野院平蔵 | 海辺の街道・潮風の浜の野伏60体 | 5,940 EXP・410モラ |

潮風の浜は城下の広場の左側から入れる狩場です。浜の右端は海辺の街道につながります。どちらの入口もLv40から使えます。精鋭の野伏に近づくと、名前とHPが表示されます。倒した野伏は復活するため、どちらか一方の精鋭だけでも一斗の目標を達成できます。野伏の撃破は、対象条件が重なる複数の依頼に一回ずつ加算されます。

一斗の依頼は、離れ小島のLv58の精鋭部屋と、荒海・影向山・白狐側・たたら砂・ヤシオリ・鳴神の征討入口のLv60の精鋭部屋でも進みます。受注欄の「討伐・調査地点」で行き先を選ぶと、その場所をM地図で確認できます。ヤシオリでは地上の遺跡殲滅者が対象で、上段の希少遭遇にいる聖骸獣を倒しても件数は増えません。7室での通常攻撃による討伐、途中セーブの復元、報酬の重複防止を確認しました。[7室の討伐結果](../../evidence/inazuma-daily-spur-elites.json) · [依頼欄から荒海の地図を開く](../../evidence/inazuma-daily-spur-map.json)

潮風の浜は今回追加した試作の狩場で、背景は既存の潮見の岬の仮画像を使っています。狩場で「この地点の配置比較を開く」を選ぶと、同じ敵配置を元画像と軽量設定で見比べられます。報酬額と対象地点は試作値です。

Luaで全五候補の達成と精鋭の復活を確認しました。Chromeでは徒歩移動、攻撃、精鋭の表示、報酬受取、古いセーブの読み込み、配置比較を確認しました。通常操作で200体を倒す所要時間は未計測です。 [Luaの検証結果](../../evidence/daily-ina-lua.json) · [Chromeの検証結果](../../evidence/daily-ina-web.json)
