# 花見の席が、埋まっています

ナド・クライで第1話「その宝の話、確かめてみる？」を報告すると、町の広場から「花見の入口」へ入れます。ラウマの依頼（Q-NOD-S04）を受け、入口の花札で G を押します。

1. 右の門から花見道の外周へ進み、スライム三体を退けます。奥の門を抜けると、動物が先に来ている静かな観賞区画に着きます。
2. 手前で花びらを拾い、岩棚へ跳んで紫の実を拾います。岩棚の左端から下り、前列席の手前でラウマと話します。ウサギとキツネは前列に座ったままです。
3. さっきの岩棚に跳び直し、その右端からもう一段登ります。同行者も岩棚を登ります。上の見晴らし席で G を押すと、月花が約0.8秒かけて開き、上から見た絵が現れます。絵の中央に金色のしべが見えます。
4. 上段の奥で、拾った花びらと紫の実を使って花飾りを掛けます。右の門から入口へ戻り、依頼手帳で報告します。報告後は入口の近道から見晴らし席へ戻れます。花飾りのそばで G を押すと、同行者を含めて体力が回復します。

入口は第1話に合わせてLv120です。初回報告で7,253,017 EXPと、試作値として6,800モラを受け取ります。花見に時刻の条件はありません。開花後のセーブから見晴らし席に戻ると、開いた花をそのまま観賞できます。花飾りを作るための回収は一度で済み、見晴らし席で何度でも休めます。

月花は自作の3Dモデルを側面・斜め・上面から参照し、つぼみ、開いた花、上からの見え方を描き分けました。動物と花飾りも今回のドット絵です。ラウマは会話で登場します。庭は新しい仮背景、入口と外周は既存の林の仮画像です。本番は3Dで背景を配置する方針です。 [月花の形状モデル](../../evidence/nod-moon-bloom-views.png) · [画像と描画形式の記録](../../evidence/nod-moon-bloom-art.json)

見晴らし席の同じフレームでは、描画命令はPNGが37件、標準矩形が8,797件、軽量16色が2,214件でした。軽量16色で標準矩形より74.8%少なく、月花の形と二匹の動物の輪郭は残ります。花びらの筋や毛並みの細かな陰影は簡略化されます。 [PNG](../../evidence/nod-moon-bloom-view-png.png) · [軽量16色](../../evidence/nod-moon-bloom-view-light.png) · [開花前](../../evidence/nod-moon-bloom-closed.png) · [報告後の再訪](../../evidence/nod-moon-bloom-revisit.png)

波止場を終えたLv129セーブでも、コロンビーナと二段の岩棚を登り、月花の開花と花飾りの設置を確認しました。開花中は一時停止でき、報告後に近道で戻ると開いた花と花飾りが見えます。Lv130で以前の報告済み92件と所持品80点、コロンビーナの同行を確認しました。この試走の同一フレームは元PNG31件、標準矩形9,570件、軽量16色2,538件で、標準矩形より73.5%少ない描画命令です。 [Lv129からの通し検証](../../evidence/earned-nod-moon-bloom-browser.json)

`python -X utf8 test_nod_moon_bloom.py` で外周の途中保存、二段のジャンプ、開花の一時停止、花飾りの保存と休憩を確認できます。ローカルサーバーを8906で起動して `node test_nod_moon_bloom.mjs` を実行すると、Chromeで受注から観賞・報告後の再訪までを確認できます。波止場から続ける場合は `LAB_MOON_BLOOM_CHECKPOINT` にセーブを、`LAB_MOON_BLOOM_OUTPUT` に出力先の接頭辞を指定します。 [Luaの結果](../../evidence/nod-moon-bloom-lua.json) · [Chromeの結果](../../evidence/nod-moon-bloom-browser.json)
