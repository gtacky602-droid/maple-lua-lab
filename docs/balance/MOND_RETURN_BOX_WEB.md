# 返却箱の小さな逃亡者

「配達は、スライム待ち！」を報告すると、城門広場でリサの依頼（Q-MON-S02）を受けられます。返却台で事情を聞き、右の門から図書館裏の果樹道へ入ります。

1. 青緑の栞、石段に跳ねた泥、倒れた草の順に G で調べます。泥を調べるときは Space で石段に上がります。
2. 箱は奥へ跳ね、距離が開くと止まります。果樹道の奥まで追うと水スライム3体が飛び出します。通常攻撃で進められます。
3. 3体を倒したあと、箱の上の本を G で回収します。西の門から広場へ戻り、リサに報告します。

追跡の途中で引き返しても手がかりは記録され、箱を追い直せます。戦いが始まったあとは倒したスライムを記録します。報告時は固定の290 EXP、試作値の130モラと強化鉱2個を一度だけ受け取ります。保存して読み込んだあとも、城門広場の返却台で短い魔物観察記録を読めます。

箱・栞・泥・草は、自作モデルを正面・斜め前・斜め後ろから確認してドット絵にしました。水スライムは既存絵です。箱が進む距離、速度、敵HPは試作値です。果樹道はラボ用の仮背景を使い、本番は3D配置の方針です。 [形状モデル](../../evidence/mond-return-box-views.png) · [画像の出典と変換](../../evidence/mond-return-box-art.json)

同じ追跡場面の1フレームで、描画命令はPNGが17件、標準の矩形描画が5,337件、軽量16色が1,333件でした。軽量16色では標準の矩形描画より約75％減り、金具や衣装の輪郭の細部が粗くなります。青緑のふたとその下の水スライムは見分けられます。 [PNG表示](../../evidence/mond-return-box-chase-png.png) · [軽量16色](../../evidence/mond-return-box-chase-light.png)

サーバーを8910で起動し、`python -X utf8 test_mond_return_box.py`、`node test_mond_return_box.mjs` の順に実行すると、手がかりの順序、途中退出、戦闘、報酬、保存後の観察記録を再検査できます。 [Lua](../../evidence/mond-return-box-lua.json) · [Chrome](../../evidence/mond-return-box-browser.json)
