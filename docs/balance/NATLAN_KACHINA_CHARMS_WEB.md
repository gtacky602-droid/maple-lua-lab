# 並べてみよう、冒険のしるし

Lv100でナタの谷の集落に着いたら、依頼一覧からカチーナの加入依頼を受注できます。集落の作業台でGを押して相談し、右手の門でFを押して彩石の採集路へ進みます。

1. 谷底で青緑の小片を拾います。次の採集点ではカチーナが岩棚へ上がる間、旅人が谷底に出てきた魔物二体を倒します。
2. 岩棚の先でカチーナから紫の小片を受け取ります。右の大岩の下でジャンプを長押しして足場に乗り、琥珀色の小片を拾います。登り方は大岩の手前とM地図の依頼地点で確認できます。三色とも採集の進行に沿って手に入ります。
3. 右端の門から集落に戻ります。作業台で中央に置く色と並びを選び、旅人用とカチーナ用を仕上げます。仕上げ前に保存した場合も、次回作業台を開くと選択が戻ります。
4. 依頼一覧で報告してカチーナを同行に選びます。完成した飾りは作業台でもう一度見られます。

どの組み合わせでも、報告の報酬は1,319,124 EXP、4,800モラ、カチーナの加入と初期装備です。モラと初期装備の名称・数値は試作値です。カチーナの表示は既存の低頭身スプライトを使用しています。作業台、大岩、飾りの台と三色の小片は、オリジナルの3D形状を3方向から確認して描き起こしました。採集路の背景は、本番で3D配置にする想定の仮画像です。 [カチーナの参照記録](../../evidence/kachina-reference-audit.json) [小物の3D形状](../../evidence/nat-kachina-charms-views.png) [素材の変換記録](../../evidence/nat-kachina-charms-art.json)

採集路の同じフレームで、Luaの描画指示は標準矩形14,696件、軽量16色4,196件、PNG表示33件でした。軽量16色は標準矩形比で約71%少なく、岩棚のカチーナ、谷底の魔物、小片の色を見分けられます。幻境実機での性能は未検証です。 [PNG表示](../../evidence/nat-kachina-charms-trail-png.png) [軽量16色](../../evidence/nat-kachina-charms-trail-light.png)

Luaで討伐途中の再開、見た目の異なる三通りの同一報酬、旧カチーナ加入依頼の保存互換性を検証しました。Chromeでは通常攻撃とジャンプで採集を進め、幅390pxの作業台、飾りの下書きの保存・復元、加入後の展示まで確認しました。 [作業台](../../evidence/nat-kachina-charms-workshop.png) [完成展示](../../evidence/nat-kachina-charms-exhibit.png) [Lua検証](../../evidence/nat-kachina-charms-lua.json) [Chrome検証](../../evidence/nat-kachina-charms-web.json)

夕映えの対戦を報告したLv109のセーブから、魔物を一体倒して保存し、再開後に残り一体を倒しました。紫を中央にした横一列の石飾りは、下書きと完成展示の両方で復元できました。カチーナを同行に入れて保存し、再読み込み後の初期装備と以前の報告済み80件を照合しました。 [Lv109の通し検証](../../evidence/earned-natlan-kachina-charms-browser.json)
