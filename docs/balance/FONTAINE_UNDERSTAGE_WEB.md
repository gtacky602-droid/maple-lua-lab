# フォンテーヌの舞台下と別稽古場

Lv80で月飾りの依頼（Q-FON-M01）を報告したあと、水辺の広場で「客席の下は、大忙し！」（Q-FON-M02）を受けます。門は `F`、調査と選択肢の切り替えは `G`、ジャンプは `Space` です。

1. 月飾りの吊り場から舞台裏へ進みます。送り綱で海の書き割りを横に動かし、引き幕を上げます。出てきた階段を二段登ると、上下に往復できる昇降台があります。
2. 作業床では、波板を立てて射出口を遮ります。予告灯のあと、飛び道具が板に当たることを確認できます。波板の西側から跳んで上段へ回り、上段と地上の警備メカを止めると射出口も止まります。
3. 保管室で荷札、行先板、受領記録を照合します。返送分を錨印の現行配送に切り替えると、別稽古場に入れます。安全を確認して広場へ報告すると、1,921,946 EXP、3,900モラ、強化鉱4と別稽古場への近道を一度受け取れます。

上げた幕の階段、立てた波板、退けた警備メカ、返送の記録は保存されます。保管室から保存した場合は、保管室で再開します。報告後は別稽古場で配送記録を読み返せます。

## 仮素材と比較

作業床と稽古場はラボ用の仮背景画像です。本番は3D配置で作る方針です。波板は、板の輪郭と木の支えをオリジナル形状モデルで三方向から確認してからドット絵にしました。素材単体の矩形は標準3,391件、軽量16色790件です。作業床で `P` を押し、描画方式を切り替えて同時刻の見た目を比較できます。警備メカは既存の整備カートの外見と通常挙動を使用しています。[形状参照](../../evidence/stage-wave-views.png) · [素材記録](../../evidence/stage-wave-art.json)
