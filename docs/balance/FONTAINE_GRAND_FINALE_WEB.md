# フォンテーヌの大舞台機関と公演再開

Lv80で「客席の下は、大忙し！」を報告すると、水辺の広場で「大舞台機関、ただいま暴走中！」（Q-FON-M03）を受けられます。門は `F`、調査と選択肢の切り替えは `G`、ジャンプは `Space` です。上段から降りるときは下方向と `Space` を押します。

1. 監視所で作業員二人の退避を確認します。操作室で「波板を立てて作業床を守る」か「床板を伸ばして上段を広げる」を選びます。退避と設備配置はセーブ後も引き継がれます。
2. 二段通路の地上と上段を巡って作業メカを止めます。波板を選ぶと射出口の飛び道具を遮れます。床板を選ぶと射線より上に足場が伸びます。
3. 中央でグラン・フィナーレの外装の駆動部を攻撃します。外装が止まると制御部が現れ、右の停止盤で主回路を切れます。停止のあと、一拍遅れて紙吹雪が降ります。
4. 右の上段で短い公演の準備をし、合図灯が緑になったら `G` で幕を上げます。早く押した場合は緑を待てます。合図を逃した場合はもう一度準備できます。

外装を初めて止めたときに3,020,570 EXP、報告時に3,550,820 EXP、6,100モラ、強化鉱5がそれぞれ一度入ります。報告後は広場の近道から公演後の主舞台へ戻り、記録を読み返せます。

## 試作の範囲

グラン・フィナーレは、車輪、折り畳んだ腕、太陽の銘板、雲の書き割りをオリジナル形状モデルの三方向で確認してドット絵にしました。主舞台の背景はラボ用の仮画像です。本番では3D配置を使う方針です。[形状モデルの三方向](../../evidence/grand-finale-views.png) · [素材記録](../../evidence/grand-finale-art.json)

標準矩形はボス単体で11,798件、軽量16色は3,035件です。ラボでは `P` で停止し、同じ場面のPNG・標準矩形・軽量16色を切り替えられます。ボスは外装の停止と公演への切り替えを遊ぶ段階です。横薙ぎや荷台の押し出しなどの固有技と連続作画、整備後の再戦、協力プレイは制作途中です。

Chromeの同一フレームでは、描画命令数がPNG20件、標準矩形16,038件、軽量16色4,098件でした。[PNG版](../../evidence/fontaine-finale-boss-png.png) · [軽量16色版](../../evidence/fontaine-finale-boss-light.png)
