# 夜道の先に、温かい一杯

ナド・クライで第2話「近道、寄り道、月の道」を報告すると、町の広場から「灯台守の暖房小屋」へ入れます。フリンズの依頼（Q-NOD-S05）を受け、巡回図の前で G を押します。

1. 右の門から海岸へ出ます。地上の第一灯を確認し、岩棚へ跳んで第二灯まで進みます。灯台の光と灯りが道の目印になっています。
2. 曲がり角では、二段の岩棚から投石役に近づけます。投石の前には点線で狙いが表示され、表示された場所から動くと避けられます。先に高台の投石役を退けると、地上に残ったスライム三体の位置が見えます。
3. 全員を退けたら右の門から合流標へ。フリンズが受け持った外側の道と合流し、強化鉱5個を受け取ります。右端から暖房小屋への近道が使えます。
4. 暖房小屋の茶卓で飲み物と焼き菓子を囲み、依頼手帳から報告します。その後も茶卓で体力を回復でき、近道を往復できます。

受注は第2話に合わせてLv120からです。初回報告で9,330,761 EXPと、試作値として8,400モラを受け取ります。投石役には既存の敵のドット絵と投射物処理を使い、先に見える予告と速度・ダメージをこの区画用に設定しました。

新しい小物は、誘導灯、やかんと二つのカップ、焼き菓子の皿です。自作の形状モデルを正面と前後の斜めから確認して描きました。フリンズは会話で登場します。灯台が見える海岸と暖房小屋の背景はラボ用の仮画像です。本番では3D配置を使う方針です。 [三方向の形状モデル](../../evidence/nod-lantern-patrol-views.png) · [小物と背景の記録](../../evidence/nod-lantern-patrol-art.json)

投石予告の同じフレームでは、描画命令はPNG42件、標準矩形7,161件、軽量16色1,813件でした。軽量16色で標準矩形より74.7%減り、暗い海岸でも投石役と予告の点線は見分けられます。 [予告のPNG](../../evidence/nod-lantern-patrol-warning.png) · [予告の軽量16色](../../evidence/nod-lantern-patrol-warning-light.png) · [高台から見渡した地上](../../evidence/nod-lantern-patrol-lookout.png)

茶卓の同じフレームでは、描画命令はPNG28件、標準矩形5,325件、軽量16色1,365件でした。軽量16色で標準矩形より74.4%減り、やかんとカップの輪郭が残ります。金属や焼き菓子の細かな陰影は簡略化されます。 [茶卓のPNG](../../evidence/nod-lantern-patrol-tea-png.png) · [茶卓の軽量16色](../../evidence/nod-lantern-patrol-tea-light.png)

`python -X utf8 test_nod_lantern_patrol.py` で二つの灯り、投石の予告と回避、撃破の途中保存、近道と回復を確認できます。ローカルサーバーを8907で起動して `node test_nod_lantern_patrol.mjs` を実行すると、Chromeで受注から報告後の近道往復までを確認できます。 [Luaの結果](../../evidence/nod-lantern-patrol-lua.json) · [Chromeの結果](../../evidence/nod-lantern-patrol-browser.json)

## 花見の獲得セーブから通した巡回

Lv130から受注し、高台の投石役を退けて保存しました。暖房小屋から道を歩き直すと、曲がり角にスライム3体だけが残っていました。報告後はLv131に上がり、以前の依頼93件、所持品80点、コロンビーナの同行を維持しました。近道を往復して茶卓で休めます。

茶卓ではカップから小さな湯気が立ちます。湯気の描画は3矩形で、元PNGと両方の矩形画質で位置が一致します。一時停止中は動かず、再開すると上に動きます。このセーブの同じ茶卓フレームは元PNG25件、標準矩形6,101件、軽量16色1,640件でした。軽量16色で標準矩形より73.1%少なくなりました。 [Lv130からのChrome検証](../../evidence/earned-nod-lantern-patrol-browser.json)
