# 拍手は、まだ早い！

フォンテーヌ第2話を報告したあと、水辺の広場で受注します。広場から窓明かりの別稽古場へ向かい、舞台係のそばで G を押します。

1. 操作台で最初の稽古を開き、幕・照明・波を順に動かします。画面のボタンと G のどちらでも、表示された合図を送れます。
2. 次の稽古はフリーナの台詞から始まります。約1.5秒の間を置き、「光と幕を合わせる」の合図が出たら、光と幕を同時に動かします。次の合図で波を出します。
3. 舞台係のそばで拍手を受け取り、水辺の広場に戻って報告します。初回報酬は 610,121 EXP と3,300モラです。モラと合図の間隔は試作値です。

合図より早く押すと、その場で台詞を待つ案内が出ます。光と幕を動かした後に波を早く押しても、光と幕はそろった状態で次の合図を待てます。合図の受付に締切はなく、画面の文字だけで進められます。終えた稽古は保存に残ります。稽古の途中で閉じると、その回の頭から再開します。

報告後、主舞台の公演にも光と幕、波、裏方への拍手が加わります。第3話の公演を済ませている場合は、主舞台の上段にある「再演の合図灯」で、稽古の演出をもう一度上演できます。右側の合図灯では、第3話の公演再開の記録を読み返せます。

操作台、照明器具、幕は、自作の形状を正面・斜め前・斜め後ろから参照してドット絵にしました。波は既存の舞台用スプライトを使い、フリーナは台詞で登場します。稽古場と主舞台の背景は、本番の3D配置を想定したラボの仮画像です。 [形状資料](../../evidence/fon-furina-cues-views.png) [素材と変換記録](../../evidence/fon-furina-cues-art.json)

同じ稽古場のフレームを一時停止し、Lua の描画指示を数えました。PNG表示29件、標準矩形30,279件、軽量16色6,815件でした。軽量16色は標準矩形より約77%少なく、幕のひだや波の輪郭も確認できます。 [PNG表示](../../evidence/fon-furina-cues-rehearsal-png.png) [軽量16色](../../evidence/fon-furina-cues-rehearsal-light.png)
