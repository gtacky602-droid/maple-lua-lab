# 淵下宮の灯室と探検記

稲妻の道から淵下宮の入口拠点に入り、右手の門から帰路しるべの棚へ向かいます。棚、灯室、小間、窪みはラボ独自の地形案です。灯室の背景は点灯と消灯の仮画像を切り替え、本番は3D配置を想定しています。既存のLv40探索路も使えます。

| 設計ID | 依頼と受注場所 | Lv | 初回報告（EXP / モラ / 強化鉱石） |
| --- | --- | ---: | ---: |
| Q-B03-01 | 海の底の、遠足案内（入口拠点） | 100 | 284,000 / 3,200 / 3 |
| Q-B03-02 | 灯りを消すと、道になる（入口拠点） | 105 | 391,000 / 4,400 / 4 |
| Q-B03-03 | 表紙のない探検記（道順記録の小間） | 110 | 103,552 / 371,745 / 5 |

1. 帰路しるべの棚で入口の壁、中央の上段、奥の地上を順に調べます。休憩場所と実際に戻れる道を案内にし、入口拠点へ報告します。
2. 照り影の灯室で、点灯中の壁の継ぎ目を地上から見ます。左の操作盤で `G` を押して消灯すると、上段の足場と右端の出口が現れます。足場へ跳び乗って調べ、消灯したまま出口を通ります。上段の操作盤で点灯した場合は手前の安全な床へ戻ります。
3. 小間で出口を記録して入口拠点へ報告すると、拠点と小間の短縮路が使えます。観測進捗は保存され、灯室へ入り直すと照明は点灯に戻ります。
4. 小間で最後の依頼を受け、石版裏の窪みで灯断ちの盤尾獣を退けます。奥の記録箱からメモを回収し、小間で新しい表紙と帰り道を加えて報告します。報告後は、探検記のそばで `G` を押すと読み返せます。

## 灯断ちの盤尾獣

「板背の直進」は予告した方向へ本体ごと突進します。手前に岩があれば本体と攻撃範囲が岩で止まり、反撃できる時間が長くなります。攻撃範囲より高い石棚へ上がることでも避けられます。「盤尾の払い」は近くの地面を攻撃するため、予告の外へ離れて避けます。反撃時間には光界障壁10が外れ、ダメージが1.24倍になります。光界0でもこの間は通常攻撃が通ります。ボスや報酬の数値は試作値です。

通常討伐報酬は討伐時に入り、表の初回分は依頼の報告で一度だけ受け取れます。

協力部屋から灯室に進むと、各自が消灯して石棚を渡ります。道順記録の小間で合流し、石版裏の窪みで盤尾獣の突進と反撃時間を共有します。討伐後は各自で道順を追記し、報告後に探検記を読み返せます。 [共闘の道順と検証](../COOP_WEB_PREVIEW.md#灯断ちの盤尾獣)
