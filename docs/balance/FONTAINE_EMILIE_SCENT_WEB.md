# 旅の香りを、ひとしずく

フォンテーヌ・水辺の広場に到着すると、エミリエの加入依頼を受けられます。調香工房の門から入り、台のそばで G を押して話を聞きます。

1. 船着き場で港花を摘み、低い石段に跳び上がって乾いた葉を集めます。重甲ヤドカニを退けてから、右端の木片を拾います。
2. 工房へ戻り、海風を強めた青い試作瓶を試します。依頼主の話を聞くと、家の扉を開けてほっとした瞬間を思い出したかったことが分かります。
3. 木を土台にした三つの配合から、香りを一つ選びます。瓶の近くで G を押し、右側にいる依頼主に渡します。
4. 水辺の広場で報告すると、依頼手帳からエミリエを同行に選べます。調香工房では選んだ香りの記念小瓶を G で読み返せます。

三つの配合のいずれでも、初回報告は 465,460 EXP、2,900 モラです。エミリエの初期装備は入門長柄の ATK +1 と、花を装備していない場合の HP +10 です。報酬のモラと装備の加算値は試作設定です。重甲ヤドカニの戦闘は既存の通常戦闘を使います。

調香台、素材、小瓶の8点は、自作の形状を正面・斜め前・斜め後ろから確認してドット絵にしました。エミリエは既存の待機絵を使っています。工房と船着き場の背景は本番の3D配置を想定した仮画像です。 [装飾の形状資料](../../evidence/fon-emilie-scent-views.png) [エミリエの既存素材の参照記録](../../evidence/emilie-reference-audit.json)
