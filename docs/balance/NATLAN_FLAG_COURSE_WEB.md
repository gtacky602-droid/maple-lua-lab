# ナタの旗取りと二つの中継印

Lv100でナタ・谷の集落から「その旗、取りに行ってみない？」（Q-NAT-M01）を受けられます。門の近くで `F`、案内板や旗のそばで `G`、ジャンプは `Space` です。

1. スタート広場の案内板でルールを読みます。坂道は広く、敵が5体います。岩棚道は敵が1体で、二段の岩棚を通常ジャンプで登ります。手前と奥に同じ二つの中継印があり、途中で道を替えても押した印は残ります。
2. 二つの印を集め、先の切れ目でカチーナに話しかけます。カチーナが回り込んで足場を下ろします。編成と加入に関係なく進めます。セーブで再開しても、下ろした足場は使えます。
3. 頂上の旗を取ると、高台・水辺の旗と頂上までの二つの道を側面図で確認できます。報告時に3,768,926 EXP、6,200モラ、強化鉱4が一度入り、集落から頂上へ直接戻れるようになります。頂上から既存の岩場狩場にも行けます。

初回は時間制限なしです。報告後はスタート広場の案内板からタイム計測を始められます。計測中に二つの中継印を押して頂上の旗を取ると、最短記録を保存します。コースの外に出る、拠点へワープする、途中のセーブから再開する、のいずれかでその周回の計測は終了します。

## 門の案内と継続セーブ

M地図では、坂道と岩棚道の両方に「依頼の進行地点」を表示します。門が閉じている間は、案内板を読む、中継印を二つ押す、カチーナのそばでGを押す、のうち次に必要な操作が分かります。カチーナが足場を下ろしている間は、戦闘画面の下に残り秒数が出ます。足場がつながったら右へ進み、頂上では上段の旗を取って集落へ戻ります。

ナタ到着時の同じLv100セーブから、坂道と岩棚道を別々に通りました。最初の中継印を押した後に保存を読み込み、両方とも次の印から再開しました。Luaでは、下ろした足場を再読み込み後に渡れることも両方の経路で確認しました。旗の報酬を受け取るとLv101に到達します。頂上で同じ場面を一時停止して比較すると、両経路とも標準3,941件、軽量16色1,009件でした。 [Luaの両経路](../../evidence/earned-natlan-flag-lua.json) · [Chromeの両経路](../../evidence/earned-natlan-flag-browser.json)

## 仮素材と描画比較
