# 追いつくより、先回り

ナタの旗取りを報告したら、谷の集落でキィニチの依頼を受注します。Gで狩りの話を聞き、近くの門でFを押して巡り岩の狩道へ進みます。

1. 足跡と折れた枝をGで調べます。順番は自由です。M地図で未調査の手がかりを確認できます。両方を調べると狭い坂道、開けた岩場、上下の岩棚が地図に並び、各地点の足場を開いて確認できます。岩棚の目印にはジャンプを長押しして届きます。
2. 目印の近くでGを押すと行き先が決まります。牙獣は東の岩で方向を変え、選んだ場所に戻ってきます。画面に折り返しまでの秒数と、戻ってくる場所を表示します。狭い坂道では牙獣の追跡範囲が短く、開けた岩場では距離を取り直せます。岩棚からは下の動きを見て飛び降りられます。
3. 手がかりを調べずに戦うこともできます。牙獣が途中で逃げても通り道へ戻ります。逃げる前や途中で倒し切った場合も報告できます。
4. 集落で討伐を報告すると、巡り岩の狩道の右端から岩場の狩場へ抜ける近道が開きます。

待ち伏せ場所と正面突破でキィニチの台詞が変わります。初回報告はどの進め方でも1,807,313 EXP、5,600モラ、強化鉱石5個です。モラ、鉱石、牙獣のHP、折り返しの時間は試作値です。大型個体への拘束は既存の耐性処理で減速になります。キィニチとアハウは台詞で登場します。

牙獣は参照記録のある既存スプライトを拡大表示しています。足跡、枝、目印、岩は、オリジナルの形状モデルを三方向から確認して描き起こしました。狩道の背景は本番の3D配置を想定した仮画像です。 [牙獣の参照記録](../../evidence/fanged-beast-reference-audit.json) · [狩道の小物の3D形状](../../evidence/nat-kinich-ambush-views.png) · [素材の変換記録](../../evidence/nat-kinich-ambush-art.json)

狭い坂道で牙獣が戻った同じフレームを比較すると、Luaの描画指示は標準矩形19,304件、軽量16色5,172件、PNG表示41件でした。軽量16色では約73%少なく、牙獣の角と尾、折れ枝、待ち伏せの目印を見分けられます。毛並みや岩の陰影は簡略化されます。幻境実機での描画性能は未検証です。 [PNG表示](../../evidence/nat-kinich-ambush-trail-png.png) · [軽量16色](../../evidence/nat-kinich-ambush-trail-light.png)

`test_natlan_kinich_ambush.py` で三つの折り返し先、拘束耐性、一撃での正面突破、調査と待ち伏せ先の保存・復元、狩場への近道、報酬の一回付与を確認しました。`test_natlan_kinich_ambush.mjs` ではChromeで足跡と枝を調べ、狭い坂道・正面突破での討伐と報告、実際にジャンプして岩棚の待ち伏せ先を選ぶ操作を確認しました。 [Lua検証](../../evidence/nat-kinich-ambush-lua.json) · [Chrome検証](../../evidence/nat-kinich-ambush-web.json)
