# 小さな潜航艇の、初めての海

フォンテーヌ第1話を報告すると、水辺の広場で受注できます。フレミネの玩具を点検し、隣の門から浅瀬の試験区画へ潜ります。

1. WASDか方向キーで泳ぎ、Gで泡の向きと珊瑚の岩陰を調べます。タッチ操作では左右に加え、上下のボタンが表示されます。
2. 強い流れの手前で止まった玩具を調べます。流れに正面から入ると押し戻されます。下の緩い側道を泳ぎ、泡の列、珊瑚のくぼみ、光の入る石窓のうち一つに目印を置きます。
3. 玩具が選んだ目印を経由して右端に帰るのを見届けます。右の浮上口でFを押し、広場へ戻って報告します。
4. 報告後は広場の作業台で玩具を見られます。別稽古場に行けるようになると、そちらでも展示を見られます。浅瀬には再び潜れ、右上の見晴らしを自由に観賞できます。

旅人を水中で操作している間、戦闘の同行者は陸で待ちます。浮上時と保存を読み込んだときに、潜る前の編成と操作キャラに戻ります。水中の縁に出たときは近くで通った回収灯へ戻ります。「回収灯へ戻る」ボタンでも戻れます。

三つの目印のどれを選んでも、初回報告は1,323,568 EXPと4,550モラです。モラと泳ぐ速度、流れの強さは試作値です。フレミネは台詞と合図灯で案内します。浅瀬の背景は本番の3D配置を想定した仮画像です。 [玩具と目印の形状資料](../../evidence/fon-freminet-dive-views.png) [素材と変換記録](../../evidence/fon-freminet-dive-art.json)

浅瀬の同じフレームで、Luaの描画指示はPNG表示121件、標準矩形15,131件、軽量16色3,982件でした。軽量16色では標準矩形より約74%少なく、玩具の丸い窓と珊瑚の輪郭を見分けられます。水中の旅人は既存の待機絵に泡を添えて表示しています。 [PNG表示](../../evidence/fon-freminet-dive-shallows-png.png) [軽量16色](../../evidence/fon-freminet-dive-shallows-light.png)
