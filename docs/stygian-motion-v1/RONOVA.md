# ロノヴァ：全12項目 モーション・演出 v1.0

共通：[COMMON](COMMON.md)。原本：[最難関v0.4](../../DESIGN_RONOVA_APEX_BOSS_MOVESET_V04_20261117.md)。ユーザー指定の現時点の最難関、死の権能、確定死、有限復活を維持。ここでの技名・時刻・死亡ルールは本作の制作基準であり、原作の正式技・原作フレームの断定ではない。

## 本体・三資源・演出の区別

人体144px、描画浮遊+0.20U、rootは足場面。長い髪と羽、手の少ない動き、背景の赤い目が主役。本人の手先を巨大翼で隠さない。威圧感を出すため頭身を他キャラより伸ばさない。原作衣装の詳細は動画・画像を直接再確認する。

HPは旅人／仲間個別。Lifeは実プレイヤーのペアで共有100。復活の灯はペアごと5回を制作開始値とする。これらは原作値ではない。普通の回復・盾はLifeを回復しない。任意交代でLifeを回復させない。

Life0は操作キャラに1回の死亡イベント。相方が生きていれば自動交代し、**その0到達イベントに一度だけLifeを35へ補正**。これは試行全体で1回という意味ではない。再度の0到達でも、既存の救助で生き返った相方がいる場合に限り同じ処理を適用する。任意交代・同一イベント再通知では補正しない。救助自体は既存の時間・再使用制限を維持する。相方救助に成功して継戦できることは許容し、灯は増えない。

ペア全滅時のみ灯1消費。灯1→0でもその復活は実行し、残り0で生存中は続行。次のペア全滅で観戦。本人のHP／Lifeは全回復、ボスHP・フェーズ・CT・光界はリセットしない。CTは経過時間分だけ減る。通常のHPダメージとLife・裁定を別種のイベントにする。

通常即死攻撃は`authority_lethal`。HP・盾・軽減を無視するが、専用の無敵や回避契約を未実装のまま飛び越えない。本制作基準では**空間的な回避と復帰保護は有効、通常回避の無敵も既存の有効区間に従う**。盾だけで防ぐことは不可。必須経路は無敵に頼らなくても成立するようQAする。

## 復活の灯：モーションと状態を一致させる

1. 片方死亡：共通死亡表示12tick、相方が生存なら自動交代。灯は減らない。既存の自分の仲間救助は維持する。
2. ペア全滅：`wipeGeneration`につき1回だけ灯を予約減算。HUDで該当灯が0–18tickで細く消え、通常のGAME OVERは出さない。
3. 120tick待機：視点は戦場を保ち「復帰まで」を表示。誰も生存せず復帰待ちだけならボスの行動と危険進行を停止し、復帰タイマーだけ動かす。生存者がいるマルチではボスは継続。
4. 安全復帰：検証済みの安全床へ本人ペアを出す。t0白い人影、t12輪郭、t24完全表示。120tickの復帰保護。攻撃／能動スキルで解除、移動・ジャンプでは維持。ボスが新しい個人裁定を保護中のownerに付けない。
5. 旧castで復帰直後に再死亡させない：復帰前の本人への個人裁定と回収義務をcancel、グローバル危険が無い地点を選ぶ。安全地点が無ければ強制出現させずボスの次castを待ち、安全判定を通してから復帰する。
6. 灯0で次全滅：観戦表示。全員観戦かつ予約復帰なしで失敗。退出／再接続で灯を再充填しない。他の実プレイヤーを蘇生する機能は追加しない。

命中・Life0・裁定が同tickなら同一死亡世代へ一つだけ死亡。裁定はhuman+castで最大1回。ボスHP0と最後の死亡が同tickならクリアを優先し、灯を無駄に消費しない。これらは未実装の契約で、実機APIが保証すると断言しない。

## フェーズ・禁止する重ね合わせ

1ゲージP1 100–75%=RN01/02/03、P2 75–45%=RN04/05/06/10、P3 45–15%=RN07/11/12、P4 15–0%=RN08追加。RN09は反撃窓の表現。各追加技は最初単独。RN05/06/08は同時起動しない。RN03の回収経路をRN07で塞がない。RN08の全期間は独立試練として他の通常技を起動しない。

極限でも予兆自体を消さず、低品質や画面の大きさで安全情報が失われないことを優先する。4難度の倍率・報酬は別設計、今回はこの1つのタイムラインを基準にする。確定死を受けず、復活を使わず勝つルートを最終QAの必須項目にする。
