# 隊長：全9項目 モーション・演出 v1.0

共通：[COMMON](COMMON.md)。技名・IDの原本：[隊長v0.3](../../DESIGN_CAPITANO_BOSS_MOVESET_V03_20261117.md)。古い全体案のCP番号とは意味が違うため、この9項目を正として使う。ムービーの氷剣・高速接近を参考にした本作用の構成。原作の正式技名ではない。

## 外観・静と動

人体152px、仮面と濃紺の身体、片手の氷剣。顔に新しい眼や表情を描かず、仮面の傾きと剣先の向きで読む。剣を使う手・外套の戦闘時の形は直接の映像で確認する。入場時の外套あり→戦闘の腕が見えるシルエットへの切替はENTERのt60までに終える。

脚は短く太い接地、上半身は立てた軸。ファルカの二刀のような左右に大きい重量移動にしない。斬撃はSLASH+ICE、突きPIERCE+ICE、強打BLUNT+ICE。刀身は待機時に薄青、攻撃先頭2tickだけ白い芯。白い吹雪を常時描かない。
