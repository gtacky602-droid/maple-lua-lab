# 幽境・隊長の凍天の演武

スネージナヤ・雪の町の入口（x650）から「幽境・凍天の演武場」へ入る。Lv144の依頼「凍天の演武・三つの型」はミティヤに報告する。受付では難度と勝利報酬の聖遺物セットを選ぶ。

| 難度 | 解放Lv | 制限時間 |
| --- | ---: | ---: |
| 通常 | 144 | 240秒 |
| ハード | 159 | 255秒 |
| マスター | 176 | 270秒 |
| 極限 | 195 | 300秒 |

難度ごとにHP、技の順序、技を出す間隔、報酬を設定した。難度・ダメージ・報酬ともラボ用の試作値。勝利で指定セットとモラを受け取り、各難度の初勝利では追加モラが入る。最速タイムと、そのときの同行者・主力技も難度ごとに残る。 [戦闘データ](../../content/stygian-matches.json)

## 三つの型

- 入場から1秒で外套ありの姿から氷剣の構えに変わる。2秒後に戦闘開始。HPは一つで、残り65%と30%が型の切り替え。閾値を越えるダメージはそこで止まり、現在の技が収まってから次の型に進む。
- 第一の型では二連、遅い三段目がある三連、疾走の終点で出る一閃、正面の扇。疾走の走路は青線、終点の攻撃範囲は別の輪郭で出る。
- 第二の型では低い斬波、三本の氷晶、破片が四方向へ散る氷板、時刻固定の構え。氷板が立っている間は歩いて通れる。構え中もHPダメージは通り、反撃はカード開始168ティック目に一度だけ出る。氷晶は柱の間に1.2Uの安全幅を確保するため、設計案の1.6U間隔を1.65Uに広げた。
- 第三の型の「終式・凍天一閃」は、疾走の終点を避け、低い氷線を跳び、高い氷線を地上でかわし、最後の扇から離れる。終わると4秒間反撃できる。再発動は通常技を三回挟む。
- 討伐で予告・飛翔体・地上の判定を取り消し、剣を下げる演出に移る。保存からは雪の町で再開できる。 [設計書](CAPITANO.md)

## ドット絵と背景

公式映像のサムネイルと外套ありの3Dモデルを参照し、既存の左右別の入場絵に加えて、外套を脱いだ構えと踏み込みを左右別に作った。構えは約2.9〜3.0頭身。氷剣は独立した絵を手元で回転させる。雪の演武場はブラウザーが表示する仮背景で、本番は3D配置を使う方針。 [公式映像](https://www.youtube.com/watch?v=8qon5akq198) [生成記録](../../assets/capitano-stygian-generation-v1.json)

同じ瞬間を一時停止し、描画設定で見比べられる。剣の位置と向き、予告線、戦闘状態を揃えて比較した。Chromeで取得した同一フレームでは標準9,284件、軽量16色版2,345件の描画コマンドだった。 [外套](../../evidence/stygian-capitano-coat.png) [踏み込み](../../evidence/stygian-capitano-dash.png) [PNG](../../evidence/stygian-capitano-png.png) [標準矩形](../../evidence/stygian-capitano-standard.png) [軽量16色](../../evidence/stygian-capitano-light.png)

## 検証と残作業

Luaで九つの技の時刻、疾走と氷板の通過、斬波の命中とジャンプ回避、構え、終式の再発動、討伐と保存を検証。Chromeでは通常難度で受注・入場し、低い氷線を跳び、高い氷線を地上でかわし、討伐・報告・再開まで確認した。 [Lua検証](../../evidence/stygian-capitano-lua.json) [Chrome検証](../../evidence/stygian-capitano-browser.json)

技ごとの連続作画、効果音、映像全編での武器の持ち手と動きの照合、上位難度の通しプレイとバランス、実マルチと順位表、本番3D配置と幻境実機の検証が残る。
