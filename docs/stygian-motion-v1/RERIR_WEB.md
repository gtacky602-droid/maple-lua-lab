## 第一幕と霧

爪の三連撃のあとに蹴りが三回来る。突進は終点を先に示し、深淵の棘は扇状に三群、黒球は四つが順に飛ぶ。マントを閉じる構えは反発の予兆で、その間も攻撃できる。

HPが65%になると霧に入る。足元の足跡と矢印を見て、赤い輪郭が出たら **H** か画面の「灯を掲げる」を一度押す。早押しや失敗からやり直せる。一回目に結界が半分になり、二回目は結界が消えて3秒間反撃できる。霧が晴れた直後の「三重地殴」だけは、三つの地面攻撃のあとに四球が続く。

## 第二幕と二度の回収

第一幕のHPがなくなると1.5秒の幕間を経て、第二幕のHPと槍が出る。月光の祝福ではHPやゲージを増減しない。槍の連撃、跳躍、黒球から突進、棘から二つの地面波へ移る。第二幕の残りHP70%と25%で試練を予約し、二つの試練の間には通常技を最低二回挟む。

左右の地上と中央の足場に淡金の光が一つずつ出る。中央へはジャンプで登る。同行者へ交代しても回収が続く。三つ集めると淡金の輪が最後の衝撃を防ぐ。回収が足りない場合は通常のダメージを受ける。第二回の回収成功後は4秒間、失敗後は1.6秒間反撃できる。勝利には第二幕のHPを攻撃で削り切る必要があり、試練が始まる前の一撃でも倒せる。 [個別設計](RERIR.md)

## 絵と確認範囲

左右別の144px待機絵を既存素材として使い、爪の軌跡と槍を別に描く。霧は戦闘中の演出。背景にはラボの異界画像を仮に使い、本番は3D配置を使う方針。 [既存素材の参照記録](../../evidence/rerir-idle-reference-audit.json)

Luaで13項目の時刻、連携A/B、灯の早押しと失敗後の再試行、空中試練の成否、交代、勝利と保存を確認した。通常難度のChromeでは、一度目の灯を見送ってから結界を解除し、二つの回収試練で中央の足場にジャンプして三つの光を集めた。両方の最終衝撃を防ぎ、第二幕を倒して依頼を報告し、保存から再開できた。 [Lua検証](../../evidence/stygian-rerir-lua.json) [Chrome検証](../../evidence/stygian-rerir-browser.json)
