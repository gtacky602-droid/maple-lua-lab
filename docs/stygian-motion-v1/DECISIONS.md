# 制作判断・旧版との差分 v1.0

入口：[MASTER](../../DESIGN_STYGIAN_MOTION_VFX_MASTER_V1.md)。記録日2026-11-17。ここは仕様の採用状態を混ぜないための表であり、原作設定の新規調査報告ではない。

## 1. ユーザーが明示している方向

旧メイプル風の低頭身・数字。キャラクターらしい服装と原作動作を残す。ファルカは二刀と特殊E跳躍突き立て・特殊重撃のクロス上昇・前進二連撃。シュバランケは男の子の姿で拳。隊長はムービーの氷剣戦闘。レリルとロノヴァは実際のボス戦を参考にする。ロノヴァは当面の最高峰で、確定死技と有限復活を持つ。制作実装はCodex、ここでは全技のモーション・演出を詳細化してリポジトリに記録する。

今回の49項目は、これまで話した技・状態を取り落とさず整理した数であり、ユーザーが細かな秒数・頭身・倍率を一つずつ承認したという意味ではない。

## 2. この依頼に対して選定した制作開始値

| 論点 | v1で採る値・方式 | 理由と変更範囲 |
|---|---|---|
| 仕様の正本 | MASTERと本ディレクトリ | 過去案が多く、古い技名の混入を防ぐ |
| 時間 | 60Hz整数tick、半開区間、個別カードで固定 | 「約0.8〜1.5秒」の選択を作画担当へ丸投げしない。原作計測ではない |
| 人体サイズ | FK140/CP152/XB84/RR144/RN144px | 旅人88pxとの比較基準。素材キャンバスと混同しない |
| 頭身 | 頭飾り除外で約3.0 | 現行ART_REFERENCE_POLICYの2.8〜3.2に合わせる。髪込み2.4等の別計測と併存可能 |
| ファルカ第二元素 | 初版VFXは風＋炎の固定 | 制作中に色が毎回変わらない。編成判定・ダメージ属性を実装したわけではない |
| ファルカの二連撃 | 低い第一→高い第二、別予兆 | ユーザー指定の二連撃の軸は保ち、2Dの回避時間を取る。原作と同フレームとはしない |
| 隊長CP08 | 時間固定の構え→予告付き反撃 | AIや既に放った持続攻撃の誤検出を避ける。反射・自動無敵なし |
| シュバランケ | 全8項目を少年の同じ体格 | 旧108〜124pxの成人寄り案は使用しない |
| レリルRR10 | 固定時刻のマント反発 | 多段・AIで反撃を連続発生させない。自動軽減なし |
| レリル | 二幕二ゲージ、霧2回成功、回収2局面 | 最新v0.4の第一候補を採る。総HP・報酬変更は別 |
| レリル回収失敗 | 通常被害1回 | ロノヴァの確定死と区別。ダメージ倍率は戦闘原本側で決める |
| ロノヴァ | 4段階1ゲージ、75/45/15% | 最新v0.4の候補を制作基準にする |
| 命Lifeと灯 | 共有Life100／灯5回、ペア全滅で1消費 | 詳細はRONOVA。既存の光界ゲージとは別、灯の回復はなし |
| 命0の35補正 | 0到達イベントにつき、自動交代が成立したとき1度 | 「試行全体に1回」と「毎tick」を両方排除。任意交代・救助だけで無料回復しない |
| 強制命分離 | 分離量min(36,Life-1) | 回収前に不可避の死亡を起こさず、回収を攻略として成立させるための補足 |
| 確定死の無敵扱い | HP・盾・軽減無視、既存回避無敵と復帰保護は有効 | 事前に見える安全路も必須。新しい貫通属性を暗黙追加しない |
| 所有者 | 回収・個人裁定は実プレイヤー単位 | 交代で進捗消失せず、マルチで他人の球を奪わない |
| 非攻撃状態 | FK06/RR12/RN09はACTIVE無し | 構え・祝福・弱体姿勢を見ただけで追加ダメージや回復を出さない |
| ダメージ数値・報酬 | 今回決めない／変更しない | モーションと演出の範囲を越える性能・経済の改変をしない |

上記は今回こちらが詳細化して選んだ初版。実測で不成立なら、理由と変更前後を残して改訂する。実装担当が無断で最高難度を下げる／画像に合わせて判定を拡大することとは分ける。

## 5. 原作確認と今回未実施の事項

今回の完了は文書と機械可読索引の作成。画像生成、実スプライト分割、音声制作、攻撃コード変更、ラボ起動、ユーザープレイテスト、幻境実機試験はしていない。JSON整合チェックの合格は戦闘の回避可能性・楽しさ・FPSの合格を意味しない。
