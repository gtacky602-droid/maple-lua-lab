# ファルカ：全7項目 モーション・演出 v1.0

共通：[COMMON](COMMON.md)。元案：[幽境全体FK01–07](../../DESIGN_STYGIAN_CANON_MOVESETS_V02_20261117.md)、[3技キーポーズ](../../DESIGN_FARKA_2D_KEY_MOTIONS_V03.md)。ユーザー指定の跳躍突き立て／クロス切り上げ／前進二連撃を中核にする。原作の英語名は旧資料の参照名であり、今回フレーム解析したものではない。

## 固定する外観・動き

表示人体高140px、二刀。重心は腰、足の踏ん張りと肩の回転を大きくし、髪・布は本体に4tick遅れて付いてくる。顔を斬撃で長く隠さない。原作衣装の左右差は直接資料で照合する。

第二元素は初版の**見た目比較を炎に固定**。左手側に風、右手側に橙の芯を描く基準だが、原作の実際の持ち手は動画確認で必要なら交換する。プレイヤー編成から突然属性を変えない。これはダメージ属性決定ではなく、ボス版の選定した色構成。P1通常は白い刃、P2以降は風／炎の二刀。

音は重い剣風。風側は抜ける高音、炎側は短い低音。待機・入場・敗北はCOMMONのFK仕草を使用。通常被弾で二刀連携を毎回キャンセルしない。

## FK01 二刀の通常連撃

**固定尺204tick=3.40秒。** TELL[0,48)、LOCK24。ACTIVE[48,54)、[66,72)、[84,90)、[108,114)、[132,138)。RECOVERY[144,204)。5つの攻撃要求窓、各窓1対象1回まで。既存被弾無敵は維持。

**キー姿勢**：P0 t0両剣を腰の外へ下ろす。P1 t24後足へ荷重、肩を前後にひねる。P2 t48前手の腰横薙ぎ。P3 t66後手の返し。P4 t84前手の斜め上。P5 t108後手の低い振り。P6 t132両肩を使う締めの横薙ぎ。P7 t144刀身を低く残して止まる。P8 t192待機へ戻り、t204READY。顔の高さを維持し、腕だけを伸縮させない。

**移動・範囲**：t48/66/84/108ごとに前進0.10U、総0.4U。LOCK後向き固定。各Hitboxは発生時のroot基準で前方rect[0.1,1.45,0.15,1.05]、3段目だけv上端1.55。5段目はu上端1.75。背面へ360度判定を作らない。予兆は最初から全5段の包絡範囲を示す。

**絵・音**：t0剣柄近くに5つの小さい切れ目を点灯、各攻撃開始で1つ消す。t48等にweapon_tipのSLASH、P2以降はWIND/FIREを交互に追加。命中SLASH、空振りに火花なし。t144尾を18tickで消し、足元は滑らせない。tell t0、lock24、swing各ACTIVE先頭、recover144。shake0。

**対処・素材**：間合い外または背面。途中の間を終了と誤読させない。9キー＋刀身2層＋剣筋5向き。中断はCOMMON ABORT、t144以降は攻撃判定ゼロ。

## FK07 終盤連係（新規判定を持たない親）

開始時にA/Bを選び、頭上の小アイコンで「落下→X」または「落下→二連」を表示する。途中で無告知に分岐しない。

**A標準：尺432tick。** FK03をt0から通常通り、FK04をt204から開始。親のACTIVEは子の[102,108)、[258,264)、[270,276)のみ。最後のRECOVERYを[288,432)へ延長し、子FK04の通常終端を使わない。

**B派生：尺528tick。** FK03 t0、FK05 t204。ACTIVE[102,108)、[309,315)、[375,381)。最終RECOVERY[384,528)。途中のFK03後隙[114,204)は削らない。親の全体名を見せても、子の各WARN／LOCKは省略しない。

新規本体キーは接続の2枚以内。前の剣を抜く姿勢→次の構えに繋ぐ。子の炎・風を次のACTIVEまで持ち越さない。音・shakeは子を共有、親による追加大音量／追加hitなし。親中断で全子をキャンセルする。

## フェーズ・素材引き渡し

1ゲージ、P1 100–65%=FK01/02/06、P2 65–30%=FK03/04追加、P3 30–0%=FK05/07追加を制作基準にする。新技の初回は単独で提示。FK07を2回連続で選ばない。phase演出90tick、本人の二刀の芯だけ強くし、足場や頭身は変えない。

必要資産はFK共通状態、各カードの本体キー、二刀ソケット、WARN3型（前方、着地、X）、風弧、炎弧、DUST、AFTERIMAGE。既存16姿勢は構図資料として残すが新規格完成素材とは扱わない。原作確認／新しい低頭身作画／左向き衣装／判定同期／プレイ検証を別々にチェックする。
