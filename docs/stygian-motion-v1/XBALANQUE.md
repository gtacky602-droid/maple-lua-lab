# シュバランケ：全8項目 モーション・演出 v1.0

共通：[COMMON](COMMON.md)。原本：[少年姿へ修正済みの8技票](../../DESIGN_XBALANQUE_BOSS_VFX_MOVESET_V03.md)。**見た目は男の子、武器ではなく拳**というユーザー指定を優先する。腕を成人の筋肉・鎧・巨大手袋に変えない。原作ムービーの印象を使うが、以下の拍・火球・放射・連係は本作の設計。

## 基準体格と火の役割

表示人体高84px、赤系の髪・暗色衣装の特徴は原作画像で照合する。小さい肩、短い腕と脚、大きい顔。身体が小さくても足→腰→肩→拳の順の体重移動を描く。拳を大きく見せる部分はFIRE_GAUNTLETという別FXで、身体そのものを膨らませない。

火の色はCOMMON FIRE。P1は橙中心、P2黄金の芯、P3は攻撃先頭だけ白金。常時燃える幅は拳0.16U以内。大技でも顔、拳、前足が見えるよう、手前火のalphaを0.35へ落とす範囲を設ける。命中はBLUNT+FIRE、飛翔弾はBURST+FIRE。剣筋のSLASHを主役にしない。

## XB07 烈日連携（親・合成）

開始時にA/B/Cを選び、2つの小アイコンで次の技を表示。各子のTELL・LOCK・安全域を保持し、子の後隙を黙ってキャンセルしない。

**B456tick**：XB02 t0、XB03 t156。近接ACTIVE42–48/66–72/90–96、弾ACTIVE204–294/228–318/252–342。最終RECOVERY[348,456)。

親による追加判定なし。接続キーは拳を下げる→引くの2枚まで。本体の体型を変えず、炎の尾は次の予兆までに消す。音は子を再利用し、最後だけ軽い終了音。Aは二連→三連、Bは近接→射撃、Cは落下→直拳という違いがポーズで見えること。中断で子弾を含め全停止。

## フェーズと終了

P1 100–65%=XB01/02/03、P2 65–30%=XB04/05追加、P3 30–0%=XB06/07/08。新技単独→既知技の連携の順。XB08の安全帯へXB03を同時に撃たない。大技は連続させず通常技3回を挟む。

聖火はフェーズに同期する背景演出のみ。時間切れ敗北を新設しない。クリアで拳の炎が消え、男の子の姿のまま手を下げる。倒れて消滅・殺害されたという描写にしない。共通身長84px、左右の衣装差、拳ソケット、火の巻き方を全8項目で保つ。
