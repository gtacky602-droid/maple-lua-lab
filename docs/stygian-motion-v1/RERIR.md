# レリル：全13項目 モーション・演出 v1.0

共通：[COMMON](COMMON.md)。原本：[レリルv0.4](../../DESIGN_RERIR_BOSS_MOVESET_AND_VFX_V04_20261117.md)。格闘→霧と灯→長柄→二度の回収という既存案を採る。原作の行動・服装の再検証は素材制作時に行う。全ての名前・時間・試練操作は本作用。

## 人物・幕・不変条件

人体144px、銀白髪、暗色の覆いと赤黒い爪・マントを識別記号にする。格闘では腕・足が先、髪とマントは6tick遅れる。槍形態は武器の全長より先に手元と穂先を読ませる。暗いエフェクトの芯は淡紅、背景に埋もれる黒一色にしない。色はCOMMON ABYSS、回収物は淡金のPICKUP。

二幕二ゲージを制作基準にする。第一幕65%で霧を一度挟み、結界2回解除後に第一幕へ戻る。第一ゲージ0で幕間90tick→第二ゲージ。第二幕70%到達後RR09、25%到達後RR13を各1回予約。HP0は勝利を優先し、未実行ギミックのためHPを1へ固定しない。複数閾値を跨いだときは技終了後に順に処理し、二つの上空試練の間に通常技を最低2回挟む。

暗転・霧・空中姿勢は無警告攻撃の理由にしない。原作の固定仲間／QTEは要求せず、ギミックは実プレイヤーのペア単位で扱う。レリルにロノヴァ専用の確定死・復活灯を追加しない。

## RR05 霧中の襲撃／灯の2回成功

**失敗1試行240tick、成功で早期分岐。** 霧への入場72tickはphaseイベントで一度だけ。霧の濃さは背景0.30、人物前0.12、必須予兆に被せない。結界は2段の専用表示、通常HPと別。

試行P0 t0鹿の足跡が左右いずれかへ3点、P1 t48襲撃位置に爪の影、P2 t84赤い輪郭が露出し灯の有効窓開始、P3 t132短い蹴り、P4 t144引く、P5 t216再び霧へ。LOCK48、灯窓[84,132)、失敗時ACTIVE[132,138)、失敗後RECOVERY[144,240)。襲撃範囲は表示したR前rect[0,1.4,0.1,1.0]。出現位置を先に知らせ、画面外から攻撃しない。

灯は装備キャラに依存しない`context_action`。E交代を奪わない。入力は通常技とは別の短い押下、一試行1成功のみ。e=成功tickならACTIVEをcancel、e+0淡金照射、e+6結界片、e+12完全露出。1回目は結界1/2、露出RECOVERY[e+12,e+102)、その後次試行。2回目は結界0、RECOVERY[e+12,e+192)の3秒ダウン後に霧終了。

灯を早く押したら小さな不成立表示だけ、t84以降の再入力を禁止しない。成功を消費したボタン保持で次試行まで自動点灯しない。鹿音は任意、必ず足跡と方向矢印を併記。sfx48布、84灯受付の二音、成功eで照射、失敗132は蹴り。shake0。結界削りにHPダメージ数字を出さない。

素材：霧背景、前景薄霧、鹿痕、本人の半透明差分、灯、2段結界、通常蹴り。再挑戦で結界と成功回数を初期化。マルチの灯操作で同一露出の成功を重複加算しない。

## RR09 天墜の予兆／第一回回収

**上限1260tick=21秒。** t0–120上空準備、回収[120,960)、落下攻撃[240,252)/[420,432)/[600,612)、最終爆発[1008,1020)、着地1050、RECOVERY[1080,1260)。

P0槍を空へ、P1 t72上昇開始、P2 t120高度3.5Uで両腕を開く、P3各落下で片手を下ろす、P4 t960槍を胸前、P5 t1008深淵紋が開く、P6 t1050着地、P7 t1080槍を下げる。8キー＋浮遊保持。

回収球は3個、戦場x=2/5/8Uの到達可能な床・上段から、経路検査済み配置を選ぶ。1実プレイヤーにつき3つの論理ID、本人の操作キャラが触れると回収。仲間交代でも進捗継続。マルチで他人が取って球が無くならない。取得時PICKUPがownerへ収束し1/3表示。

落下は幅0.65U高さ2Uの縦帯。各120tick前から予告し、その球の取得点と唯一の経路を塞ぐ位置は選ばない。全回収で最終爆発専用の輪を表示。1008時の爆発は当該ペアに成功防御を1回適用し、その他の既存盾と混同しない。失敗は通常の被害イベント1回、倍率は戦闘原本で決定し隠れた即死なし。

巨紋は奥、プレイヤーと回収物は手前。爆発は縁から開き中心を透かす。sfx0上昇、各予告低音、各取得二音、960詠唱相当の短音、1008爆発、1080静音。S2は1008だけ。早く取っても爆発時刻は同じ、普通の攻撃を追加しない。

## RR13 天墜の終告／第二回回収

**成功側上限1320tick=22秒。** RR09の構えと上空キーを再使用。回収[120,960)、落下[252,264)/[432,444)/[612,624)、最終判定[1008,1020)、着地1050、成功RECOVERY[1080,1320)。失敗側はRECOVERY[1080,1176)で槍戦へ。

配置はRR09と左右反転した別の検証済み3球経路。HUDに「第2局面」と3球だけを表示し、新しい操作を追加しない。取得成功で巨紋に二つの割れ目、t1008防御と露出が成立、t1080本人のマントが落ちて4秒の反撃窓。原作の特定人物のQTEを強制しない。命中した攻撃でHP0になった時だけ勝利。

失敗は通常被害1回、無条件即死・残機消費なし。成功の人数が多くても反撃窓の倍率や長さを人数倍にしない。マルチでは1人以上成功なら共通の長い窓を開き、個々の防御成功は各人に適用する。全員失敗なら短い窓。

色・音・S2はRR09を共有、違いは第2局面の紋の裂けとt1080の露出音。別の巨大爆発を足さない。所要時間は初期基準、長い待機が冗長なら経路試験後に回収上限だけを変更し、予兆を短縮して難しくしない。

## 素材・中断・テスト

格闘、マント、槍、空中を4リグ構成にせず同じ身体とソケットで接続する。武器のみ交換。前後の髪とマントの位置を全13項目で一致させる。霧、灯、2段結界、球、黒弾、棘、巨紋、回収UIは別層。

結界値・回収値・2本のHPは別状態。全ての取得・灯成功にcastとownerを付け、重複しない。死亡者の古い球・試行退出後の灯は消す。0HPクリアと幕間の競合ではクリア／幕定義を先に判定し、再生成無限ループを防ぐ。各ACTの総HPや被害倍率はここでは変更しない。
