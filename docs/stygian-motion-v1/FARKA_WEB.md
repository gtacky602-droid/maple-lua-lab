# 幽境・ファルカ「二刀の鍛錬」

モンド・城門広場の入口（x295）から「幽境・二刀の鍛錬場」へ入る。Lv12の「双剣の鍛錬」を受注すれば、勝利後にアンバーへ報告できる。受付で難度と聖遺物セットを選ぶ。旧簡易模擬戦も試作ボタンから参照でき、旧個人記録は従来欄で読める。

指定の二刀動作を、七つのモーション・演出設計に沿って組み込んだ。難度、HP、ダメージ、技の順、報酬はラボの試作値。HP65%と30%を境に、単独の技を見せてから各90tickの構えを挟む。時間制限は設けず、難度別の最速、同行者、主力技を記録する。 [設計](FARKA.md) [時刻表](MANIFEST.json) [戦闘データ](../../content/stygian-matches.json)

## 七つの技

| 技 | 予告と対処 |
| --- | --- |
| 二刀の通常連撃 | 五つの剣筋。踏み込みを含む範囲全体を先に表示する。 |
| 前方跳び斬り | 斜めに飛び、固定した着地点の前を斬る。左右の上段に着地したときは、その高さで斬撃が出る。 |
| 跳躍・双剣突き立て | 着地点の印を固定し、跳んでから二刀を床に突き立てる。攻撃は着地の一窓。印の外へ移動する。 |
| クロス切り上げ | 交差する二本の斜線を先に表示する。二つの斬撃を背後か間合いの外で避ける。 |
| 前進二連撃 | 立ち位置を読む予告のあと前進し、低い炎、高い風の順で斬る。低い一撃はジャンプ、高い二撃目までに地面へ。上段に降りた場合は **下＋Space** で降りられる。 |
| 二刀の構え直し | 剣の向きと色を整える。構え中も攻撃が通る。 |
| 終盤連係 | 突き立てのあとクロス、または前進二連撃。始めに組み合わせを表示。最初の反撃時間を保ち、終盤に2.4秒の隙を作る。 |

## 素材と検証

立ち絵とモデル四方向を照合済みの左右別本体を使う。髪先を含め152px表示で人体は約140px。二本の剣は手元を基準に別々に回し、風と炎の線も独立。城壁の仮背景は内蔵ImageGenで制作した。本番では3Dを配置する方針。 [人物の参照記録](../../evidence/farka-chibi-reference-audit.json) [手元と剣](../../content/farka-idle-layers.json) [仮背景の生成記録](../../assets/farka-dual-court-background-v1.json)

Luaで七技の時刻、上段と地面の差、二つの連係と子技の反撃時間、クリア・報酬・保存を検証した。Chromeの通常難度では、落ちる地点から離れ、前進二連撃を同じ横位置でジャンプと着地でかわした。終盤連係の後に勝利し、依頼報告と保存からの再開を確認した。 [Lua検証](../../evidence/stygian-farka-lua.json) [Chrome検証](../../evidence/stygian-farka-browser.json)

高い斬撃の予告中の同一フレームで、Lua描画命令はPNG27件、標準矩形9,782件、軽量16色2,610件。標準から約73%減。軽量版でも二本の剣と斬撃の高さが読める。 [PNG](../../evidence/stygian-farka-high.png) [標準矩形](../../evidence/stygian-farka-standard.png) [軽量16色](../../evidence/stygian-farka-light.png)
