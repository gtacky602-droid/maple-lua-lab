## 操作と技

地面にある左右の風輪の中央で **Space** を押し続けると高く跳べる。中央上段へは、左右どちらかの中段から中央側へ跳ぶ。キャラ固有の飛行や装備を条件にせず、旅人と手持ちの同行者で対処できる。風標は表示されている足場に着地すると点灯する。

| 技 | 予告と対処 |
| --- | --- |
| 刻み風 | 低い一線、中段、低い一線の順。発動前に高さが見える。 |
| 渡り風 | 終点を固定して横に飛ぶ。床と最上段は横風の帯の外。 |
| 風標の結び | 左右の中段の風標を踏む。両方点灯すると最後に踏んだ足場へ放浪者が降り、2.6秒攻撃できる。間に合わないと地面に風が走る。 |
| 一線落ち | 落下位置を固定してから飛び込む。落点の印から離れる。 |
| 逆巻く二段 | 床を横切る風のあと、上の足場を通る風が来る。 |
| 四風の決着 | 床の風を越え、外側の中段と中央上段の風標を踏み、安全門を使う。二つ点灯で門が160px、反撃時間が4秒。未達でも112pxの門と2.5秒の反撃時間が残る。 |

「四風の決着」は最終段階で最初に出る。再発動の前に通常技を三つ挟む。門は横移動で入れ、どの高さでも同じ位置が安全。最後の風が過ぎたら、**下＋Space** で足場から降りることもできる。

## 素材と検証

立ち絵と3Dモデルの四方向を照合済みの左右別ドット絵を使い、飛行、風標、突進の残像は別に描いた。峡谷の風見台は内蔵ImageGenで作ったラボ用の背景。地面と足場は背景の手前に描き、本番では3D配置を使う方針。 [ドット絵の参照記録](../../evidence/wanderer-reference-audit.json) [背景の生成記録](../../assets/wanderer-windcourt-background-v1.json)

Luaで六技の発動、風輪からのジャンプ、着地による風標の点灯、固定した突進と落点、両方の門幅と反撃時間、失敗時の終了処理を確認。Chromeの通常難度では、床で渡り風をかわし、左右の風標を踏んで足場上から反撃し、最後は中央上段の風標と安全門を通って無被弾でしのいだ。勝利報酬、依頼報告、保存からの再開も確認した。 [Lua検証](../../evidence/stygian-wanderer-lua.json) [Chrome検証](../../evidence/stygian-wanderer-browser.json)

最後の安全門に入った同一フレームで、Lua描画命令はPNG155件、標準矩形5,624件、軽量16色1,603件。標準から約71%減。軽量版では帽子や布の細かな模様が粗くなるが、外形と中央の安全幅は分かる。 [PNG](../../evidence/stygian-wanderer-gate.png) [標準矩形](../../evidence/stygian-wanderer-standard.png) [軽量16色](../../evidence/stygian-wanderer-light.png)
