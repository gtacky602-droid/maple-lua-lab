# フォンテーヌ地方伝説と通常個体の見た目

フォンテーヌの9戦、計11体を通常個体と見比べた。公式紹介図、ゲーム内図鑑、名前が見える現地画面など24点を確認。湖辺の二体は、それぞれに対応する通常個体と第5稿Aの待機絵を共用した。カニは堅盾型の通常個体と地方伝説2体で輪郭をそろえた待機候補を制作した。 [画像URLと確認箇所](../evidence/fontaine-legend-base-references.json) · [公式の新敵紹介](https://genshin.hoyoverse.com/en/news/detail/112690)

## ラボで見比べる

通常敵の素材比較で「濁水」と入力すると、噴出型と粉砕型が表示される。元PNGと軽量16色の矩形版を並べ、通常個体の試作サイズ76pxで片目と腕の形を確認できる。マップの配置プレビューでも両方を選べる。通常個体のフィールド配置は調整前。 [通常敵の素材比較](http://127.0.0.1:8989/enemies-art.html?q=濁水&zoom=2) · [地方伝説の第5稿A/B](http://127.0.0.1:8989/bosses-art.html?q=湖辺の&zoom=1)

カニは同じ寸法と床位置で、通常型と地方伝説の候補を表示できる。軽量16色は通常型2,809→942矩形、地方伝説型2,642→926矩形。殻の段と大きな前脚は読める。目や関節の境界は原寸より小さく見える。本編への差し替えは既存の構え・攻撃との照合後に行う。 [同寸・16色比較](../evidence/fontaine-sternshield-shared-preview.png) · [作画と矩形数の記録](../evidence/fontaine-sternshield-shared-art.json) · [通常型](http://127.0.0.1:8989/enemies-art.html?q=堅盾&zoom=2) · [地方伝説2体](http://127.0.0.1:8989/bosses-art.html?q=堅盾型&zoom=2)

Chromeで検索から各候補を表示し、390px幅とマップ配置の3描画設定を確認した。 [Chromeの確認記録](../evidence/fontaine-legend-base-browser.json)

## 追加で見る資料

通常と名付きの比較は、同じ角度の立ち姿、側面、背面の順で増やす。照明の強い水中画像や攻撃の瞬間は、輪郭とエフェクトを読む用途に使う。2D図鑑の色面と、ゲーム画面で見える立体の形を照合する。現時点は静止画の比較で、単体3Dモデルの回転確認は残っている。

- 幻霊の図鑑画像は青白い片目が読みやすい。左右の腕が重なる戦闘画面は、顔がどの水塊にあるかを確認できる。 [通常の2型](https://game8.jp/genshin/546441) · [名付き2体の近景](https://www.hoyolab.com/article/22483368)
- マシナリーの通常機と名付きは、影と支柱を見比べると共通の脚が分かる。 [通常機のゲーム画面](https://kamigame.jp/genshin/page/277187221486862841.html) · [名付きの力場](https://game8.jp/genshin/546492)
- カニの2体と同型の堅盾型には層のある殻がある。小型の重甲ヤドカニは丸い一枚殻で、小型の絵は小型の通常個体に使う。 [堅盾型の図鑑アイコン](https://patchwiki.biligame.com/images/ys/0/04/ti19n7or2q3jvzn73f7lt9qmhrbzjt6.png) · [両方の名付き個体と通常種](https://genshin-impact.fandom.com/wiki/Sternshield_Crab)
