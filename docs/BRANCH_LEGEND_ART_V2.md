# 地方伝説4戦のドット絵・第2稿

15枚の個別PNGは各288×144 px。全ポーズを同じ座標で重ねられる。左上を原点とし、各画像の (144, 132) を敵の床位置に合わせる。水の2体は最下端から床まで12 pxの余白がある。岩獣は手前の爪を床に合わせた。攻撃方向は左。ニニアンは正面に近い左右対称の姿で、両腕が上がると縦方向の攻撃を表す。

一覧シートは左から待機・構え・攻撃の順。切り出し矩形 crop は左・上・幅・高さ、pivot は切り出し後の床位置。opaque_box は個別画像で色がある範囲で、右端と下端は含まない。Luaラボ用のコンパイラーは矩形に床位置を含め、浮遊の間隔をPNGと各矩形描画で保つ。制作は別チャットのGPT-6.2 Astraが担当した。 [全ポーズの比較](../evidence/legend-art-v1-v2.png) · [透過PNGシート](../assets/legend-poses-source-v2.png) · [切り出しと床位置データ](../assets/legend-poses-v2-layout.json)

## 画像で確かめた特徴

公開されている8枚のゲーム画面で確認した。3Dモデルデータや回転ビューは未確認。配布絵には独自生成したスプライトを使用した。プロジェクト内にこの5体専用の元GIFは見当たらず、既存のV1シート2枚を比較元に使った。

|対象|資料と視点|絵に採用した特徴と理由|
|---|---|---|
|湖辺のヴィヴィアン|奥から全身が見える [Altema](https://altema.jp/gensin/vivianne) と、両腕を広げたところを近くから写した [GameMad](https://gamemad.com/guide/266052)|縦長の胴を細いしずくで終わらせ、丸い拳を胴から離した。足元の草や岩が透け、待機中も浮いて見える。攻撃では一方の拳を左へ伸ばす。|
|湖辺のニニアン|浜で低く広がる [Altema](https://altema.jp/gensin/ninianne) と、浮いて両腕を上げる [Sportskeeda](https://www.sportskeeda.com/esports/genshin-impact-local-legend-locations-achievements)|中央の核を水のくぼみに収め、両端に大きな拳を置いた。待機は幅広く、構えは拳を内側に寄せ、攻撃は上へ振り上げる。青緑と明るい核はラボの水柱予告に合わせた配色。|
|シネアス|石床へ続く道の遠景 [Altema](https://altema.jp/gensin/cineas) と、正面から胸と両前脚が見える [HoYoLAB投稿](https://www.hoyolab.com/article/27928197)|高い肩から爪までを濃紺の大きな形でつなぎ、顎の下に灰色の明部を置いた。横向きでは細い尾と低く伸ばした爪が突進の向きを示す。|
|赤璋巡岳府君・炎|2体を近くから写した [GameWith](https://gamewith.net/genshin-impact/article/show/43755) と、少し離れて並ぶ [HoYoLAB投稿](https://www.hoyolab.com/article/24739626)|肩と前脚に赤褐色の大きな岩板を重ね、踏み込むと板の先が前へ出る。暗い岩肌を残すことで氷個体と同じ種類に見える。|
|赤璋巡岳府君・氷|同じ2場面。並んだときに片方の前脚の白青が浮き上がる。 [GameWith](https://gamewith.net/genshin-impact/article/show/43755)・[HoYoLAB投稿](https://www.hoyolab.com/article/24739626)|前脚に明るい青白の結晶を立てた。炎個体の平たい板と氷個体の尖った先端で、色以外でも見分けられる。|

湖辺の生成候補は2体とも尖った横顔とひれが目立ち、ポーズを並べても体形の差が小さかった。この2体は描き直し、球形の拳を共通にした。岩獣は候補の前脚の形を採用し、各ポーズをゲーム用の解像度に縮小して透過PNGにした。生成元シートのファイル名と採取範囲は切り出しデータに記録した。

## ラボで比較する

[ボスの待機素材比較](http://127.0.0.1:8977/bosses-art.html?q=%E6%B9%96%E8%BE%BA%E3%81%AE)を開き、名前で絞り込む。各カードの左が元PNG、右が選んだ矩形描画。初稿と改稿は続けて並ぶ。戦闘画面はMの地図から「狩場・任意戦」へ進み、Pで止めて「描画方式」を変更する。

Luaの検証で水の2体は同じ床位置から浮き、通行条件・命中・退路・再戦・討伐と保存が通った。同じ予告フレームで四戦とも標準から16色へ切り替え、描画指示数が約73%減った。 [Lua検証ログ](../evidence/sites-branch-legends-lua.json)
