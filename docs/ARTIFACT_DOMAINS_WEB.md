# 山脊の見守りと山風の荊冠の周回

[Luaラボ](http://127.0.0.1:8989/)で **M** を開き、山脊の見守りか山風の荊冠を選ぶ。外の扉で **F** を押すと広間に入れる。難易度と狙うセットを選んで挑戦する。途中で退出した場合は入口からやり直せる。 [外の扉までの経路](SITES_DOMAIN_ENTRANCES_WEB.md)

山脊ではシールドで攻撃を吸収すると周囲へ反撃が出る。山風では通常攻撃を当てると、5秒間スキルを強める効果が最大5段までたまる。領域の番人は、炎・水・氷・雷の命中を個別に記録し、3回受けた元素への耐性が上がる。攻撃そのものはラボの共通挙動を使用。敵の種類と数、山脊Ⅰと山風Ⅰの陣の切り替えは資料と照合した。 [山脊の公式紹介](https://genshin.hoyoverse.com/en/news/detail/12376) · [山脊の難度別編成](https://paimon.moe/domains/ridge_watch) · [山風のゲーム内編成と報酬](https://game8.jp/genshin/784051)

## 周回報酬

- 全陣を制限時間内に倒すと、選択したセットの聖遺物1個とEXP・モラを受け取る。Ⅰ〜Ⅲは★4、Ⅳは★5。部位は同じ難度の勝利ごとに花、羽、時計、杯、冠の順。itemLvは必要Lvに20を足した値。
- バッグが満杯なら、聖遺物は町の未回収品に入り、EXPとモラは勝利時に入る。時間切れと途中退出のあとも、同じ難度を選んで挑戦できる。保存後は拠点で再開し、受け取った装備・保留品と難度ごとの勝利回数・最速タイムを復元する。
- 新セットは町で装備できる。2部位の試作効果は千岩牢固が最大HP+20%、蒼白の炎が物理ダメージ+25%、天からの贈り物が攻撃命中時の共通ゲージ+1、影に沈む幻が物理耐性低下中の敵への物理ダメージ+25%。新セットの4部位効果は後続。

入場Lv、敵HP・威力、勝利報酬、セットの一部効果、2D地形はラボ用の試作値。敵は既存の代理絵で、背景はラボの仮画像。 [設定データ](../content/artifact-domains.json) · [セット一覧](../content/artifact-sets.json)

Luaで8難度を移動と通常攻撃で制覇し、陣、再戦、満杯時の保留、保存復元、4セットの装備効果を確認した。Chromeで両秘境への往路、Ⅳの手動戦闘、狙ったセットの獲得、保存からの再開を検証した。 [Luaの検証記録](../evidence/artifact-domains-lua.json) · [Chromeの検証記録](../evidence/artifact-domains-browser.json) · [山脊の勝利画面](../evidence/ridge-watch-domain-clear.png) · [山風の戦闘画面](../evidence/windcrown-domain-battle.png)
