# 赤璋巡岳府君・シネアスと通常のヴィシャップ

移即・天虞とシネアスを、対応する通常個体の図鑑、ゲーム内の全身、元素が付いた状態、別角度の動画で見比べた。12点のうち7点は、従来の地方伝説だけの作画記録に加えた通常型の資料。通常型と名付き個体のページにある同じ図鑑画像は1点に数えた。 [確認した画像・動画と出典](../evidence/vishap-legend-references.json) · [前回の作画記録](BRANCH_LEGEND_ART_V2.md)

| 地方伝説 | 共通する形 | ドット絵への反映 |
| --- | --- | --- |
| 赤璋巡岳府君・移即と天虞 | ヴィシャップ・岩と額の橙色、顎の淡い縁、幅のある肩、岩板の重なり、先細りの尾が対応する。付与前の通常型でも体は黄褐色の岩肌。 | 通常型の肩、胴、脚、尾を土台にする。移即は前脚の橙の発光、天虞は前脚の青白い結晶を示す。地面の炎と空中の氷は体の色と分けて見る。現行稿で2体の頭と脚の形が大きく異なる点を次稿で揃える。 [付与前・炎・氷の通常型](https://genshinchronicle.com/gameplay/geovishap-genshin-impact-guide/) · [2体が並ぶ近景](https://gamewith.net/genshin-impact/article/show/43755) |
| シネアス | アビサルヴィシャップ・原種と、濃紺の尖った頭、顎の両側の淡色、太い前脚、高い背の突起が対応する。 | 改稿した待機絵の共用を試す。次稿では額の青い細長い突起、顎の明暗、背と尾の長さを横の資料から詰める。足元の青い円や胸の強い光は戦闘中の見え方として扱う。 [通常型の図鑑と旋回](https://wiki.biligame.com/ys/深海龙蜥·原种) · [シネアスの現地](https://altema.jp/gensin/cineas) |

シネアスの配置比較は左から通常型候補、シネアス改稿、シネアス初稿。左と中央は同じ素材を118px高・同じ接地で描く。赤璋の配置比較は左が移即、右が天虞の現行稿。元PNGと3段階の矩形描画で、色と輪郭を確かめられる。 [シネアスの配置比較](http://127.0.0.1:9009/map-art.html?node=cineas-legend-chamber) · [赤璋の配置比較](http://127.0.0.1:9009/map-art.html?node=chizhang-legend-terrace)
