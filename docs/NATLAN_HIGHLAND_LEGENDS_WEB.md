# 古の聖山とオシカ・ナタの地方伝説

| 戦闘 | 入場Lv | 地図と入口 |
| --- | ---: | --- |
| 微末 | 130 | **M → 古の聖山 → 狩場・任意戦**。東島の石棚の左にある岩棚から西の石広場へ |
| 銅の錠 | 180 | **M → オシカ・ナタ → 狩場・任意戦**。東の遠い岩礁の右の棚から装置の岸へ。光の道で浮遊島に渡り、島の右の棚から遺構へ |

微末の入口は、古の聖山の中央の浮き台から東島へ渡る既存の経路につないだ。戦闘を出ると東島の石棚へ戻る。 [古の聖山と微末への道](https://game8.jp/genshin/635875) · [石広場の現地画面](https://gamerch.com/genshinwiki/913117)

## 浮遊島への光の道

オシカ・ナタの寄港地で、Lv124の依頼「浮遊島への光の道」を受ける。装置の岸に着いたら二つの浮遊装置を **J** の通常攻撃で壊す。光の道が現れたら右の岩棚に上がって **F** で乗る。片方だけ壊した状態もセーブに残る。

浮遊島へはLv124から渡れる。銅の錠の遺構の入口はLv180で開く。渡った後は左の船着き石から **F** で戻れる。依頼を報告すると次の訪問でも光の道を使える。装置の数、通常攻撃で壊す操作と軌道はラボ用の試作。背景は仮画像で、微末と銅の錠の固有技は仕様待ち。 [装置とスピリットウェイの現地画面](https://game8.jp/genshin/655679) · [ラボの移動画面](../evidence/natlan-bronzelock-spiritway.png)

共闘では、古の聖山の昇降機とオシカ・ナタの渡し舟を同じ部屋で移動できる。浮遊装置は各自が壊し、光の道を渡った先で仲間と合流する。 [共闘の道順と検証](COOP_WEB_PREVIEW.md#微末と銅の錠)

## ドット絵とソロ検証

微末は岩の隙間に見える橙色の芯、銅の錠は銅の装甲と長い機械の頭で見分けられる。各3枚。構えと動作は見た目を確認するための素材。 [全6ポーズと16色比較](../evidence/natlan-highland-legends-poses.png) · [画像の参照記録](../evidence/natlan-highland-legends-art-sources.json)

LuaでLv制限、装置一つを壊した状態からの再開、飛行中の一時停止、帰還位置、討伐報酬とセーブを確認した。Chromeで **M** の案内、**J** で装置を壊す操作、**F** での往復、元PNGと軽量16色の表示を確認した。標準の矩形描画から軽量16色へ切り替えると、画面全体の描画命令数は微末で8,465から2,284、銅の錠で10,456から2,698に減った。 [Luaテスト](../evidence/natlan-highland-legends-lua.json) · [ブラウザテスト](../evidence/natlan-highland-legends-browser.json) · [実画面の比較](../evidence/natlan-highland-legends-comparison.png)
