# 座標付きの狩場71区画

[ローカルラボ](http://127.0.0.1:8973/)で本編を開始し、Mで地図を開く。新しく通れる狩場には「試作区画」が表示される。地名で検索すると、戻り先と門の種類、通行Lvが分かる。Sites取込979地点のうち、976地点がラボに接続済み。 [入口と配置の対応表](../sources/map-research/sites-geographic-fields.json)

| 出入口 | 件数 | 試作した通り方 |
| --- | ---: | --- |
| 地上の支道 | 54 | 既存のフィールドから狩場へ寄り道し、同じ門へ戻る。 |
| 上段・坂道 | 3 | 風龍廃墟、スメールの山の遺跡、ドラゴンスパインでは上段の足場から入る。 |
| 地下の通路 | 9 | 荒海、砂漠、ナド・クライ北部など、既存の地下入口から同じ階層の脇道へ入る。 |
| 小舟 | 2 | 無相の岩の周辺から孤雲閣の浜へ、鶴観の浜から離れ小島へ渡る。 |
| 水路 | 2 | フォンテーヌ湖の水中回廊から足場のある狩場へ渡る。水中の道は泳ぎ、狩場は歩いて戦闘する。 |
| 昇降機 | 1 | 海祇島東沖の中継島から池の下へ降りる。 |

すべての狩場から元の入口へ戻れる。通行Lvは既存の入口と設計推奨Lvの高い方に合わせた。例えばLv14の回廊から入る風龍廃墟は通行Lv14、設計推奨Lv13と表示する。既存の門と依頼の進行、ワープ地点・神像873件も検査した。

通常敵は設計の種類・数・Lv・再出現時間を使い、3,140体分を3画面の足場へ配置した。1狩場で最大48体。任意戦53件は一体ずつ脇部屋に置いた。敵のドット絵と挙動は既存素材を仮使用した。背景と地形もラボの試作。原作の階層や入口との一致、狩り効率、本番の3D背景配置には個別の確認が必要。

山脊の見守り方面（10009）、鷹飛びの浜南側（85351）、風止み西側（98500）は、取込元の照合待ちを引き継いだ。Mの地図で「設計中の地点」を選ぶと、3件の位置と入口候補が見える。

## 試走結果

- Luaで全71狩場と任意戦53部屋の往復を確認した。計248方向。68件でレベルが1足りない状態も試し、71件で保存後に元の拠点へ戻れることを確認した。移動試験では被ダメージを抑え、フォンテーヌの戦闘は通常攻撃による撃破と再出現を別に確認した。 [Luaログ](../evidence/sites-geographic-fields-lua.json)
- Chromeでフォンテーヌの水路と鶴観の小舟を往復し、狩場でMを押して現在地と戻り先を確認した。 [Chromeログ](../evidence/sites-geographic-fields-browser.json) · [フォンテーヌの水中地図](../evidence/sites-geographic-water-atlas.png) · [狩場](../evidence/sites-geographic-water-field.png)

Luaは `python -X utf8 test_sites_geographic_fields.py`、Chromeは `node test_sites_geographic_fields.mjs` で検査する。Chromeの検査はLuaの検査で作った作業用セーブを使う。
