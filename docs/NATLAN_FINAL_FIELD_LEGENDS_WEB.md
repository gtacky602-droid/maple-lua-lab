# ナタの岩洞・秘境脇・ざぶざぶ湾の任意戦

**M → ナタ → 狩場・任意戦** で戦闘を選ぶ。3戦ともLv120。入口の近くで **F** を押す。

| 戦闘 | 入口 |
| --- | --- |
| ピーク | 北西の崖先の左の棚 → 星岩の墜落地の西の山腹 → 二段登って岩洞へ |
| 「戦羊」と「鉄爪」 | 火山南の征討入口の右端、または南岸の崖道の左の棚 → 秘境脇の草地 → 広場 |
| 最後のテノチズトク人 | 西島の桟橋の左の棚 → ざぶざぶ湾の浅瀬 |

ピークへの岩道は足場が重なる場所で **Space** を使う。退出すると上段の入口へ戻る。戦羊と鉄爪にはそれぞれのHPと当たり判定があり、二体を倒すと一組分の報酬と討伐記録が付く。片方だけ倒して退出した場合は再入場で二体とも復帰する。ざぶざぶ湾は歩ける浅瀬で、退出すると桟橋の棚に戻る。

任意依頼「岩洞と秘境脇の道標」はナタ拠点で受けられる。山腹の上段と秘境脇の草地で、それぞれ **G** で調べる。戦闘地点は固有名に対応する公式地図のマーカーを参照し、道と足場、依頼はラボ用に作った。背景は仮画像。固有技は仕様待ち。 [ピークの山腹と岩洞](https://gamewith.net/genshin-impact/article/show/54907) · [戦羊と鉄爪の秘境前](https://gamewith.net/genshin-impact/article/show/55053) · [ざぶざぶ湾の現地画面](https://gamewith.jp/genshin/article/show/511996)

## ドット絵と検証

A案の大きな色面を参考に、ピークは暗い角と白い牙、戦羊は湾曲した角、鉄爪は金色の腹と頭の飾り、テノチズトク人は幅広い帽子と暗い眼窩で描き分けた。4体それぞれに待機と見た目確認用の構え・動作を制作した。 [全12ポーズと16色比較](../evidence/natlan-final-legends-poses.png) · [画像の参照記録](../evidence/natlan-final-legends-art-sources.json)

LuaでLv制限、帰還位置、二体の個別HPと一組分の報酬、再挑戦、セーブからの復元を確認した。Chromeで **M** の案内、**G** の調査、**F** の入退場、元PNGと軽量16色の表示を確認した。標準の矩形描画から軽量16色へ切り替えたときの画面全体の描画命令数は、ピークで9,475から2,666、戦羊と鉄爪で7,763から1,974、テノチズトク人で6,586から1,838に減った。 [Luaテスト](../evidence/natlan-final-legends-lua.json) · [ブラウザテスト](../evidence/natlan-final-legends-browser.json) · [実画面の比較](../evidence/natlan-final-legends-comparison.png)
