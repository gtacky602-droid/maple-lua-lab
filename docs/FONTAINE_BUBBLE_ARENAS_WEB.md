# 極彩色のルケアとシャサニョン

[ローカルLuaラボ](http://127.0.0.1:8985/)でMを押し、フォンテーヌの「狩場・任意戦」で選ぶ。両方ともLv100。門の深さでFを押す。上下左右で泳ぎ、Jで水撃、SpaceかShiftで急回避する。

| 挑戦 | 入口 | 攻略の目印 |
| --- | --- | --- |
| 極彩色のルケア | 水門西の深い棚 → リフィー・ルケアの彩り棚 | ひれをたたんだら、オレンジの予告と同じ深さを本体が突進する。上下にずれる二連弾と、上下同時の泡は空いた深さへ移る。 |
| シャサニョン | 湾の南の沈水溝 → モルテ・シャサニョンの泡室 | K印のある泡が正面の近くに来たらK。泡が引き返して本体に当たる。オレンジ色の泡は泳いでよける。 |

ルケアの共闘は水門西の深い棚で部屋を作る。本体と突進の位置を共有し、命中は各キャラの深さと位置で決まる。シャサニョンは、調査の進み具合が異なる仲間も塔外・塔内の各入口から同じ部屋に入れる。泡を返した人に命中と貢献が付く。 [ルケアの戦闘画面](COOP_WEB_PREVIEW.md#消えゆく老兵ドアーチュルケアの水中共闘) · [シャサニョンの塔外と塔内](COOP_WEB_PREVIEW.md#シャサニョンと魔剣クルージュの水中共闘)

## モルテの塔の水門調査

フォンテーヌ廷の観測係からLv94で受ける。湾の南の沈水溝で外圧計をGで調べると、Fで塔の圧力室へ潜れる。圧力室で内側の水門をGで調べ、Fで沈水溝に戻り、フォンテーヌ廷で報告する。報告後は塔外の泡室への直通門が消え、圧力室から塔の下層へ入る道と退路が開く。地図の道順と戦闘背景も切り替わる。討伐記録は同じシャサニョンに続けて保存する。

報告前にも塔外からシャサニョンと戦える。原作の塔外と塔内の位置関係を参考にしたラボ用の探索依頼で、水圧計・弁・報告条件・二つの仮背景はラボの設計。戦闘のHP、泡の射程・威力・タイミング・報酬も試作値。 [既存の配置案](../design/world/encounters.json) · [塔外と塔内のゲーム画面](https://altema.jp/gensin/shasanyon)

## 素材と試走

二体とも待機・構え・攻撃の3枚。ルケアは大きな扇ひれと小さな胴、シャサニョンは裾が反った傘と下へ流れる触腕。名前付きのゲーム画面と一般種の2Dアイコンを確認して描いた。 [6ポーズの比較](../evidence/fontaine-bubble-art-poses.png) · [素材の参照](../evidence/fontaine-bubble-art-sources.json)

LuaでLv境界、ルケア本体の移動と命中、泡が戻りきった時点のダメージ、オレンジの泡と早すぎるK、依頼4段階、報告前後の門と背景、再戦、報酬とセーブを確認した。通常操作を使う単独の自動試走でルケア70.68秒、シャサニョン20.55秒。シャサニョンでは泡を6回返した。 [Luaの記録](../evidence/fontaine-bubble-lua.json)

ChromeでMの道順、Fでの入退場、Gでの調査、Kで泡が戻って当たる順序、報告後の入口と背景、元PNGと軽量16色の同一フレームを確認した。 [Chromeの記録](../evidence/fontaine-bubble-browser.json) · [ルケアの突進](../evidence/luachra-dash-field.png) · [軽量16色](../evidence/luachra-dash-light.png) · [塔外のシャサニョン](../evidence/chassanion-outside-field.png) · [軽量16色](../evidence/chassanion-outside-light.png) · [報告後の塔内](../evidence/chassanion-inside-field.png)
