# 港から乗る帰りの船と途中寄港

[ローカルLuaラボ](http://127.0.0.1:8974/)で本編を開始し、港の門へ歩いてFキーを押す。航海中は画面に行き先と残り時間が出る。Mキーの地図にも船の行き先があり、地図を開いている間は航海が一時停止する。到着時は自動で着岸する。表の秒数はラボ内の航海時間。

| 経路 | 通行Lv | ラボでの通り方 |
| --- | ---: | --- |
| 璃月港 ↔ 稲妻・離島 | 40 | 両方向とも30秒。離島の西側に璃月行きの乗り場がある。 |
| ナタ港 ↔ ナド・クライ到着港 | 120 | 両方向とも90秒。出航30秒から50秒未満に甲板中央からオシカ・ナタへ下船できる。 |
| 港北の細い島 ↔ オシカ・ナタ | 120 | ナタ港で北行きに乗り継ぐ。寄港地では西側がナド・クライ行き、東側がナタ行き。どちらも再乗船から40秒で到着する。 |
| 沈玉の谷 ↔ フォンテーヌ東湾 | 88 | 谷北の埠頭から両方向45秒の外海便。下部連絡桟橋から昇降機で東湾へ上がり、水中階段から水中の棚へ向かう。 |
| パハ島 ↔ ナド・クライ北部沿岸 | 129まで | 高い桟橋と北部の港を5.2秒の連絡舟で往復する。 |
| 白虹峠の終着駅 ↔ 雪線の切通し | 140 | 駅裏の保守歩廊を通り、谷沿いに戻る。 |

オシカ・ナタの寄港は任意。下船すると航海のタイマーが止まり、寄港地では時間を気にせず探索できる。航海中にセーブして読み込むと最後に乗った港か寄港地から再開し、依頼と訪問の記録を引き継ぐ。船を早く降りたい場合は甲板西端の「航海を中止し出発港へ」を使う。ワープは着岸後に使える。

南行きの寄港時間、沈玉・フォンテーヌ便の乗り場・時間、パハ島の渡し舟と駅裏の歩廊はラボ用の試作。ナタ発の出航・途中下船・寄港地から再乗船する流れは既存の企画を基準にした。海と港の背景は共用の仮画像。 [出典と接続データ](../sources/map-research/sites-return-ferries.json) · [船旅の企画](../sources/20261113-master.md)

## 試走

- Luaで6組、重複を除いた39方向を確認した。6便が時間どおりに着岸し、南行きでも寄港の開始前・終了後は下船できないこと、寄港を通過できること、再乗船後に保存すると寄港地から再開することを確認した。既存の寄港依頼も回帰検査した。 [Luaログ](../evidence/sites-return-ferries-lua.json)
- Chromeで離島から璃月までの30秒便と、オシカ・ナタで乗り直してナタに着く40秒の航海を確認した。 [Chromeログ](../evidence/sites-return-ferries-browser.json) · [璃月行きの地図](../evidence/sites-ferry-liyue-atlas.png) · [ナタ行きの甲板](../evidence/sites-ferry-natlan-deck.png)
- 新規冒険をLv120まで進めたセーブで、ナタ港からナド・クライ行きに乗った。Luaで90秒の自動着岸と、オシカ・ナタで下船して乗り直す40秒の区間を確認した。航海中のセーブはナタ港から再開し、M地図を開くと航海時間が止まる。 [Lv120の連続試走](../evidence/natlan-fresh-route.json) · [北行きの道順](../evidence/natlan-fresh-nod-atlas.png)

Siteの経路候補421組のうち128組を試作として実装し、274組を既存ルートで確認した。残る19組は発見・専用ゲート8組と、屋外の道筋・階層11組。 [地域の接続台帳](../design/world/atlas-route-plan.json)

Luaの検証は `python -X utf8 test_sites_return_ferries.py`。そこで作る検証用セーブを使い、8974のラボで `node test_sites_return_ferries.mjs` を実行する。
