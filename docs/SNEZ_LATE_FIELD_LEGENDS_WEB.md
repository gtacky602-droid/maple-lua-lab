# 慈悲深き聖原とノヴォキッチェヴの地方伝説

**M → スネージナヤ → 狩場・任意戦** から古代種の巣穴を案内できる。ノヴォキッチェヴ側の2戦は **M → ノヴォキッチェヴ（構造未確定） → 狩場・任意戦**。3戦とも地下の表示からも選べる。入口は **F**、足場へは **Space**、調べる場所では **G**。

| 戦闘 | 入場Lv | ラボの通り方 |
| --- | ---: | --- |
| 古代種・カチカチネズミ | 160 | 雪の町で「裂け目の三匹」を受ける。北の海岸へ下りる坂の左の岩棚から裂け目へ。入口で道具を調べ、地上・中段・高い岩棚で一匹ずつ助ける。 |
| 災禍古樹 | 198 | ノヴォキッチェヴの拠点で「晶鉱樹洞の水路」を受ける。旧線の下層・東口の上段から鉱区へ。水位表を確認し、左の足場から水路へ進み、上の棚で水門を調べる。 |
| 荒くれの異怪の獣衆 | 200 | 拠点で「北の街灯」を受ける。鉱区の水位表を確認したら、分岐の右から北の路地へ。街灯の案内人と、上の足場にある見張り台を調べる。 |

## 原作の出現条件とラボでの試作

古代種は原作で「大地に裂け目を」を進め、慈悲深き聖原の裂け目で三匹にアイススグリを渡して救出すると出現する。ラボでは道具と餌の準備、三匹の救出を順に **G** で進める。背景は雪の洞窟の仮画像。 [裂け目と三匹の現地画面](https://gamewith.jp/genshin/article/show/586864)

災禍古樹は「すべての河川を枯らさぬために」の先の支流に、獣衆は「奇妙な灯」の先の市街地に出現する。ラボでは水路の点検と北の街灯の聞き込みでそれぞれの通路を開く。両方とも旧線の東口から同じ分岐を使い、通行条件を満たした後は帰り道も使える。 [晶鉱樹洞の地下地図](https://gamewith.jp/genshin/article/show/586801) · [北の市街地と獣衆3名](https://gamewith.jp/genshin/article/show/586825)

獣衆の3名はそれぞれHPと当たり判定を持つ。ラボでは開始時から3体が並び、全員倒した時点で討伐記録と報酬が1回入る。日替わりの先発、戦闘途中の合流、各個体の技は仕様を詰める段階で扱う。

## 通常個体との見た目の比較

5体のために、肖像、戦闘画面、通常種の全身、任務版など計21枚を照合した。5体それぞれに、待機・構え・動作の3ポーズを用意した。 [参照画像と照合結果](../evidence/snez-late-field-legends-art-sources.json) · [全15ポーズと16色版](../evidence/snez-late-field-legends-poses.png)

- **古代種・カチカチネズミ**は通常種の丸い胴、短い脚、白い頬を残した。名付きの現地画像にある金色の背棘と長い牙も描いた。
- **災禍古樹**は宿老の樹霊と共通する長い手足と枝分かれした幹を残した。赤い結晶のある任務版は地方伝説と正面の輪郭が一致し、この素材を共用できる。背面の結晶の数と枝先は資料で確認できていない。
- **獣衆3名**は通常型の装備を基に、スタヴローギンの木筒、バルバラの長い耳と脚の刃、ヴェルホヴェンスキーの採鉱具で見分けられるようにした。黄色い鉢巻は名前付きの肖像に合わせた。

## 地図と進行の確認

戦闘地点は公式マップの印 `2:107102`、`2:107100`、`2:107101` の座標を使った。ノヴォキッチェヴでは北側の印も含めて同じ縮尺で地図に収め、各戦闘への道順とレベル、開放条件を表示する。 [印の照合記録](../design/world/encounters.json)

Luaで3つの依頼、古代種の救出途中の保存復元、入場レベル、往復と高い足場への帰着点、獣衆の一部討伐で報酬が出ないこと、3戦の討伐記録と報酬を確認した。 [Lua試走](../evidence/snez-late-field-legends-lua.json)

Chromeで地下地図からの案内、上の足場への移動、3件の報告、5体のPNG表示と軽量16色を確認した。同じフレームを静止し、画面全体の描画命令数を比較した。 [Chrome試走](../evidence/snez-late-field-legends-browser.json) · [同じ場面の描画比較](../evidence/snez-late-field-legends-comparison.png)
