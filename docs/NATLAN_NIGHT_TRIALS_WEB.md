# 先人の神殿の夜魂の試練

**M → ナタ → 狩場・任意戦** を開き、試練を選ぶ。経路の最後に「黒曜石の柱」と表示される。柱の近くで **F** を押すと試練に入る。

| 試練 | レベル | 柱までの道 |
| --- | ---: | --- |
| アンデッド | 118 | テケメカンの谷・南端の桟道で上段へ跳び、先人の神殿の東の池へ |
| シェマリの陰 | 116 | テケメカンの谷・段丘南の道から、先人の神殿の北西の崖下へ |

試練の左端に出口がある。**F** で元の柱まで戻り、再び触れるとHPが満タンの個体でやり直せる。全滅時も元の柱へ戻る。討伐記録はセーブに残り、読み込み時はナタ拠点から再開する。レベル不足でも入口の地上ルートは通れる。

原作の入口の観察をもとに、ラボの既存フィールドへ枝道をつないだ。2体の戦闘とレベルは試作で、固有技は仕様待ち。背景は夕闇の岸辺の仮画像。 [池と崖下の位置・柱](https://www.sportskeeda.com/esports/all-10-genshin-impact-night-s-trial-locations-in-natlan) · [シェマリの陰の入口](https://www.hoyolab.com/article/34271514)

## ドット絵

アンデッドは青白いカピバラの丸い胴、短い四足、丸耳。シェマリの陰は大きく張り出す翼と上の輪で見分けられる。浮遊位置は共通の床ピボットを基準にし、待機時の当たり判定も胴の下端に合わせた。2体の各3枚と、共通の黒曜石の柱1枚を実装した。 [噴流・大霊の化身の公式紹介](https://genshin.hoyoverse.com/en/news/detail/125446) · [画像の参照記録](../evidence/natlan-night-trials-art-sources.json)

## 検証

- Luaでレベル不足時の入口、柱の往復、移動中に一時停止して再開する処理を確認した。
- Luaのテストで両キャラのHPを0にし、元の柱へ戻ることを確認した。通常攻撃での討伐、1回分の報酬とセーブ、再挑戦時のHP初期化も確認した。 [Luaテスト](../evidence/natlan-night-trials-lua.json)
- ChromeでMの地図とFの往復、柱の表示、同じフレームの元PNG・軽量16色を確認した。標準の矩形描画から軽量16色に切り替えると、画面全体の描画命令数はアンデッドで7,088から1,883、シェマリの陰で6,593から1,783に減った。 [ブラウザテスト](../evidence/natlan-night-trials-browser.json) · [表示比較](../evidence/natlan-night-trials-comparison.png) · [黒曜石の柱](../evidence/natlan-night-trial-totem.png)
