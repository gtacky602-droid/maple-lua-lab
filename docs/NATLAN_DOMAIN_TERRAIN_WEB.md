# ナタの秘境へ続く5つの狩場

冒険中に **M → ナタ → 狩場・任意戦** を開き、目的地を選ぶと道順が出る。5つの狩場はLv119から入れる。足場を登るときは **Space**、足場から降りるときは **S＋Space**、門を通るときは **F** を使う。

| 狩場 | 現地での目印 | ゲーム画面 |
| --- | --- | --- |
| 東の秘境周辺 | 川沿いに4段の足場が続く。入口近くの水辺から滝裏へ、右奥の地上からは2つの脇部屋へ進める。 | [滝前の段丘](../evidence/natlan-domain-waterfall-terrain.png) |
| 南西の秘境周辺 | 源泉北の岩径から入り、左の岩棚に跳び上がると「二つの鍵の洞窟」へ入れる。洞窟を出ると同じ岩棚に戻る。 | [トヤックの洞口](../evidence/natlan-domain-cave-terrain.png) |
| 北西の秘境周辺 | 断崖南の道から、高低差の大きい岩棚を左へ進む。ヒルチャールレンジャーの脇部屋は、崖の下段の棚から入る。 | [クァワカンの断崖](../evidence/natlan-domain-cliff-terrain.png) |
| 中央の秘境周辺 | 岩壁の細道を抜け、大霊の化身がいる祭壇へ入れる。 | [中央の祭壇](../evidence/nat-spirit-alcove-comparison.png) |
| 火山南の征討入口 | 石のアーチを望む海岸に低い足場が並ぶ。「戦羊」と「鉄爪」の広場に向かうときは、右端の門から秘境脇の草地へ進む。 | [アトクパンの南岸](../evidence/natlan-domain-shore-terrain.png) |

5つの狩場では既存の画像を使用し、滝裏の燃素洞、蝕土者の岩室、蛍術師の野営地、二つの鍵の洞窟、大霊の祭壇、レンジャーの寝床、南岸の草地の7地点に仮画像を追加した。M地図で選んで「この地点の背景を比較」を開くと、キャラを元PNGに固定したまま背景を5段階で見比べられる。[滝裏](../evidence/nat-falls-cavern-comparison.png) · [二つの鍵の洞窟](../evidence/nat-spring-key-comparison.png)

ナタ12地点の単体Luaファイルの合計は4,096矩形で218,492 B、5,120矩形で301,598 B、6,144矩形で365,250 B。保存したファイルは1個の共通復号器で読める。復号器は35,260 Bで、この合計には含まない。[全ファイルの実測](../evidence/scenery-download-tiers.json) · [5狩場と7地点の往復](../evidence/natlan-domain-terrain-browser.json)

足場と門の位置は横スクロール用に設計した。背景にはラボの仮画像を使い、プレイヤーと敵が乗る足場はLuaで判定する。本番の背景は3Dで配置する方針。

## ドット絵を見比べる

ラボの「マップ配置比較」で地点を選び、**この地点の本編配置を読み込む** を押す。左に元PNG、右に軽量版が同じ座標で並ぶ。カメラを動かすと両方が一緒に移動する。「軽量設定」で標準・中間32色・最軽量16色を切り替えられる。

下の数値は、各地点の敵48体を描く矩形の総数。東の秘境で同じ位置を比べると、16色でも聖骸牙獣の角と巻いた尾、人型の笠と武器は見分けられる。顔の細い線と服の陰影は粗くなる。 [同じ画角での画像比較](../evidence/natlan-domain-art-compare.png) · [Chromeの計測値](../evidence/natlan-domain-art-compare.json)

| 狩場 | 標準 | 最軽量16色 | 削減率 |
| --- | ---: | ---: | ---: |
| 東 | 139,520 | 40,664 | 70.9% |
| 南西 | 123,168 | 35,264 | 71.4% |

## 移動と依頼の検証

Luaで4地点それぞれの敵48体の接地を確認し、通常ジャンプで岩棚を往復した。Chromeでは中央の秘境も含む5地点で、Mの現在地と道案内を確認し、門を計20回通った。 [足場と往復の記録](../evidence/natlan-domain-terrain-lua.json) · [Chromeでの移動とM地図](../evidence/natlan-domain-terrain-browser.json)

ナタのLv100のセーブから6件の依頼を報告し、Lv120でナド・クライに到着。セーブを読み直して次の依頼を受注できた。 [ナタを通した記録](../evidence/natlan-fresh-route.json)
