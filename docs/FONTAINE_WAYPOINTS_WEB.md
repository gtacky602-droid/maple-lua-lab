# フォンテーヌと往日の海のワープ地点・神像

[ローカルLuaラボ](http://127.0.0.1:8966/)の「本編ルートへ」から開始する。スメールからフォンテーヌへはLv80で進める。地上では水色の門に近づいてF、水中ではWASD・方向キーで門と同じ深さまで泳いでF。調査の目印の近くではGを押す。到達済みの移動先はワープ一覧で地区・階層ごとに選べる。

公式地図からフォンテーヌ100地点と往日の海17地点を取り込み、既存6ステージと新設111ステージに割り当てた。階層ID付きはフォンテーヌ42件、往日の海7件。フォンテーヌ湖、ノストイの遺構、往日の海など37ステージに上下左右の遊泳を実装した。 [HoYoLAB公式テイワットマップ](https://act.hoyolab.com/ys/app/interactive-map/index.html) · [地点と階層の照合記録](../sources/map-research/fontaine-marker-review.json)

地上・水中を含めて153本の道を往復できる。うち船7本、昇降機15本、水路27本。ノストイ沖から海底の水路を通って往日の海へ移動できる。水路の区間は乗り継ぎ時間があり、遊泳ステージではキャラを操作して門へ寄る。

M地図の「狩場・任意戦」では、ベリルの入江の河原Lv91とベリルの山裾Lv95を探せる。通常敵は河原に42体、山裾に45体で、どちらもラボ用の試作。既設のベリルの秘境周辺はLv99。 [試走と討伐EXP](balance/EXPERIENCE_MONSTER_QUEST_V02.md)

## 検証範囲

公式資料と照合した項目はID、座標、種別、階層ID。地点名、水中門の深さ、足場、通路、レベル、仮背景はラボ用の設定。遊泳ステージでは探索と調査を実装した。水中表示は既存のドット絵と気泡を使用。潜る時に攻撃ポーズを解除し、技の待ち時間は遊泳中も進む。本番の背景は3D配置で制作する方針。

- Luaで117地点の153本の道を両方向に通り、クエスト4件の報告と保存復元を確認した。深さが合わない門は通れず、一時停止中は泳げない。ロード後は訪問済みの水中へワープできる。 [Luaの検証結果](../evidence/fontaine-waypoint-test.json)
- Chromeで水深を合わせて門を通り、二つの標識の依頼と往日の海の調査を報告した。ノストイ沖から往日の海に入り、再読み込み後にフォンテーヌ湖の水中へワープできた。 [Chromeの検証結果](../evidence/fontaine-waypoint-browser.json) · [フォンテーヌ湖](../evidence/fontaine-waypoint-swim.png) · [往日の海](../evidence/bygone-waypoint-swim.png)

Luaの検証は `python -X utf8 test_fontaine_waypoints.py`。その実行で用意される `work/fontaine-waypoint-browser-save.json` を「JSONを読み込んで再開」で開くと、Lv99の水辺の広場から確認できる。Chromeの検証は `node test_fontaine_waypoints.mjs`。別ポートの場合は `LAB_URL` を指定する。
