# 織房の連続依頼

璃月港の依頼欄で受注し、「この依頼を追跡」を押すと、調査のたびに次の目的と門の案内が変わる。港の右側にある「布巻きの作業路」への門から出発する。

## 織房の停電調査（Lv32）

1. 作業路で点検札を `G` で調べる。
2. 足場の下で `Space` を長押しして上がり、ヒューズ箱を `G` で調べる。
3. 作業路の右の門を `F` で通り、糸道の配電室で停止時刻を記録する。
4. 作業路を経由して港へ戻り、「報告」を押す。

## 糸道に灯を戻す（Lv34）

1. 停電調査を報告してから受注する。
2. 配電室で遮断器を操作し、右の門から埋もれた織房へ入る。
3. 左右の杼を破壊して芯を攻撃し、双杼織機を止める。
4. 織房の右の門から配電室へ戻り、試験灯を `G` で点灯する。港で報告する。

先に単独依頼で織機を倒した場合は、織機が復帰してから討伐の段階を進められる。各依頼の報酬と開放レベルは試作値。作業路と配電室の背景は仮画像で、足場、調査地点、門はLuaが処理する。

## 検証

`python test_threadline.py` は、調査地点の順序と高さ、門の開放条件、依頼中の保存と再開、討伐後の進行、報酬を一度だけ受け取れることを確認する。ラボを起動して `LAB_URL` にURLを設定し、続けて `node test_threadline.mjs` を実行すると、Chrome上で受注から復旧報告まで同じ流れを操作できる。
