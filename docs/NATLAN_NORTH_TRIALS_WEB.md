# 硫晶の支脈とウィッツトリの丘の夜魂の試練

ナタ拠点の依頼を受け、**M → ナタ → 狩場・任意戦** で試練を選ぶ。地図には途中の昇降機、岩戸の条件、黒曜石の柱までの経路が出る。柱の近くで **F** を押すと試練へ移動する。

| 試練 | レベル | 入口の依頼 |
| --- | ---: | --- |
| トゥラカルワスクアウィトゥル | 112 | 共鳴晶岩の順番 |
| イチカウイピリの庇護 | 118 | 大岩に帰る三つの光 |

## 共鳴晶岩の順番

「万火のほとぎ周辺・岩の窪地」の昇降機で地下へ降り、共鳴晶岩の窪みに入る。刻印板に示された順に、三つの石の近くで **G** を押す。中段にある石には **Space** で登る。順番を間違えたら最初から灯せる。三つそろうと岩戸が開き、洞窟の奥の柱へ進める。

## 大岩に帰る三つの光

「万火のほとぎ周辺・北端の尾根」から川辺に入る。木の根元、結晶の岩棚、土の高台の三方向を好きな順に回る。それぞれの奥を **G** で調べ、ついてきた光を来た道で川辺へ連れて戻る。三つとも戻ると大岩が割れ、黒曜石の柱が現れる。放した光と大岩に戻った光の進行は、セーブして続けられる。

仕掛けはラボ用の試作で、依頼の報告前でも現地で試練に入れる。ソロでは退出・全滅時に元の柱へ戻り、再挑戦時に敵のHPが全快する。協力部屋では仕掛けを各自で進め、柱の先で合流する。全員が敗北すると初期化し、出口から離脱した場合は残りHPを保持する。削岩刃と飛び石、根柱と葉の波はラボ用の試作攻撃。背景は仮画像。 [共闘の道順と検証](COOP_WEB_PREVIEW.md#トゥラカルワスクアウィトゥルとイチカウイピリの庇護) · [谷底と共鳴の仕掛けの参照](https://gamewith.net/genshin-impact/article/show/47976) · [大岩の三方向の参照](https://game8.jp/genshin/655676)

## ドット絵と検証

トゥラカルワスクアウィトゥルは青い霊体の約3頭身、丸い仮面と歯のある円盤状の削岩刃。イチカウイピリの庇護は緑の葉束と金の紋を持つ浮遊体にした。各3枚を同じ床ピボットにそろえ、待機絵の床からの空きを当たり判定に反映した。 [画像の参照記録](../evidence/natlan-north-trials-art-sources.json)

Luaで順番を間違えたときのやり直し、光の途中セーブ、実際に戻った枝道だけの進行、両依頼の報酬と両試練の討伐記録を確認した。Chromeで昇降機、Mの案内、Gでの仕掛け操作、Fでの入退場を確認した。標準の矩形描画から軽量16色に切り替えたときの画面全体の描画命令数は、トゥラカルワスクアウィトゥルの場面で8,372から2,249、イチカウイピリの庇護で6,836から1,728に減った。 [Luaテスト](../evidence/natlan-north-trials-lua.json) · [ブラウザテスト](../evidence/natlan-north-trials-browser.json) · [元PNGとの表示比較](../evidence/natlan-north-trials-comparison.png) · [三つの光がそろった川辺](../evidence/natlan-witztli-three-lights.png)
