# Sitesの設計区画32件の試走

[ローカルラボ](http://127.0.0.1:8973/)で本編を開始し、Mの地図から発見済みの地域を選ぶ。Sitesの32件は、取込元で公式座標が未設定の区画。本作独自の配置と通行条件を設計し、6件を既存ステージに対応させ、26件に新しい地形と門を設けた。地図上の位置は地域内の関係を示す略図。 [32件の対応とルート](../sources/map-research/sites-slot-trails.json)

| 地域 | 通行の試作 |
| --- | --- |
| 金リンゴ群島 | 船着き場から別の3島へ小舟で渡る。島内は徒歩。危機の島とプリン島では高い足場の門へ跳ぶ。 |
| ヴェルーリヤ・ミラージュ | 瓶の模様を合わせて広場へ入る。既存の乗車券を報告してから花棚の停留所を使える。既存の水車前行きと、試作の遊園行きがある。 |
| シムランカ | 絵本の折り目を通って森と星軌の駅へ。星軌便で王城へ渡り、砕けた海は渡り台を使う。 |
| ナド・クライ特別地域（仮） | 既存の入口から霜道と見張りの林へ進む。谷は石段、凍った水路は昇降機と地下回廊でつながる。極光境界の戦いは任意。 |

到着広場や既存の駅では、以前の依頼で利用できた通行Lvを維持した。新設区画は取込元の推奨Lvを使う。狩場の通常敵860体分を登録し、1フィールドに最大48体、3画面に分けて配置した。入口と出口の手前には巡回が入らない帯を設けた。任意戦6区画の敵は既存の絵と汎用挙動を仮使用している。背景もラボ用の仮画像を使用した。

## 確認したこと

- Luaで32区画と設計28経路の両方向を試走。乗車中の自動到着や寄港を含めて62方向の遷移を確認した。試走では移動を戦闘と切り分け、通常攻撃による撃破・再出現は別に確認した。隠し世界の入口、依頼の進行、帰還先を検査し、星軌便の乗車中に保存した場合は出発駅で再開することを確認した。 [Lua検証](../evidence/sites-slot-trails-lua.json)
- Chromeで金リンゴ群島の地図、小舟の往復と狩場の出現数、シムランカの星軌便の往復を確認した。走行中もMの地図で行き先を確認できる。途中停車のない便の画面表示と、従来のトロッコの途中下車も検査した。 [群島の地図](../evidence/sites-slot-islands.png) · [桟橋の狩場](../evidence/sites-slot-dock.png) · [Chrome検証](../evidence/sites-slot-trails-browser.json)

取込元979件のうち905件がラボに接続済み。内訳は公式のワープ地点・神像873件と、今回の設計区画32件。座標付きの残り74件は、地図の「設計中の地点」に入口候補がある。 [世界の接続台帳](../design/world/atlas-route-plan.json)
