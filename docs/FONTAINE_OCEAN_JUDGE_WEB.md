# オーシャン巡回法官の水中任意戦

[ローカルLuaラボ](http://127.0.0.1:8980/)で本編を開始する。Mで地図を開き、フォンテーヌの「狩場・任意戦」から「中央湖・巡回法官の水底」を選ぶ。「中央湖の深い標識」の東にある門と深さを合わせ、Lv100でFを押す。戦闘中も入口側のFで退ける。元の門の深さに戻り、入り直すと新しい一戦が始まる。 [配置案](../design/world/encounters.json)

- WASD・方向キーで上下左右に泳ぐ。急回避は Space または Shift。移動入力が入っている間はその方向に急回避する。
- 近い深さで相手を向いてJを押すと、水撃が届く。長押しで繰り返せる。水中の戦闘区画では画面の「水撃」「急回避」も使える。
- 横に長い枠は、固定した深さを伝わる波の予告。上か下に離れる。二つの狭い枠は番号順に噴き上がる。
- 大きい爪を立てて装甲を閉じたときは、背後に回るか、装甲が開くまで待って水撃を当てる。

予告・水撃・急回避・敵HP・報酬はラボ用の試作値。討伐記録は通常のセーブに残り、戦闘中の一時状態は退却や全滅で消える。討伐はこの任意戦の報酬として記録される。全滅時は水辺の広場へ戻る。

## ドット絵

Astra 6.2の別チャットで、公開されたゲーム画面7点の正面・斜め・攻撃姿勢を確認した。ラボの絵は、段のある甲羅と左右で大きさの違う爪を持つ独自のデザイン。待機・構え・攻撃の3ポーズを甲羅の中心で揃え、泳ぐ位置に置いた。透過PNGは約38KBで、戦闘画面に初めて表示するときに転送する。水中背景はラボ用の仮画像。旅人と同行者は既存のドット絵で泳ぐ。 [参照画像と採用理由](../evidence/ocean-judge-art-sources.json) · [3ポーズと縮小比較](../evidence/ocean-judge-art-poses.png) · [ラボの待機絵比較](http://127.0.0.1:8980/bosses-art.html?q=%E3%82%AA%E3%83%BC%E3%82%B7%E3%83%A3%E3%83%B3%E5%B7%A1%E5%9B%9E%E6%B3%95%E5%AE%98)

## 検証

Luaで通行Lv100、地図の案内、退路と同じ深さへの帰着、水撃の向きと深さ、急回避の間隔、三つの予告と命中、報酬の重複防止、セーブ、全滅時の帰還を確認した。装甲を閉じた間の同条件の水撃は正面6、背後24。水撃・遊泳・急回避の自動入力で最大HPから29.88秒、残りHP65で討伐した。 [Luaの記録](../evidence/ocean-judge-lua.json)

ChromeでM・F・J・Spaceを操作し、戦闘への入場、水撃、上下の急回避、退却と再入場、待機素材のギャラリーを確認した。同じ停止場面で標準矩形から16色へ切り替えると、全体の描画指示は7,679件から2,044件。 [Chromeの記録](../evidence/ocean-judge-browser.json) · [戦闘PNG](../evidence/ocean-judge-field.png) · [戦闘の軽量16色](../evidence/ocean-judge-light.png)

再検証は `python -X utf8 test_ocean_judge.py` を実行し、8980のラボで `node test_ocean_judge.mjs` を実行する。
