# 沈玉の谷と往日の海の地方伝説

[ローカルLuaラボ](http://127.0.0.1:9016/)で本編を開始する。Mの地図で「沈玉の谷」か「往日の海」を選び、「狩場・任意戦」で挑戦場を探す。入口の黄色い道順をたどり、門の近くでFを押す。

| 挑戦 | 通行Lv | 入口と回避 |
| --- | ---: | --- |
| 赤璋巡岳府君・移即と天虞 | 95 | 沈玉の谷・谷の南東の草段から赤璋の丘へ。炎の踏み込みと氷の輪を見て動く。二つの予告が出たら、番号順に攻撃が来る。どちらの体への攻撃でも共有HPが減る。 |
| シネアス | 160 | 「珊瑚の間の水の通り道」を報告してから、往日の海・東端の別室へ。乾いた石床で、横に伸びる突進や足元に出る潮の予告を避け、身を低くして止まる間に反撃する。 |

入口寄りは安全。戦闘中も入口のFから調査路へ戻れる。再挑戦は入り直すと始まり、倒した部屋で待つ間は再出現しない。共有HPの二体は合わせて一戦としてEXP、モラ、討伐記録を一度受け取る。記録はセーブに残る。途中で保存した場合は地域の拠点で再開する。2戦とも日次や本編の必須討伐から外れた任意戦。 [配置案と根拠](../design/world/encounters.json)

攻撃、HP、共有HP、調査報告の条件、足場はラボ用の試作。赤璋の2体はヴィシャップ・岩と共通の体型で、待機・構え・攻撃を描く。シネアスは肩と前脚の形を公開画像で照合した改稿を使う。背景はラボの仮画像で、実機の3D配置は別途検証する。 [赤璋の共通体型と3ポーズ](VISHAP_LEGEND_BASE_REFERENCES.md) · [シネアスの参照画像と採用した特徴](BRANCH_LEGEND_ART_V2.md)

素材比較では、採用した待機絵と旧稿の元PNG・軽量版を見比べられる。 [赤璋巡岳府君の待機絵](http://127.0.0.1:9016/bosses-art.html?q=%E8%B5%A4%E7%92%8B%E5%B7%A1%E5%B2%B3%E5%BA%9C%E5%90%9B) · [シネアスの待機絵](http://127.0.0.1:9016/bosses-art.html?q=%E3%82%B7%E3%83%8D%E3%82%A2%E3%82%B9)

## 検証

- LuaでLvと調査報告の境界、6行動の予告と命中、戦闘中の退路、報酬の重複防止、セーブ後の討伐記録を検査した。別の検査では移動・ジャンプ・通常攻撃の入力だけで、設定した最大HPから討伐まで確認した。赤璋巡岳府君は82.18秒で残りHP7、シネアスは103.73秒で残りHP140。操作を自動化したローカルLuaでの結果。 [Luaログ](../evidence/sites-branch-legends-lua.json)
- 最初の予告が出た同じLuaフレームで、標準矩形から軽量16色に切り替えると、赤璋巡岳府君は12,146→3,568件、シネアスは6,365→1,777件。 [標準・軽量の計測](../evidence/sites-branch-legends-lua.json) · [Chromeの比較ログ](../evidence/sites-branch-legends-browser.json)

再検証は `python -X utf8 test_branch_legends.py` のあと、`LAB_URL` に検証ラボのURLを設定して `node test_branch_legends.mjs`。素材の再変換は `python -X utf8 tools/build_branch_legend_art.py` で実行する。
