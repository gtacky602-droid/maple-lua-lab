# 沈玉の谷と往日の海の狩場

[ローカルLuaラボ](http://127.0.0.1:8975/)で「本編ルートへ」を押し、Mの地図で「沈玉の谷」か「往日の海」を選ぶ。「狩場・任意戦」で行き先を絞れる。調査の道を選ぶと通行Lvと脇道の狩場Lvが並ぶ。狩場を選ぶと、入口までの道順や通れない場合の必要Lvが分かる。

| 地域 | 調査の道 | 今回追加した狩場 |
| --- | --- | --- |
| 沈玉の谷 | Lv20で入口と探索路、Lv21〜32で周辺の道やワープ地点 | Lv75〜90の29区画。狩場の脇部屋には任意の遭遇を計30件配置した。 |
| 往日の海 | Lv80の入口と探索路、Lv90〜93で水中や遺構を観察 | Lv142・148・151の石床3区画。各区画に大型の魔像役を2体置いた。水路のひとつはFで渡り、乾いた足場に出る。 |

調査、お茶の配達、共鳴石、音の絵本の進行と、既存のワープ・船便は従来の通行条件で使える。例えばLv90の調査地点「珊瑚の浅い水路」で、Lv142に達すると乾いた石床の狩場へ渡れる。帰りの水路は狩場の入口側にあり、敵の討伐は不要。セーブから再開すると地域の入口拠点に戻る。

敵はSitesの配置案の種類、頭数、敵Lv、再出現時間を使用した。スプライトと挙動は既存素材、敵HPや地形、本番用3Dに置き換える背景はラボの試作。沈玉の通常敵には通常EXP、大型魔像と脇部屋の遭遇には精鋭EXPを適用した。報酬効率と装備をそろえた状態での連続狩りは今後の調整対象。赤璋巡岳府君とシネアスには[専用の任意戦](BRANCH_LEGENDS_WEB.md)がある。 [配置と入口の対応](../sources/map-research/sites-branch-hunts.json) · [高難度のLv案](quest-v1/SIX_DECISIONS_DRAFT_V01.md)

- Luaで32狩場と30脇部屋を往復した。124方向の移動、全狩場のLv境界、入口拠点からのセーブ復元を確認した。移動試験は戦闘の影響を抑えて実施。沈玉Lv75と往日の海Lv142では検査用に敵HPを調整した上で、通常攻撃による撃破とEXP・再出現まで確認した。 [Luaログ](../evidence/sites-branch-hunts-lua.json)
- Chromeで地図からLv142の乾いた石床を選び、水路を渡って魔像2体のいる狩場へ入り、泳ぐ調査路へ戻った。 [地図](../evidence/bygone-hunt-atlas.png) · [乾いた足場](../evidence/bygone-hunt-dry-floor.png) · [Chromeログ](../evidence/sites-branch-hunts-browser.json)
- 璃月83地点・フォンテーヌと往日の海117地点、茶の配達、共鳴石、猊獣、既存船便のLua回帰検査を実施した。
