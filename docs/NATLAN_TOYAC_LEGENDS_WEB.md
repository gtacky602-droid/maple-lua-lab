# トヤック源泉地の地方伝説

ナタ拠点の依頼を受け、現地の仕掛けを解くと奥へ進める。**M → ナタ → 狩場・任意戦** で強敵を選ぶと、準備地点を経由する経路が表示される。

| 任意戦 | レベル | 入口まで |
| --- | ---: | --- |
| バラチコ | 120 | 源泉北の岩径 → 南西の秘境周辺 → 二つの鍵の洞窟 → 格子奥の岩室 |
| コシーホ | 116 | 海の浅瀬の洞の上段 → 電気水晶の岸辺 → コシーホの石広場 |

## 二つの鍵の洞窟

「秘境脇の二つの鍵」を受注する。洞窟では床にある檻と上段の棚を **G** で調べ、奥の格子で両方の鍵を使う。格子を開けると、入口の **F** で岩室へ進める。鍵の入手と格子の状態は依頼の進行に記録される。

## 電気水晶の岸辺

「岸辺の三つの電気水晶」を受注する。海の浅瀬の洞で **Space** で上段に跳び、岩段から岸辺に出る。**E** でアンバーに交代し、紫の水晶へ向けて **K**。3個すべてを炎元素で砕くと石広場の入口が開く。砕く順番は自由で、途中で出入り・保存しても砕いた分は残る。水晶を壊すと依頼が進み、討伐数と討伐報酬は発生しない。

二つの依頼はナタ拠点で報告できる。試作では、仕掛けを解くとその場で奥へ進める。背景は洞窟と岸辺の仮画像。ボスの技は仕様待ちで、既存の通常攻撃、討伐報酬、退却、再挑戦を検証した。鍵と水晶の発想には、現地のプレイ記録を参照した。 [バラチコの鍵](https://www.hoyolab.com/article/33800251) · [コシーホの水晶](https://www.hoyolab.com/article/33847750)

## ドット絵と検証

バラチコは暗い外套と短い二枚の刃、コシーホは紫の甲羅と淡色の四足で見分けられる。待機とテスト用の差分を各3枚、同じ床位置にそろえた。名前付きの戦闘画面、標準種の画像、正面と横から見える資料を照合した。 [画像の参照記録](../evidence/natlan-toyac-legends-art-sources.json)

Luaで、鍵による格子の開閉、炎元素でのみ進む水晶の記録、途中セーブの復元、依頼の報酬と討伐セーブを確認した。ChromeでMの経路、Fの往復、GとKの入力を確認した。同じ場面で標準矩形から軽量16色に切り替えると、画面全体の描画命令数はバラチコの場面で7,575から2,013、コシーホで7,908から2,144に減った。 [Luaテスト](../evidence/natlan-toyac-legends-lua.json) · [ブラウザテスト](../evidence/natlan-toyac-legends-browser.json) · [元PNGとの表示比較](../evidence/natlan-toyac-legends-comparison.png)
