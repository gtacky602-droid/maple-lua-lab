# 滝裏と高台の夜魂の試練

**M → ナタ → 狩場・任意戦** で試練を選ぶ。地図には各入口と、途中の壁伝いの区間が表示される。黒曜石の柱の近くで **F** を押すと試練へ移動する。

| 試練 | レベル | 柱までの道 |
| --- | ---: | --- |
| アトラトの祝福 | 114 | テケメカンの谷・東の谷へ入る坂の上段 → 滝裏の燃素洞 → 壁の上の足場 |
| 神骨の蛇姫 | 118 | トヤック源泉地・源泉北の神像 → 懸木の民の南東・四角い高台の最上段 |

## アトラトの祝福

東の谷へ入る坂の右側にある岩棚へ **Space** で上がり、**F** で滝裏へ入る。燃素洞では、壁の手前で **F** を押すと岩壁に沿って上の足場へ渡る。足場を右へ進むと柱がある。ナタ拠点の依頼「壁に刻まれた道しるべ」を受けると、壁の両側の刻印を **G** で調べられる。

配置案の「東の秘境周辺」にも入口をつないだ。そちらの狩場はLv119なので、Lv114で挑む場合は坂の上段から入る。試練では旅人だけで戦い、途中退出・全滅で柱へ戻ったときに同行者のHPと元の操作キャラが戻る。

## 神骨の蛇姫

神像の先の高台で、足場が重なる場所を使って **Space** で一段ずつ上がる。最上段の右端に柱があり、試練からは同じ高さの柱へ戻る。通常の2人編成で試せる。

壁伝いの移動と高所への登り方はラボ用の試作。背景は仮画像で、今回のボス固有技は仕様待ち。 [滝裏と壁面の参照](https://game8.jp/genshin/655678) · [高台の参照](https://game8.jp/genshin/655673)

## ドット絵と検証

アトラトは金色の扇と斜め下へ伸びる二本の尖り、蛇姫は丸い耳飾りと筒形の砲身で見分けられるようにした。待機・構え・動作テストの各3枚を共通の床ピボットにそろえた。 [画像の参照記録](../evidence/natlan-cliff-trials-art-sources.json)

Luaで壁伝いの途中移動と一時停止、Lv114の迂回、旅人が倒れている場合の入場制限、同行者の復元、4段の高台と元の高さへの帰還を確認した。両試練の報酬と討伐記録も保存できる。ChromeでMとF、壁伝いの表示、旅人単独の表示を確認した。標準の矩形描画から軽量16色に切り替えると、画面全体の描画命令数はアトラトで4,851から1,248、蛇姫で6,831から1,715に減った。 [Luaテスト](../evidence/natlan-cliff-trials-lua.json) · [ブラウザテスト](../evidence/natlan-cliff-trials-browser.json) · [元PNGとの表示比較](../evidence/natlan-cliff-trials-comparison.png) · [壁伝いの画面](../evidence/natlan-atlatl-wall.png)
