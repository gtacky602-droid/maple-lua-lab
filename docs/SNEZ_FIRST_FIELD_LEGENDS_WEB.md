# スネージナヤの雪の広場・氷の洞窟・秘境の脇道

**M → スネージナヤ → 狩場・任意戦** で戦闘を選ぶ。入口は **F**。岩棚があるところでは **Space** で上がる。

| 戦闘 | 入場Lv | 入口 |
| --- | ---: | --- |
| チュリン | 152 | 東の谷あいの右の岩棚 → 霜の精の村の南の広場 → 二つの手合わせ → 彫刻広場 |
| バンダースナッチ | 156 | 石壁沿いの坂の右の岩棚 → スヴェトロレドフカの地下道 → 氷扉の先の洞窟 |
| フュリオサ | 158 | 町南の地下道の右の岩棚 → 秘境北西の脇道 → 雪原。Lv159の都南の秘境周辺からも通れる |

共闘でも手合わせ二戦と氷扉の操作は各自が進める。フュリオサの雪原は町南の地下道と秘境周辺の両方から合流できる。 [共闘の道順と検証](COOP_WEB_PREVIEW.md#チュリンバンダースナッチフュリオサ)

## チュリンまでの二戦

雪の町でLv149の「雪の広場の二つの手合わせ」を受ける。広場のヴァルコドラクのところで **G**。次の二つの区画で、弟子、ブラーギンの順に手合わせを終える。勝利はセーブに残り、再訪時は勝った相手と戦い直さずに通れる。チュリンだけ再挑戦できる。先行二戦の相手にはラボの既存の仮素材を使った。 [二戦と広場の現地画面](https://game8.jp/genshin/803754)

## 氷壁から洞窟へ

雪の町でLv148の「氷壁の下の通路」を受ける。地下道の道標と、上段の操作盤を **G** で調べると洞窟へ通れる。原作では魔神任務の進行で洞窟が開く。ラボでは現地の二か所を調べる手順を試作した。 [原作での解放条件](https://gamewith.jp/genshin/article/show/572637)

## 秘境北西の雪原

フュリオサはLv158から、町南の地下道を経由して挑める。秘境周辺に寄る場合はLv159。脇道からはそれぞれの地点へ戻れる。

## ドット絵と検証

3体それぞれについて、名前付きの肖像、戦闘画面、通常種の全身など計19枚を照合した。全身が一致する通常敵は今回の3体では確定できなかった。 [作画に使った19枚と確認できた範囲](../evidence/snez-first-field-legends-art-sources.json) · [これまでの通常個体との比較](LEGEND_BASE_ART_REVIEW.md)

- チュリンは同じ衣装の通常個体を特定できなかった。肖像と横向きの戦闘画面から、白灰の髪と髭、緑の丸眼鏡、淡い上着を拾った。
- バンダースナッチは通常種と共通する低い胴、外殻、大きな紫の前爪を残した。名前付きの肖像に合わせて目を赤く描いた。戦闘中の目の色は発光が重なり判別できなかった。
- フュリオサは通常種の弓、青い後ろ髪、脚と尾を使い、赤い前髪と明るい胸元は名前付きの肖像に合わせた。

各3ポーズを描いた。背景は仮画像を表示し、技の仕様は別途決定する。 [全9ポーズと16色比較](../evidence/snez-first-field-legends-poses.png)
